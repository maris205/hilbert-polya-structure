# Claim boundary

This import is an external, source-preserving RH research corpus.  It has not
been independently re-executed, re-reviewed, or accepted as a result of the
`zeta_mvp0` programme.

Accordingly, it must not be used to promote or alter any existing
`zeta_mvp0` claim, gate, paper number, release state, or repository-
availability label.  In particular, the import does **not** establish or
upgrade any of the following:

- the Q, W, \(S_{\rm op}\), \(P^*_{\rm loc}\), \(P_0\), or Z gates;
- an endogenous prime-power or von-Mangoldt trace;
- a zeta-zero spectral correspondence;
- a Hilbert--Pólya operator satisfying the required zeta identification; or
- the Riemann hypothesis.

Historical source assertions, `PASS` labels, PDFs, tests, and ledgers retain
their source context and are not independent evidence in this target
programme.  Any future promotion of an individual imported item into a
direct `zeta_mvp0/paper_*` package requires a separate scoped review,
source/hash/link validation, minimal-command verification, and the
corresponding updates to the programme README and global claim ledger.

This boundary follows the target programme's
[evidence policy](../docs/EVIDENCE_POLICY.md) and
[global claim ledger](../docs/GLOBAL_CLAIM_LEDGER.md).
