From the Paper 02 project root, the accepted release hashes can be audited
without rewriting the archives by running
\begin{verbatim}
python scripts/audit_release_hashes.py
\end{verbatim}
When the bulk A1 tree archive is available locally, the complete release DAG
can be replayed without writing by running
\begin{verbatim}
PYTHONDONTWRITEBYTECODE=1 python \
  scripts/build_r401_val_l2_a1_release_provenance.py \
  --project-root "$PWD" --verify-only
\end{verbatim}
The focused contract tests can be run with
\begin{verbatim}
PYTHONDONTWRITEBYTECODE=1 pytest -q -p no:cacheprovider \
  tests/test_r401_val_l1_contract.py \
  tests/test_r401_val_l2_s0_contract.py \
  tests/test_r401_val_l2_a1_release_provenance.py
\end{verbatim}
The L2 contract tests alone do not promote an implementation run.  The
separately sealed A4.14 release licenses the stated three-slab smoke, while
the A4.15 release extends only the local reduced-root certificate to all 51
slabs.

Rebuilding the validated executable requires the separately pinned CAPD,
MPFR, GMP, compiler, and flag configuration under \texttt{validated/}.  The
official CAPD source is identified by a commit.  Exact executables bound by
authoritative release manifests are mirrored for fresh-clone hash replay;
binaries from invalid or superseded attempts and LaTeX auxiliary files are
excluded from version control.

The compact A4.15 certificate, aggregate, checker, postcheck, and release
objects are mirrored in Git.  Its 1.2-GiB raw-node directory and bulk tree
payloads/manifests are intentionally excluded from ordinary Git.  A fresh
clone can audit the compact 19-role release, but complete raw-node replay and
the deep A1 command above require a separately transferred immutable bulk
archive.

For audit transparency, failed and superseded attempts remain in
\texttt{results/} with explicit non-licensing markers.  They must not be
cited as proof objects.  The release labels
\path{PASS_CONTIGUOUS_LOCAL_BRANCH},
\path{PASS_LOCAL_MONODROMY_GAP}, and
\path{PASS_LOCAL_COMPLEMENT_ALL_SLABS} all carry
\path{final_status: null}; none of them means that the global R401-VAL
theorem-domain programme is complete.
