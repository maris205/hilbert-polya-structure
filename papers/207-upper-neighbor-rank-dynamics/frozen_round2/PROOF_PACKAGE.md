   inference is made from a numerical cyclic atlas.

classes; no general-alphabet extension is implicit. The only fixed point
is zero; every other recurrent state has exact period two. The global
entrance upper bound is not asserted sharp. Computer verification of the
local finite lemma is part of the proof, not optional empirical support.

inspectable; gate and later manuscript checkers remain separate processes.
