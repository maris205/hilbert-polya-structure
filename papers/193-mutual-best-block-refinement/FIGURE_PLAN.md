# Figure plan — P193 mutual-best block refinement

## Decision

No figure is used in the short manuscript.

The literal simultaneous nomination rule is reduced exactly to one
first--minimum exchange in each nontrivial direct-sum block.  A diagram would
repeat the proof without making either the recursive clock or the inverse
component grouping easier to verify.  The two ordinary-generating-function
identities and the every-target fibre product are therefore kept as displayed
formulas, while one compact table records finite author-side controls.

This is a deliberate layout decision, not a missing-artifact exception.
Should the note later be expanded, the only justified illustration would be a
single worked permutation showing old direct-sum blocks, simultaneous swaps,
and the refined blocks after one epoch.  Such a figure must not be presented as
evidence for an all-parameter claim.
