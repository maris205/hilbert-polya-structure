# Figure plan — P191 Round 0

**Decision:** no publication figure.

The smallest useful visual is already algebraic: a composition is an
increasing path through cut positions, and the displayed orbit

`(1,2,1,1,1) -> (1,3,1,1) -> (1,4,1) -> (1,5)`

shows the sharp clock.  The every-target inverse is more legible as its two
recurrences and a small exact-control table than as a node-link diagram.  A
decorative figure would consume space without clarifying an additional
relationship.
