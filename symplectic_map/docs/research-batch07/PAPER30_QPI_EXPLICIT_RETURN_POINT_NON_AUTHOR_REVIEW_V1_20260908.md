## 逐消费者检查

### 1. 原时间矩阵及全允许特征相容性 — PASS

V 的 $B_0$、$\bar x=st/(sx-y)$、$\bar y=sx/y$、$\bar t=st$、
$\bar w=(1-sx/y)w$ 与 JR 实际公式一致。
用 J 的原 $A_0,A_1$ 重新代入，独立得到
$\bar A(z)B(z)-B(sz)A(z)=0$；不是把循环矩阵相容性当成无出处的假设。
该差的 $z^{-1},z^0,z^1$ 三个可能非零系数分别为零矩阵，$z^2$ 系数直接抵消。
所有原式属于 $\mathbb Z[s^{\pm1},x^{\pm1},y^{\pm1},t^{\pm1},w^{\pm1},z^{\pm1},(sx-y)^{-1}]$。
精确消去所得为零整系数分子，故能在分母为单位的任意特征中专化；未除以 $2,3,r$。
按原有序乘积望远镜相消，末端为 $B(s^rz)=B(z)$，所以得到 $\bar M B=B M$。

### 2. 谱模同态方向与除子符号 — PASS

J 用的是 $\lambda\cdot v=Mv$ 的模，而非特征向量直线的任意对偶约定。
$B(Mv)=\bar M(Bv)$ 正给源模到目标模的线性映射。
于是 $b_Q$ 是 $L_{F_tQ}\otimes L_Q^{-1}$ 的有理截面。
依通常有理截面除子约定，该线丛是 $\mathcal O_C(\operatorname{div}b_Q)$，
没有在从同态到 Picard 差时反号；若改用对偶谱模才会另改约定，此处没有这样做。

### 3. $M(0)$、秩一核与小特征边界 — PASS

独立代数核验给出 $A_0^2=tA_0$、$A_0e_T=te_T$、$B_0e_T=0$，
其中 $e_T=(w,1-y)^{\mathsf T}$ 非零。
由于 $(B_0)_{12}=swx/y$ 为单位，$B_0\ne0$；$B_0^2=0$ 使其秩恰为一。
因此 $M(0)=A_0^r=t^{r-1}A_0$，两个特征值为不同的 $0,T$，
其 $T$-特征线就是 $\ker B_0$，其 $0$-特征线不在该核中。
在 $y=1$ 时实际矩阵为 $\left(\begin{smallmatrix}0&swx\\0&0\end{smallmatrix}\right)$，
故并未暗除以 $y-1$。在特征二中 $T\ne0$ 仍区分两根；$r=1$ 也无例外。

### 4. 两简单根、幂等谱格和非完美底域 — PASS

谱多项式模 $z$ 为 $\lambda(\lambda-T)$，在两根的导数分别为 $-T,T$，皆是单位。
V 写出的逐次递推确在 $\mathscr F$ 内唯一确定每个后续系数，给出两条实际 $A$ 中的根。
根差为单位，因而完备谱代数分裂为两个 $A$ 因子；幂等投影正是这两个因子的模投影。
J 的 $\tau_*L=A^2$ 在此基变换后，所对应的因子模就是两端点上的真实完备线丛格。
它们是秩一自由直和因子，而非仅在分式域选取的特征向量。
每格基的约化非零，两基合成 $A^2$ 的基，所以源、目标基矩阵的行列式都是单位。
全过程不需要 $\mathscr F$ 完美、可分闭或代数闭。

### 5. 准确的一阶极、一阶零与行列式单位 — PASS

源 $0$-谱格的本原基 $e_0(z)$ 在 $z=0$ 落在非零 $0$-特征线中。
前项检查保证 $B_0e_0(0)\ne0$，故 $Be_0(z)$ 的向量赋值准确为 $-1$。
目标谱基变换在 $\operatorname{GL}_2(A)$ 内，不改变向量的最小赋值；
相容性排除另一谱分量，故标量 $b_0$ 的赋值准确为 $-1$。
独立核验 $\det B=1$，结合两个谱基行列式皆为单位，
得到 $\operatorname{ord}b_0+\operatorname{ord}b_T=0$，所以 $\operatorname{ord}b_T=1$。
这不是仅从 $B_0e_T=0$ 猜测一个下界；准确等式所需的单位条件已经满足。

### 6. 其余点及无穷远无额外除子 — PASS

在 $z\ne0,\infty$，$B^{-1}=I-B_0/z$ 也是正则矩阵。
谱代数模的正则互逆矩阵在有限态射的模对应下是线丛同构，
这同样覆盖二次谱投影的分歧点，不依赖分歧处可分裂成特征线。
在无穷远，J 固定的是同一个平凡推下向量丛，并以 $\mu=z^{-2r}\lambda$ 作用。
$B=I+z^{-1}B_0$ 及其逆在该图正则，且仍与 $\mu$ 作用相容。
因此两无穷远点赋值均为零，没有规范或转移函数引入的隐藏极点。
至此准确除子确为 $P_T-P_0$。

### 7. 参数依赖规范、全部点延伸与共同谱曲线 — PASS

不同非零 $w$ 由常数对角共轭相连；这里的“常数”指不依赖 $z$。
允许该矩阵依赖动力参数，在适当稠密参数开集仍给实际谱模族同构。
因此每步都可用更新后的 $w$，再与 J 的固定规范比较，不要求 $r$ 步后 $w$ 周期恢复。
原 $x,y$ 生成 $\mathscr F$，$sx-y$ 不是零函数；有限次时间更新为函数域同构，
故所需分母和规范单位同时有效的稠密开集非空。
$I_r$ 被原时间变换保持，且 $(s^jt)^r=T$，每一切片确使用同一带固定 $z,\lambda$ 的 $C$。
两边的 Picard 映射均为态射，$X_t$ 整而 Picard 目标分离，泛点等式因而延到全曲线。
任意原域上原一步有理式及其逆在光滑射影泛曲线上唯一延拓为同构，与 R 的几何同构一致；
此消费者不需要额外选择原域截面。此延伸不声称原 $B$ 本身在每个动力点处都定义。

### 8. $r$ 步端点拉回、无残余倍数或同源核 — PASS

逐步合成 Picard 等式确给 $\mathcal O_C(rP_T-rP_0)$，没有切片的谱坐标置换。
两端点上 $Z$、$z$ 分别是商曲线和原谱曲线的局部参数，且 $Z=z^r$，
故 $\pi^*p_T=rP_T$、$\pi^*p_0=rP_0$ 是整数除子等式。
因而回返差为 $\pi^*\mathcal O_E(p_T-p_0)$，并非该拉回再乘 $r$。
固定 torsor 作用使 $\alpha_t(Q+p_T)$ 恰等于这一表达式；$\alpha_t$ 的闭嵌入推出点等式。
J 的拉回无核身份与此一致；没有用不确定的同源逆像来猜测 $p_T$。
$r=1$ 是同一计算中的恒等覆盖，不需补例外条款。

### 9. 原域 torsor、Weierstrass 符号与非挠性 — PASS

所使用的是原 $K$ 上已经固定的 $E$ 作用，不是任选 $X_t\simeq E$ 后再降回原域。

故所示点确为 $-(0,0)$，特征二中仍成立，且两点因 $T\ne0$ 不相同。
