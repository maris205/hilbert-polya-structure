## Anti-claim ledger

The following strings or their semantic equivalents are prohibited: “generic
map,” “all affine-triangular maps,” “entropy,” “topological degree,” “periodic
classification,” “torus conjugate,” “arithmetic dynamics,” “positive
characteristic,” “first in the literature,” and “optimal.”  The canonical map is
one exact-gradient composition.  The affine-triangular literature is cited only
to delimit terminology and cannot be used as evidence for T1–T8.

## Collision evidence ledger

Papers 12–20 are used as a bounded internal collision screen.  For each row the
reviewer must verify the object listed in the novelty matrix, note a one-line
nonidentity with (A_g,B_g,C_g), and retain the result in the source lock.  A
collision finding changes the novelty wording, not the theorem.  No web search
result, citation count, or author-name similarity is admissible evidence of
novelty.

## Notation ledger

(R=(g-3)/2), (e_3=(0,0,1)^T), and \mathbf1=(1,1,1)^T.  Use
\(\mathbb A^6\) only for the ambient affine space; do not write A6 as a
