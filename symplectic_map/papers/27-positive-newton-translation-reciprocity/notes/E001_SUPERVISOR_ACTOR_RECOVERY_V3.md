## 7. Five-pipe topology and blocking semantics

with pipe2(O_CLOEXEC | O_NONBLOCK). It relocates every end to a distinct fd
at or above 20 with F_DUPFD_CLOEXEC and closes every original. Let the fstat
node of an endpoint be (st_dev,st_ino). The structural proof is exactly:

1. all ten relocated FD integers are pairwise distinct;
2. the read and write endpoint of each one pipe have the same node;
3. the five pipe nodes are pairwise distinct;
4. across the ten endpoints there are exactly five node values and each has
   multiplicity exactly two, at its declared read/write pair;
5. every endpoint is a FIFO, no endpoint aliases actor fd 0, 1, or 2, and no
   endpoint is a PTY.

The roles are:

| Pipe node | Actor-retained end | Direct supervisor end |
| --- | --- | --- |
| ACK input | write | fd 0 read |
| result stdout | read | fd 1 write |
| external stderr | read | fd 2 write |
| live-empty payload stdin | write | fd 3 read |
| launch release | write | fd 4 read |

Before DIRECT_INTENT, the actor calls set_blocking(True) on the child-facing
result-stdout write description and the child-facing external-stderr write
description and verifies O_NONBLOCK is clear on both. DUP2 preserves those
blocking open-file descriptions as child fd 1 and fd 2. Thus V8 write_all can
write a maximum bounded RESULT without an unhandled EAGAIN. The actor-retained

writer, and their child read descriptions retain the exact behavior required
by V8; V8 itself performs its frozen blocking transitions.

File actions DUP2 the five declared child ends to 0 through 4 and then CLOSE

child enters with exactly fds 0, 1, 2, 3, and 4; because one endpoint from
each pair is inherited, its five fstat nodes are pairwise distinct. After a
