1. **M0:** no independent v2 R2 source-lock pass means no candidate code.
2. **M1:** development output is non-official and cannot preview a registered
   value or alter the frozen mathematical fixtures.
3. **M2:** deployment review must bind independent scientific roots, real
   negative controls, and closed-world permissions.  Hollow validators fail.
4. **M3:** R100 has one attempt.  Mathematical mismatch, scope mismatch,
   trace-category confusion, forbidden access, timeout, or resource failure is
   terminal for v1; there is no rerun, third engine, or majority vote.
5. **M4:** reviewers may hash and inspect sealed records only.  They cannot
   recompute another case, modify a fixture, or select a new parameter.
6. **M5:** a machine result never substitutes for the source proof.  Writing
   authorization depends on project policy and independent disposition.
