# Experiment Plan

## NO SCIENTIFIC RUN

**No scientific, numerical, computational, CAS, parameter-scan, data, or code
run is required, planned for execution, or authorized.**

This is a pure-mathematics theorem package.  Finite sampling could neither
prove the universal cardinality statements nor close a missing degeneracy
branch.  The only appropriate future validation is an independent symbolic
proof-and-citation audit.  The audit plan below is a readiness checklist, not
authorization to perform it.

The experiment-planning workflow is therefore adapted at the user's explicit
boundary: claims are mapped to admissible mathematical evidence, while all
scientific-run fields are set to not applicable.

## Future independent symbolic audit blocks

Every block below is **NOT AUTHORIZED FOR EXECUTION** by this source-design
stage.

### A1: Statement and convention audit

- Confirm the collected-support convention `1<=e_1<...<e_s=d`.
- Confirm all of `a,c,b_j` are nonzero and `char K=0`.
- Confirm `H(x,y)=(P(x)+ay,x)` and the meaning of `T_m`.
- Confirm finite rank does not silently become finite generation.
- Deliverable if later authorized: a signed statement checklist, not data.

### A2: Unit-equation input audit

- Check Amoroso--Viada Theorem 6.2 against the primary text.
- Check `A(q,R)=(8q)^(4q^4(q+R+1))`.
- Verify the algebraically closed domain and the base-extension injection for
  arbitrary characteristic-zero `K`.
- Verify tuple ranks `2r` and `3r` without adjoining coefficients.
- Deliverable if later authorized: citation-and-rank memorandum.

### A3: Sparse-image lemma audit

- Re-derive the nondegenerate tuple fiber bound `d A(q,2r)`.
- Recount the proper zero subsets as `2^q-q-2`.
- Check that every selected subsum polynomial is nonzero and has at most `d`
  roots.
- Test the reasoning against infinite torsion symbolically, without enumerating
  examples.
- Deliverable if later authorized: marked proof copy.

### A4: PC1 degeneracy audit

- Fix `Z=z/c`, `U=-au/c`, `M_j=-b_jv^(e_j)/c` before classifying.
- Check GZ and GU for every nonempty `J`, especially `J=[s]` and `|J|=1`.
- Check R0 root degree `e_maxJ-e_minJ` and R1 root degree `e_maxJ`.
- Check the second recurrence when `c+a rho` vanishes.
- Confirm simultaneous zero subsums are covered by a union, not a claimed
  partition.
- Independently recompute both defining subset sums for `M(e)` and then its two
  checksums.
- Deliverable if later authorized: branch-coverage certificate.

### A5: PC3 absorption audit

- Re-derive the A/B/C labels from the three normalized variable terms.
- Check all nine adjacent transitions.
- Verify closure of `BA`, `CB`, and the compatible `CBA` chain.
- Confirm the `3^4 d^2=81d^2` union bound.
- Confirm the sharpness scalar order `t^d,t,c,-t,(-t)^d`.
- Match both predecessor hashes and the no-parallel rule.
- Deliverable if later authorized: standalone/absorption certificate.

### A6: Boundary-literature audit

- Re-run the primary-source search at the date of any future source lock.
- Preserve the precise Krieger et al. Theorem 1.7 / Theorem 1.8 / Corollary 1.9
  distinctions.
- Preserve the exact Bell--Ghioca residual-set statement and rational-torus-map
  caution.
- Preserve Ji--Xie--Zhang non-density, the Mello--Yasufuku epsilon-range
  mismatch, and the restricted Kim et al. construction ranges.
- Deliverable if later authorized: updated bounded-search log, never a priority
  certificate.
