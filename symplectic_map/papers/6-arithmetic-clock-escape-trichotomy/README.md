# Finite Arithmetic Capacity under Additive Readouts

Status: `COMPLETE_LOCAL / FINAL_REVIEW_PASS / CAPACITY_BOUND_CERTIFIED`.

If every exact prime hit decomposes as a finite-rank locally constant term,
a logarithm whose square has support in one fixed finite prime set, and a real
algebraic action term, then the number of distinct prime hits is at most the
rational rank plus the size of that support set.  This is a scoped additive
capacity theorem, not a universal trichotomy or a Hilbert--P\'olya result.
