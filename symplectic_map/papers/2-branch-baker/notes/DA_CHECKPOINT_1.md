# Devil's-Advocate Checkpoint 1

## Verdict

`PASS_WITH_MAJOR_SCOPE_REDUCTION`

Proceed to implementation only after explicit user confirmation of this
design freeze.  The candidate is feasible and falsifiable, but it is not a
positive arithmetic candidate and should not be marketed as a new baker,
natural extension, zeta formula, or quantization.

## Strongest counterargument

The entire three-state construction is a classical full two-shift in a
two-step presentation.  Its exact zeta and boundary correction already occur
in the kneading/Markov literature, while the finite-rank prime-clock no-go is
short enough to be regarded as elementary.  The project may therefore yield
only a rigorous negative note, not a broad symplectic-arithmetic advance.

## Response quality

Score: 4/5.

The revised design concedes the classical components, makes them controls,
and pre-declares `A0_FAIL / STRUCTURAL_ONLY` if the finite clock behaves as
proved.  It retains value by separating four often-conflated notions:
critical smooth lifting, branch-history coding, piecewise symplecticity, and
an arithmetic clock.  The response is adequate to run a bounded verification
but does not justify downstream prime/zero or quantization work.

## Required stress tests already incorporated

1. Distinguish factor-orientation weighting from Lefschetz index weighting.
2. Distinguish a finite symbolic carrier from the full inverse-limit
   continuum.
3. Use a matched dissipative map with identical future code to expose every
   code-only effect.
4. Reject the anti-symplectic sign implementation.
5. Keep the parent derivative cocycle separate from baker monodromy.
6. Freeze the finite-clock no-go before any candidate code or validation.

## Remaining risks

- The claimed general theorem must specify finite memory and multiplicative,
  locally constant edge/block weights; a statement about all finite-state
  smooth systems would be false.
- Boundary quotient claims require a fully explicit half-open convention and
  a separate closed-boundary relation.
- A correct implementation mostly verifies bookkeeping, because the main
  conclusions are analytic predictions.
- Publication value depends on clarity and sharp scoping, not numerical
  surprise.

No consecutive concessions were made in this checkpoint.  The design was
changed only after direct prior art falsified the broader novelty framing.
