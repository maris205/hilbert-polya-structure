# Finite-Rank Multiplier Clocks

Status: `COMPLETE_LOCAL / ROUTE_A_REJECTED / A1_WEAK`.

This paper constructs and audits the frozen PCF Markov--baker carrier, proves
that any fixed finite-memory locally constant multiplier clock has finite
rational rank, and therefore cannot contain the full set of rational-prime
logarithms.  The exact carrier remains a reusable structural control; the
claim is not a no-go theorem for point-dependent roofs, countable-state
systems, or growing families.
