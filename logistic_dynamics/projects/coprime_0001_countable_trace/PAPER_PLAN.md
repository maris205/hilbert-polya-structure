# Paper plan — a trace-class coprime renewal determinant

## One-sentence contribution

An intrinsic countable coprime shift with logarithmic roof admits a canonical
trace-class transfer kernel exactly on `Re(s)>1`, with explicit primitive and
repetition cycle ledgers, while the same matrix fails to be bounded on the
boundary half-plane.

## Claim--evidence matrix

| Claim | Evidence | Boundary |
|---|---|---|
| The frozen kernel is trace class for `Re(s)>1`. | Mobius rank-one decomposition and the nuclear bound `zeta(sigma)^2/zeta(2 sigma)-1`. | This is the counting-measure `ell^2` realization. |
| The half-plane is exact for the same matrix. | The `e_2` column has squared norm equal to an odd p-series. | Scalar continuation or another function space is not excluded. |
| Trace powers equal the cyclic coprime ledger. | Finite projections, trace-norm convergence, and absolute cycle summability. | No lambda-one trace-log or Euler product is asserted without a spectral-radius bound. |
| Periods one through three have explicit primitive formulas. | Label one is excluded; pair and triple inclusion-exclusion formulas are exact. | Coprimality is not promoted to a prime-orbit law. |
| The implementation is reproducible. | Disjoint validation/test label blocks and exact Fraction identities through power six. | No determinant values or roots are computed. |

The manuscript and certificate use no prime table, primality predicate,
Riemann-zero table, xi/zeta numerical evaluation, determinant root search, or
parameter fitting. Euler products appear only as symbolic identities.
