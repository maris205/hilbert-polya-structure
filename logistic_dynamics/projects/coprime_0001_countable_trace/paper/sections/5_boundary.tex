\section{The exact operator boundary}

\begin{proposition}
For \(\sigma=\Re s\leq1\), the frozen matrix \(L_s\) is not a bounded
operator on \(\elltwo(\I)\).
\end{proposition}

\begin{proof}
Apply \(L_s\) to \(e_2\).  The only nonzero entries occur at odd \(m\geq3\),
and
\[
\lVert L_se_2\rVert_2^2
=2^{-\sigma}\sum_{\substack{m\geq3\\m\ {\rm odd}}}m^{-\sigma}.
\]
The odd subseries of the p-series diverges for \(\sigma\leq1\).
\end{proof}

This is a boundary for the frozen Hilbert-space realization, not a no-go
theorem for every scalar continuation.  A continuation of \(D_{\cop}\), a
different Banach space, or a regularized operator would require a new source
lock and a separate determinant identity.  The current stage keeps all such
objects outside scope.
