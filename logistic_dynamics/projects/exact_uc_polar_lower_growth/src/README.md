# Self-contained certificate source

`log_0001_lower_growth.py` freezes the 100-decimal-place rational bracket for
the unique real root of `u^3-2*u^2+2*u-2`, performs exact polynomial and
Cauchy-geometry checks, and evaluates the scalar lower-bound ledger with
1024-bit outward Arb balls.  It imports no code outside this project.
