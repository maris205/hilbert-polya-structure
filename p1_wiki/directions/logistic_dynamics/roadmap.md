## 已执行的路线

源档案将这条探索记录为如下顺序；箭头表示已保存的研究推进，不表示最后一项已经满足 Riemann 目标：

```text
历史 Logistic 零点匹配数值
  → 数据泄漏与稳定性审计
  → 精确 U_c 的物理首返结构 / ACIP
  → 内禀极坐标 roof 与复分支
  → LOG-0001 Fredholm 行列式及增长链
  → 符号、renewal、量子图、Hénon/FIO 的广度试探
  → 可复用的障碍与下一项目交接
```

其中前两步被保留为历史证据而非现行 Route-A 候选定义；主线的可复现解析边界见 [LOG-0001 稳定结果](../../../logistic_dynamics/LOG0001_STABLE_RESULTS.md)。完整阶段顺序和每一步的状态见 [阶段索引](../../../logistic_dynamics/STAGE_INDEX.md)。

## 当前停放点

`LOG-0001` 已到达“同一对象”的解析检查点：匹配空间、内禀 roof、带符号迹账本、Fredholm 行列式以及增长/阶数论证必须作为一条源锁链一并读取。当前指令是：

- 停放该链，不再用更多固定点估计推进；
- 不计算 Fredholm 根、不作 Riemann 零点比较；
- 不从回归文法推断素数律；
- 不将 `1 <= ord(D_pol) <= 2` 改写成精确阶或 `T log T` 定理；
- Route B 保持关闭。

这不是取消档案中的已记录解析结论，而是把它们限制在其证书、函数空间和行列式约定覆盖的范围内。

## 允许的最小重新开启门

关闭文档给出的唯一项目级优先入口是一个**结构上新的**、连通的、非 Selberg 型、可数多通道 renewal 文法。开始前不创建候选 ID；先满足以下先后门：

```text
显式文法 + 内禀有限群/幺正 cocycle
  → 同一函数空间上的 nuclear / trace-class 行列式
  → 右半平面零点自由定理
  → 同一迹账本的延拓定理
```

clock、归一化、函数空间和行列式约定都必须在目标数据之外明确冻结。若对象不显式、相位来自拟合，或需要读取目标零点数据，则标记为 `NOT_TESTABLE` 并停止；不得借用旧对象的后验重标定。

## 历史广度试探怎样复用

这些是 `logistic_dynamics/` 内部的设计约束，不是对独立顶层 Session 的替代路线图：

| 记录的线索/障碍 | 可复用的筛选规则 |
|---|---|
| `OBR-005`、`OBR-006` | 有限态有限 roof 的固定条带零点只能是 `O(T)`；有限面积模覆盖的 Selberg 除子至少为 `Omega(T^2)`，两者都不应靠装饰重开。 |
| `OBR-007`、`OBR-008` | 严格单调时钟会压塌周期轨道；单位格点时钟导致与 completed-ξ 结构不相容的竖直周期性。 |
| `OBR-013` | QG 的错误总长度系数在其源锁下不可用事后缩放修补。 |
| `OBR-015`、`OBR-017` | COPRIME 的端点零点积聚、正整数 renewal 的额外实零，都是在各自冻结类别内的严格障碍。 |
| TH-0001 的实 caustic | 重新开启需要源锁的多 chart 相位 / Maslov 转换账本；不能先算谱或行列式。 |

这些结论都带范围限定：它们不否定所有相关模型。顶层 Hénon、Symbolic 等方向须回到各自目录和各自路线图处理。

## 交接检查单

1. 先从 [来源与阶段](sources.md) 找到要引用的阶段和 source lock。
2. 核对该阶段的 `status`、Route-A 标签、`failure` 与 `next_task`，不要只引用标题。
3. 对新对象先完成 Route-A 所需的算术来源、原始轨道、行列式和可提升性证据；没有明确授权前不进入 Route B。
4. 将新证据、旧失败记录和再现命令并列保存，而非覆写冻结材料。
