# Finite setting

Let $L=\{S_1,\ldots,S_{16}\}$ be the frozen named support and let $\Phi(A)\leq Q=\mathbb Z/9\oplus\mathbb Z/3\oplus\mathbb Z/2$ be the subgroup generated by a retained support $A\subseteq L$. Write $H_0,\ldots,H_{19}$ for the twenty actual subgroups in the source-bound C75 order. For $D=L\setminus A$, C80 defines $$\tau_H(D)=\min\{|R|:R\subseteq D,\ H\subseteq\Phi(A\cup R)\}.$$ We study the complete threshold vector $$v(A)=\bigl(\tau_{H_0}(D),\ldots,\tau_{H_{19}}(D)\bigr)
 \in\mathbb Z_{\geq0}^{20}.$$ This construction uses the actual point-set subgroups. The C75 lifted ambient group has order $11520$, whereas the effective C76 action on the sixteen labels has order $1920$; these objects remain distinct throughout.

# Rigidity theorem

For every $A\subseteq L$ there is a vector $w_{\Phi(A)}$ such that $v(A)=w_{\Phi(A)}$. Exactly twenty distinct vectors occur, one for each actual subgroup of $Q$, and $$\{i:v(A)_i=0\}=\{i:H_i\leq\Phi(A)\}.$$ Consequently the zero coordinates recover $\Phi(A)$. For actual subgroups $K_0,K_1\leq Q$, $$K_0\leq K_1
 \quad\Longleftrightarrow\quad
 w_{K_0}\geq w_{K_1}\quad\text{coordinatewise}.$$

The threshold definition gives $\tau_H(D)=0$ exactly when no restoration is needed, equivalently $H\leq\Phi(A)$. Thus the zero set is the principal ideal below $\Phi(A)$ and recovers its unique maximum.

The finite certificate enumerates all $65536$ supports and verifies that the C80 vector is constant on each point-set closure fibre. All twenty C75 subgroups occur as closures, and their vectors have distinct zero ideals; hence exactly twenty vector classes occur. The certificate also checks the forward coordinatewise inequality for all $20^2$ ordered subgroup pairs. For the converse, $w_{K_0}\geq w_{K_1}$ implies that every zero coordinate of $w_{K_0}$ is zero in $w_{K_1}$. Therefore $\mathord\downarrow K_0\subseteq\mathord\downarrow K_1$, which implies $K_0\leq K_1$.
