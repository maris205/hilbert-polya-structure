## 证据与可复现边界

- 源端的数学断言以对应论文、证明包和审查材料为准；本页只说明从哪里进入。
- C424–C428 的封存、成员清单、摘要和 Git 对象有专门的 release / independent 回执；不要重新生成 receipt 来覆盖历史身份，也不要在封存根内写入整理性修改。
- C429–C433 的草稿、构建准备、评价记录和协调文档必须同其检查点一起读。它们既不等于零，也不等于已完成的论文。
- Route-A 评价、源端数学结论与目标 Riemann/Hilbert–Pólya 结论是不同层次。完整的链接/构建/封存校验只能说明相应工件和过程，不证明目标数学命题。
