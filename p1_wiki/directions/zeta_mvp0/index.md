# zeta_mvp0：第一阶段自由探索

`zeta_mvp0` 是本仓库最早的结构化 Hilbert--Pólya 搜索线。这里的知识库页把两类材料分开：

- **原生 programme**：`paper_01_*` 与 `paper_02_*` 所在的、受门槛和证据政策约束的研究线；
- **导入 RH 档案**：从 `prime_dynamics_theory` 原样保留的外部参考语料，不是本 programme 的新论文或新证据。

这一分隔是本页的首要阅读规则；不能用档案中的历史结论改写原生 programme 的门槛、台账或 RH 状态。

原生路线以“候选生成 → 明确结构门槛 → 独立核验 → 有界表述”为组织原则。当前仪表盘将 Q、W 与 \(S_{\rm op}\) 记为已证明；\(P^*_{\rm loc}\) 仅在其明示的局部层面成立；\(P_0\) 仍开放，Z 未获授权，RH 不主张。详见[结论与边界](conclusions.md)及上游[programme README](../../../zeta_mvp0/README.md)。
