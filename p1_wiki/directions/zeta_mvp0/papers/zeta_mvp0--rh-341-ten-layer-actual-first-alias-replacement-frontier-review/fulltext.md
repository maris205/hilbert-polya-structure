# Exact synchronized prefix reduction

For every $n\ge2$, the corrected all-order constituent is $$\label{eq:five-slot}
 q_{\sigma,k,n}
 =\mathcal B_{\sigma,k,n}+\mathcal S_{\sigma,k,n}+\mathcal R_{\sigma,k,n}
  +\mathcal P_{\sigma,n}-\mathcal A_{k,n}.$$ RH-339 states this all-order proposition explicitly; RH-334 supplies the underlying all-order raw partition and the first-alias typed observation. Let $$\label{eq:direct-identity}
 p_{\sigma,k,n}:=\tau_{\sigma,n}-a_n
 =q_{\sigma,k,n}-d_{\sigma,k,n},
 \qquad d_{\sigma,k,n}=h_{\sigma,n}-s_{k,n}.$$ At a common finite cut $u$, define $$\begin{aligned}
\label{eq:budgets}
 P_u(R)&=\sum_{2\le n<u}\frac{|p_{\sigma,k,n}|R^n}{n},&
 E_u(R)&=\sum_{2\le n<u}\frac{|q_{\sigma,k,n}|R^n}{n},&
 D_u(R)&=\sum_{2\le n<u}\frac{|d_{\sigma,k,n}|R^n}{n}.\end{aligned}$$

For every common finite cut and radius, $$\label{eq:sync}
 |P_u(R)-E_u(R)|\le D_u(R).$$ Consequently $D_u(R)\to0$ implies $P_u(R)\to0$ if and only if $E_u(R)\to0$.

Equation [\[eq:direct-identity\]](#eq:direct-identity){reference-type="eqref" reference="eq:direct-identity"} and the reverse triangle inequality give $\bigl||p_n|-|q_n|\bigr|\le|d_n|$ at each order. Multiply by $R^n/n$ and sum. This is the exact RH-340 argument.

\label{eq:two-residuals}

\label{eq:compensations}
