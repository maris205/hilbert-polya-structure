## 档案身份

这是从 `prime_dynamics_theory` 做的**源保留（source-preserving）外部 RH 研究语料导入**。导入记录锁定到源提交 `02d51d372e9c95ffc2ed36727829363a32cec030`，目标位于 `zeta_mvp0/papers/`，并保留相关的根文档摘录和导入元数据。

导入导航记录的范围包括 403 个 `papers/RH-*` 源目录、`RH-ROADMAP-after-RH50.md` 和指定根文档内容。可从上游[小写 readme 导航](../../../zeta_mvp0/readme.md)开始，再核对[源 provenance](../../../zeta_mvp0/rh_import_metadata/PRIME_DYNAMICS_RH_SOURCE_PROVENANCE.md)。

## 不可跨越的边界

该语料：

- 未在 `zeta_mvp0` programme 中独立重跑、复审或接受；
- 不是新的 `zeta_mvp0/paper_*` package；
- 不得改变 Q、W、\(S_{\rm op}\)、\(P^*_{\rm loc}\)、\(P_0\)、Z 或 RH 的原生状态，也不得改变既有 paper 编号、release state 或 repository-availability label；
- 不得单凭历史论文、PDF、测试、ledger 或 `PASS` 标签，建立内生 prime-power/von-Mangoldt trace、zeta-zero 对应、合格 Hilbert--Pólya 算子或 RH。

这些不是对源档案内容真伪的重新裁定，而是目标 programme 的证据边界。完整措辞见[导入 claim boundary](../../../zeta_mvp0/rh_import_metadata/PRIME_DYNAMICS_RH_CLAIM_BOUNDARY.md)。

## 正确使用方式

1. 将其当作带固定源身份的参考档案，而不是当前 programme 的结果库。
2. 如需文件身份比对，按[导入复现指南](../../../zeta_mvp0/rh_import_metadata/PRIME_DYNAMICS_RH_REPRODUCE.md)对 pinned source 做只读比较。
3. 如有未来项目希望将某个导入项纳入原生 `paper_*` 线，须另行进行范围明确的 review、source/hash/link 验证、最小命令验证，并同步更新 programme README 和全局 claim ledger；本档案页不执行也不预先批准该提升。
