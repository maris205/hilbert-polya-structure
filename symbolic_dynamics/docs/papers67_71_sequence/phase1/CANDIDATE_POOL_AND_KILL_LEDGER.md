# Candidate pool and kill ledger

## Selection rule

A row survives only if it supplies all of the following:

1. a primary system cluster not occupied by P1--P66;
2. a theorem-sized residual after returning known results to their owners;
3. a proof engine with a concrete finite or symbolic hostile check;
4. an explicit falsifier/stop rule;
5. no dependence on a batch-wide determinant, substitution or graph-splitting
   template.

## Three important negative results of Stage 1

1. **Endpoint count is not pattern count.**  Distinct discontinuity endpoints
   in a torus coding need not carry distinct names; the failed formula is kept
   in the executable falsifier.
2. **A familiar explicit system is not made new by adding a package.**  The
   powers-of-two sparse shift was removed after an exact-system source was
   found, despite clean Cantor--Bendixson and automorphism calculations.
3. **A current open problem is not a short-paper contract.**  The Heisenberg
   generating-partition question is excluded.  P70 instead asks a separate,
   finite-dimensional congruence problem with a closed representation-theory
   proof engine.
