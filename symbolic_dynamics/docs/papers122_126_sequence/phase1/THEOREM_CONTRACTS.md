# Frozen theorem contracts — P122–P126

These contracts define the minimum paper-scale progress that each final
system must preserve through review.  Removing a core item reopens the value
gate; replacing it with computation does not satisfy the contract.

## P122 — even record-block reversal

1. Strict lexicographic descent and sharp maximum depth `n-1`.
2. Exact one-step fibres by admissible record cuts, with an `O(n^2)`
   arithmetic DP and a worked target.
3. A five-coordinate weighted record automaton enumerating every image and
   Garden count for all `n`.
4. Foata/cycle and all-odd-cycle fixed enumeration explicitly zero-credit;
   P105/P117/P120 firewall explicit.

## P123 — odd-component complementation

1. Parity-pruned component/co-component split height equals pointwise entrance
   time.
2. Complete recurrent/fixed/period-1-or-2 classification.
3. Sharp maximum depth `floor((n-1)/2)` with witnesses for every order.
4. Recursive labelled EGFs for every cumulative and exact temporal layer,
   hence fixed/recurrent/two-cycle/zeta censuses.
5. Gallai/cograph/cotree/species machinery zero-credit.

## P124 — cross-colon monomial-ideal basins

1. Literal staircase and sourced total-degree OR normal forms.
2. Complete recurrent power/checker classification and sharp rectangle/square
   depth law.
3. First occupied diagonal and its parity trace determine every attractor and
   checker phase.
4. Four-state contact-parity transfer counts every basin; reflection gives
   the terminal ballot formula.
5. OR-path, colon/staircase, reflection, and rowmotion/toggle machinery
   zero-credit; P107/P104 firewall explicit.

## P125 — quadratic-state shear

1. Polar-bit invariant and exact eight-state quotient.
2. Depth at most two and exact periods in `{1,2,3,4}` with all short cases.
3. Exact `0/1/2` fibres, complete image tower, and Witt-sensitive layers.
4. Exactly six decorated component shapes and exact cycle/zeta census.
5. Explicit braid and quantum-YBE failures; quadratic/transvection/YBE
   background and P99/P103/P106/P109/P118 silhouettes zero-credit.

## P126 — balanced composition refinement

1. Exact pointwise/global clock and cumulative temporal layers.
2. For `K=2^t`, the small-part-to-ones canonical form is the complete kernel
   invariant of `Phi^t`.
3. Canonical codewords form a suffix code with an explicit image decoder.
4. Every nonempty fibre is a product of `K`-restricted composition counts
   over one-runs; the maximum equals the cumulative depth count.
5. The entire `t`-image is in weight-preserving bijection with compositions
   having parts `1` or `>K`, giving the rational OGF and Garden census.
6. Restricted-composition, code, D0L/fragmentation, and balanced-clock inputs
   zero-credit.
