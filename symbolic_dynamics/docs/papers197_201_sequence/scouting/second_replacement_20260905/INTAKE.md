1. **ND1**. On all simple undirected graphs on `[n]`, join distinct `u,v` in
   `N(G)` exactly when `|N_G(u) symmetric-difference N_G(v)|=1`, using **open**
   neighborhoods. All old edges are discarded before applying this rule.
2. **D2G**. On the same carrier, join `u,v` in `M(G)` exactly when their old
   graph distance is exactly two. Equivalently, `uv` is an old nonedge with a
   common neighbor. This is not persistent graph-square closure.
3. **CCW**. For each odd prime `p`, on every ordered triple `(A,B,C)` of points
   in `F_p^2`, if the triple is affinely independent, output `(B,C,O)`, with
   `O` its circumcenter for `Q(x,y)=x^2+y^2`. If affinely dependent, hold the
   **whole ordered triple**. A nonsingular two-by-two linear system defines
   the unique center even when the quadratic form is isotropic.
