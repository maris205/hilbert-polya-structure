## One bounded literal probe: CSP, cross-sum pair

For odd prime powers q, use the full carrier (F_q^3)^2 with the standard
coordinate cross product and dot product. Define

    C(u,v) = (u×v, u+v).

This is naturally a vector area/resultant pair, with no clock coordinate,
least-selector erasure, normalization convention, or added sink. It is
not the already killed XPF literal; however, changing one coordinate
of a killed cross-product family cannot establish eligibility. It must
produce genuinely separate global structure. The following calculation
shows exactly what it does and does not supply.

### Complete elementary inverse, all odd q

Write the target as (w,s). A source has v=s-u and must solve u×s=w.
If s=0, only w=0 is possible; its sources are all (u,-u), q^3 in total.
For s nonzero, the linear map u->u×s has kernel span(s), rank two, and
image s-perp, even when s is isotropic. Thus

    |C^{-1}(w,s)| = q        if s != 0 and w·s = 0,
                    q^3    if (w,s) = (0,0),
                    0      otherwise.

All sources can be parameterized without dividing by a norm. Choose k
with s_k!=0, put a=k+1 and b=k+2 cyclically, and choose t in F_q. Set

    u_k=t,
    u_a=(t s_a-w_b)/s_k,
    u_b=(w_a+t s_b)/s_k,
    v=s-u.

The remaining cross equation follows from w·s=0. Consequently the image
size is (q^3-1)q^2+1, and the unique maximum fibre is at (0,0), size q^3.
This atlas is elementary alternating-form linear algebra and is closely
shared with the old XPF/V04 region; it is not sufficient progress alone.

### Temporal obstruction to selection

Every output pair is orthogonal. Writing a=u·u, b=v·v, c=u·v,

    (u×v)·(u×v)=ab-c^2,
    (u+v)·(u+v)=a+b+2c.

After the first step c=0, so the norm factor is the genuinely nonlinear
two-scalar map (a,b)->(ab,a+b). This is not the XPF monomial Fibonacci
factor. It does not yet give a temporal theorem: classifying this scalar
map for arbitrary q and lifting each cycle through the orthogonal-vector
frame dynamics remain unresolved here. Finite enumeration of those
