## Pairwise separation

- P177 is stochastic and has no transient state; P178, P180, and P181 are
  deterministic, while P179 is monotone absorbing.
- P178 and P180 both use finite fields, but P178's engine is adaptive
  backward integration in a unipotent translation module; P180's is radial
  semiconjugacy to a multiplicative cube map.
- P179 and P181 are combinatorial finite maps, but P179 is a random walk
  generated by commuting idempotents on a partition lattice; P181 is a
  deterministic noninvertible permutation map with a two-cycle core.
- P177 and P179 both use Markov language, but P177 is a periodic group walk
  with Fourier history counts, whereas P179 is an absorbing refinement chain
  with coupon support constraints.
