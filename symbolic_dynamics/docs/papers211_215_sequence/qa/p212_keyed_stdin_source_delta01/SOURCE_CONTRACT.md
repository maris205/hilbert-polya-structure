## Settlement, failures and acceptance limit

The supervisor sets and reads back Linux child-subreaper status before the
single Node spawn, sets a waitable SIGCHLD disposition, and starts Node in
a separate native session. It records discrete own task/children chains,
raw proc stat identity/start ticks, actual waitid WNOWAIT observations and
actual waitpid status. Final stream hashes require Node exit 0, actual ECHILD,
a final sampled empty own-descendant chain, only the expected Node reaped by
this supervisor, and completed inner and Node records for exactly both calls.

This is materially broader ownership than the inner native query PGID:
orphaned descendants can reparent to the living subreaper. It is NOT a census
of every process sharing an SID, an exhaustive historical spawn trace,
continuous tracing, or proof excluding escaped/duplicated external writers.
The kernel children interface is racy; disappearance or inconsistent identity
fails closed and is preserved, not smoothed into an inferred successful trace.

retry, signal, cleanup, lookup or body action. Source exceptions close only
owned descriptors. On an unresolved supervisor timeout it may exit without

must retain the actual process/session handle and perform a separately scoped
