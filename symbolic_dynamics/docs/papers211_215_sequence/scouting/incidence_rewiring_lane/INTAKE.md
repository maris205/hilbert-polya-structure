## One literal: SDS, synchronous degree-two splicing

For each integer $n\ge0$, the carrier is all simple undirected graphs on
$[n]=\{0,\ldots,n-1\}$, including isolates. Put
$D(G)=\{v:d_G(v)=2\}$ and $C(G)=[n]\setminus D(G)$. Define
$$
E(F(G))=E(G[C(G)])\ \cup\
\{\{a,b\}: N_G(v)=\{a,b\}\text{ for some }v\in D(G)\}.
$$
All terms use the old graph. Edges incident to any old degree-two vertex
are removed, but a newly generated edge may again touch such a vertex.
Duplicate generated edges are identified. No loop is generated because
the two neighbours of a degree-two vertex are distinct. All labels remain.
The empty graph at $n=0$ is fixed. The acronym is a local handle only.

This is not sequential smoothing/deleting all degree-two vertices: on the
labelled path $0-1-2-3$, the result has edges $02,13$, with all four labels
retained. It is not local complementation: $0-1-2$ maps to the single edge
$02$, not a triangle. It is not the unrestricted common-neighbour graph or
ordinary graph square: a three-leaf star is fixed here.
