therefore closes **NO_PROMOTION** without a pilot, expanded parameter box,
reserve, admission request or new manuscript number. No second rule was
needed after this failure of the required residual axes.

This is not a theorem that all local functional-graph surgeries are old,
nor proof of global ownership for BGR. The literature check is bounded and
an exact-owner non-hit receives zero novelty credit.
