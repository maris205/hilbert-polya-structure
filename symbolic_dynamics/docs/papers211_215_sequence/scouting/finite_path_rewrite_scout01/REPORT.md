## 1. Tamari Pop: source-defined, not a new tree rule

On the finite Tamari lattice of semilength-n Dyck paths, the published map
takes x to the meet of x and its lower covers. Encoding these paths as
binary trees does not create a new literal.

Letong Hong's 2022 paper gives the sorting-time cumulative generating
function (Theorem 1.1), the bracket-vector mechanism (Section 3), and an
explicit image criterion in 312-avoiding permutations (Theorem 4.7):
the target ends in n and has no consecutive double descent.
Theorem 1.2 gives image cardinality M_(n-1). Its abstract instead displays
M_n; this desk uses the numbered body's indexing, not that abstract line.
The direct text also gives Pop_Tam = pi_down followed after ordinary
descending-run Pop (Theorem 4.3 and the displayed specialization).
[Hong, author body](https://arxiv.org/html/2201.10030).

No new all-target fibre formula has been established here, and the known
time/layer mechanism cannot be claimed again to pair with such a future
formula. Parameterizing the baseline path or changing representation
does not by itself repair this value gap.

The actual old PPS original reverses maximal descending runs on all S_n.
The Tamari operator has an additional sylvester projection on the
312-avoiding carrier: it is not silently identified with bare PPS.
P144 instead absorbs the first two ground-level primitive components
and fixes every primitive Dyck path. For n >= 3 it has multiple fixed
points, whereas a finite-lattice Pop has only its minimum fixed:
a nonminimum x has a lower cover y and Pop(x) <= y < x. Thus P144 is
not a conjugate of this operator on the same semilength carrier.
Their generic tree/Tamari/scheduler vocabulary supplies no credit.

## 2. Complete chronological loop-erasure: normalization only

Shiping Cao defines complete LE on a finite vertex sequence by starting
at index 0, jumping to one after the last occurrence of the current
vertex, and stopping when its vertex equals the endpoint. The body
distinguishes LE from subset-based partial erasure. Its refinement theorem
is equality in distribution for random paths, not pathwise equality;
Example 2.2 explicitly exhibits different pathwise results.
[Cao, author body](https://arxiv.org/html/2201.08899).

The finite restriction is immediate but not a new nomination. For a fixed
nonempty finite directed graph G and N >= 0, consider all walks of at most
N edges and apply complete LE. Each retained jump is an edge because the
last repeated vertex equals the retained one and its following old edge
remains available. Start and endpoint are preserved, and length never
increases. A retained vertex cannot recur later: the next retained index
lies after its last old occurrence. Thus the output is self-avoiding.
On an already self-avoiding walk every jump is to the next index, so LE
fixes it. Consequently LE squared equals LE; the entry time is zero for
a self-avoiding input and one otherwise.

This is a direct inspection consequence, not a theorem attributed to
Cao or a fresh contribution. A finite size cutoff, a tree graph, or a
different encoding does not produce a substantive temporal axis.
No evaluated inverse enumeration was derived. An elementary normalization
clock would not become a new time contribution merely by adjoining one.
One-loop-at-a-time schedules, externally varying erasure subsets and
longest-loop rules were not nominated or executed.
