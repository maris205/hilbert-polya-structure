## Four attempted autonomous maps, ranked before the sole pilot

1. **WFS / weighted fibre summation.** For an odd prime $p$, use the finite
   module $X_p=\mathbb F_p^{\mathbb F_p}$ of all functions. Set
   $$S(f)(y)=\sum_{x\in\mathbb F_p:f(x)=y}x.$$
   An empty sum is zero. All labels and field addition are literal; there
   is no canonical representative or omitted singular branch. This is
   identity-weight pushforward by the state function, then feedback.
   Sole pilot: exactly $p=3,5$, all $27+3125=3152$ functions, one producer
   execution with a 60-second timeout. No $p=7$ rescue run is authorized.
2. **TPE / transpose parity erasure.** On $M_n(\mathbb F_2)$, $n\ge1$, let
   $r=A\mathbf1$ and set $E(A)=A^\mathsf T\operatorname{Diag}(r)$.
   Thus delete even-parity rows and then transpose. No pilot: source-first
   comparison with P127, P189, earlier Sinkhorn/sum-normalization scouts,
   and parity deletion is required. This is not a Sinkhorn sink completion.
3. **FLD / finite logarithmic derivative.** For $q=p^e$ and $N\ge0$, on
   $U_N=1+x\mathbb F_q[x]/(x^{N+1})$, set
   $$L(f)=1+x f'(x)/f(x)\pmod{x^{N+1}}.$$
   The Euler derivation $x\,d/dx$, not bare differentiation modulo the
   ideal, is well defined at the truncation boundary. Every $f$ is a unit.
   No pilot: ghost-component factorization and triangular section are
   already strong candidate-kill mechanisms.
4. **CGD / cyclic Galois determinant.** For $q=p^e$ and $m\ge1$, on
   $(\mathbb F_{q^2})^m$, with cyclic indices, set
   $$D(z)_i=z_i z_{i+1}^q-z_i^q z_{i+1}.$$
   Field elements, including zeros, are the whole carrier. No pilot:
   outputs all lie in the same one-dimensional trace-zero space, which
   makes the next image zero. The inverse is a classical adjacent
   determinant constraint and is not yet an evaluated two-axis atlas.

All four are attempted definitions, not four cleared new systems. Pure
scalar power, valuation collapse, linear lifts, adjugate, Hensel,
orthocenter, fixed/diagonal commutator, nilpotent-image and Brandt-sandwich
templates were excluded from the slate. No literal/conjugate non-hit
establishes mathematical value or global novelty.
