## Primary access

PRIMARY_ACCESS.json preserves all 21 actual web requests, their returned
provider-reference identifiers and result-length metadata. It contains
no copied bulk web bodies. SOURCE_AND_COLLISION.md states the small direct
source portions actually used; failures and mere metadata are separated.
A request with an open or line number is not itself proof that all requested
content was returned or read. In particular no full Adachi, Fleiner,
Schipper or Bal–DeGaetani proof is freshly asserted.

The source comparisons are bounded. Searches, date filters and zero exact
hits cannot establish global absence, global novelty or independent review.
