## Literal LAR: least-leaf antipode relay

The carrier is the set of simple undirected labelled trees on `[n]`, with
the singleton and two-vertex tree held. For `n>=3`, let `v` be the
least-labelled degree-one vertex, let `u` be its unique neighbour, and let
`a` be the least-labelled vertex maximizing graph distance from `v`.
Delete edge `uv` and add edge `av`. Labels and all other edges stay fixed.
The farthest vertex is another leaf, so `a!=u` for `n>=3` and the update
is a tree on the same carrier.

This is one literal candidate, not four fulfilled slots. Rooted rotations,
parity contraction, least-leaf grandparent lifting, root grafting and fixed
metric farthest-set feedback are collision controls, not new candidates.

## Pre-pilot deduction and subtraction

The selected leaf label can only decrease or stay unchanged: old leaves
other than `a` remain leaves, `v` remains a leaf, and the only possible new
leaf is `u`. A strict label drop is possible exactly when `deg(u)=2`
and `u<v`. On any interval with the same selected leaf, deleting it leaves
a fixed tree `S`; its attachment follows the lexicographic farthest-vertex
map of `S`. These are author deductions, not independent review.
