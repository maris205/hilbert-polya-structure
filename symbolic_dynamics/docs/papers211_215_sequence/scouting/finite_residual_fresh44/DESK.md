## Literal system and subtraction

For a finite nonabelian group G and n ≥ 2, the finite autonomous deterministic map is

F : G^n → G^n,  F(x)_i = x_i x_{i+1},

with indices modulo n and simultaneous updates. Multiplication order is part of the definition. Its noncommutativity distinguishes it from an additive cellular automaton, but does not establish novelty.

Local comparison: `docs/papers204_208_sequence/scouting/algebra_third/PROOF_AND_ADAPTER_NOTES.md`, section ND, already treats the inverse-difference rule D(x)_i = x_i^{-1} x_{i+1}. That is not literally F: its telescoping image/fibre argument must not be transferred to multiplication. This local distinction motivated the primary-source check; it is not a positive novelty result.

Primary owner: Marcus Pivato, *Multiplicative Cellular Automata on Nilpotent Groups: Structure, Entropy, and Asymptotics*, [arXiv math/0108084](https://arxiv.org/pdf/math/0108084), printed page 2, Example 1(a), explicitly gives the same local rule g(b_0,b_1) = b_0 b_1. The paragraph following Example 1 calls it the nearest-neighbour multiplication CA and points to earlier references 10 and 11. The introduction also distinguishes nonabelian multiplicative CA from the additive/linear case. This desk inspected the actual primary PDF, not merely a search snippet. The displayed arXiv header identifies v3, 28 August 2002; the rendered title page separately displays 20 November 2018. That date discrepancy is not resolved here.

The owner's example uses bi-infinite configurations. The finite ring does not create a different local rule: embed x ∈ G^n as its n-periodic bi-infinite repetition. Updating commutes with this embedding because each output reads the same ordered adjacent pair, including across the cyclic boundary. Hence G^n with F is exactly the invariant n-periodic restriction of that source's CA.
