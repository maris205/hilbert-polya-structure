## Exact static adapter, not a conjugacy

The old polynomial is \(M(a,b)=(b,ab)\). For comparison only, interpret that
already documented polynomial on the assigned \(I^2\); this is not a second
candidate nomination or an assertion that the old finite-field carrier was
already this ring ideal. Define the two bijective re-encodings
\[
P(x,y)=(x,y+t),\qquad Q(u,v)=(u-t,v).
\]
They preserve \(I^2\), and direct substitution gives
\[
F=Q\circ M\circ P,
\qquad F^{-1}(u,v)=P^{-1}\!\left(M^{-1}(u+t,v)\right).
\]
Thus image size, every fibre cardinality, the fibre-size distribution and
the number of maximizing targets transfer from ring multiplication.
Importantly, \(Q\ne P^{-1}\); the displayed relation is not a conjugacy and
does not transport iterates, recurrence or entrance times.

Equivalently, the first equation of an inverse fixes \(y=u\), leaving
\(x(t+u)=v\) with \(x\in I\). Multiplication by \(t+u\) is a homomorphism
on the additive group \(I\). Every nonempty solution set is exactly one
coset of \(I\cap\operatorname{Ann}_R(t+u)\). If
\(s=\operatorname{ord}_t(t+u)\), using \(\operatorname{ord}_t(0)=m\), its
image is \(t^{\min(m,s+1)}R\) and its kernel has
\(q^{\min(s,m-1)}\) elements. These are elementary chain-ring coefficient
counts, not a distinct inverse construction. They require the restriction
\(x\in I\): using the full-ring annihilator cardinality at \(s=m\) would
overcount by a factor \(q\).
