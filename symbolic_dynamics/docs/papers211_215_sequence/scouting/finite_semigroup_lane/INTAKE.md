## Literal KIP: kernel/image projection product

For $n\ge1$, let $O_n$ be **all** nondecreasing functions from $[n]=\{1,\ldots,n\}$
to itself. For $f\in O_n$, let $X_f$ be the set of greatest elements of its
nonempty kernel blocks and $Y_f=f([n])$. For any set $A\subseteq[n]$ containing
$n$, put
$$e_A(i)=\min\{a\in A:a\ge i\}.$$
Define the single autonomous map
$$T(f)=e_{X_f}\circ e_{Y_f\cup\{n\}},$$
where the right factor acts first. Both sets and both projections are
recomputed from the old function at each epoch. All labels are retained.
The addition of $n$ is part of the definition, including when $f(n)<n$.
Both factors are nondecreasing, hence $T(f)\in O_n$.
