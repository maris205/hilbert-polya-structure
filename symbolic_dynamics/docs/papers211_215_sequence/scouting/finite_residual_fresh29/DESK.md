## 1. Greenberg–Hastings: complete inverse, but a product mechanism

The known deterministic three-state graph rule was freshly read in Doba's
[primary paper](https://wpmedia.wolfram.com/sites/13/2018/09/27-2-1.pdf),
Definition 1 and preceding rules, printed pp. 101–103. The opening source

Here is a complete elementary control for the customary $q\ge3$ version.
On any finite simple graph $G=(V,E_G)$ with $n=|V|$, positives advance by one
modulo $q$, while zero advances to one iff it has a neighbour of colour one.
This is a known-rule control, not a newly nominated parameter extension.

For target $y\in\{0,\ldots,q-1\}^V$, put
$$E_y=\{v:y_v=2\},\quad U_y=\{v:y_v=1\},\quad
Z_y=\{v:y_v=0\},$$
and let $N(E_y)$ be the open neighbourhood. Then
$$|F^{-1}(y)|=
\begin{cases}
2^{|Z_y\setminus N(E_y)|},&U_y\subseteq N(E_y),\\
0,&\text{otherwise}.
\end{cases}$$
**Status: PROVABLE AS STATED.** Every source colour one necessarily and
exclusively produces target colour two, so its set is forced to be $E_y$.
For $y_v\ge2$, the unique source is $y_v-1$. For $y_v=1$, the source must
be zero and see $E_y$, giving exactly the displayed admissibility condition.
For $y_v=0$ and $v\in N(E_y)$, the only source is $q-1$. For $y_v=0$ and
$v\notin N(E_y)$, either zero or $q-1$ works. These last choices never create
new source colour one because $q\ge3$, so they are mutually independent.
This proves both the necessity and sufficiency of the complete decoder.

The unique maximum target is $y=0^V$, with $2^n$ sources. Indeed equality
requires $|Z_y\setminus N(E_y)|=n$, hence $Z_y=V$; conversely the zero
target has exactly the sources $\{0,q-1\}^V$. At $n=0$, there is one target
and one source, consistent with the same statement.

This inverse is easier than the already-written FCA inverse, not a new
nontrivial combinatorial mechanism. No independent all-source temporal
residual was established. A cited asymptotic theorem plus these independent
binary choices does not meet the requested two-axis candidate threshold.
