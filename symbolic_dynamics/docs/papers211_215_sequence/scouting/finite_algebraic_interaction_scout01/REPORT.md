   Coxeter groups*, [arXiv:1512.04764v1](https://arxiv.org/abs/1512.04764v1).

   invariance. Its generator is the inverse of this desk's right move.

   not merely a topical neighbor. No Coxeter transitivity proof is borrowed.
   The metadata says submitted 2015-12-15 while the PDF title page prints
   2018-09-27; both observations are retained without inventing a new version
   or equating PDF layout with publisher pagination.

2. Tetsuya Ito, *Finite orbits of Hurwitz actions on braid systems*,
   [arXiv:0912.0405v1](https://arxiv.org/abs/0912.0405v1), 2009-12-02.
   Read the actual [17-page PDF](https://arxiv.org/pdf/0912.0405v1),
   introduction's right-action definition and Section 3, Lemma 1, with nearby
   product-conjugation calculations. These are braid-system results, not a
   theorem about every finite group. The extracted interval indices in Lemma
   1(3) need care, and are not used to import an exact indexed identity:
   the group sweep formula is derived directly in our proof note.
   Its whole-Hurwitz-orbit classification is not a census for one fixed word.
   No figures or complete paper proof were reviewed.

3. Cristopher Moore, *Quasi-Linear Cellular Automata*,
   [arXiv:adap-org/9701001](https://arxiv.org/abs/adap-org/9701001), metadata
   submission 1997-01-20. Read the [41-page PDF](https://arxiv.org/pdf/adap-org/9701001),
   Sections 1–2 definitions and Sections 7.1–7.2. It distinguishes idempotent
   Steiner quasigroups from loops obtained by adjoining an identity, and

4. Masood Aryapoor, *The pasch configuration and Steiner triple systems*,
   [arXiv:1306.1257v1](https://arxiv.org/abs/1306.1257v1), 2013-06-05.
   Read the actual [nine-page PDF](https://arxiv.org/pdf/1306.1257v1),
   introduction and Sections 2.1–2.2 through the proof of Proposition 2.2.
   Section 2.1 defines the unordered distinct-triple pair-product maps.
