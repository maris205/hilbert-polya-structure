  1987--1994, DOI `10.3966/160792642019102006027`, establish that random walks

For a component of order `s`, the pivot quotient sends its labelled pushes to
the `s-1` coordinate generators and the all-ones generator.  This exact bridge
makes the folded-hypercube hit direct.  The final manuscript therefore does
not retain the connected spectrum, period, or return moment as contribution.
The surviving inverse uses only `(n,Q_G)`; the true component partition is a
post-return test oracle.  Its explicit failure boundary includes identical
spectra for connected `P_4` and `K_4`, unmarked starting orientations, and all
positive-order edgeless graphs when `n` is unknown.
