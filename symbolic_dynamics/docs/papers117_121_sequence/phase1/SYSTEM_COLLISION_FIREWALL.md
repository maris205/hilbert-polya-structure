## Within-batch separations

- Only P117 is a shrinking boundary system; P120 is a bijection on fixed
  tree topology and P121 strictly decreases block rank.
- Only P118 is a graph-colouring map; its recurrence is reached in two
  rounds, whereas P119 has unbounded parameterized depth and P117 has sharp
  linear depth.
- P119 and P121 both have uniform recursive fibres in some coordinates, but
  one is a deterministic group coboundary and the other is a stochastic
  random-tree split.
- P117 and P120 both use parity, but P117 parity controls transient boundary
  loss while P120 parity selects commuting local involutions.
- Zeta functions, generating functions, finite-map basin language, and
  exhaustive checks are generic tools and receive no collision credit.
