## Selected replacement

`RCS`, rectangular-corner stripping of integer partitions, is selected as
`SELECT_REPLACEMENT_P160`.  For positive `a,b`, one update deletes the first
`a` rows and first `b` columns of a Ferrers diagram and translates the
southeast remainder.  It passed the freeze gate because it has:

1. a sharp all-time rectangle clock and cap-`N` height, with exact absorption
   shells;
2. a separate all-time/every-target fibre theorem from a forced-core plus
   two-boundary bijection;
3. an every-exact-weight image threshold for every nonempty target at positive
   time; and
4. an ordered-parameter recovery interface from three target probes.

Barnes--Savage's first-row/first-column deletion and Durfee decrement;
Gordon--Houten's and Andrews's generalized, including unequal/rational-slope,
Durfee rectangles; Chen--Ji--Zang's static two-boundary `m`-Durfee symbol and
weight decomposition; Andrews--Eriksson's Ferrers/Durfee/bounded-product
background; and the resulting two-Pochhammer factorization are explicit
zero-credit inputs.  The retained conjunction starts only with the fixed
`(a,b)` literal crop through all times, arbitrary prescribed targets, the
separate empty branch, exact cap support, and ordered recovery.  The source
screen is a bounded non-hit only; it does not establish novelty, priority,
owner absence, or release readiness.
