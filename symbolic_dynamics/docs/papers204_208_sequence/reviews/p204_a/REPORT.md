## Decisive finding, in compact form

Let $\beta_m(S)$ be the number of permutations of $[m]$ with exact descent
set $S$. For the paper's every-block factor,

$$D_{r,m}(A)=\binom{r+m}{m}\,\beta_m(A-1).$$

Subtract one from each positive block letter. The resulting word is the
suffix of a length-$r+m$ inversion code with exactly $r!$ prefix completions.
The standard code transports its internal ascents to descents of the suffix
permutation. Counting that suffix by its label set and relative order gives
$\binom{r+m}{m}\beta_m(A-1)r!$ completed permutations; cancelling $r!$
proves the adapter for all parameters. MacMahon's exact descent-set formula
therefore evaluates the entire inverse axis without a new counting
mechanism. The full argument, source locators and limits are in
[SOURCE_AND_PROOF.md](SOURCE_AND_PROOF.md), §4.

Moreover, permutation complementation equates complementary descent-set
counts, so all target fibre **cardinalities** are identical at every time
$t\ge2$. The manuscript's phase masks remain correct for source identities.
This is a framing limitation and a warning about count-only validation,
not a counterexample to either displayed theorem.
