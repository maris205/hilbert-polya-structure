# B initial package roles

`SHA256SUMS` is the final nonself physical inventory of this initial package.
It is not a runtime read trace and does not certify its own bytes. Its digest
and payload count are delivered outside the package to root. The initial
seal must be preserved before later accepted-delta additions.

`INPUT_PINS.sha256` pins all 509 physical frozen Round1 files relative to the
workspace root, including the Round1 seal. `AUDIT_INPUTS.actual.json.gz`
contains 120,840 actually full-byte-read current physical path keys;
`AUDIT_ROLES.actual.json` partitions those paths by declared audit role.
That collection includes source context and inherited evidence; it does not
mean all source bodies were semantically read or all inherited commands rerun.
Current root lifecycle/index controls are not reviewed scientific inputs.
Only the exact frozen historical roles apply to the pre-Round1 controls.

`verify.py`, its physical committed copy, `PARAMETERS.json` and the complete
`CANONICAL.json` are the independent scientific artifact. The first source's
hash-matching reconstruction is explicitly under history. Commitment JSONs
bind the actual independence order. `compare_outputs.py` and its complete
native stdout are a later cross-schema audit, never the B scientific producer.

`produce01`, `pair01` and `build02` contain complete source-only inner-driver
and scientific/build execution evidence: before/after file/configuration/
membership keys, bounded observations, complete native streams, result codes,
source copies and per-run nonself payload inventories. `build01` is a retained
incomplete failed attempt. The original adapter was not rewritten; a separate
one-line corrected build adapter is present. Outer launchers record actual
native transport, but are not advertised as source-only startup-traced.

`native/*` has owned new-session start/result/full-stream records. Each
completed command's process group is quiescent before stream binding.
`native/audit02` records the final evidence audit and is generated after that
auditor's internal input census; the final seal audit checks its completed
raw-stream binding rather than retroactively putting its in-flight bytes in
the earlier census. Seal generation similarly cannot include its own unfinished
stdout or an enclosing launcher result, so it uses an ordinary native tool
return outside the sealed directory for the final manifest digest/count.

The cold-build `REPORT.json` accurately reports no mechanical visual check;
the subsequent actual six-page view record supplies that separate evidence.
`record_views.py` only binds already made observations and is not itself a
visual viewer. Source web records are literal tool-return serializations,
not invented downloadable PDFs or native HTTP executions.

`FINDINGS.json` and `DELTA.md` are INITIAL_PENDING_ROOT_RESPONSE. Initial
mathematical acceptance does not imply root response acceptance. Exactly two
manuscript reviewers are involved; a helper, root verification or mechanical
comparison is not a third independent review.
