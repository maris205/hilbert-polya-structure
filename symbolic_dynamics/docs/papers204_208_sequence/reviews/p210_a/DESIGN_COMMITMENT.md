# P210 Review A independent design commitment

Process: `/root/p210_a_reviewer`, a new nonauthor manuscript reviewer. This
process has no previous P210 contribution. It has read the frozen proof package
and mathematical TeX statements, but has not semantically read any author or
candidate checker or canonical output. Root, original scout, author and its
runtime helper are excluded reviewers. Generic project contracts and orientation
are known; candidate verdicts are not proof inputs for this design.

The independent carrier is an integer bitmask of cumulative cuts in the N unit
cells, N=1..12 inclusive: exactly 4095 states. A transition removes precisely
those old cuts for which the length of the adjacent left interval is no greater
than the right interval. All removals are computed before any deletion. Paths
in the resulting complete functional graph determine stabilization times and
fixed endpoints. Interval endpoints identify blocks permanently and distinguish
unchanged blocks from newly born unions; every disappeared cut and every birth
along every trajectory is checked against the oriented mass/birth statements.

All-target inverse sets are reconstructed from this graph. Independent segment
factorization uses weakly increasing compositions generated by cut masks of each
target mass and literal boundary descent; their concatenated cut sets must equal
the complete graph source sets. Attained first-endpoint sets for every suffix
are computed from those actual source sets, then compared with the three-branch
scan, never replaced by an interval assumption. Endpoint partition coefficients
are independently obtained with integer coin-change coefficient extraction and
compared with literal weak refinements, including equal endpoints.

Image encodings implement a threshold automaton into triangular blocks and
separate reserved-final-block decoding. Exhaustively enumerate all triangular
compositions within the SAME N<=12 box and verify both inverses, mass and image
surjectivity. Check every all-surplus witness whose mass is within that box,
all its intermediate states and exact clock. The all-size claims are assessed
deductively; bounded computation cannot prove them or arbitrary unbounded surplus.

Canonical stdout will contain every state transition, time, endpoint, trajectory
birth/deletion event and every target's complete source-mask set, suffix first
sets, fibre counts and (when feasible) triangular encoding, plus all triangular
decodings, witness records and exact check census. No digest-only substitute.
Standalone standard-library-only verify.py and PARAMETERS.json will be hashed
with this design before any author checker/canonical semantic inspection. Later
comparison will be a separate explicitly disclosed adapter, not checker code.

Scientific checker code is original to this process. Runtime/build instrumentation
may be reused only after full reading and disclosure. Review A is internal,
process-separated, not blind/external expert certification. OWNER_AMBER /
HOLD_EXTERNAL. Only reviews/p210_a/ is writable.
