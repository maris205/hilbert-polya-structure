# Sixth set-family / partition intake — fixed before execution

2026-09-06 UTC. Only this new directory is writable.
Six literal maps are considered below; none has a paper or reserve status.
UZ and UD deliberately share an incidence primitive but have different
time directions. They are two literal controls, not two certified
independent theorem mechanisms. All boxes are exhaustive, with no samples.

| Code | Literal finite autonomous map | Fixed initial boxes |
|---|---|---|
| SHD | For a family $H\subseteq2^{[n]}$, output the subsets shattered but not strongly shattered by $H$ | $n=0,1,2,3,4$, all $2^{2^n}$ families |
| UZ | $H\mapsto\{A\subseteq[n]:|\{B\in H:B\subseteq A\}|=1\}$ | Same full boxes |
| UD | $H\mapsto\{A\subseteq[n]:|\{B\in H:B\cap A=\varnothing\}|=1\}$ | Same full boxes |
| UPC | A DAG whose edges respect the fixed natural order on $[n]$ maps to pairs joined by exactly one positive-length directed path | All upper-triangular Boolean relations for $n=0,\ldots,6$ |
| AKC | For every set partition $\pi$ of $[n]$, form the permutation $s_\pi$ cycling each block in increasing order; output the cycle-support partition of $s_\pi^{-1}(1\,2\,\cdots\,n)$ | All partitions for $n=0,\ldots,8$; empty partition fixed |
| TDP | A subset $S$ of a fixed rectangular integer grid maps to every grid point maximizing its closed-halfplane Tukey depth relative to $S$ | All subsets of $1\times b$ for $b=1,\ldots,6$, and of $2\times2$, $2\times3$, $3\times3$, $3\times4$ |

For SHD, $A$ is shattered when all traces on $A$ occur; it is strongly
shattered when a complete $A$-direction subcube lies inside $H$ with one
fixed assignment on the other coordinates. Subsets $A$ in the output are
the ordinary bit-vector points of the same ground cube. Empty/full input
families are included.

UD equals UZ followed by complementing each output subset, but that is
postcomposition, not an asserted conjugacy. The fully symmetric
all-neighbors exact-transversal/Galois operator is not the UD literal:
UD asks for exactly one old family member, not one point in every old edge.

UPC counts paths of all positive lengths, not only shortest paths and
not paths modulo two. The fixed label order makes the output a DAG again;
no transitive-closure completion is silently applied.

AKC is a whole-partition probe, not a claim to extend the classical
noncrossing Kreweras theorems unchanged. On the noncrossing stratum the
literal is the old named action and receives zero credit. Canonicalizing
cycle supports after each step loses cyclic orientation off that stratum;
this is the specific possible new transient, with no priority claim.

For TDP, a closed halfplane containing the query point is used. Maxima
are over the fixed grid, not just currently occupied points. The empty
source has depth zero everywhere and therefore maps to the full grid.
No ad hoc empty-state sink is added.

## Desk deductions and occupied boundaries

Already excluded without extra numerical-row credit:

- ordinary blocker / exact-transversal duality and any symmetric universal
  Galois transform;
- partition shift-join/meet, equal-size merging, crossing closure,
  cyclic maximum/median block transfer and the old RSK transpose lifts;
- direct noncrossing Kreweras complementation as a standalone candidate;
- graph power, odd-path parity/inverse linearization, lower shadows and
  pairwise-union semigroup powers;
- partition row/column transposition: the first image is a standard
  tableau and every inverse is a sequence of Ferrers matching choices;
- all unions of maximal disjoint subfamilies: distinct output unions
  necessarily intersect, giving an immediate retraction;
- convex-hull complement/defect and ordinary extreme-point retractions.

The first known danger for TDP is nested depth regions and consequent
boundary erosion. If that is the temporal engine, it receives zero credit.
The unique-incidence operators must face generic triangular Boolean
cascade and static incidence-counting adapters. Weak signals do not
authorize larger $n$, larger grids or additional graph/group wrappers.

## Separately declared replacement MHT — before its execution

MHT maps a family $H\subseteq2^{[n]}$ to the family of all
minimum-cardinality hitting sets of $H$. For the empty family the output
is $\{\varnothing\}$; if $H$ contains the empty edge, its output is the
empty family. Thus the literal is autonomous on the entire same carrier.
The fixed exhaustive boxes are $n=0,1,2,3,4$ only. No larger box is authorized.

This differs from the ordinary blocker, which retains every
inclusion-minimal hitting set rather than only those of minimum size.
The ordinary blocker primitive is entirely owned; MHT is a rank-filtered
probe, not a certified independent mechanism. A 2026-09-06 pre-pilot
historical literal search for minimum hitting sets / minimum transversals
found no exact prior literal in the searched scouting Markdown, which is
not a novelty certificate. Symmetric incidence duality and rank descent
are the specific adapters to deduct before any proposed admission.
