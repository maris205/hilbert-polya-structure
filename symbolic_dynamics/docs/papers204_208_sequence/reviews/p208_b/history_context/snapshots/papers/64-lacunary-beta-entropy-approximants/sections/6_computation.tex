\section{An exact-arithmetic triangular control}
\label{sec:computation}

Take $g_j=j$, equivalently
\[
 q_j=j+1,\qquad n_j=\frac{j(j+1)}2.
\]
Then $\beta$ is the unique root in $(1,2)$ of
\[
 \sum_{k\geq1}\beta^{-k(k+1)/2}=1,
\]
numerically $\beta\approx1.5498524695188884304$.  The accompanying program uses no external packages; its relative location is
\begin{center}
\path{checks/verify_certificates.py}.
\end{center}
With the first 18 positions and denominator $2^{72}$, exact rational sign tests from \cref{prop:rational-certificate} give
\[
 \frac{7318971355448747171761}{4722366482869645213696}
 <\beta<
 \frac{3659485677724373585881}{2361183241434822606848}.
\]
The same dyadic procedure encloses each $\beta_j$.  The output stores the resulting symbolic logarithmic interval, not merely a decimal approximation.
