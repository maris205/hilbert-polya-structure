\section{Strict Extensions Cannot Supply Periodic Orbits}
\label{sec:extension}

The grading already closes the most literal stationarization proposal.

\begin{theorem}[Periodic-point projection obstruction]
\label{thm:extension}
Let $(X,\sigma)$ be a strictly graded shift.
If $(Y,S)$ and $\pi:Y\to X$ satisfy \eqref{eq:semiconjugacy}, then
\begin{equation}
  \Fix(S^n)=\varnothing
  \qquad\text{for every }n\geq1.
\end{equation}
\end{theorem}

\begin{proof}
Suppose $S^ny=y$ for some $y\in Y$ and $n\geq1$.  Iterating
\eqref{eq:semiconjugacy} gives
\[
  \sigma^n(\pi(y))=\pi(S^ny)=\pi(y).
\]
If $\pi(y)\in X_k$, strict grading places the left-hand side in $X_{k+n}$
and the right-hand side in $X_k$.  The components are disjoint, so equality
is impossible.
\end{proof}

For the graded source itself, the standard natural-extension construction
also collapses, for a different but related reason.

\begin{proposition}[Empty full-backward-orbit inverse limit]
\label{prop:inverse-limit}
For a strictly graded shift,
\begin{equation}
 \varprojlim(X,\sigma)
 =\bigl\{(x_0,x_{-1},\ldots):
     \sigma(x_{-j})=x_{-j+1}\text{ for every }j\geq1\bigr\}
 =\varnothing.
\end{equation}
Moreover,
\begin{equation}
  \bigcap_{n\geq0}\sigma^n(X)=\varnothing.
\end{equation}
\end{proposition}

\begin{proof}
Assume $x_0\in X_k$ has a full backward orbit.  Because every application of
$\sigma$ raises the level by one, disjointness forces
$x_{-j}\in X_{k-j}$.  No component with negative index exists, contradicting
the requirement when $j>k$.

For the intersection statement, \eqref{eq:strict-grading} yields
$\sigma^n(X)\subseteq\bigsqcup_{k\geq n}X_k$.  A point has one finite level,
so it cannot belong to all of these tails.
\end{proof}

\begin{remark}[Scope]
\label{rem:extension-scope}
\Cref{thm:extension,prop:inverse-limit} concern systems that retain an
equivariant map \emph{to the frozen wheel shift}.  A factor, observational
recoding, quotient, or independently defined stationary grammar may not
satisfy \eqref{eq:semiconjugacy} in this direction.  Such a construction is
not refuted here, but neither is it an extension of the stated kind; it must
re-establish its arithmetic interpretation from its own definition.
\end{remark}
