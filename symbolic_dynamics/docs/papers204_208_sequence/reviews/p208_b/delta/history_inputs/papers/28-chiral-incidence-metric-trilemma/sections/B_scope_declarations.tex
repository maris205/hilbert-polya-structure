\section{Scope and ownership declarations}

\begin{enumerate}
  \item \textbf{Arithmetic specialization.}
  Every critical-line theorem uses $u=1$.  If
  $T_s(u)=\sum_pu^{\ell(p)}p^{-s}q_p$ is retained, an $r$-fold atom
  contribution carries $u^{r\ell(p)}$.  The altered threshold for
  $|u|<1$ is not continuation of the $u=1$ result.

  \item \textbf{Trace ownership.}
  The finite formula for $\Tr\cB_s^2$ is a cutoff identity.
  The countable $\cB_{1/2+it}$ is not Hilbert--Schmidt, so no ordinary
  second trace is asserted.

  \item \textbf{Determinant ownership.}
  The Euler determinant of $T_s$ on $\Re s>1$ and the chiral
  $\detthree(I-z\cB_s)$ on $1/3<\Re s<2/3$ are different objects.
  The latter deletes powers one and two.

  \item \textbf{Spectral ownership.}
  The compact self-adjoint operator depends on $t$.  No fixed operator
  with spectral parameter $t$ is claimed.

  \item \textbf{Metric scope.}
  Metric rigidity covers bounded positive boundedly invertible common
  metrics.  It does not classify indefinite or unbounded metrics.

  \item \textbf{Control inference.}
  Mutated, composite-only, and generic-poset controls reproduce the
  native motion.  Their role is to reject arithmetic selectivity.

  \item \textbf{Target-zero firewall.}
  No target-zero position, label, fitting criterion, or comparison
  enters the definitions, the exact audit, or the route decision.
  Auxiliary zeros in $z$ are not identified with zeta zeros.

  \item \textbf{Route status.}
  The frozen tuple is
  \[
  \begin{gathered}
  (\texttt{A0\_STRUCTURAL\_ARITHMETIC\_RELATION},
   \texttt{ A1\_FAIL},\\
   \texttt{A2\_ANALYTIC\_DETERMINANT},
   \texttt{ A3\_FAIL},\texttt{ A4\_FAIL}).
  \end{gathered}
  \]
  Overall status is \texttt{ROUTE\_A\_REJECTED}; Route B is locked.
\end{enumerate}
