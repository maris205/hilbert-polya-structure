Li--Liu's continuous-alphabet invariant is governed by the normalized maximum
independent-set size \citep{LiLiu2026}.  The present finite-alphabet invariant
uses all independent sets, weighted by $3^{|I|}$.  This distinction explains
both the common approximation templates and the different proof obligation:
for entropy, a maximum independent set gives only a lower bound, while the
upper bound requires control of the full partition function.

Airey--Bowen--Lin already obtain a mixing SFT with two different positive
sofic entropies \citep{AireyBowenLin2022}.  Their system and counting problem
are substantially different, but their theorem owns the general headline.
Our result should therefore be read as a natural-system reduction with an
explicit interval, not as the first positive-dependence example.

There are two natural next questions.  First, can one calculate either
endpoint exactly, perhaps through local weak limits and a quenched hard-core
free energy?  Second, for $q$ active colours, for which $q$ can one obtain a
strict separation between a parity lower bound and a uniform-permutation
upper bound?  The scalar annealed calculation in \Cref{rem:activity} answers
only the upper-bound side; equality would require new concentration or
interpolation input.
