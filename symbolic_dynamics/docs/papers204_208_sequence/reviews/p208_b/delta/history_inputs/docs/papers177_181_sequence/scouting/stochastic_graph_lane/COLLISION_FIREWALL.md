## RHT versus the nearest internal systems

RHT toggles the point set of a projective hyperplane.  It is an additive walk
on the **whole Boolean subset group** (\mathbb F_2^E).  The increment masks
span the augmented simplex code (W=\langle\mathbf1,C\rangle), and every
closed component is the crown graph (K_{2^d,2^d}\setminus M).

| coordinate | P145 | RHT |
|---|---|---|
| state | orientations of one fixed graph modulo component pushes | every subset of projective points |
| generator | push one vertex, i.e. add one cut/star vector | toggle one entire projective hyperplane |
| component | folded hypercube determined by graph-component order | crown graph, independent of an ambient graph |
| spectrum | degree-weighted product of folded-cube spectra | exactly (±1,±1/(2^d-1)) with a global simplex-coset lift |
| inverse axis | recover graph component-order multiset from spectrum | every-time target history depends on whether the summed nonzero forms vanish |

Fourier analysis and code/Cayley vocabulary transfer and receive zero credit;
the folded-hypercube theorem does not imply the crown conjugacy or history
formula.  P127 uses a deterministic state-selected parity toggle and P162
uses set intersection under ambient translations; neither has this additive
projective-hyperplane kernel.  No P172--P176 map uses a random additive code
mask.  RHT therefore clears the **internal literal and two-axis** gate, not an
external novelty gate.

## Why LFS remains behind RHT

LFS has a correct every-configuration theorem, but its forward operator is a
commutative random meet walk.  The Boolean-zeta eigenbasis is the generic
semilattice proof, while its endpoint count is the characteristic polynomial
of a contracted represented matroid evaluated at (q^t).  Historical `R7`
already contains the literal random-hyperplane intersection on the subspace
lattice, and P158/P170 have repeatedly used random-mask intersection.  The
configuration-level target refinement is nontrivial but not yet enough to
reopen that occupied silhouette.

RHT and LFS also share the same finite-geometric masks.  Even if LFS cleared
its historical gate, this lane recommends at most one of the pair to preserve
batch breadth.

## Decisive kills

- `ZSI` is a q-odd paired-history version of P158's complementary-history
  intersection.  Its bipartite/odd-component survival exponent is a new
  formula but does not change the two-axis proof architecture.
- `DPC` factors through the old odd-degree-set statistic.  The incidence-rank
  theorem, not the final two-clique drawing, controls every fibre.
- `CDS` and `RSS` reduce coordinatewise to scalar squaring and are further
  crowded by current-diagonal P175.
- `RSI` and `RSG` are exact occupancy encodings.  Their graph dress supplies
  no independent inverse mechanism.
- `TCP` is an idempotent pruning operator and fails the temporal threshold.

## Kill switch

RHT is killed if a source states the same random toggle, an equivalent
augmented-simplex-code walk, or the conjunction of crown components and the
all-time nonzero-form-sum kernel.  A source need not use the name RHT.  A
bounded phrase-search miss is never evidence that such a source does not
exist.
