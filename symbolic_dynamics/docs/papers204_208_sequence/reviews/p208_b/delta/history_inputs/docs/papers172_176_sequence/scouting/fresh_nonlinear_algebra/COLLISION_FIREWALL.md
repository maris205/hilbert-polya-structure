## M01 hostile comparison

The candidate is

\[
\Phi:M_n(\mathbb F_q)\to M_n(\mathbb F_q),\qquad
\Phi(A)=[D(A),A].                                        \tag{1}
\]

### P119 subtraction

| coordinate | P119 | M01 |
|---|---|---|
| carrier | (U_n(\mathbb F_q)), multiplicative group | full matrix algebra (M_n(\mathbb F_q)), additive bracket output |
| update | (X\mapsto X^{-1}J^{-1}XJ), fixed regular (J) | (A\mapsto[D(A),A]), diagonal factor extracted from the current state |
| clock | lower-central filtration, sharp height (n-1) | diagonal is erased in one step, so (\Phi^2=0) |
| inverse | uniform centralizer cosets on each filtration restriction | nonuniform target fibres, summed over proper colourings of the target support |
| proof | centralizer/orbit--stabilizer plus triangular differences | independent scalar equations ((d_i-d_j)a_{ij}=y_{ij}) plus graph support |

The words `commutator`, `finite field`, `fibres`, and `functional tree` are
fully subtracted.  P119 cannot prove M01's image criterion or fibre
polynomial: its fixed element creates uniform cosets, whereas M01's state
feedback makes the diagonal both a colour assignment and a varying kernel
dimension.  Conversely M01 has no long clock and cannot claim the filtration
axis.

### Graph-colouring/Potts and P118 subtraction

Proper colourings, chromatic polynomials, Potts partition functions, and
occupation marking are classical and receive zero credit.  P118 also owns
the broad architecture “graph-colouring update + quotient + fibres + full
functional graph.”  Its mex update first collapses complete multipartite
colourings and its inverse is a labelled-EGF reconstruction.  M01's graph is
not the state carrier: it is extracted from the support of an arbitrary
matrix target, and the same graph controls solvability and the number of free
ordered entries through the weight (q^{\sum n_c(n_c-1)}).  The literal
matrix-to-support fibre identity does not transfer from P118 or generic Potts
theory.

### P102/P127/P171 subtraction

M01 contains neither (AA^*\), (AA^{\mathsf T}), parity margins, Boolean
matrix multiplication, graph squaring, nor clique-cover inversion.  The
first iterate is entrywise scaling controlled by diagonal differences, and
the second is zero.  Therefore the Gram/transpose engines do not prove (1).
All generic “nonlinear matrix map with exact fibres” presentation language is
still spent.

### M01 result

After these subtractions, one conjunction remains:

1. state-derived diagonal feedback forces a universal two-step clock;
2. image membership is exactly (q)-colourability of an arbitrary target's
   undirected support; and
3. every target fibre is the occupation-weighted proper-colouring sum, with
   zero the unique maximizer and an exact all-time extension.

This is not mechanically supplied by P119, P118, or a Gram paper.  M01
therefore receives **`SURVIVE_INTERNAL / GREEN_OWNER_THIN / HOLD_EXTERNAL`**.
The proof is short and owner-sensitive, so a direct source or equivalent
polynomial-map construction remains an immediate kill switch.
