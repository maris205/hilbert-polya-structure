### Exact internal reduction

Contract the fixed reference pairs.  Each component of the union of the
current and reference matchings becomes a signed permutation cycle.  Repairing
reference pair `i` removes `i` from that cycle, shortcuts its neighbours, and
makes `i` a singleton.  Consequently:

- the accepted-move profile transition `k -> 1+(k-1)` is exact;
- uniform marks on already singleton parts are only self-loops; and
- conditional on acceptance the process is precisely the `S06` cycle-erosion
  process permanently killed in the P147--P151 stochastic scout.

P105 separately occupies permutation-cycle pruning, and current RCD records
already subtract random cycle-deletion/exposure packages.  Matching signs and
the target switch-count do not create an independent temporal engine.

**Gate:** `KILL_INTERNAL_S06_CYCLE_EROSION`.
