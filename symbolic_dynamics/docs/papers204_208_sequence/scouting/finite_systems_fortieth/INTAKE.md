## LLG — simultaneous leaf-to-grandparent lifting

For each integer $N\ge0$, the carrier $\mathcal T_N$ is the set of rooted,
labelled, unordered trees on exactly $\{0,1,\ldots,N\}$ with root $0$.
Equivalently a parent map $p$ has $p(0)=0$, and each nonroot parent orbit
reaches $0$ without another cycle. A leaf means a nonroot vertex with no
children. All decisions use the old tree simultaneously:

$$p'(v)=\begin{cases}
0,&v=0,\\
p(p(v)),&v\ne0\text{ is an old leaf},\\
p(v),&v\ne0\text{ is an old nonleaf}.
\end{cases}$$

A root-child leaf therefore stays attached to the root. No vertex, label,
root or edge-order convention changes. This is not vertex-deleting pruning,
unary suppression, all-vertex pointer jumping or selectable local surgery.

## OMP — meet of immediate predecessors on tree ornamentations

Fix any finite rooted plane tree $T$. For a vertex $v$, a decoration
$\delta(v)$ is a nonempty connected vertex set whose highest vertex is
$v$. The carrier $\mathcal O(T)$ consists of all such assignments for which
every two decorated sets are nested or disjoint. Order assignments by
coordinatewise inclusion. Let $D(\delta)$ be the maximal assignments strictly
below $\delta$. The literal update is

$$G(\delta)(v)=\bigcap_{\eta\in\{\delta\}\cup D(\delta)}\eta(v).$$

The self-inclusion makes the minimum case unambiguous. The finite carrier
and coordinate intersections are justified in the proof package. The
single-vertex base tree has a singleton carrier. On a chain, ornaments are
laminar intervals; this is not a claim about unrestricted interval partitions.
