## ORR: odd increasing-run reversal

For $n\ge0$, the state space is $S_n$, with its empty permutation at $n=0$.
Split the one-line permutation into its maximal strictly increasing runs.
Reverse every odd-length run and keep every even-length run unchanged,
simultaneously in the old run positions. A singleton reversal does nothing.
This is a total length- and label-preserving autonomous map, not an
alternating-time schedule. All entries retain the parity of their positions.

Pre-code deductions: every nonfixed step strictly increases inversion
number; the fixed locus has only singleton or even-length increasing runs.
The full inverse has an interval-partition decoder, not source enumeration.
The ordinary inversion argument and block decoder alone are zero-credit
background. A nontrivial exact temporal theorem and independent residual
must survive source subtraction before any gate request.

**One original pilot:** all permutations for exactly $n=0,1,\ldots,7$,
eight complete boxes and 5914 states. Compare two update representations;
evaluate all target fibres and the interval decoder; record every transition,
exact entry time and eventual period, all fixed states, target fibre counts,
and attained maxima/witnesses. No $n=8$ or selected large witness extension.

## HXC: least-intersection hyperedge XOR

For $n\ge0$, use all families $H$ of distinct nonempty subsets of
$[n]=\{0,\ldots,n-1\}$. Order a set $e$ by its binary code
$b(e)=\sum_{i\in e}2^i$. For each $e\in H$, if no other edge intersects $e$,
output $e$. Otherwise take the least-coded other intersecting edge $m_H(e)$
and output $e\triangle m_H(e)$. The next family is the set of all outputs:
duplicates merge. Every partner is selected from the old family, not from
earlier updates. Distinct edges have nonempty symmetric difference, so no
empty-edge clipping is needed. The empty family is fixed.

Pre-code deduction: any non-disjoint family has a mutual least-neighbour
pair (take the least nonisolated edge), whose two outputs coincide. Family
cardinality therefore strictly decreases until a disjoint-edge family is
reached. This generic loss argument alone is not a qualifying temporal axis.
No full all-parameter inverse/extremum formula is assumed or claimed.

**One original pilot:** all families for exactly $n=0,1,2,3,4$,
five complete boxes and $1+2+8+128+32768=32907$ states. Compare literal
set and bitmask updates; evaluate the complete all-target inverse census and
attained maxima from the full map; record every transition, exact entry time,
period and fixed state. This is a numerical census, not an asserted new
structural inverse theorem. No $n=5$, random sample or repaired literal.
