## Exact proposed system: NED, nearest old-empty dispatch

For integers $n\ge1$, $M\ge0$, the finite state set is
$X_{n,M}=\{x\in\mathbb Z_{\ge0}^n:\sum_i x_i=M\}$, with labelled cyclic indices.
If every coordinate is positive, hold the state. Otherwise each old positive
coordinate sends exactly one chip to the first old zero clockwise. All sends
are simultaneous. Equivalently, old positive coordinates decrement by one,
and every old zero receives the length of the positive run just before it.
The zero state holds. Conservation and nonnegativity make this a total map.
No sink, clock phase, schedule or variable-length trimming is included.
