## Deductive audit

The carrier is $E_n=\{x:x_0=0,0\le x_i\le i\}$ for $n\ge1$; comparison is
strict, and the whole array is recomputed synchronously. Each positive block
starts immediately after a zero at global position $r$. Zeros are fixed
barriers, because no nonnegative entry is below zero and the barrier is
below every positive entry. Therefore a block's first output has local bounds
$1\le b_j\le j$ independently of earlier blocks.

The crucial first-image implication was checked including ties: when
$b_j>1$, the old value at $r+j$ is at most the preceding old value. Every
position strictly after the preceding nearest-smaller index is therefore
not smaller than the current old value. This gives $p_j\le p_{j-1}$ and
$b_j\ge b_{j-1}+1$. If instead $b_j=1$, its next nearest-smaller location is
the left zero. Consequently the second image is locally $j$ in the first
case $b_j=1$, and $1$ in the case $b_j>1$. Core values $1,j$ are exchanged
by the next update; every core point is a two-step preimage of itself.
This proves exact second image, recurrence and $P^4=P^2$, not just an
upper bound on periods. The $002$ boundary and zero-prepended $0122$
witnesses prove the asserted heights $0,0,1,2$ for $n=1,2,3,\ge4$.

The two-step target coordinate equals $j$ exactly when the original internal
edge is an ascent. The zero set and each internal ascent set are therefore
necessary and sufficient source data for an even endpoint, with the mask
complemented at odd times at least three. This validates the time parity in
the formula without assuming a one-step inverse characterization.

For a cut segment $[a,b]$, its decreasing entries have upper bound $r+a$,
so the count is $\binom{r+b}{b-a+1}$, not a binomial using only local
indices. Inclusion--exclusion over absent required ascents has the sign
$(-1)^{|A|-|B|}$. Separate zero-delimited blocks are independent only after
their exact zero positions have been fixed. The empty product gives the
all-zero fibre one. These observations check the full claimed fibre proof,
including global flags, ties, singleton blocks and noncore targets.
