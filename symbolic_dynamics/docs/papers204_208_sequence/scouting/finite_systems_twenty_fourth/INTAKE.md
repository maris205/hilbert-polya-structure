## D1 / LBR: leftmost binary braid rewrite

empty word at `n=0`. If `w` contains `010`, replace its least-starting
occurrence by `101`, leaving all other positions unchanged. If no such
occurrence exists, fix `w`. Windows are linear, not cyclic; there is one
replacement per epoch, not a simultaneous update. The rule preserves length,
so it is a finite autonomous deterministic map on every stated carrier.

This is recorded as a literal description, **not a new-system count**.

to the legal `101 -> 010` edge at the same position in old stochastic `S24`.

It is not conjugate to the stochastic kernel, and no such claim is made.
The local relation is also the classical one-rule `aba -> bab` Semi-Thue
example, under `a=0,b=1`.
