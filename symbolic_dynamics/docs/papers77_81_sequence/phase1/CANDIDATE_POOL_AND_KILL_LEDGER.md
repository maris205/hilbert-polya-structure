## Corrections forced by hostile review

- P77 Cantor–Bendixson height is `d+2`, not `d+1`; lowering beyond the
  bottom gives the absorbing zero map; `End` means all continuous
  shift-commuting selfmaps, while onto endomorphisms are only shifts.
- P79 uniformity is for consecutive blocks through length `k`, not arbitrary
  coordinate sets.  At `epsilon=0,1` the Markov order is exactly `k`; infinite
  Markov order is only for `0<epsilon<1`, `epsilon != 1/2`.
- P80 retains the degenerate but consistent `n=1` identity case and states
  that every *nonrecurrent* state has transient depth one.
- P81 claims uniqueness only inside the `O(d)`-invariant homogeneous
  one-step Markov class.  The Funk spectrum is cited prior art.  The open-ball
  covering proof now includes the strict spherical triangle argument.
