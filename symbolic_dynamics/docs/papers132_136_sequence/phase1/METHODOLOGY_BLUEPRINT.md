# Methodology blueprint — P132–P136

## Design

This is deductive mathematics supported by exact computational
falsification.  Four lanes independently freeze literal maps before fitting
theorems: root/cross-family, algebraic/arithmetic,
combinatorial/geometric, and stochastic/local rewrite.

## Stage 1 protocol

1. Inventory the P1–P131 carrier/update/proof interfaces.
2. Audit at least 27 systems per lane, recording carrier, map, observable,
   exact range, assertion count, signal, and disposition.
3. Promote at most three per lane to focused proof spikes.
4. Search direct primary owners for every promoted interface; imported tools
   and enumerations receive zero contribution credit.
5. Apply pairwise and historical collision firewalls.
6. Run two devil's-advocate checkpoints and freeze exactly five contracts.

## Stage 2 protocol

For each contract, implement a deterministic paper-local verifier and
canonical transcript, write an anonymous short paper, run a pre-review
integrity gate, obtain two hostile reviews, repair every critical/major issue,
and rerun final integrity from fresh inputs.  Final PDFs must reproduce in an
isolated stable LaTeX/BibTeX build (including any final label-settling pass)
and pass page, font, text, metadata, and
manifest checks.

## Validity boundaries

- Bounded enumeration cannot establish an all-parameter claim.
- A bounded owner non-hit cannot establish novelty or priority.
- Generic finite-map, linear-algebra, transfer-matrix, generating-function,
  and stopping-time machinery is background unless the literal system forces
  a new theorem after subtraction.
- Negative pilots remain versioned so replacement does not erase selection
  history.

The academic research workflow supplies the staged integrity and independent
review gates.  The user's standing authorization removes intermediate pauses,
not those gates.  Cross-model upload is disabled; unpublished material remains
local.
