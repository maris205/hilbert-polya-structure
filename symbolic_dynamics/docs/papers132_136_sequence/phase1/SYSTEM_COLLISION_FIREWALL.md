## Conjugacy and mechanism checks

- P132's one-step coordinate predicate is directly present in dynamic prefix
  majority queries, but the repeated complete-vector feedback is not replaced
  by that data-structure problem.  The manuscript must say this explicitly.
- P134 must distinguish `beta(beta(w))`, recomputing a whole border table on
  the previous table as an integer word, from traversing failure links
  `beta^j[i]` within the original word.  Confusing these kills the claim.
- P135 cannot count Britnell–Wildon's centralizer-orbit partition or
  Skuratovskii's wreath commutator computation as new.  Its admissible claim is
  only the induced iterated partition system after those facts are imported.
- P136 is literally a specialization of the Pitt/Bar-Yehuda random cover
  process.  Only the exact sunflower endpoint/discrete-selection-count
  conjunction survives;
  no algorithmic invention or approximation claim is allowed.
- The inversion-rank system was removed because an exact 2026 owner matched
  the operator, theorems, and witness.  This demonstrates that literal
  ownership overrides an otherwise strong internal signal.
