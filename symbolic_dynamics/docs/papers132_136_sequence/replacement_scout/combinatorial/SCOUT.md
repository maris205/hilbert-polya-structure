## 3. FM1 theorem contract: least-cycle opening

### 3.1 Literal map and normal form

Let `f:[n]->[n]`.  Every weak component of its functional digraph consists of
one directed cycle with rooted in-trees attached.  If any cycle has length
greater than one, let `m` be the least label on the union of all such cycles
and define

```text
Phi(f)(m)=m,                 Phi(f)(v)=f(v) for v!=m.
```

The changed component becomes a rooted tree with loop-root `m`; no other
component changes.  Therefore one nontrivial cyclic component disappears at
each round and none can be created.

Write `c_+(f)` for the number of cycles of length at least two.  Then

```text
depth(f)=c_+(f),                         max depth=floor(n/2).
```

The endpoint `E(f)` opens every original nontrivial cycle at its least label.
The fixed/recurrent set is the set of rooted forests encoded as endofunctions
whose cycles are all loops.  Thus

```text
|Fix(Phi_n)|=(n+1)^(n-1),
zeta_Phi_n(z)=(1-z)^(-(n+1)^(n-1)).
```

The least-label scheduler contributes no theorem credit: the component cuts
commute, and any scheduler eventually produces the same endpoint.  Its role
is only to make the literal one-step map unambiguous.

### 3.2 Every-target depth-fibre polynomial

Let `F` be a fixed target.  For each loop-root `r`, let `T_r` be its rooted
component and put

```text
a_r(F) = #{v in T_r\{r} : every vertex on the F-path v,...,F(v),r
                             other than r has label greater than r}.
```

Define the terminal depth-fibre polynomial

```text
B_F(u)=sum_{E(f)=F} u^depth(f).
```

Then the exact pointwise formula is

```text
B_F(u)=product_{r in roots(F)} (1+a_r(F) u).                 (FM1.1)
```

Indeed, within the component `T_r`, a source either already has the loop at
`r`, or it replaces that loop by `r->v`.  The latter closes precisely the
root path from `v` into a cycle.  The opening rule returns `F` exactly when
`r` is the least label on that cycle, which is the displayed path condition.
There are no other sources: changing any nonroot arc changes the terminal
tree, while an arc between target components cannot be restored by opening a
cycle.  The choices for distinct rooted components are independent, and each
changed root contributes one unit of depth.  This proves (FM1.1).

This is genuinely target-sensitive.  It is not a function only of component
sizes or root count.  It also yields the sharp largest terminal fibre.  If a
component has size `s`, then `1+a_r<=s`, with equality exactly when its root
is smaller than every other vertex in that component.  Consequently

```text
max_F |E^(-1)(F)| = I(n),
I(1)=1,
I(n)=3^(n/3)                         if n=0 mod 3,
     4*3^((n-4)/3)                  if n=1 mod 3 and n>=4,
     2*3^((n-2)/3)                  if n=2 mod 3.
```

This is the classical integer-break product, but its realization as the
largest pointwise basin follows from (FM1.1).  The maximizer is not claimed
unique.

### 3.3 Complete depth census

Let `T(z)` be the Cayley rooted-tree series, `T=z exp(T)`.  A mapping is a set
of components, and a component is a directed cycle of rooted trees.  Mark a
component whose cycle has length at least two by `u`.  The bivariate EGF is

```text
M(z,u)
 = exp(T(z) + u*(log(1/(1-T(z)))-T(z)))
 = exp((1-u)T(z))*(1-T(z))^(-u).                         (FM1.2)
```

Thus `n![z^n u^k]M(z,u)` is the exact depth-`k` layer.  The verifier checks
the same layer independently by choosing the cyclic set, choosing a
permutation on it with `k` nontrivial cycles, and attaching a rooted forest.

Two proof routes are ready:

1. the local inverse route proves (FM1.1), the endpoint, and the extremal
   fibre directly from root paths;
2. the species/Pruefer route proves (FM1.2), the recurrent census, and all
   aggregate depth layers independently.

## 4. FM2 theorem contract: leaf-to-loop dynamics

### 4.1 Literal map and endpoint

For `f:[n]->[n]`, call `v` a leaf when it has indegree zero.  If leaves exist,
take their least label `v` and set

```text
Psi(f)(v)=v,                 Psi(f)(x)=f(x) for x!=v.
```

Changing `v` removes its old outgoing edge and makes `v` a new loop.  In every
in-tree, vertices are processed from the leaves toward the cyclic core.  An
original cyclic vertex is never a leaf, and an original cycle is never
changed.  Hence

```text
depth(f)=n-|Cyc(f)|,
E(f)(v)=f(v) if v was cyclic in f, and E(f)(v)=v otherwise.
```

The maximum depth is `n-1`.  A state has no leaf exactly when all indegrees
are one, hence exactly when it is a permutation.  Therefore

```text
Fix(Psi_n)=S_n,              |Fix(Psi_n)|=n!,
zeta_Psi_n(z)=(1-z)^(-n!).
```

Again, choosing the least leaf is only a deterministic scheduler.  The
endpoint and depth are scheduler-independent; no credit is requested for
that fact.

### 4.2 Every permutation target and every depth

Fix a target permutation `sigma`.  Let `m=fix(sigma)` and `c=n-m`.  Define

```text
B_sigma(u)=sum_{E(f)=sigma} u^depth(f).
```

Then

```text
B_sigma(u)
 = 1 + sum_{k=1}^m binom(m,k)*(n-k)*n^(k-1) u^k.          (FM2.1)
```

To prove this, every nontrivial cycle of `sigma` is forced to be an original
cycle of `f`.  Among the `m` fixed points of `sigma`, choose `k` that were
noncyclic in `f`; the other `m-k` were already loop-roots.  The chosen `k`
vertices form a directed forest feeding into the specified root set
consisting of the `c` nonfixed cyclic vertices and the `m-k` source loops.
This root set has size `n-k`.  Cayley's fixed-root forest formula gives
`(n-k)n^(k-1)` forests.  The `k` noncyclic vertices are exactly the vertices
processed by the dynamics, proving both the coefficient and its depth mark.

At `u=1`, (FM2.1) simplifies to

```text
|E^(-1)(sigma)| = (c+1)*(n+1)^(m-1),                    (FM2.2)
```

with value one when `m=0`.  Thus the basin depends only on the fixed-point
count of the target.  The identity is the unique largest target and has
basin `(n+1)^(n-1)`.

The exact global layers are

```text
L(n,0)=n!,
L(n,k)=binom(n,n-k)*(n-k)!*(n-k)*n^(k-1),  1<=k<=n-1.   (FM2.3)
```

Here one chooses the `n-k` cyclic vertices, permutes them, and attaches a
forest rooted at them.  The verifier checks (FM2.1)--(FM2.3) for every one of
the 50,069 maps through `n=6`, not only aggregate totals.

Two proof routes are ready:

1. the chronological route proves that leaf-to-loop processing preserves the
   original cyclic core and uses the selected source loops to derive
   (FM2.1);
2. the static core/forest route classifies all sources of a permutation and
   obtains (FM2.2)--(FM2.3) from Cayley/Pruefer enumeration without following
   an orbit.

## 5. Important negative controls

### 5.1 HF1: why an all-time fibre theorem can still be zero-credit

Put `d(A)=A\{max A}` and `d(empty)=empty`.  HF1 is exactly the direct image
map `H -> d[H]` on the powerset of the Boolean lattice.  After `t` rounds,

```text
d^t(A)=empty                              if |A|<=t,
d^t(A)=A with its t largest elements removed otherwise.
```

For a target edge `B`, let `p_t(B)=|d^(-t)(B)|`.  Explicitly,

```text
p_t(empty)=sum_{j=0}^t binom(n,j),
p_t(B)=binom(n-1-max(B),t)                for B nonempty.
```

The element fibres of a function are disjoint.  Therefore, for every target
hypergraph `G`,

```text
|{H:d^t[H]=G}| = product_{B in G} (2^p_t(B)-1),           (HF1.1)
```

and the `t`-step image contains exactly `2^(2^(n-t))`
hypergraphs for `0<=t<=n`.  Also, the depth of a nonfixed `H` is its maximum
edge size, and the exact depth-`t` layer is

```text
2^(sum_{j=0}^t binom(n,j)) - 2^(sum_{j=0}^{t-1} binom(n,j)).
```

All of this is correct and exhaustively checked.  None is promoted because
(HF1.1) holds for the covariant powerset lift of **every** finite function:
to obtain a target subset, choose a nonempty subset independently from each
element fibre.  The Boolean maximum-deletion map only supplies easy values of
`p_t(B)`.  This is exactly the kind of generic theorem subtraction that killed
PM1 and GR1.
