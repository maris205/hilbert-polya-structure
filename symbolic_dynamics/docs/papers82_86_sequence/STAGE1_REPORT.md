# Stage 1 report — Papers 82–86

Result: **five early-signal theorem contracts selected**.

The round began with a cross-subclass pool and used two short exact probes as
the maximum patience budget.  Five systems survived because their decisive
phenomena appeared immediately:

1. a rank-two frozen-state transfer matrix in a shifted Fredkin network;
2. a consecutive-parameter recurrence transition in a Catalan loop shift;
3. a divisor-indexed Ramanujan period spectrum in a unitary Cayley shift;
4. a constructive chronology-collapse conjugacy for periodic alphabets;
5. finite-range dependence together with provably infinite Markov memory in
   a finite-field hidden product process.

The complete selection and kill rationale is in
`phase1/CANDIDATE_POOL_AND_KILL_LEDGER.md`.  Every selected contract has an
analytic proof target, a deterministic regression control, and an explicit
prior-owner firewall.  No GPU experiment was appropriate: all five questions
are exact symbolic/combinatorial problems.
