## Focused theorem contract — `BQC`

Fix integers `n >= 1` and `c >= 2`.  Work with labelled simple graphs on
`[n]={1,...,n}`, including isolated labels.  Put

```text
q_c(i) = floor((i-1)/c)+1.
```

For a graph `G`, define `Q_c(G)` by

```text
{r,s} in E(Q_c(G)), r<s
iff some {u,v} in E(G) has {q_c(u),q_c(v)}={r,s}.
```

Edges whose endpoints coalesce become loops and are omitted.  Labels larger
than `ceil(n/c)` remain isolated, so this is a self-map of the fixed finite
carrier.

For `t >= 0`, set

```text
m_t = ceil(n/c^t),
B_r(t) = {i in [n] : floor((i-1)/c^t)+1=r},
s_r(t) = |B_r(t)|.
```

The proposed paper gate is the following conjunction.

1. **All-time and sharp temporal theorem.**  For every `t`, `Q_c^t(G)` is
   obtained by applying `q_c^t(i)=floor((i-1)/c^t)+1` to both endpoints of
   every original edge, OR-ing duplicates, and deleting loops.  Thus, with
   `kappa_c(u,v)=min{t:q_c^t(u)=q_c^t(v)}`,

   ```text
   tau(G) = 0                                      if E(G)=empty,
            max_{uv in E(G)} kappa_c(u,v)          otherwise.
   ```

   The unique recurrent state is the empty graph and the global height is
   exactly `ceil(log_c n)`: the edge `{1,n}` realizes equality.

2. **Complete image theorem.**  The time-`t` image consists exactly of all
   graphs whose nonisolated support is contained in `[m_t]`.  Hence

   ```text
   |im(Q_c^t)| = 2^binom(m_t,2).
   ```

3. **Every-target, every-weight fibre theorem.**  If a target `H` has an edge
   incident with a label larger than `m_t`, its fibre is empty.  Otherwise the
   source-edge generating polynomial is

   ```text
   sum_{G: Q_c^t(G)=H} z^|E(G)|
     = (1+z)^[sum_r binom(s_r(t),2)]
       product_{{r,s} in E(H)} ((1+z)^[s_r(t)s_s(t)]-1).
   ```

   In particular, at `z=1`,

   ```text
   |(Q_c^t)^(-1)(H)|
     = 2^[sum_r binom(s_r(t),2)]
       product_{{r,s} in E(H)} (2^[s_r(t)s_s(t)]-1).
   ```

   This also gives every exact source-edge-weight coefficient.  Among
   supported targets the empty target minimizes the fibre and the complete
   target maximizes it.

### Proof engine

Nested consecutive blocks prove the semigroup law: a quotient by `c` and then
by `c` is the quotient by `c^2`, and induction gives time `t`.  An original
edge remains visible exactly until its two endpoint labels enter one block,
which proves the pointwise and extremal clocks.  For a supported target, source
edges split independently into disjoint bins: internal-block edges are free;
each target edge requires a nonempty subset of its `s_r s_s` cross edges; each
target nonedge requires none.  Multiplication gives the polynomial.  These are
two genuinely independent theorem axes (coalescence time and target-resolved
inverse atlas), even though both are elementary.

### Boundary attacks frozen into the contract

- At `t=0`, every block is a singleton and the polynomial is `z^|E(H)|`, so
  the identity fibre is one graph.
- At `n=1`, the height is zero and the only state is already empty.
- When `t >= ceil(log_c n)`, there is one block; the only supported target is
  empty and its polynomial is `(1+z)^binom(n,2)`.
- The last block may have size strictly less than `c^t`; all formulas use the
  actual `s_r(t)`, not a false equal-block simplification.
- Any target edge outside `[m_t]` has fibre zero.

## Collision decision

`BQC` is not a graph-pruning, closure, local-complement, line-graph, graph-power,
or data-dependent core process.  Its closest internal paper is P148, but P148
contracts alternating levels of a plane rooted tree and promotes ordered child
blocks; its inverse is a recursive tree expansion.  `BQC` instead applies a
fixed arithmetic partition to arbitrary labelled graphs and its inverse bins
independent edge choices.  P143's quotient is a target preorder quotient used
inside an embedding count, not an iterated graph quotient.  No main theorem
transfers from either paper.

The external risk is still real: quotient graphs are classical, and the
remaining formulas are short consequences of a fixed nested partition.  The
proper status is therefore

```text
ONE_FOCUSED_AMBER / NO_SECOND_SURVIVOR / HOLD_EXTERNAL.
```

Promotion requires a deeper exact-map owner search and a hostile assessment of
whether the weighted fibre atlas is enough residual content for a short paper.
The other fifteen systems are not silent reserves.
