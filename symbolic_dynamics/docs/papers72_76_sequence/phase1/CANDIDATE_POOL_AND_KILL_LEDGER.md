# Candidate pool and kill ledger

## Selection rule

A candidate survives only if it supplies a distinct primary system, a closed
theorem after owner subtraction, an explicit proof mechanism, and a finite
hostile check.  Five superficial variations of one construction do not count
as a five-paper round.

## Selected candidates

| Slot | System | Decisive clue | Why it survived |
|---:|---|---|---|
| P72 | one-vertex 2-graph shift | commute one red letter across a length-`a` blue boundary | turns a two-dimensional torus closure condition into a finite one-step transfer operator |
| P73 | planar critical-Jordan substitution | the `B` array is a pointwise lower envelope and `C` plus one site is an upper envelope | upgrades complete-supertile `R log R` growth to an exact all-translates rectangle theorem |
| P74 | Dyck--Motzkin shift | a context sees only the two exposed stacks of the polycyclic normal form | gives complete finite sequences, not merely entropy rates |
| P75 | RACG geodesic shift | join-factor support is monotone in the clique automaton | yields the entire recurrent graph, MME multiplicity, entropy, and zeta at once |
| P76 | four-IET natural coding | every prescribed itinerary is an intersection of translated branch intervals | converts finite language variation into exact rational polyhedral geometry |

## Reserves and rejected directions

| Candidate | Disposition | Reason |
|---|---|---|
| higher-form closed-cochain `Z^d` SFT | `COOL_INTERNAL` | the rank/cocycle counting engine is too close to P67 and P69 despite a viable formula |
| binary circle `Z^d` coding | `KILL_INTERNAL_P60` | rotation/Sturmian geometry duplicates the P60 neighborhood |
| bounded-stack Dyck sofic approximants | `RESERVE` | the entropy asymptotic is promising, but selecting it beside P74 would spend two seats on one system cluster |
| polygonal billiard finite-language chambers | `RESERVE_PROOF_BURDEN` | semialgebraic elimination is viable, but finite-segment versus full bounce-language realization needs a longer bridge and overlaps P76's parameter-cell mechanism |
| Arnoux--Rauzy directive-prefix threshold | `RESERVE_UNCLOSED` | strong finite evidence exists, but repeated directive letters still require a complete sharp-threshold proof |
| sandpile/recurrent chip-firing shift | `COOL_INTERNAL` | the available periodic-completion statement approaches P58/P65's mechanism |
| rank-two Bratteli--Vershik/fusion cone | `KILL_OWNER` | finite-rank invariant-measure theory owns the contraction core; no independent language theorem was closed |
| generic substitution discrepancy | `KILL_OWNER_OR_TOO_BROAD` | general spectral/Jordan theory is owned; only the explicit P73 envelope theorem survives |
| Dyck zeta or periodic-point formulas | `KILL_OWNER` | existing Markov-Dyck/Motzkin theory owns those quantities; P74 is restricted to exact context sequences |
| three-IET/Sturmian coding | `KILL_INTERNAL_P60` | system and arithmetic mechanism are too close to an existing route-A paper; P76 fixes four intervals |

## Negative controls retained

- P72 explicitly fixes one four-cycle; not every four-cycle has the same
  rectangular profile.
- P74 rejects the tempting closing-symbol histogram formula: at length two
  with one close, matched and unmatched normal forms already contribute
  different bins.
- P76 claims only that a language change must cross a collapse wall; it does
  not claim every formal arrangement wall changes the language.
