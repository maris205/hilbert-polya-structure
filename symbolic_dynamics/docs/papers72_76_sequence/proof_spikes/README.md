# P72--P76 proof-spike register

This directory records the batch-level role of the five deterministic controls.
They are finite proof-regression checks, not experiments and not substitutes for
the general proofs in the manuscripts.

| Slot | Independent finite gate |
|---:|---|
| P72 | all 24 binary commutation bijections and all rectangular periods up to 3, with an edge-level torus enumerator independent of the transfer implementation |
| P73 | exact Jordan identities through level 12 and a substitution-closed, phase-disjoint 3-by-3 recognizability certificate |
| P74 | exhaustive normal-form counts for Dyck and Motzkin families with two and three bracket types |
| P75 | every graph in the NetworkX atlas through seven vertices, including local irreducibility and the predicted recurrent-component count |
| P76 | exact-rational cylinder inequalities versus an independent discontinuity-preimage partition for three length vectors through word length six |

The source commands and immutable outputs are stored in the corresponding
paper packages.
