# Methodology blueprint -- P127--P131

## Research paradigm and method

This is a theoretical-mathematical study with exact computational
falsification.  The research question asks for existence and classification
of all-parameter temporal laws, so the primary method is deductive proof.
Exhaustive finite enumeration is used to reject conjectures, locate edge cases,
and independently check formulas; it is not used to promote a conjecture into
a theorem.

## Data strategy

The input data are generated from literal definitions in versioned pilot
programs.  Each lane records every admitted system, carrier bounds, exact
arithmetic used, assertions executed, canonical stdout, signal, and kill or
promotion decision.  Literature data are owner-direct primary sources located
for the interfaces of promoted candidates; secondary descriptions do not
establish ownership or theorem content.

## Analytical framework

1. Freeze the P1--P126 collision map and define at least 22 systems per lane.
2. Enumerate bounded slices using integer or rational arithmetic and test
   explicit falsification targets.
3. Promote at most three candidates per lane; write a prospective theorem
   contract before expanding the computation.
4. Search direct-owner interfaces and give all imported machinery zero credit.
5. Require two-route proof support: a deductive derivation plus a structurally
   different control or independent implementation.
6. Freeze exactly five mutually separated contracts, then build paper-local
   deterministic verifiers and anonymous manuscripts.
7. Run two independent hostile reviews, repair all critical/major defects, and
   perform isolated PDF and manifest QA.

## Validity criteria

| criterion | design control |
|---|---|
| Construct validity | carrier and literal update fixed before theorem fitting |
| Internal validity | proofs separated from finite pilots; edge cases stated |
| Error detection | canonical outputs, independent controls, hostile review |
| Portfolio validity | direct-owner and P1--P126 collision ledgers |
| Reproducibility | exact code, assertion totals, hashes, isolated builds |
| Claim calibration | bounded non-hits and zero-credit inputs labelled explicitly |

## Limitations by design

- The owner search can bound a queried interface but cannot certify global
  novelty; external novelty and priority therefore remain on hold.
- Exhaustive checks cover declared ranges only.  Every all-parameter statement
  must have a proof independent of those ranges.
- Breadth creates selection pressure toward simple laws.  The permanent kill
  ledger preserves negative evidence and prevents silent theorem fitting.

## Ethics, reporting, and preregistration

No human subjects, personal data, intervention, or empirical population are
involved.  Human-subjects administration is not applicable.  No EQUATOR
guideline is applicable to a self-contained theorem note.  Preregistration is
not required for this theoretical exploratory round; the carrier/update freeze,
canonical pilots, and theorem contracts serve as the internal anti-drift audit.

Cross-model review is unavailable because no external-provider consent was
requested; internal independent reviewers are used instead.
