## 2. From-scratch subgroup and normalizer derivation

Write

```text
G_n=D_(2n)=<r,s | r^n=s^2=1, srs=r^(-1)>,  n>=3,
C=<r>.
```

### 2.1 Complete subgroup carrier

If `H<=G_n` lies in `C`, cyclicity gives one and only one divisor `d|n` with

```text
H=R_d=<r^d>.
```

Otherwise, `H` contains a reflection `r^j s`.  Its rotation part is
`H intersect C=<r^d>` for a unique `d|n`.  Multiplication by the chosen
reflection shows that the nonrotation coset is exactly
`<r^d> r^j s`, hence

```text
H=H_(d,j)=<r^d,r^j s>.
```

The residue `j` is unique modulo `d`; taking `0<=j<d` gives a unique key.
Thus the complete carrier is

```text
{R_d:d|n} disjoint_union {H_(d,j):d|n,0<=j<d},
```

with `tau(n)+sigma(n)` states.  This classification and count are classical
owner material and are not part of the residual claim.

### 2.2 Complete normalizer formula

Every `R_d` is invariant under `r -> r^(-1)`, so it is normal in `G_n` and

```text
N(R_d)=G_n=H_(1,0).                                       (2.1)
```

For a dihedral subgroup, conjugation by `r^u` sends

```text
r^j s -> r^(j+2u)s.
```

It preserves `H_(d,j)` exactly when `d|2u`.  The normalizing rotations are
therefore generated by `r^(d/gcd(d,2))`.  A reflection normalizer differs
from an element of `H_(d,j)` by such a normalizing rotation, so adjoining
`r^j s` gives the whole normalizer:

```text
N(H_(d,j))
 =H_(d/gcd(d,2), j mod (d/gcd(d,2))).                     (2.2)
```

This proof also handles `d=1`.  Formula (2.2) is an exact parity halving, not
merely an isomorphism-type statement.  Direct primary owners of this one-step
rule are recorded in Section 8, so (2.1)--(2.2) receive zero credit.

## 3. Iteration, forest, and temporal formulas

Put `n=2^a m`, with `m` odd, and write `d=2^k e`, `e|m`.  Repeated use of
(2.2) gives, for every `t>=0`,

```text
N^t(H_(2^k e,j))
 =H_(2^max(k-t,0) e,
      j mod (2^max(k-t,0) e)).                            (3.1)
```

For each odd divisor `e|m` and residue `j mod e`, the fixed root `H_(e,j)`
has at level `k` the `2^k` lifts

```text
H_(2^k e, j+l e),  0<=l<2^k.
```

Each level-`k` vertex with `k<a` has exactly two children at level `k+1`.
Therefore the dihedral vertices form `sigma(m)` full binary inverse trees of
height `a`.  Every rotation vertex is a source leaf and maps in one step to
the distinguished root `H_(1,0)=G_n`.

It follows immediately that

```text
depth(R_d)=1,
depth(H_(d,j))=v2(d),
#fixed roots=sigma(m),
#dihedral vertices at depth k=2^k sigma(m), 1<=k<=a.
```

Hence the depth polynomial is

```text
D_n(z)=sigma(m)+tau(n)z
       +sigma(m) sum_(k=1)^a 2^k z^k.                    (3.2)
```

Every orbit reaches a fixed root, so all cycles are fixed points and

```text
#Fix(N^t)=sigma(m),  t>=1.
```

The zeta factor `(1-z)^(-sigma(m))` is generic finite-map bookkeeping and is
not a residual contribution.

## 4. Images and every-target fibres for all time

After `t>=1` steps, the image contains exactly levels
`0,...,max(a-t,0)` in every binary tree.  Therefore

```text
|im(N^t)|=sigma(m)(2^(max(a-t,0)+1)-1).                   (4.1)
```

No positive iterate lands on a rotation subgroup.  Let a dihedral target be
`H_(2^k e,j)`, with `e` odd.

If `k>=1`, a source must lie exactly `t` levels above it.  Its reflection
residue is one of the `2^t` lifts modulo `2^(k+t)e`, provided that level
exists.  Thus

```text
|(N^t)^(-1)(H_(2^k e,j))|
 =2^t  if k+t<=a,
 =0    if k+t>a.                                         (4.2)
```

For a fixed root, every level through `min(t,a)` has entered.  The geometric
sum contributes `2^(min(t,a)+1)-1`.  In addition, all `tau(n)` rotations feed
the distinguished root at every positive time:

```text
|(N^t)^(-1)(H_(e,j))|
 =2^(min(t,a)+1)-1+tau(n)[(e,j)=(1,0)].                  (4.3)
```

Summing (4.2)--(4.3) over all targets gives
`tau(n)+sigma(n)` at every `t`; targets outside (4.1) have fibre zero.  This
independently closes the claimed all-time fibre atlas.

A second from-scratch literal program, again importing none of the project
verifier, checked the depth multiset, image size, every individual target
fibre, source mass, and fixed iterates for every `3<=n<=120` and every audited
time `1<=t<=a+3`.  Its terminal transcript was

```text

DEPTH_IMAGE_ALL_TARGET_FIBRE_FIXED_ITERATE PASS
```

This is bounded exact pressure; equations (3.1) and (4.1)--(4.3), rather than
the scan, establish the all-parameter quantifiers.

## 5. Hostile audit of the unlabelled-graph signature

Define

```text
S(n)=(a,sigma(m),tau(n)),  n=2^a m, m odd.                (5.1)
```

### 5.1 Sufficiency

Equal signatures give the same number of fixed roots, the same full binary
tree of height `a` at each root, and the same number of extra source leaves at
the distinguished root.  Match the distinguished roots, match the other
roots arbitrarily, preserve binary lift positions, and match the `tau(n)`
rotation leaves.  This is a graph conjugacy.

### 5.2 Necessity, including the one-root repair

The unlabelled directed graph recovers `sigma(m)` as its number of fixed
vertices.

Let `L` be the maximum tail.  If `L>=2`, then `a=L`.  If `L=1`, only `a=0`
and `a=1` are possible.  Since `n>=3`, both cases have `m>1`, hence more than
one fixed root.  For `a=0`, exactly one fixed root has nonfixed predecessors;
for `a=1`, every fixed root has two binary-tree predecessors and the
distinguished root has additional rotation predecessors.  Thus the graph
distinguishes `a=0` from `a=1`.

Once `a` and `sigma(m)` are known, the number of dihedral vertices is

```text
sigma(m)(1+2+...+2^a)=sigma(m)(2^(a+1)-1).
```

The remaining vertices are exactly the rotations, so

```text
tau(n)=|V|-sigma(m)(2^(a+1)-1).                           (5.2)
```

Unlike the old excess-indegree sentence, (5.2) remains valid when `m=1` and
there is only one fixed root.  Consequently, for all `n,q>=3`,

```text
graph(N on Sub(D_(2n))) ~= graph(N on Sub(D_(2q)))
iff S(n)=S(q).                                             (5.3)
```

## 6. Explicit `33/35` graph conjugacy

Both parameters are odd and satisfy

```text
sigma(33)=48=sigma(35),  tau(33)=4=tau(35).
```

All 48 dihedral vertices are fixed roots.  Match `H_(1,0)` to `H_(1,0)` and
then match the remaining `(d,j)` pairs in lexicographic order.  Match rotation
leaves in divisor order:

```text
R_1  -> R_1,
R_3  -> R_5,
R_11 -> R_7,
R_33 -> R_35.
```

Every dihedral vertex is fixed and every rotation maps to `H_(1,0)`, so this
bijection commutes with the update.  The independent literal-map check gave

```text

PHI_33_35 domain True codomain True injective True commutes True
```

Thus the collision is a genuine unlabelled graph conjugacy, not merely equal
state, depth, or degree counts.

- `subgroup_entries` constructs and deduplicates the theorem's claimed

- The verifier tests sufficiency on four equal-signature pairs but contains no

- The printed profile hash covers deterministic summary lines; it is not a
