# Problem anchor — P152–P156

**Route:** A.  **Batch:** exactly five anonymous theorem notes.  **External
status:** `HOLD_EXTERNAL`.

## Anchored research question

Outside the literal systems and proof mechanisms already occupied by P1–P151,
which five genuinely different finite, absorbing, or exactly soluble random
dynamical systems show an early exact signal that can be promoted to a clean
all-parameter temporal theorem together with an independent structural,
inverse, fibre, extremal, or distributional theorem after direct-owner
subtraction?

The aim is breadth across dynamical subclasses.  A candidate that needs local
patching but never develops a strong small-instance silhouette is killed in
favour of a different system form.

## Operational subquestions

1. Which literal updates already display a stable, non-generic clock, image,
   periodic, endpoint, or law profile in exact small cases?
2. Which observed profiles admit deductive all-parameter proofs and a
   paper-local falsification-pressure verifier?
3. Which theorem conjunctions remain substantive after the direct owners and
   every mechanism-level collision with P1–P151 receive zero credit?

## Progress threshold

A selected paper must contain all of the following:

1. a literal and mathematically natural dynamical system, not merely a new
   carrier for an occupied map;
2. an all-parameter deductive theorem rather than an enumerative extrapolation;
3. a sharp temporal, recurrent, terminal, image, or endpoint statement;
4. an independent inverse, fibre, structural, extremal, identifiability, or
   distributional result;
5. a deterministic exact verifier with a frozen transcript; and
6. a self-contained anonymous short manuscript with explicit owner
   subtraction, limitations, and external-hold boundaries.

A one-step closure, generic finite-map spectrum, parameter sweep, known
algorithm dynamically relabelled, or isolated numerical pattern is below the
threshold.

## Design and evidence boundary

This is exploratory pure-mathematics research.  Finite computation supplies
counterexample pressure and checks derived identities; it is never used as a
proof.  Owner search uses primary or authoritative sources.  A bounded search
non-hit is recorded only as a search result, never as novelty, priority,
authorship, or release clearance.

## Batch separation rule

Freeze exactly five systems whose carrier, literal update, temporal
silhouette, second theorem axis, and main proof engine are pairwise separated.
Automatic replacement is required whenever a profile is weak, owner-saturated,
or collision-equivalent to P1–P151.
