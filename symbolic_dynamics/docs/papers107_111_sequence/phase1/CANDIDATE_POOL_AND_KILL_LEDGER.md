## Selection principle actually applied

Large assertion counts did not force selection.  A candidate could pass every
finite test and still be rejected by owner subtraction or the internal
firewall.  Conversely, no selected theorem is inferred from enumeration:
each contract contains an explicit infinite-family proof obligation and a
second control route with a different failure mode.
