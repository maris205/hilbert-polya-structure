## Historical P1–P106 boundary

The repository already occupies or explicitly rejects broad classes of
symbolic shifts, finite-type and sofic systems, substitution and S-adic
systems, graph/hom/relation shifts, cellular automata, random reset and stack
cocycles, affine/power-map functional graphs, finite-field torsion windows,
sumset and code closures, sublattice shears, valuation digit erasure,
cap–floor synchronization, group-algebra norms, double adjugation, random
monomial matrices, permutation cycle pruning, and MIS polarity.  Shared
background is permitted only when phase space, update, headline invariant,
and proof engine are all separated.

The nearest historical neighbors are:

- P100 for P107 because both use valuations; P107 alternates an annihilator
  complement and ideal power, has a universal two-cycle and resonance, and
  never erases a least digit.
- P83/P89/P101 for P108 because Fibonacci or capping vocabulary appears;
  P108 is a deterministic saturated second-order recurrence with exact
  lattice-point transient layers, not a renewal shift or random map product.
- P73/P99/P103 for P109 because Jordan, subspace, or matrix language appears;
  P109 evolves the full subspace lattice by the image of one nilpotent
  operator and counts a time/rank kernel.
- P94/P105/P106 for P110 because partitions, cycles, or lattices appear;
  P110 coarsens an equivalence relation by translated joins and never deletes
  labels or applies a polarity.
- P70/P93/P99/P104 for P111 because Heisenberg, cocycle, unipotent, or random
  matrix motifs appear; P111 is a positive two-generator semigroup whose
  central word-area has polynomial scale and `n^2` pressure.
