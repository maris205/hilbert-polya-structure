# Ra-1-arithmetic-symbolic-dynamics

This is the Route-A, roadmap-phase-1 project for arithmetic symbolic
dynamics.  The final name component is the actual project name; `project` is
not a literal suffix.

All generated research outputs live under `papers/`.  Each entry is a complete
paper project containing the shareable PDF, modular LaTeX, proofs, experiments
or theorem packages, machine-readable results, evaluation records, review
history, and a paper-local manifest.

The concise conclusions and direct PDF links live in the
[umbrella README](../README.md).  Shared inputs remain outside this project:

- [Route-A evaluator](../skills/route-a-evaluator.md);
- [Route-B evaluator](../skills/route-b-evaluator.md);
- [prior-work corpus guide](../docs/prior_work/README.md).
