# Paper Project Index

Each directory below is a self-contained paper project with a frozen question,
evidence boundary, stop rule, shareable `main.pdf`, source, supporting research
artifacts, and review history.

## Status vocabulary

- `PLANNED`: claims and tests are specified, but no result exists.
- `ACTIVE`: frozen work is currently being executed.
- `COMPLETE / FROZEN`: results and evaluations are archived; changes are
  limited to provenance or correctness fixes.
- `STOP_SCOPED`: the preregistered mechanism fails an adversarial or
  identifiability gate.

### 02 — Wheel-sieve stationarization obstructions

This paper project isolates the strongest surviving arithmetic lead, the
endogenous wheel-sieve recursion.  It proves that strict extensions,
forward-well-founded strong-bisimulation quotients, representative-exact
clock-labelled quotients, and finite-local exact-clock recodings cannot supply
the missing periodic dynamics in their stated classes.  The remaining infinite
observational recoding is not yet source-locked.  No new candidate ID or
Route-B permission exists.
