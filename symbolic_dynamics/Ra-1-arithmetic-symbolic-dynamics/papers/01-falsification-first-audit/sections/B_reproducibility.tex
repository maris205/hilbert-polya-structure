\section{Reproducibility and Evidence Ledger}
\label{app:reproducibility}

\subsection{Frozen commands}

All six evaluator records bind the experiment code to the full source commit
recorded in the accompanying test report (prefix \texttt{7c059754141b}).
The relocation and paper generation do not alter that experiment-code
provenance.  A fresh frozen
rerun from the Stage-01 root used
\begin{verbatim}
python -m pytest -q
\end{verbatim}
and returned \(29/29\) passing tests.  The stage-manifest entry for the test
report binds the command, output, and Python/package versions.

From the Stage-01 root, the four experiment entry points are:
\begin{verbatim}
python finite_state_arithmetic_skeleton/experiments/run_session4_core.py
bash farey_gauss_transfer/experiments/run.sh
bash wheel_sieve_level_shift/experiments/run.sh
bash knauf_spin_chain_audit/experiments/run.sh
\end{verbatim}
The first command runs the \candidate{01}--\candidate{03} core.  Candidate
directories retain their frozen configurations, run logs, machine-readable
results, and tests.

From the paper directory, regenerate all paper figures and the candidate table
with:
\begin{verbatim}
python figures/generate_all.py
\end{verbatim}
The figure scripts resolve the Stage-01 root from their own file locations.
They read YAML, CSV, and JSON inputs and fail if cross-format summary fields do
not agree.
