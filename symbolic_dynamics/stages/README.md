# Research Stage Lifecycle

Each stage is a self-contained research unit with a frozen question, evidence
boundary, and stop rule.

## Status vocabulary

- `PLANNED`: claims and tests are specified, but no candidate result exists.
- `ACTIVE`: frozen work is currently being executed.
- `COMPLETE / FROZEN`: results and evaluations are archived; changes are
  limited to provenance or correctness fixes.
- `STOP_SCOPED`: the preregistered mechanism fails an adversarial or
  identifiability gate.

This stage isolates the strongest surviving arithmetic lead, the endogenous
wheel-sieve recursion.  It proves that strict extensions, finite strong
bisimulation quotients, and state-class exact-clock quotients cannot supply
the missing periodic dynamics.  The live branch is an infinite observational
recoding whose source lock is still incomplete.  No new candidate ID or
Route-B permission exists.
