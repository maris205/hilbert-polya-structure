\section{Finite-coefficient relation-saturation trilemma}
\label{sec:theorem}

\begin{theorem}[Finite-coefficient saturation]
\label{thm:saturation}
Fix $r\ge2$, the unquotiented affine Hashimoto shift, the unit transition
marker $z$, the damping in \cref{eq:matrix-operator}, and finite-rank
transports satisfying \cref{eq:inverse-transport,eq:uniform-transport}.
\begin{enumerate}
  \item \emph{Ordinary branch.}  No primitive orbit with invertible holonomy
  has a trivial complete Euler factor.
  \item \emph{Flat graded branch.}  If the coefficients descend to the filled
  Cayley $2$-complex, relation-factor cancellation occurs only at balanced
  parity; balanced parity cancels every closed orbit.
  \item \emph{Non-flat graded branch.}  Cancelling each translated defining
  cell, its free-group conjugates, and every repetition does not imply
  cancellation of mixed cell products.  The frozen shear pair cancels the
  direct affine relator but has a primitive mixed word with supertrace
  $-4r^4(r-1)$.  If cancellation is strengthened to every finite mixed
  product of conjugated cells and inverses, it applies to every closed Cayley
  word, and $\Zgr(z)=1$.
\end{enumerate}
Consequently this coefficient class cannot erase the complete affine relation
ledger while retaining a nonzero primitive arithmetic sector on the same
object.
\end{theorem}

The clauses have separate dependencies.  The ordinary branch uses only
finite-dimensional determinant algebra.  The flat branch uses the inherited
contractibility theorem.  The direct-pass/mixed-fail statement uses exact
$2\times2$ multiplication.  Complete saturation uses only the presentation
kernel as a normal closure.  The finite audit proves none of these
infinite-scope statements.

\begin{corollary}[No first-trace escape]
\label{cor:first-trace}
The condition $\Tr W=0$ does not delete a primitive factor.  For
\[
  J=\begin{pmatrix}0&-1\\1&0\end{pmatrix},
  \qquad \Tr J=0,
\]
one has $\Tr(J^2)=-2$ and $\det(I-tJ)=1+t^2$.  A factor decision must include
every repetition.
\end{corollary}

\begin{corollary}[Nilpotent transport changes category]
\label{cor:nilpotent}
The matrix $N=\left(\begin{smallmatrix}0&1\\0&0\end{smallmatrix}\right)$
satisfies $\Tr(N^m)=0$ for all $m\ge1$ and $\det(I-tN)=1$, but $N$ is not
invertible.  It is an endomorphism weight or automaton transition, not local
parallel transport.
\end{corollary}

\begin{corollary}[Flatness has no selective branch]
\label{cor:flat}
Let the parity ranks be $d_+$ and $d_-$.  On the filled contractible Cayley
complex, every closed holonomy is identity up to gauge, so a graded primitive
factor is $(1-t)^{d_--d_+}$.  Unequal ranks retain every factor; equal ranks
cancel every factor.
\end{corollary}

The theorem does not infer mixed-product cancellation from individual-cell
cancellation.  That implication is false, and the explicit shear family below
is its counterexample.  The terminal conclusion instead says that if mixed
cancellation is imposed for the entire normal closure, then the target class
is already the whole closed ledger.
