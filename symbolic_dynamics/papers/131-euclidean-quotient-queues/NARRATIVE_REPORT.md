# Narrative report — P131

The initial proof spike found a sharp linear transient and fibres of size at
most two.  The hostile gate then exposed two issues that materially changed
the paper.  First, digit words `[a_1;...]` with all displayed entries positive
do not represent all positive rationals.  The final carrier is therefore the
honest half-level `0<q<1`, written `[0;a_1,...,a_k]`.  Second, the digit model
is literally a restricted composition carrier immediately after P126.  A
rational name alone cannot supply separation.

Hostile Review A correctly observed that the first path subsection still
compressed the path to quotient lengths before comparing the update, so it
was not an independent engine.  Round 1 now defines a literal self-map `Psi`
on normalized `L/R` strings: it moves the first constant block, complements
the remaining symbols to renormalize at `L`, and either appends the moved
block or absorbs a terminal equality symbol.  The paper proves the full
string identity `E Phi = Psi E`, then derives singleton-block absorption and
both inverse strings without invoking the digit recurrence.  The verifier
checks these full strings, not only run-length tuples.  This route is not
used to claim Stern--Brocot coding; that infrastructure is explicitly zero
credit.

The residual remains compact but concrete: an exact terminal decoder, every
depth layer, and every pointwise one-step fibre for a natural Euclidean
quotient queue.  Necklace counts and divisor fixed counts are demoted to
classical corollaries.  The result is not advertised as a new class of
continued-fraction transformations, and bounded owner non-hits are not
novelty evidence.

The same review forced the internal subtraction into the manuscript itself:
P117 and P122 are zero-credit presentation/mechanism ceilings, and P126 is
acknowledged as a literal composition-carrier collision under
`a_k -> a_k-1`.  The residual is permitted only because the raw Euclidean
path engine is now complete and the level maps have incompatible temporal
structures for every `N>=4`.  Their finite functional graphs at `N=2,3` are
isomorphic, and the manuscript now states that exception explicitly.
