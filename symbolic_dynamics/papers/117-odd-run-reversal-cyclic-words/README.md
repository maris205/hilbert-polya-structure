# P117 — odd-run reversal on labelled cyclic binary words

Status: anonymous internal manuscript; external release, novelty, priority,
and submission remain HOLD.

The paper studies one specified parallel rule: every bit in every odd-length
cyclic run is flipped.  It proves the exact recurrent set, fixed and
two-cycle counts, finite zeta function, and the sharp maximum preperiod for
every word length.  The odd and even clocks are controlled by different
arguments: run coalescence and a boundary-parity cost eroder.

Primary artifacts:

- main.tex and references.bib: anonymous manuscript source;
- main.pdf: settled author PDF;
- PAPER_PLAN.md and NARRATIVE_REPORT.md: frozen claim and story contracts;
- CLAIMS_EVIDENCE.md and CONTROL_RESULTS.md: proof/control traceability;
- code/verify.py and code/verification_output.txt: canonical exact control;
- figures/table_exact_counts.tex: useful finite census table.

Build from this directory with the commands in BUILD.md.  Computation is
falsification evidence only; every all-length claim has a proof in the text.
