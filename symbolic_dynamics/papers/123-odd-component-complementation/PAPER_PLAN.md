# Paper plan

## Thesis

Odd-component complementation is governed pointwise by a parity-pruned component/co-component split tree. That same tree gives both an exact entrance clock and a complete all-depth labelled enumeration.

## Section architecture

1. **Map and subtraction boundary.** Define the synchronous map, state the refinement lemma, and deduct Gallai/cograph/cotree and connected-graph enumeration background.
2. **Pointwise split clock.** Define the parity-pruned split tree, prove the recursive depth formula, and classify recurrent and fixed graphs.
3. **Sharp global clock.** Prove the upper bound by order loss along active branches and give recursive witnesses for every odd and even order.
4. **All-depth labelled census.** Derive the odd connected base class, the recursive EGFs `O_t`, the assembled graph EGFs `F_t`, exact depth layers, and fixed EGF.
5. **Recurrent and zeta census.** Convert fixed/recurrent coefficients into two-cycle counts and the exact finite-order Artin--Mazur zeta function; report mechanically checked small orders.
6. **Controls and limits.** State the exhaustive verifier boundary and retain external HOLD.
