## Review Body

**Genuine strength.** The dimer code does not choose an external checkerboard origin: target-part membership selects the anchors, so odd translations carry anchors to anchors. This directly addresses the obvious equivariance objection, and applying the inverse fibre bijection on the same intrinsic dimers makes invertibility transparent.

**Strongest counter-argument.** The strongest skeptical case is that every theorem in the package is already latent in the elementary checkerboard phase decomposition, so the manuscript may overstate the independence of its four contracts. Conditional on a phase, the system is just an unconstrained product over the two parity classes. Pairing one even and one odd site turns it into a full shift on (A\times B), making entropy depend on (mn), making the one-site pressure equal one half of a product partition sum, and making finite-index counts powers of (mn). The finite-dependence obstruction is likewise the observation that a single phase bit is copied to arbitrarily distant sites. From this viewpoint the conjugacy classification is not a new rigidity phenomenon but an induced full-shift recoding, while the thermodynamic and periodic statements are bookkeeping corollaries. A rival exposition could begin with the index-two even subaction, classify its two full-shift components, and reconstruct the full action as an odd-translation swap; the dimer code would then be a routine induced-system isomorphism. The so-what objection is especially sharp because ordinary entropy already proves necessity and the remaining results do not distinguish systems with the same product. Still, this attack does not expose a logical break. The paper’s sufficiency proof solves the nontrivial full-action problem that the even-subaction picture alone leaves open: anchoring dimers by symbol part, rather than absolute parity, yields a translation-equivariant radius-one map with an explicit inverse. The phase argument also correctly separates a law carried by the shift from one whose support equals the whole shift.

**Logic-chain stress test.** The main possible failures were an origin-dependent code, an inverse using different dimers, entropy necessity without sufficiency, and an invariance assumption hidden in the deterministic-phase argument. Equations defining the code use intrinsic part membership in both directions, while the remote-equal-event argument proves deterministic phase before subgroup invariance is invoked.

**Alternative path.** One may formulate the system as two full (\mathcal E)-shifts exchanged by the odd coset and classify the resulting induced actions. This provides a conceptual cross-check, but the manuscript’s intrinsic block code is stronger because it works directly for the full action.

**So-what and frame-lock conclusion.** The package’s substantive point is the explicit two-sided conjugacy mechanism and the exact parity boundary for invariant finite dependence. The only broad hidden premise would be that completeness removes every inter-dimer constraint; that premise is proved from the target graph and is explicitly excluded for general bipartite targets. No core-invalidating frame lock remains.
