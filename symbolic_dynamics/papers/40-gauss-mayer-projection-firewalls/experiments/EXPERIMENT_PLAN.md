# SD-C42 exact authority-integration experiment plan

This plan implements the frozen retrospective contract in
`experiments/PREREGISTRATION.md`. It is frozen before creation of authority
code, vendored inputs, Route output, or results.

## 1. Claim-to-test matrix

| ID | Scoped claim | Fresh evidence | Failure condition |
|---|---|---|---|
| C1 | The literal six-card rules leave C01/C02/C04, then select C04 by A3/A4. | Parse all six normalized cards and derive each predicate and comparison. | Missing card, hidden predicate, C02 removed, wrong survivor set, or preset winner. |
| C2 | The newly frozen pair object is typed and linked to inherited `L_s^2` only by the declared bridges. | Check `X`, `X2`, `iota`, `rho`, splitting law, A/B/J, and raw branch order. | Any cross-type equality, unproved transport, wrong parity, or index-order mutation passes. |
| C3 | Three scalar projections jointly fail the rational-integer/clock/repetition conjunction. | Recompute exact quadratic algebra, truth matrix, and three collision classes. | Any row is misclassified, an exit gets obstruction credit, or stale terminal appears. |
| C4 | The same-object Mayer determinant is analytic only on the frozen domains and local-`u` boundary. | Recompute source/target coefficient forms and validate all domain labels. | Arbitrary-`u` Selberg semantics, lost stability denominator, or domain collapse. |
| C5 | Ownership is a frozen-schema absence claim, not a universal no-go. | Parse selector declarations and terminal language. | Universal impossibility or post-hoc selector ownership appears. |
| C6 | Strict Route-A v0.2 remains rejected despite A1 and A2 analytic evidence. | Independently construct and validate the exact tuple, controls, B lock, and NA fields. | Any mandatory control/schema field is missing or overall/B status changes. |
| C7 | The authority certificate is reproducible and seal-safe. | Fresh A/B, hidden cold C, relocation, full-payload replay, paired-state audit, ledger, and idempotence. | Any deterministic mismatch, mixed state acceptance, exact-set drift, or hygiene failure. |

The experiment establishes only this frozen finite contract. It does not show
a universal impossibility theorem for projections, encodings, selectors, or
dynamical zeta constructions.

## 2. Locally vendored input layer

Create an integrator-owned normalized six-card packet under
`docs/inputs/route_cards/`. It contains every decision-relevant field from
SD-C01--SD-C06, a source path label, each original byte SHA-256, normalization
schema, and exact card order. The authority implementation reads this packet
only. An optional external provenance comparison may be enabled, but hidden
mode must remove it without changing source, science, Route, report, or audit
bytes.

Create machine-readable frozen contracts for:

- immutable 11-file research lock and dependent seal hierarchy;
- expected 15-file control lock, deterministic seeds, grids, and fixtures;
- object/type ownership and permitted bridge relations;
- three projection rows and terminal matrix;
- Route-A v0.2 schema and paired artifact states;
- exact managed-path and result-path sets;
- declared Python dependency sets.

No contract may point to `/tmp`, the historical Paper-01 tree, a mirror, or a
user-specific absolute path.

## 3. Source packet

Implement a source-only module that reads the local frozen contracts and emits
a canonical JSON packet. It must not import either evaluator. Primitive packet
fields include:

1. six normalized Route cards and hashes;
2. literal control seeds and raw generated sequences;
3. digit and pair words sufficient to recompute `sigma`, `sigma^2`, `iota`,
   and `rho`;
4. raw matrices A(a), B(a), J and branch-composition fixtures;
5. raw primitive-word inventories for every bounded D/k run;
6. trace, determinant, discriminant, exact quadratic-root, derivative, clock,
   and repetition inputs;
7. explicit collision words without classification labels;
8. Mayer-domain, coefficient, and ownership declarations;
9. chronology hashes and Route schema inputs.

The packet may contain source declarations but not trusted aggregate PASS
Booleans or a trusted final Route decision.

## 4. Main evaluator

The main evaluator reads only canonical packet bytes and recomputes:

- the six-card survivor and winner derivation;
- all typed conjugacy and return-map identities;
- primitive necklace inventories and the splitting census;
- A/B/J algebra and non-palindromic raw-branch order;
- exact `Q(sqrt(Delta))` projection data and the three-row truth matrix;
- the three collision classifications;
- all A0 and A1 control outcomes from literal seeds;
- Mayer domain/coefficient constraints and selector ownership scope;
- the canonical six-run/39,622-row science summary;
- the strict Route tuple and terminal decisions.

It emits a compact canonical science projection plus a detailed evaluation.

## 5. Independent evaluator

Implement a second evaluator in a physically separate module with no imports
from the source generator, main evaluator, packet adapter, or Route renderer.
It parses the raw packet independently and uses distinct algorithms where
practical:

- direct cycle/rotation enumeration rather than source-owned summaries;
- direct integer matrix multiplication and symbolic quadratic normalization;
- direct recomputation of LCG/Fisher--Yates controls;
- independent six-card predicate derivation;
- independent Route schema construction.

AST checks enforce the no-import boundary and the exact declared Python
dependencies, including the pinned third-party PyYAML version. Its canonical
science projection must be byte-identical to the main projection.

## 6. Route renderer and strict schema

Render exactly one fixed authority card:

`evaluations/route_a/SD-C42/2026-08-17.yaml`.

The renderer consumes the independently agreed science projection and emits
strict Route-A evaluator v0.2 fields. A separate Route validator checks:

- exact A0--A4 labels and order;
- all seven A0 and six A1 literal controls;
- `ROUTE_A_REJECTED`, Route B false/locked;
- no target declaration and all target/root fields explicitly NA;
- exact narrow terminal and ownership-scope language;
- paired provenance triple and exact state note;
- YAML key exactness, scalar types, and forbidden legacy fields.

The Route card is fixed in State A and excluded from the immutable experiment
ledger because Stage 2 later changes only its provenance metadata.

## 7. Adversarial mutation suite

Declare each mutation in a machine-readable registry and execute every entry
against both evaluators. The minimum families are:

1. omit or duplicate a historical card;
2. falsify a historical card byte hash;
3. remove C02's zero orbit or add a hidden `nontrivial` predicate;
4. preset or swap the A3/A4 winner;
5. swap `X` and `X2`, block size, `iota`, `rho`, or `sigma^2`;
6. substitute an untyped `rho=sigma^2` equality;
7. change the odd/even splitting term or a D=2 census;
8. transpose A/B/J or use same-index K composition;
9. mutate the non-palindromic exact value or weight;
10. swap trace, discriminant, norm, derivative, or quadratic-root selectors;
11. alter each row/cell of the projection truth matrix;
12. remove or relabel each of the three collision classes;
13. claim collision minimality;
14. tamper each A0 control family, seed, or generated payload;
15. tamper each A1 control family, seed, or generated payload;
16. collapse the three Mayer domains or assert arbitrary-`u` Selberg meaning;
17. remove the stability denominator or change the target coefficient;
18. inject a post-hoc selector or universal ownership/no-go claim;
19. restore the stale broad terminal;
20. alter retrospective chronology or claim prospective status;
21. tamper a research/control/prototype hash;
22. add a forbidden source/evaluator import or undeclared dependency;
23. omit, duplicate, or add a managed result/text path;
24. mix pending/sealed provenance, notes, manifest states, or commit fields;
25. per-field full-payload tampering, truncation, type substitution, and
    reordering where order is semantic.

Additional mutations may split these families for diagnostic precision. The
final report states the exact mutation count and per-evaluator rejection count.

## 8. Fresh-run protocol

1. Freeze the two experiment documents and record their SHA-256 values.
2. Finalize locally vendored inputs, contracts, source, both evaluators, tests,
   Route renderer, runner, auditor, and lock files without creating results.
3. Record dependency, research, and prototype locks.
4. Confirm the authority starts with an empty `results/` directory, no fixed
   Route output, no experiment report, and no manifest.
5. Run A from that empty state.
6. Copy all deterministic outputs aside, clear results, and run B; compare the
   exact deterministic byte set.
7. Run the complete mutation registry against both evaluators.
8. Build a truly empty hidden cold clone containing only static owned inputs
   and code; run the complete integration runner outside the project CWD.
9. Compare A/B/cold-C deterministic science, Route, report, ledger, and audit
   hashes according to their declared stability boundary.
10. Build a dummy State-B clone with a nonzero lowercase 40-hex provenance
    triple and exact self-excluding manifest; require the exact stored audit
    stdout SHA from State A.
11. Run every unsafe paired-state mutation and retain the rejection
    certificate.
12. Run the complete authority runner twice more and require the final run to
    report `changed_paths=0`.
13. Run standalone normal and hidden audits and require identical stdout.

The authority is restored to State A after all clone tests.

## 9. Output layout

The implementation may write only:

- `code/**`;
- `docs/**`;
- `evaluations/route_a/SD-C42/2026-08-17.yaml`;
- `experiments/**`;
- `results/**`;
- root `EXPERIMENT_REPORT.md`.

The canonical result set will include the source packet, main evaluation,
independent evaluation, science projection, control/prototype reproduction
records, mutation certificate, test report, Route evaluation projection,
analysis summary, ledger, and integrity audit. The exact filenames are frozen
in the static exact-set contract before the first canonical authority run.

The immutable ledger excludes its own file, the fixed Route card, and
`PAPER_MANIFEST.sha256`. The integrity audit excludes mutable current-state
facts from its output and therefore remains byte-identical across State A,
State B, normal provenance, and hidden provenance.

## 10. Analysis and reporting

Use exact integer/rational/symbolic comparisons; no statistical approximation
is needed. Report:

- exact test, mutation, integrity, ledger, managed-text, and result counts;
- all final 64-hex output hashes;
- A/B/cold-C identity boundaries;
- dummy State-B audit identity;
- full-run idempotence and changed-path count;
- exact chronology and novelty limitations;
- exact writer/integrator ownership exclusions.

The analysis summary must separate source declarations, evaluator-derived
facts, Route decisions, boundary/exit classifications, and historical
provenance. It must never convert a type exit, ownership absence, or frozen
finite-control failure into a universal theorem.

## 11. Acceptance gate

The final block is released only if every claim-to-test row passes, both
evaluators agree byte-for-byte on science, the frozen witness targets are
reproduced, every mutation is rejected twice, both artifact states audit to
the same bytes, all exact sets and hashes pass, authority remains State A,
full-tree hygiene passes, and the final full runner changes zero paths.

Otherwise the run remains in-flight and the exact failing check is reported;
no partial result is synchronized into writer-owned material.
