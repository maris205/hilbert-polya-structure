# Paper 40 authority integrity protocol

This authority experiment is a deterministic retrospective reconstruction from
immutable local inputs. Predecessor outcomes and corrective smoke runs were
known. Only the declared checker inputs were frozen before the clean canonical
authority run. There is no network, mirror, Git, absolute-path, or host
temporary-directory runtime dependency. Mutable writer files are not science or output-content
runtime inputs; they are read only by the deliberate whole-authority hygiene
gate.

The complete runner must:

1. verify the normalized eleven-file research set, both experiment-plan bytes,
   the vendored sixteen-file prototype packet, the losslessly base64-encoded
   Route-A v0.2 skill bytes, and the exact PyYAML 6.0.2 runtime declaration;
2. launch the source producer, main evaluator, and independent evaluator in
   separate fresh processes, with evaluator/source/peer import firewalls;
3. require distinct evaluator source hashes, algorithm IDs, function families,
   and call-graph fingerprints while comparing only their canonical science
   projections;
4. create fresh runs A and B plus a hidden-provenance cold run C and require all
   nine artifacts in every branch to be byte-identical;
5. independently recompute raw primitive inventories, exact card selection,
   pair/digit/grouping types, branch order, collision witnesses, projection
   predicates, controls, and strict Route-A output;
6. execute all 164 packet mutations against both evaluators, 24 explicit Route
   mutations, and the exhaustive 398-case recursive Route schema policy; the
   latter has frozen ID-set SHA-256
   `ea76a28ee16f23cbf9897e60c79be604bc093204d860a32a215e29ca8e499123`;
7. freeze the exact result set and the exact integration-managed text set; the
   immutable SHA-256 ledger excludes itself, the mutable fixed Route card, and
   `PAPER_MANIFEST.sha256`;
8. separately enumerate every non-PDF authority file dynamically (excluding
   only the optional root manifest for State-A/State-B byte stability) and audit
   UTF-8, LF, exact-one-EOF, trailing-whitespace, and control-byte hygiene across
   writer prose, TeX, bibliography, figure sources, research files, and
   integration files;
9. execute all twenty-two dependency, missing/extra/duplicate exact-set,
   host-path-hygiene, and paired-state negatives in isolated clones and require actual auditor
   rejection rather than asserted certificates;
10. require normal and hidden-provenance standalone audit stdout to be
    byte-identical; and
11. run a full output-empty hidden cold clone twice, requiring authority/cold
    byte identity and zero changed paths on the second complete run.

The read-only auditor accepts exactly two paired states. State A has an absent
root manifest, three exact `PENDING_FIRST_ARTIFACT_COMMIT` fields, and the exact
Stage-1 note. State B has a regular self-excluding root manifest, three identical
lowercase nonzero forty-hex fields, and the exact metadata-only seal note. The
State-B manifest must be formatted, sorted, unique, path-safe, exact-set, and
hash-correct. Every mixed state fails. State A and legal State B emit identical
audit names, counts, values, and bytes.

The fixed Route card is
`evaluations/route_a/SD-C42/2026-08-17.yaml`. Stage 2 may change only its paired
metadata fields and add `PAPER_MANIFEST.sha256`; it cannot alter scientific
bytes. The authority integrator leaves State A in place and never writes the
root manifest.

The immutable integration ledger is intentionally ownership-scoped. Mutable
writer files are not misdescribed as ledger-managed; they are covered by the
separate dynamic whole-authority text inventory and hygiene gate, which must be
rerun after the writer's final evidence synchronization.
