## Working title

**Dyadic-Sum Hankel Operators: Sharp Ideal Walls, 2-Adic Self-Similarity,
and a Complete Cycle Solver**

## Core result

For the looped arithmetic graph \(m\sim n\) iff \(m+n\) is a power of two,
the Dirichlet-weighted adjacency is bounded and compact exactly for
\(\Re s>0\), Hilbert–Schmidt exactly for \(\Re s>1/2\), and trace class
exactly for \(\Re s>1\). Equal \(2\)-adic valuations split it into a geometric
direct sum of one odd block. Ordered power-of-two edge labels admit a complete
odd/even cyclic solution theorem, yielding an independent trace evaluator.
