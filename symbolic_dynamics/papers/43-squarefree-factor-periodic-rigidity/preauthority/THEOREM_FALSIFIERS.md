# Theorem falsifiers and stop rules

## Decisive mathematical falsifiers

| Claim | Decisive falsifier | Required action |
|---|---|---|
| source compactness | exhibit a prime-failure set that has no finite cylinder witness | reject topology lemma |
| source proximality | find \(x,y,L\) for which all pairwise-distinct-prime CRT systems are inconsistent | reject main theorem |
| missing-residue step | exhibit \(x\in X_{\rm sf}\) whose support fills a chosen \(p^2\) residue ring | reject source membership or proof |
| factor proximality | give a continuous onto equivariant factor and a target pair whose lifts cannot transport proximity | reject factor lemma |
| periodic separation | give a least-period \(r>1\) orbit with zero minimum adjacent-orbit distance | reject metric argument |
| unique periodic point | construct a lawful factor with a second fixed point or any least-period \(r>1\) point | reject full package |
| fixed-point census | find \(m\) with \(\#\operatorname{Fix}(S^m)\ne1\) | reject zeta and determinant |
| zeta identity | derive an Artin--Mazur coefficient inconsistent with \(\sum z^m/m\) | reject determinant claim |
| primitive firewall | produce infinitely many distinct primitive factor orbits under the frozen dynamics | reject A1 conclusion |

## Contract falsifiers

The theorem does not apply if any of the following is true:

- only finitely many prime-square exclusions are enforced;
- the target is not compact metrizable;
- the map is not continuous, not surjective, or not equivariant;
- the target evolution is not the stated \(\mathbb Z\)-action;
- periodic objects or time markers are redefined after the result;
- a product or extension is substituted for the original source;
- the zeta function is not based on fixed points of \(S^m\).

Such an example is a scope deletion or changed object, not a counterexample to
the frozen theorem.

## Literature falsifier

`STOP_DUPLICATE` applies if a primary source is found that explicitly proves
for this squarefree admissible shift that every continuous topological factor
has exactly one periodic point, or equivalently fixes all factor
Artin--Mazur ledgers at \((1-z)^{-1}\), with materially the same quantifiers.

Known source proximality by itself is already assigned zero novelty credit.
A publication of the exact factor-periodic corollary would remove even the
bounded program-closure claim.

## Selection falsifier

Recompute `eligible_45` directly from the immutable C02, C03, and C05 cards.
If any card other than C02 passes every clause, or C02 fails a clause, the
claimed uniqueness is false. Even a unique result does not repair the rule's
retrospective chronology.

## Route falsifiers

- If a nontrivial rational-prime primitive ledger is obtained from the same
  factor object, A1 must be reevaluated.
- If a nontrivial same-ledger completed determinant is proved, A2 and A3 must
  be reevaluated.
- If a fixed self-adjoint same-clock operator with the required completed
  divisor is defined, A4 must be reevaluated.
- Attractive aperiodic entropy or word-complexity data do not change any of
  these verdicts.

## Integrity falsifiers

- any authority, mirror, root README, root manifest, registry, or Git mutation
  by the Phase-1 worker;
- any host-absolute path inside the package;
- an unsorted or self-including manifest;
- a Route artifact path that does not resolve relative to its declared base;
- any trailing whitespace;
- a local source whose byte hash differs from `SOURCE_HASHES.sha256`;
- a package file whose hash differs from the research lock or package
  manifest.

Any integrity falsifier places the package on hold before scientific review.
