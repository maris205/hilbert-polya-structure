the writer's initial reads but before new numerical production. It is not
a retroactive pre-first-read claim. It identifies the original author
proof/code, desk mathematical supplements and exact admitted source gate.
None of those originals is changed by this paper project.

of the original author bytes. Paper-local verify.py adapts the former:

disjoint inverse and evaluated h, and adds isolated/assertion runtime
guards, both explicit parity-tail checks, complete source sets/full graph
records and the sharp witness orbit in canonical stdout. The gate checker
is neither copied nor imported. All imports are from the standard library.

only its current title/role/gate-boundary framing is updated. The untouched
original retains historical pre-admission wording and every original caveat.

headline result while preserving it in the proof/audit provenance.
