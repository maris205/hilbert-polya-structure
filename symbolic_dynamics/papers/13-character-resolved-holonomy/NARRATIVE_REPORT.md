# Narrative report

Paper12 found the only positive diffuse unitary sector that preserves every
Euler moment, then proved that scalar Haar averaging deletes it from the
holomorphic determinant.  Paper13 keeps that missing Fourier information.

The new object is a positive-cocycle `Z`-skew extension of the recurrent
tensor-prime atom graph.  It has only pure atom periodic lifts, yet its Bloch
fibers retain every mixed base return in nonzero character degree.  The zero
degree is exactly `1/zeta` in the Euler half-plane; the other degrees move.
This is the first stage in the chain where the target ledger and recurrent
transverse response inhabit one resolved Fredholm family.

The gain exposes a sharper obstruction.  Inverse reversal makes the adjacent
return charge zero and immediately pollutes the target mode.  Entropy-derived
characters are gauge or a shift of `s`.  Generic positive charges and matched
nonprime inventories reproduce the motion.  The result is therefore a useful
analytic bridge, not yet an arithmetic selector or completed divisor.
