# Deterministic Stage-2 methodology

## Purpose and scope

This package bridges a frozen theorem contract to a self-contained proof and
reproducible exact controls.  It is not a manuscript, an installation unit,
or an authority record.  Every generated byte stays under
`/tmp/p49_tree_stage2`; Stage-1 inputs are read-only and content-addressed in
`SOURCE_LOCK.md`.

The analytical order is:

1. freeze the complete cyclic core and strictly transient feeder hypotheses;
2. prove exact finite-prefix counts;
3. prove matching cylinder-cover and uniform conditional-measure bounds;
4. derive the finite integer optimizer before discussing asymptotic
   saturation;
5. separate universal constant-convolution saturation from the conditional
   Fourier/divisibility corollary;
6. use computation only to falsify algebra, indexing, and boundary handling.

## Two independent implementations

### Closed-form lane

`formula_engine.py` implements:

- the rational coefficient vectors of `H_j`;
- both `H(b(m))` and the direct circular convolution of `m` with `H(c)`;
- finite geometric sums grouped by level residue;
- all weak compositions;
- one-level and `L`-level phase optimizers;
- shifted-product saturation tests;
- the `p=2` expected forms.

Every logarithmic expression is stored exactly as a rational linear form in
`log(prime)`.  For example, `log 12` is represented by coefficient `2` on
`log 2` and coefficient `1` on `log 3`.  Equality of shifted products and
all theorem identities is therefore decided by unique prime factorization,
not floating-point tolerance.

Ordering is exact as well: rational denominators are cleared, and the sign of
a difference is reduced to comparing two positive integers whose ratio has
that logarithm.  Decimal logarithms at 70-digit working precision are used
only to serialize diagnostic values and gaps.  No proof-status or optimizer
decision rests on decimal tolerance.

### Level-recursion lane

`prefix_engine.py` does not import `formula_engine.py`.  It implements:

- direct loops over every tree level;
- an independent integer factorization routine;
- the exact BLW denominator `|Delta_n|`;
- actual finite-tree recurrences for component and feeder pattern counts;
- conversion of an ordered phase assignment to a composition.

This lane never evaluates `H_j`.  The orchestrator compares its level-loop
outputs with the closed lane's residue-grouped geometric sums.  An abstract
syntax-tree check verifies that neither engine imports the other.

## Frozen enumeration domains

`run_validation.py` performs the following deterministic sweeps.

| Sweep | Exact domain |
|---|---|
| General closed formulas | `d=2..4`, `p=1..4`, every `a_j in {1,2,3}` |
| One-level compositions | every weak `p`-composition of `d` in that domain |
| Component prefixes | every root phase and depths `0..2p+2` |
| Feeder prefixes | every one-level composition at depths `p+1` and `2p+2` |
| Residue convergence | every root phase/residue, comparing cycle indices `2` and `6` |
| Actual recursive counts | `d=2..3`, `p=1..3`, every `a_j in {1,2,3}`, depths through `3` |
| `p=2` closed forms | `d=2..8`, `a_0,a_1=1..5`, every composition `(k,d-k)` |
| Exact `L`-level optimizers | `d=2..3`, `p=2..4`, two deterministic phase vectors, `L=1..3`, all compositions of `d^L` |
| Convergence controls | `d=2..4`, `p=2..6`, `L=1..8`, balanced compositions |

The canonical JSON does not dump all repeated cases.  Instead, each complete
ordered record stream is encoded with sorted JSON keys and compact
separators, then accumulated into a SHA-256 digest.  Counts, stream digests,
selected exact witnesses, and every `L`-level optimizer are retained.  The
code is the deterministic expansion rule for those digests.

## Required matched and mutation controls

Matched controls include:

- mean preservation of `H` and every feeder residue vector;
- exact equality of `H(b)` and direct `m`-convolution formulas;
- exact equality between grouped geometric sums and direct level loops;
- actual finite integer pattern counts from a recursive implementation;
- `p=2` equality, strict improvement, even saturation, odd deficit, and the
  equal-phase boundary;
- exact `d^L` prefix denominators and finite composition maxima;
- balanced-composition convergence and exact hits when `p|d^L`.

Mutation controls include:

- `p=4,d=2,a=(2,3,2,3),m=(1,1,0,0)`, which must saturate and thereby reject
  unconditional divisibility necessity;
- deletion of one complete-block edge;
- insertion of a core-to-feeder return edge;
- deletion of a feeder-to-core label edge while claiming unrestricted
  compositions;
- `d=1`, a zero phase size, and an incorrect composition total;
- the four-state strict max-SCC Hausdorff counterexample.

Only the compatible uniform conditional measure defined in the proof is
used for the lower bound.  The mutation ledger does not make claims about
unfrozen measures.

## Reproduction protocol

From `/tmp/p49_tree_stage2`, run:

```text
python -B run_validation.py
python -B build_manifest.py
python -B verify_manifest.py
sha256sum -c SHA256SUMS.txt
```

`-B` prevents bytecode-cache creation.  `build_manifest.py` refuses symbolic
links, cache paths, and nonregular entries.  `verify_manifest.py` checks path
normalization, duplicate entries, exact file-set coverage, every SHA-256,
and the absence of cache artifacts.  The manifest intentionally lists every
regular package file except itself; its own hash is printed by the verifier.

## Interpretation boundary

A passing run establishes that the implementations agree on their frozen
finite domains and that all required negative controls fire.  It does not
establish source novelty, an arbitrary reducible theorem, or correctness of
any non-transient extension.  Those boundaries remain explicit in
`THEOREM_CONTRACT.md` and `SOURCE_LOCK.md`.
