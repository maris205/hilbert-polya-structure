# Round-2 Clues — SD-C23

## In-scope Paper22 clue

Expose the quotient

\[
 q=\frac{n+1}{d}
\]

on each edge and classify relabel-natural finite-state filters or
finite-dimensional same-object cocycles.

The memoryless positive case is already settled.  If a quotient inventory
contains \(1\) and \(q\ge2\), then for every \(d\ge2\)

\[
 C_{d,q}=(d,d+1,\ldots,qd-1)
\]

is a simple primitive cycle of length \(d(q-1)\).  Retaining \(q=2\) gives a
cycle at every length \(d\ge2\); retaining only \(q=1\) is acyclic.

Paper22 must therefore deliver one of:

1. a finite-state no-go theorem;
2. a coefficientwise same-object cancellation theorem;
3. an exact first uncancelled trace obstruction.

Any character or block construction must distinguish the whole determinant
from isotypic blocks.  Moving unwanted cycles between blocks is not
cancellation.
