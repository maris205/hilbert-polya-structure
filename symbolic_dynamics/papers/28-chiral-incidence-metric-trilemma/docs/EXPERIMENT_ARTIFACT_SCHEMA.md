# Experiment Artifact Schema — SD-C30

## Deterministic ledgers

- source_compiler_ledger.csv: inverse and primitive-system checks by fixture.
- native_gram_ledger.csv: exact finite weighted Gram entries.
- infinite_gram_formula_ledger.csv: eta=2 closed prime-pair formulas.
- schatten_strip_ledger.csv: common reflected strips for q=1 through 8.
- finite_b2_diagnostic.csv: exact finite direct-versus-Gram traces.
- infinite_s2_firewall.csv: scope ledger forbidding an infinite B2 trace claim.
- b4_frequency_ledger.csv: finite control hashes and exact positive frequencies.
- det3_deletion_ledger.csv: modified determinant power ownership.
- metric_rigidity_ledger.csv: full and active-only positive metrics.
- orthogonalized_det3_ledger.csv: phase-free coordinate-collapse certificates.
- adversary_control_ledger.csv: standard and PROVES_TOO_MUCH source controls.
- marker_ownership_ledger.csv: all-repetition digit exponents at theorem u=1.
- t_sample_ledger.csv: nongating displays only.
- route_gate_summary.csv: frozen A0–A4 tuple.
- analysis_comparison_table.csv: raw block-level comparison required by analysis.

## Certificates

JSON files record source-oracle separation, parameters, environment, theorem
status, test counts, analysis, two-run identity, and integrity. SHA256SUMS.txt
hashes every Python source and result artifact except itself. CSVs must be
UTF-8 with LF line endings and no carriage-return byte.
