## Main result

$$
B_{b,s}\in S_q
\iff
\sigma>\max\{1,\log_b\|C_b\|_{S_q}\}.
$$

Boundedness, compactness, and Hilbert–Schmidt membership begin strictly at
\(\sigma>1\). Trace class begins strictly at
\(\sigma>\alpha_b=\log_b\|C_b\|_{S_1}>1\). The binary equality proof uses
adjacent paired shells because every binary same-shell block is zero.
