# P189 paper plan

**Target:** anonymous `amsart`, A4, 4--6 pages  
**Round:** `ROUND0_AUTHOR_FREEZE`  
**Lifecycle:** `OWNER_AMBER / HOLD_EXTERNAL`

| Section | Claim contract | Proof engine |
|---|---|---|
| Literal rule and subtraction | Total map on labelled `n x n` binary matrices; fixed index convention | row sums as column heights |
| Four-iterate normal form | complete formulas for `F`, `F^2`, `F^3`, `F^4`; eventual alternation | threshold transform and double conjugation |
| Functional graph and exact layers | recurrent/Fix/strict two-cycles; exact depth sets and counts; `n=1` | Ferrers paths, diagonal hooks, weighted row-sum partitions |
| Every-target inverse atlas | exact time-one and time-two fibres, including zero fibres; both image counts | independent row supports, multiset assignment |
| Exact control and limitations | independent literal verifier, attack witnesses, ownership/lifecycle boundary | exhaustive carriers plus partition-level controls |

The main theorem is deliberately split into a temporal theorem and an inverse
theorem so that the every-target fibres are not presented as a corollary of a
global image count.  No appendix is planned.  References occupy the final
portion of the 4--6 page target.
