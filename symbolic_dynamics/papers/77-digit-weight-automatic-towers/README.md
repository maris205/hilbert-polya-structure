# P77 — Digit-weight automatic towers

Internal `amsart` preprint for the countable orbit closures generated by

\[
S_{q,d}=\left\{\sum_{i\in A}q^i:A\subseteq\mathbb N_0,\ |A|=d\right\}.
\]

The paper proves the exact orbit decomposition, Cantor–Bendixson tower,
continuous lowering cellular automata, full endomorphism monoid, automorphism
group, conjugacy rigidity in `(q,d)`, and the invariant-measure/entropy
classification.

## Claim boundary

- All formulas hold for `q >= 2` and `d >= 1`.
- The exponential-support case `d = 1` is included only as a cited known base
  case.
- Novelty is asserted only for the exact combined package at `d >= 2`.
- The literature statement is explicitly a bounded primary-source search
  through 2026-08-27, not an absolute priority claim.
- `End(X)` means every continuous shift-commuting self-map, without a
  surjectivity requirement. Under the onto convention, the only
  endomorphisms are shift powers.

## Files

- `main.tex` — complete paper with all proofs.
- `references.bib` — only the six cited, primary-source entries.
- `code/verify_digit_weight.py` — deterministic finite controls.
- `main.pdf` — compiled internal preprint.
- `compile.log` — retained LaTeX build log.

## Reproduce the checks

```bash
python code/verify_digit_weight.py
```

The checks cover phased centered windows, nonconsecutive escaping exponents,
bounded-difference divisibility, truncated lowering composition, and
bidirectional base separation. They are finite hostile controls rather than
proofs of the all-scale statements.

## Build

With `latexmk`:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

Portable fallback:

```bash
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```
