# 中文摘要 — P147

固定正整数 `n`，对 `n` 的一个有序分拆，同时把每个由 `r` 个相等部件
`s` 构成的极大相邻游程 `s^r` 替换成单个部件 `rs`，并反复迭代。该映射
保持总权重，并最终进入相邻部件互异的 Carlitz 分拆。本文证明，对每个
`n`，最大吸收时间都精确等于 `floor(log2 n)`，并构造达到该界的显式初态。
此外，对任意目标 `beta=(b_1,...,b_k)`，本文给出按源长度细分的完整一步
逆像多项式：在所有满足 `s_i|b_i` 且相邻 `s_i` 不等的除数选择上，对
`u^(sum b_i/s_i)` 求和。经典 Carlitz 计数与静态游程统计仅作为已知背景，
不计入贡献。论文保持匿名，外部状态为 `HOLD_EXTERNAL`。
