# Artifact Schema — SD-C27

All CSV files are UTF-8, LF-terminated, headered, and deterministically
ordered. JSON files use sorted keys and a terminal newline.

## Source and scalar artifacts

- `code_registry.csv`: gamma word, length, affine translation and derivative,
  compact-containment certificate, post-freeze inventory tags, and source
  policy fields for every (2\le n\le4096).
- `prefix_free_certificate.json`: all-positive-integer registry audit before
  inventory selection.
- `scalar_power_rigidity.csv`: exact (alpha=1-q) power traces and residuals
  through six.
- `ordinary_matrix_firewall.json`: required meromorphic determinant, pole,
  and exact two-dimensional moment controls.

## de Rham and determinant artifacts

- `de_rham_chain_checks.csv`: (DM_0=M_1D), degreewise determinants,
  cohomology factor, and characteristic quotient.
- `de_rham_power_supertraces.csv`: exact powers one through eight.
- `local_determinant_telescoping.csv`: finite zero/one-form products and
  exact graded quotient.
- `ordinary_block_graded_firewall.csv`: ordinary product versus graded ratio.
- `shared_disjoint_determinants.csv`: shared (1-z\sum w) versus disjoint
  product on the first four atoms of each finite inventory fixture.
- `shared_disjoint_power_ledger.csv`: exact all-power mixed differences on
  those first-four finite fixtures.
- `primitive_necklace_ledger.csv`: canonical rotation, content, weight,
  pure/mixed status, and shared/disjoint inclusion.

## Controls and domain artifacts

- `arbitrary_inventory_controls.csv`: shared and disjoint assemblies on all
  atoms of seven mandatory finite inventories, including exact weight sums and
  (z=1) products.
- `marker_ownership_controls.csv`: return degree, digit degree, and object
  change for every code branch.
- `nuclearity_domain_ledger.csv`: exact finite cohomology sums and theorem
  domains; finite prefixes are never promoted to domain proofs.
- `source_oracle_certificate.json`: target-blind core/evaluator separation.

## Reproducibility and Route artifacts

- `run_parameters.json`, `environment_lock.json`, `theorem_ledger.json`,
  `summary.json`, `analysis_summary.json`, `test_summary.json`,
  `double_run_certificate.json`, `integrity_audit.json`, `SHA256SUMS.txt`.
- `route_gate_summary.csv` and
  `evaluations/route_a/SD-C27/2026-08-14.yaml` use the strict frozen tuple.

All six target-zero/root metrics begin with `not_applicable;`, target-zero
data and Route-B invocation are false, and provenance follows the pending or
sealed two-stage schema.
