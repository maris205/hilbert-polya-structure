# P197 proof package and boundaries

Author status: PROVABLE AS STATED; manuscript review pending.
Assumptions: n>=1, full labelled ternary cycle, simultaneous adjacent
sign difference, rho is LEFT shift. Main.tex contains every proof.

Dependencies:

- finite open-window identities + run contraction -> every orbit reaches
  K={D4=rho2}; explicit inverse on K -> exact recurrence and pointwise tail;
- unrotated zero-run junction + no-early-entry discrepancies -> sharp
  parity bound; use 0^(n-1)1 explicitly at n2,3;
- local identity defining tail depth + closed overlap walks -> exact CDF;
  iterate identity + Mobius -> exact cycle census;
- literal comparison trace -> zero contraction -> rank-one gap split ->
  exact Fibonacci product -> global inequality and every maximum equality.

The degree81 characteristic polynomial is an exact finite certificate from
the explicitly defined matrix and Newton identities; all81 coefficients
are checked. It is not inferred from the first12 recurrent counts.

Historical proof exposition corrected before Round0: exact gap formula
replaces unjustified merge-by-merge strictness; explicit junctions replace
a verbal four-phase assertion; the universal a^(n-1)b sharp witness claim
is restricted at n2,3. See the candidate supplements and small-witness
erratum. The main maximal-tail theorem has not changed.

No all-time fibres, efficient fixed-size depth formula, or simple list of
which period divisors occur. Generic CA, transfer matrices, Newton/Mobius
identities and Fibonacci algebra are classical, not credited as new.
