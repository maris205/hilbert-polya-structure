# P197 evidence-led paper plan

Format: anonymous short amsart, complete single-source proof. No venue,
priority or originality claim. The project format replaces generic ML
paper templates; proof length, not an arbitrary page quota, controls scope.

1. Literal simultaneous map, labels, tail convention, classical background,
   exact P164 first-front factor and other internal mechanisms subtracted.
2. Local certificate with full symmetry coverage; run contraction; inverse
   on the core; explicit junction/no-early-entry proof and n=1,2,3 cases.
3. Depth/cycle de Bruijn matrices and closed-walk proofs. Exact finite
   Newton certificate for degree81 characteristic polynomial, not fit data.
4. Comparison matrices, zero contraction, rank-one Fibonacci gaps, image
   iff and sharp maximum including all equality cases.
5. Bounded exact evidence, claim ceilings, source-access limits and hold.

Claim-evidence routes are mapped in CLAIMS_EVIDENCE.md. The core finite-case
table and the boundary/large-box table are useful exact visual summaries;
no decorative raster or architecture figure is needed. A/B reviewers must
attack the map orientation, repeated-coordinate windows, small witness
exceptions, zero fibres, and strictness/equality classification.
