# P182 figure plan

**Decision:** no external figure in Round 0.

The central object is fully specified by one three-coordinate formula, and
the main result has six exact rows.  A diagram would repeat the iterate proof
without carrying the `(q,d)` counts or targetwise fibre law.  The manuscript
therefore uses one compact theorem-summary table instead of a decorative
graphic.

If a later independent reviewer finds the dynamics hard to parse, the only
approved figure concept is a vector schematic

```text
(A,B,C) -> (C,A∩B,A+B) -> (A+B,C∩A∩B,C+(A∩B))
                           |_____________________|
                              period 1 or 2
```

with a second inset showing `A/M direct-sum B/M = J/M`.  Such a figure must
be generated as vector PDF, remain legible in grayscale, and add proof
intuition rather than numerical decoration.  It is not needed for the frozen
Round-0 manuscript.
