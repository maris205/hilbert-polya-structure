# Narrative report — Paper 34 / SD-C36

## One-sentence contribution

For a frozen class of positive one-sided symbolic recognizer compilers, exact
atom recurrence must either mix, prune, dilute the logarithmic clock beyond
whole-operator compactness, or change the time marker under first return.

## Why this paper exists

Earlier papers found the same four symptoms in separate candidates. A trial
division compiler pruned to accepted loops; a finite visible code forced long
private cycles; a Wilson verifier diluted `log p` over `p-1` steps; and first
return recovered the Euler product only after replacing the raw marker. The
project still lacked a theorem saying which assumptions make those symptoms
exhaustive.

Paper 34 supplies that theorem. It does not offer another prime selector. It
defines the positive compiler interface precisely and proves a complete
ownership classification inside it.

## Technical story

The literal primitive ledger is stronger than a signed determinant identity.
Multiplicative freeness of the atom norms makes every atom orbit a simple
private cycle. Any shared recurrent SCC contains a closed word with support
from two private cycles, and its primitive root is an additional orbit. The
remaining recognition edges lie on no closed walk. Whenever the whole
adjacency is trace class, those edges disappear from every power trace and
from the Fredholm determinant.

Private cycles avoid mixed recurrence but create the analytic obstruction. A
finite orbit-separating alphabet has only exponentially many words of bounded
length. Polynomial atom growth therefore forces logarithmically long cycles
on an infinite subsequence. Distributing total roof `log N(a)` over those
cycles leaves one edge per cycle with weight uniformly bounded away from zero.
The natural whole adjacency cannot be compact.

First return removes this dilution by replacing each cycle with one diagonal
step. It is an honest induced operator, but its marker is `z`, while the raw
cycle contributes `z^{ell(a)}`. The two objects agree only after the
nonfaithful specialization `z=1`.
