# Recognition Before Recurrence

Paper 34 / Candidate `SD-C36`.

This paper studies a deliberately narrow compiler class: stationary one-sided
countable Markov graphs with positive scalar one-step weights, a finite
orbit-separating visible code, additive atom clocks, a literal primitive-orbit
ledger, the original graph-step marker, and whole-operator Fredholm ownership
on the natural vertex space.

The main result is a recognition-to-recurrence quadrilemma. In this class,
shared recurrent computation creates mixed primitive orbits; terminal
recognition prunes from every power trace; private visible atom cycles dilute a
logarithmic clock and make the whole adjacency noncompact; and first return
changes the free marker. The result is a scoped closure theorem, not a general
claim about symbolic computation or arbitrary signed, matrix-valued, or
operator-algebraic dynamics.
