# Positive-Cone Cocycles on a Recurrent Tensor-Prime Shift

Paper08 defines **SD-C10**. The tensor-prime base graph contains loops and
both adjacent directions, hence is strongly connected and aperiodic. Every
directed cross edge receives a distinct positive free-group generator; loops
receive the identity. The canonical trace kills every mixed positive word.

For the frozen transfer `T_s`,

```text
(Tr tensor tau)(T_s^r) = sum_p p^(-rs),
det_tau(I-zT_s) = product_p (1-zp^(-s))
```

on the honest trace-class half-plane. An abelian shared-positive label gives
the same ledger, showing that positivity—not freeness alone—is the operative
mechanism.

The natural chiral double restores inverse labels through the adjoint.
Immediate `g g^(-1)` backtracking produces a strictly positive divergent
quadratic mixed trace. `det_1` and `det_2` do not exist; `det_3` exists but
deletes that first recurrent term. Its fourth trace still moves with height.
