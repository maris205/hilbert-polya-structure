# Paper08 Narrative Report

SD-C10 replaces Paper07's acyclic atom base by a bidirectional recurrent
grammar. Mixed base cycles are real, but their positive cocycle words never
close in the identity fiber. The canonical trace therefore recovers the exact
prime-power ledger and Euler determinant.

This is an A2 advance: recurrence has moved from an excluded base feature to
a trace-resolved symbolic cocycle feature. A shared positive abelian label
passes too, so the mechanism is a positive grading rather than a uniquely free
phenomenon.

Self-adjointization provides the sharp stop. The adjoint supplies inverse
letters, every edge immediately backtracks to the identity, and the first
mixed quadratic trace is positive and divergent. The first admissible
regularized determinant is `det_3`, which deletes that term. Its fourth trace
still moves with height, but no one determinant owns both the exact Euler
ledger and the first recurrent chiral trace.
