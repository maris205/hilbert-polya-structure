# Author output plan — SOURCE ONLY

2026-09-11 UTC. No verifier execution, import, parser invocation, compilation,
test, help invocation, canonical output or execution receipt accompanies this
source package. The contributor is an author and is ineligible for P215's A/B
manuscript reviews. This plan is not permission to run anything.

The fixed boxes are n=0..5, q=0..3, n outermost. All Cartesian words, including
the separate empty/zero-alphabet singleton cases, are included. The arithmetic
expectation is 4+10+30+100+354+1300=1798 states across 24 boxes; this is not an
observed count. No run may silently enlarge, prune or sample this domain.

After complete source reception, a separately bound grant must precede any
scientific execution. The future executor must pin the exact verifier,
parameters, schemas, encoder/design/proof/claim documents and theorem contract;
record the actual interpreter and its resolved identity, imported builtin sys
and runtime dependencies, argv, flags, environment, working directory and
stdout/stderr destinations. The exact runtime closure and settings require
separate root reception, not an assertion that sys-only means dependency-free.
This script performs no filesystem, dependency, hash or provenance inspection;
those are external obligations. It cannot certify its own execution grant.

The proposed successful output is one complete compact JSON object plus LF.
There are no command switches, summaries-only modes or human progress lines.
Every comparison includes both values and its boolean result. All semantic
comparison failures are accumulated without filtering: the complete document
still emits, top-level pass is false, and exit is 1. An argument error emits an
identifiable failure object and exits 2. A caught runtime exception emits its
parameter context, all completed boxes and current counters, then exits 2;
that is incomplete failure evidence, never canonical success. Hard I/O or
process failures may prevent valid JSON and must retain actual partial stdout,
stderr and the real process exit. Never rerun over a failed evidence path.

Later DATA reception must independently decode and semantically inspect the
entire output against this schema and the fixed complete domain. It must check
every state/orbit, target/fibre, recurrence term, census and comparison, not
merely pass fields or counts. Only an accepted actual successful output may
be adopted as CANONICAL.json. No such file is supplied now. Fresh strict author
replay pairs and complete raw-byte comparisons remain mandatory under the
batch contract. Reuse requires the full unchanged dependency key, including
canonical bytes and runtime settings, and explicit reuse labelling. A/B must
use distinct nonauthor processes and their own independent representations;
this author self-check is not either review. All later builds, freezes,
all-page views and final lifecycle checks remain pending. OWNER_AMBER /
HOLD_EXTERNAL is unchanged.
