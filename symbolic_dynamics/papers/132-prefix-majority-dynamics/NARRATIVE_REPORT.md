# Narrative report — P132

The paper begins from a familiar one-step object: at every location, report the
majority of the prefix ending there.  The new dynamical question is what happens
when the whole report is fed back as the next binary word.

The temporal mechanism is unusually clean.  Every word agrees with its report
on an initial fixed block.  A positive constant tail in that block doubles at
the next update; a negative tail grows according to `ell -> 2ell-1`.  This
turns a local triangular dependency into a sharp logarithmic global clock.

The inverse geometry is kept secondary but complete.  A target prescribes the
sign run of a simple walk.  Each sign change forces the same crossing edge, so
the source decomposes into Catalan excursions and a final meander.  The same
walk model gives the strict maximal fibre without an asymptotic argument.

The manuscript explicitly subtracts the direct Husfeldt--Rauhe one-step
prefix-majority predicate and all classical path machinery.  It makes no
external novelty, priority, or release claim.
