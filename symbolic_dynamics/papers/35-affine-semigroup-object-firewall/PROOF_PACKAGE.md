# Proof package — Paper 35 / SD-C37

## Main theorem

For the source-locked affine benchmark:

1. the full positive right Cayley graph has strict height and no nonempty
   directed closed path;
2. the full unweighted adjacency has infinite outdegree, while its
   `beta>1` weighted version and the finite-generator slice remain
   noncompact;
3. formal symmetrization introduces two-step primitive backtracks;
4. Hashimoto reduction leaves the reduced primitive affine relation word of
   length `r+3`;
5. finite congruence quotients preserve that labeled relation but create
   additional translation cycles;
6. the Bost--Connes zeta partition function is the first coefficient of the
   actual diagonal Fredholm trace-log, not the primitive determinant of the
   affine graph.

## Proof dependencies

- strict height uses the explicit affine multiplication law;
- reduced relation primitivity uses the unique occurrence of `v` and
  `v^{-1}` in the cyclic word;
- noncompactness uses infinitely translated orthogonal local patterns;
- quotient nonfaithfulness uses the explicit `U_q^q` cycle;
- the determinant firewall uses the trace-class identity for diagonal
  `D_beta`.

## Boundary

Signed, matrix, supertrace, groupoid, KMS, boundary, and crystal quotients are
comparison objects. No theorem claims they are impossible; each must prove
same-source, same-marker descent separately.
