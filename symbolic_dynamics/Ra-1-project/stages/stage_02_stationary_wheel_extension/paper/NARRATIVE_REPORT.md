## One-sentence contribution

For a wheel-sieve shift whose exact prime clock is generated by a frozen
recurrence, the paper proves scoped obstructions for strict equivariant
extensions, forward-well-founded strong-bisimulation quotients, and
finite-alphabet fixed-window decoders, while retaining other infinite
observational recodings only as an undefined project branch.

## Self-contained problem anchor

The revised paper includes the recurrence

\[
Q_0=1,\qquad q_1=Q_1=2,\qquad
q_{k+1}=\min\{n>q_k:\gcd(n,Q_k)=1\},\qquad
Q_{k+1}=Q_kq_{k+1},
\]

and proves by induction that \(q_k\) is the \(k\)-th rational prime. The
canonical residue graph induces a tail-path system

\[
X=\bigsqcup_{k\ge 0}X_k,
\qquad \sigma(X_k)\subseteq X_{k+1},
\qquad \tau_k=\log(Q_{k+1}/Q_k)=\log q_{k+1}.
\]

For this project, a level-blind stationarization means one target phase
space, one cutoff-independent rule, and total decoders whose inputs do not
contain an external level or a stored prime sequence. This is an
admissibility convention, not an existence claim.

## Technical story

### 1. Grading closes strict equivariant extensions

If \(\pi:Y\to X\) satisfies \(\pi\circ S=\sigma\circ\pi\), an
\(S\)-periodic point would project to a \(\sigma\)-periodic point. Strict
level growth makes this impossible. A full backward orbit is also impossible
because its level would eventually become negative. The empty intersection
of all forward images is stated as a separate consequence rather than as an
unqualified general equivalence.

### 2. Forward well-foundedness is the natural quotient hypothesis

A quotient cycle under strong forward bisimulation can be lifted repeatedly
to an infinite source path. Therefore a source with no infinite forward path
has an acyclic quotient. A finite DAG satisfies this hypothesis. The infinite
ray does not, and its universal quotient has a self-loop; this shows that
acyclicity alone is insufficient for arbitrary infinite graphs.

An independent wheel-specific obstruction applies when one class decoder
must be exact for every representative. Distinct next-prime values force each
class to remain within one level, so quotient edges strictly raise the induced
level.

### 3. Finite local observations have finite range

For finite \(A\) and finite \(W\), the domain \(A^W\) is finite regardless
of the decoder codomain. Consequently, neither an integer-valued multiplier
decoder nor a real-valued logarithmic-clock decoder can recover an infinite
exact range. Infinite alphabets, infinite memory, and other unbounded inputs
are outside this theorem, not validated by escaping it.

### 4. What remains undefined

The retained project branch is another infinite factor or observational
recoding. Before testing, it must specify the target system, topology, fixed
rule, exact decoders, global path semantics, and cutoff-consistency maps. A
finite closed target word assembled from incompatible edge representatives
does not meet the path requirement.

## Nonclaims and guardrails

The paper does not claim that:

- acyclicity alone suffices for every infinite bisimulation quotient;
- countable alphabets or infinite-memory decoders are impossible;
- the elementary mechanisms used are new standalone concepts;
- any observational recoding has passed arithmetic or periodic-orbit gates;
- a finite quotient cycle is a valid periodic point without global path
  semantics;
- Stage 02 contains numerical evidence;
- a determinant has been selected; or
- analytic determinant comparison is open.
