# Round-2 roadmap references

This directory turns the former `skills/` placement of the two Flow Route
protocols into an unambiguous **roadmap reference** location. It does not turn
them into active agent skills, and merely reading/copying them does not invoke a
Route evaluation.

## Visual programme reference

Use the updated [Hilbert--Pólya Dynamics Research Roadmap](rh_roadmap.png)
for the programme-level view. Its Round-2 section is headed **Structural
Synthesis** and states the working direction

```text
prime arithmetic
  -> symbolic structure
  -> geometric carrier
  -> closed orbits / trace formula
  -> quantum spectrum
```

For this project, read that chain through [../plan.md](../plan.md): symbolic
structure must be derived from the candidate; the geometric carrier begins as a
specified symplectic base map; its mapping-torus flow is not automatically a
Hamiltonian flow; and the quantum node is deferred. The figure is an obligation
map, not a progress dashboard or a statement that the links already hold.

source `../../p1_wiki/rh_roadmap.png` at workspace creation:

## How to use the two references

1. Begin from the candidate card and the same-object ledger in
   [../plan.md](../plan.md), not from a desired Route label.
2. Work only through A0, then A1, then A2 for one frozen candidate. The current
   project has no assigned Route-A tuple.
3. Do not use A3/A4 or Route B to repair a missing arithmetic source, roof,
   primitive-orbit convention, or same-object determinant.
4. A formal Route verdict requires an appropriate, separately authorized
   candidate-specific evaluation and evidence record. It cannot be inferred
   from this file, the roadmap image, a paper count, or an adjacent Session.

The source image remains a shared P1 Wiki asset; the local image above is an
auditable, byte-identical Round-2 reference mirror, not a revised roadmap.
