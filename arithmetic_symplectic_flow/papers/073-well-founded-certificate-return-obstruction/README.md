# 073 — Well-founded certificate-return obstruction

**Record:** ASFS-METHOD-20260914-10  
**Status:** METHOD THEOREM / PRE-P0 STOP RULE — STRICT DESCENT OF THE COMPLETE CERTIFICATE STATE EXCLUDES A1 RETURNS

This rule abstracts the common obstruction in the Pratt and ECPP screens. If the
complete state that owns an arithmetic certification transition carries a rank in a
well-founded ordered set and every nontrivial transition strictly lowers that rank,
then it has no directed periodic orbit. A periodic fibre after freezing part of the
certificate is not a periodic orbit of the complete arithmetic state.
