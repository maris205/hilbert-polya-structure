# 088 — Finite-field reversible Hénon control

**Record:** ASFS-SCOUT-20260914-59  
**Status:** EXTERNAL GEOMETRIC/A1 POSITIVE CONTROL — PRIME MODULUS IS AN EXTERNAL REDUCTION PARAMETER; PRE-P0 STOP

The polynomial automorphism (F_a(x,y)=(y,y^2+a-x)) is reversible and
area-preserving. Reducing it over a selected finite field (mathbb F_p)
makes it a permutation of the finite phase space, so every state lies on an
actual finite cycle. This is a strong geometric and orbit-ledger control, but
the prime (p) is selected before defining the finite carrier and no
prime-sieve symbolic observable is generated by the map. It is therefore an
external control, not an ASFS candidate.
