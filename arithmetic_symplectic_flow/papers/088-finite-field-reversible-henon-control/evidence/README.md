# Evidence and source boundary

- J. A. G. Roberts and F. Vivaldi, *A combinatorial model for reversible
  rational maps over finite fields*, Nonlinearity 22 (2009), 1963--1982,
  [arXiv:0905.4135](https://arxiv.org/abs/0905.4135). It treats reversible
  rational maps reduced over finite fields and includes area-preserving Hénon
  polynomial automorphisms as examples.

The determinant, inverse, reverser, and finite-permutation consequence are
direct calculations shown in [paper.md](../paper.md). No cycle enumeration,
prime list, roof, zeta/determinant, real symplectic suspension, or Route
evaluation was run.
