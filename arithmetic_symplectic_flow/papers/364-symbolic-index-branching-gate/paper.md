## 4. The internal-branching lemma, including infinite components

In a strongly connected component C that contains a cycle, every vertex has

cycle cannot leave it within C; strong connectivity forces every vertex of
C onto that finite cycle. Thus C is exactly a simple directed cycle with
one internal edge at each vertex. This argument does NOT assume C finite.

Otherwise some vertex v has two distinct internal outgoing edges e,f.
Strong connectivity supplies a finite path back to v after each edge;
truncate at the first return. This yields two first-return edge words A,B

fixes its initial vertex). Each copy contributes at least one occurrence
