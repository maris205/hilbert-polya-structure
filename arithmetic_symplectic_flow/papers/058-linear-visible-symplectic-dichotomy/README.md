# 058 — Linear symplectic visible-lattice dichotomy

**Record:** `ASFS-METHOD-20260914-07`  
**Status:** `METHOD THEOREM / PRE-P0 STOP RULE — LINEAR INTEGRAL SYMPLECTIC LIFTS EITHER LOSE VISIBLE CYCLES OR GAIN CONTINUUM PERIODIC FAMILIES`

Every `SL(2,Z)` map preserves primitive lattice vectors. Across the full linear
family, however, a map either has no nonzero periodic visible vector or has a
positive-dimensional periodic subspace in the ambient symplectic plane. Thus
linear geometry cannot supply the required discrete same-object visible packet
ledger.
