# Evidence and reproducibility boundary

## Source

- Mihai Caragiu, Alexandru Zaharescu, and Mohammad Zaki, *On Ducci Sequences
  with Primes*, Fibonacci Quarterly 52 (2014), 32--39;
  [source PDF](https://www.fq.math.ca/Papers1/52-1/CaragiuZaharescuZaki.pdf).
  It defines the prime-tuple GPF-Ducci map and proves eventual entry into a
  limit cycle.

## Exact result used here

The total integer carrier and the diagonal calculation are this record's own
definition and one-line proof.  No claim about a complete classification of
all GPF-Ducci cycles is made.  No numerical enumeration, prime list, roof,
geometric lift, determinant, or Route computation was performed.
