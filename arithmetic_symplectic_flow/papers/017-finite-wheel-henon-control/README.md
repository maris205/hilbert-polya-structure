# Finite-wheel Hénon periodicization control

**Candidate ID:** `ASFS-20260913-WHEEL01`  
**Status:** `P0 FROZEN; A0 SCOPED FAIL; A1 LOCAL POSITIVE CONTROL; Route B NOT INVOKED`

This is a deliberately adverse candidate: a 30-wheel sieve word periodically
drives a Hénon-type area-preserving base map, whose cotangent lift is symplectic.
It has an explicit primitive closed orbit of length 30 under unit roof. The
same calculation shows why this does not help the programme: the wheel and its
prime factors are finite external input, and an arbitrary squarefree wheel
would give the same construction.
