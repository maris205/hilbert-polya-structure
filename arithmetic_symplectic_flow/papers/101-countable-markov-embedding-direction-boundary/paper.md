# A countable Markov coding of surface dynamics is not a symplectic realization of an arithmetic path shift

**Paper ID:** 101-countable-markov-embedding-direction-boundary  
**Record ID:** ASFS-SCOUT-20260914-69  
**Date / status:** 2026-09-14; PRE-P0 NEGATIVE DIRECTION-OF-REALIZATION AUDIT  
**Route state:** No formal ASFS Route-A coordinate. Route B NOT INVOKED.

## Question

Can the two-sided natural path shift of an arithmetic GPF recurrence be declared a Hénon or symplectic surface system because countable-state Markov shifts occur in smooth surface dynamics?

## Result

**No admission follows.** The cited surface theory begins with a `C1+` surface diffeomorphism and constructs/analyzes countable Markov symbolic data for that diffeomorphism, modulo explicitly limited measure-theoretic sets.  It does not give a construction that starts with this particular GPF transition graph and returns a smooth area-preserving diffeomorphism with a named invariant set and an arithmetic-preserving conjugacy or semiconjugacy.

The difference matters twice.  First, the GPF shift is a distinct nonclassical carrier with its own packet convention and, where relevant, roof/zeta owner.  Second, even an eventual surface coding would require its own phase space, symplectic form, exact map, invariant domain, coding map, multiplicity rule, and orbit correspondence.  None is supplied by a general coding theorem.

| Arrow | What is available | What is missing |
| --- | --- | --- |
| Surface map to countable shift | symbolic coding for a supplied diffeomorphism | source-backed direction |
| GPF shift to surface map | no realization construction | required reverse direction |
| Surface map to ASFS | no fixed area-preserving Hénon/roof | independent geometric obligation |

## Controls

1. **Direction control.** A coding theorem is not an embedding or realization theorem.
2. **Arithmetic control.** The generic surface theorem does not preserve the GPF factor observable or derive it from the map.
3. **Symplectic control.** The cited smooth-surface statement is not an area-preserving or exact-symplectic realization claim.
4. **Same-object control.** No packet, unit roof, aggregate-log roof, or zeta from 079/087/094 is transported to a hypothetical surface system.
5. **Lineage control.** This has no documented direct prime-symbolic-to-Hénon intertwiner, matching the earlier 075 boundary.
