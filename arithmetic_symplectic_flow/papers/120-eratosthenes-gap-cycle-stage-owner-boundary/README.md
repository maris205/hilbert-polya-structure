# 120 — Eratosthenes gap-cycle stage-owner boundary

**Record:** `ASFS-SCOUT-20260914-87`  
**Status:** `PRE-P0 STOP — A WHEEL-GAP CYCLE AT ONE SIEVE STAGE IS NOT A RETURN OF THE STAGE-ADVANCING SIEVE ACTION`

Holt's discrete sieve dynamics has a genuine cyclic gap arrangement
\(\mathcal G(p^\#)\) at each fixed wheel stage and an explicit recursion to the
next stage. The update changes the primorial and the cycle population, so the
stage-advancing sieve does not return to its previous full state. A fixed-stage
cyclic ordering cannot be borrowed as its primitive packet.
