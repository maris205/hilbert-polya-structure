## Abstract

For the frozen proper-divisor scan with countably charted measured fibre laws, the entire set of eventually periodic states with nonzero isotropy-clock image has original measure zero.
If a least-period set has positive original measure, exactly continuum many distinct full source packets meeting it have zero clock image.
These statements use actual inverse IMAGE on return sets and countability of full incoming histories, not an invariant probability, finite-rank clock hypothesis or symmetry.
They do not change any null-point clock or rule out isolated positive-clock packets.
Three total controls on the same arithmetic source exhibit, respectively, positive-measure zero-clock cycles, null positive-clock cycles and no cycles.
Their full groupoids, incoming histories, kernels, isotropy and all height phases are computed without a digit cutoff.

## 2. Full inverse histories and their own IMAGE

Index all source partition pieces by a countable set \(I\).
Each actual inverse \(\theta_i:Y_i\to A_i\) is a Borel bijection with prescribed positive finite Borel \(J_i\), and
\[
 \mu(\theta_i B)=\int_B J_i\,d\mu\qquad(B\subset Y_i\text{ Borel}).
\]
Source labels must satisfy \(a(s)=s'\); every such label and every actual fibre chart is enumerated.
No target outgoing permission is imposed, and no number of predecessors is included in \(J_i\).
The hypotheses give a Borel \(F\), Borel legal domains \(D_r\), and a single Borel pointwise \(\kappa\).
Put \(D_0=X,\ S_0=0\), and \(S_r(z)=\sum_{j<r}\kappa(F^jz)\) on \(D_r\).

For each finite actual inverse word \(\Theta\) of length \(r\), restrict its domain at every intermediate chart.
Its Borel image consists of the corresponding legal source itinerary, and successive IMAGE substitution gives
\[
 J_\Theta(y)=\exp[-S_r(\Theta y)],\qquad
 \mu(\Theta B)=\int_B J_\Theta\,d\mu .
\]
Indeed one-step IMAGE extends from indicator functions to nonnegative Borel functions by simple approximation and monotone convergence; induction gives the product rule.
This fixes every point version, including every assigned null boundary.
For a target \(v\), the recursion
\[
 B_0(v)=\{v\},\qquad
 B_{r+1}(v)=\bigcup_{w\in B_r(v)}\{\theta_i(w):w\in Y_i\}
\]
is exactly its full depth-\((r+1)\) predecessor set by induction.
All compatible infinite inverse sequences are retained.
Each \(B_r(v)\) is countable, with actual states identified rather than multiplied by word labels.

Define
\[
 G=\{(z,m-n,w):F^mz=F^nw\text{ legally},\ m,n\ge0\},\qquad
 c(z,m-n,w)=S_m(z)-S_n(w).
\]
Source is \(w\), range is \(z\), and only equal triples are identified.
For two witnesses of the same triple, both depths differ by the same integer.
The longer pair adds an identical common-tail sum, proving pointwise descent.
To compose arrows, extend the witness with the shorter middle depth to the longer middle depth; the required extensions are legal because the other witness supplies them.
Cancellation of the middle sums proves additivity.
In particular \((Fz,-1,z)\) has clock \(-\kappa(z)\).

For actual inverse words \(\Theta_\alpha,\Theta_\beta\) over a common target \(y\), the history-pair map sends \(w=\Theta_\beta y\) to \(z=\Theta_\alpha y\).
Weighted substitution on every Borel part of its domain gives its own IMAGE
\[
 J_{\alpha\beta}(w)=J_\alpha(y)/J_\beta(y)
 =\exp[-c(z,|\alpha|-|\beta|,w)].
\]
These charts cover every arrow, including length-zero histories at terminals.
The complete lag, clock and joint kernels are, respectively, the actual meeting triples satisfying
\[
 m=n,\qquad S_m(z)=S_n(w),\qquad
 m=n\ \text{and}\ S_m(z)=S_m(w).
\]
No kernel is presumed to contain only units.

## 3. Entire isotropy, packet countability and physical phases

Every full source packet is an actual common-tail equivalence class.
For fixed \(w\) it is contained in the countable union
\[
 \bigcup_{n:\,w\in D_n}\ \bigcup_{m\ge0}B_m(F^nw),
\]
and equality holds by the definition of a meeting.
Thus every full source packet is countable, including all incoming states.
The relation itself is Borel: for each lag it is a countable union of Borel equal-iterate relations on legal domains.
No Borel selector or regular orbit quotient is assumed.

A nonzero-lag source loop exists exactly at an eventually periodic source.
If its eventual core has least period \(q\), equality of two sufficiently late iterates occurs exactly at depth differences in \(q\mathbb Z\).
Its source isotropy is consequently \(q\mathbb Z\).
Writing \(C\) for the signed sum around that core, the loop character is \(nq\mapsto nC\), so
\[
 H_z=c(G_z^z)=C\mathbb Z.
\]
The sum \(C\) is independent of the core phase by cyclic reindexing; incoming path sums cancel in loops.
At terminal or infinite non-eventually-periodic sources, source isotropy and \(H_z\) are zero.
Finite-forward classes are classified by their terminal endpoint: if \(z,w\) reach the same terminal in \(d_z,d_w\) steps, their unique lag is \(d_z-d_w\), with clock \(S_{d_z}(z)-S_{d_w}(w)\).
Infinite classes retain the unrestricted common-tail test; no terminal is padded.

The height extension has arrows \((w,h)\mapsto(z,h+c(g))\).
Its isotropy is the kernel of the source loop character: \(q\mathbb Z\) if \(C=0\), zero if \(C\ne0\), and zero at non-eventual sources.
Choose a reference \(p\) in one packet and any actual arrow \(g_z:p\to z\), with \(b_z=c(g_z)\).
The complete phase invariant is
\[
 [h-b_z]\in\mathbb R/H_p.
\]
Another choice changes \(b_z\) by an element of \(H_p\); equality of these cosets supplies the loop adjustment needed for an actual extension arrow.
Changing the reference only translates this coordinate.
Height translation on the orbit SET has stabilizer exactly \(H_p\).
For \(C\ne0\) its primitive is \(|C|\), with all positive repeats \(j|C|\); for \(H_p=0\) all real phases remain and there is no positive return.
Zero-clock source isotropy is not erased by this last statement.

## 4. Conditional measure-support and cardinality theorem

The sets \(P_q\) are Borel: impose \(z\in D_q,\ F^qz=z\), and exclude each smaller positive return.
Their pointwise cycle sums, level sets and all finite legal preimages are Borel.
Fix \(q\) and one length-\(q\) source itinerary, and intersect its source set with \(P_q\), obtaining \(A\).
For every Borel \(B\subset A\), the actual inverse word fixes every point of \(B\), since its forward return is the identity there.
Consequently
\[
 \mu(B)=\mu(\Theta B)=\int_B e^{-C_q(z)}\,d\mu(z).
\]
This identity does not require \(B\) to be one-step invariant.
Exhaust \(X\) by finite-measure sets, for example finitely many labels times bounded cubes.
On each finite part of \(A\), test the subsets where \(e^{-C_q}\ge1+\varepsilon\) or \(e^{-C_q}\le1-\varepsilon\), for rational \(\varepsilon>0\).
The identity forces each such subset to have measure zero.
Thus \(C_q=0\) almost everywhere on \(A\).
Countably many itineraries cover \(P_q\), so \(\mu(P_q^\times)=0\).

Every actual inverse word sends a Borel null set in its domain to a null set, directly from its IMAGE integral.
Countably many words cover each full legal \(r\)-step preimage.
Taking the countable union over \(q,r\) proves
\[
 \boxed{\mu(E^\times)=0.}
\]
By §3, this is exactly the set of eventually periodic sources with nonzero entire \(H\).
It says nothing about the values on that null set, and requires no invariant probability or finite total mass.

Now suppose \(\mu(P_q)>0\), possibly infinite.
The Borel set \(P_q^0=\{z\in P_q:C_q(z)=0\}\) still has positive measure.
Some fixed label and bounded cube contain a positive-measure part; inner regularity gives a compact positive-measure subset.
A positive Lebesgue-measure compact set is not a point.
Inside it choose two disjoint compact positive-measure subsets of arbitrarily small diameter; this is possible by taking disjoint small neighborhoods of two points of its measure support and then inner regularity.
Iterating this construction with diameters tending to zero gives a binary compact tree.
Each infinite binary path determines a distinct point by nested compactness.
Hence \(P_q^0\) has at least continuum cardinality and, being a subset of countably many Euclidean spaces, exactly continuum.

Each full source packet is countable by §3.
In usual set theory with choice, a union of \(\lambda\) countable sets has cardinality at most \(\max(\lambda,\aleph_0)\).
Therefore exactly continuum distinct full source packets meet \(P_q^0\).
Each has \(H=\{0\}\), since its core sum is zero and all incoming loops have the same character.
This also gives exactly continuum zero-\(H\) packets meeting \(P_q\); the ambient cardinality is the upper bound.
It is not an inference from nonatomicity alone: the positive Borel periodic set and countable COMPLETE packets are both essential to this argument.
The theorem does not make the exceptional nonzero-\(H\) packets nonexistent or at most countable.

## 5. Complete arithmetic graph and three own inverse atlases

For the controls, the full predecessor-label list of \((n,d)\) is:
\[
 \begin{cases}
 \{(n,d-1)\},&d>2,\ (d-1)\nmid n,\\
 \varnothing,&d>2,\ (d-1)\mid n,\\
 \{(n,n)\}\ \cup\ \{(jn,n):j\ge2\},&d=2.
 \end{cases}
\]
This follows by exhausting the scan, lowering and restart cases in the definition of \(a\); all listed labels satisfy their actual source conditions.
In particular labels with no predecessor remain objects.

The integer \(n\) never increases along a forward label orbit.
If composite, within a scan and at most one restart an actual proper divisor is encountered and \(n\) strictly decreases.
There cannot be infinitely many strict decreases of integers bounded below by2.
The eventual constant label value is therefore a prime \(p\), whose scan visits precisely \((p,2),\ldots,(p,p)\).
Conversely these labels form a cycle of least length \(q=p-1\); any cycle containing a lowering edge is impossible.
This proves all label cycles and that every label eventually reaches one of them, without inserting primality into the transition.

For a label \(s\), define \(p(s)\) by this eventual cycle, \(q(s)=p(s)-1\), and \(h(s)\) as its first hitting time of \(o_p=(p,2)\).
Let \(\delta(n,d)=1\) when \(d=n\), otherwise0, and \(R(s)=\sum_{j<h(s)}\delta(a^js)\).
These are finite operationally defined integers, not a cutoff.
Every later visit to \(o_p\) occurs at time \(h(s)+qj\), with restart count \(R(s)+j\), for \(j\ge0\).

Owners A/B/C are total on separate copies of \(Q\times\mathbb R\), with original counting times Lebesgue measure.
Their respective source fibre maps are \(x,\ 2^{\delta(s)}x,\ x+\delta(s)\).
For EVERY predecessor label \(s\) of a target label \(t\), the actual inverse on the entire target fibre is respectively
\[
 (t,y)\mapsto(s,y),\qquad
 (t,y)\mapsto(s,2^{-\delta(s)}y),\qquad
 (t,y)\mapsto(s,y-\delta(s)).
\]
There are no omitted fibre values or extra inverses.
The fixed smooth inverse determinants are respectively \(1,2^{-\delta(s)},1\) at every point.
Ordinary affine substitution proves their own every-Borel IMAGE, independently for each chart and owner.
Thus their legal clocks are \(0,\delta(s)\log2,0\).
No predecessor count enters a Jacobian.
All finite inverse label paths from the displayed list, with these fibre substitutions, give every incoming depth; all compatible infinite paths remain.
There are no terminal sources in these controls.
For completeness, a forward label history has at most two lowering edges: after the first lowering to \((d,2)\), a composite \(d\) next lowers at its least divisor, which is prime.
An infinite backward label history therefore has at most two lowerings; its sufficiently distant past stays in one finite constant-first-coordinate graph.
Such a past must contain a cycle, hence a prime scan, which cannot subsequently leave its core.
Thus a transient label has no infinite backward history, while a core label has exactly the backward prime scan.
Each control's invertible fibre edges then give exactly one full infinite backward history above any real value at a core label, and none above a transient label.

## 6. Full global control groupoids, kernels and phases

Normalize a state \(z=(s,x)\) to its first reference arrival by
\[
 u_A(z)=x,\qquad u_B(z)=2^{R(s)}x,\qquad u_C(z)=x+R(s).
\]
On the reference fibre, the actual \(q\)-step return maps are \(g_A(u)=u,\ g_B(u)=2u,\ g_C(u)=u+1\).
Every arrow of each control is EXACTLY described by
\[
 p(z)=p(w)=p,\quad
 u(w)=g^\ell(u(z)),\quad
 k=h(s_z)-h(s_w)+q\ell,\qquad \ell\in\mathbb Z.
\]
Indeed a meeting can be legally extended to the common reference label.
Reference visits have the depths just computed; conversely choose sufficiently large nonnegative reference-loop counts with difference \(\ell\).
Their normalized fibre equality gives an actual witness.
Thus this formula includes every source phase, every incoming state and all retained lags.
For A and C the clock is zero; for B it is
\[
 c(z,k,w)=(R(s_z)-R(s_w)+\ell)\log2.
\]
For every owner the lag kernel imposes the displayed \(k=0\).
For A/C the clock kernel is all of \(G\), and the joint kernel is the lag kernel.
For B the clock kernel imposes \(R(s_z)-R(s_w)+\ell=0\); the joint kernel imposes this and \(k=0\).
These are exact full tests, not assertions that kernels are units.

### A. Identity fibre

The full source packets are indexed by \((p,x)\):
\[
 \{(s,x):p(s)=p\}.
\]
Every state is eventually periodic; its sole core is the prime scan with that same real \(x\).
The complete least-\(q\) set is empty unless \(q+1=p\) is prime, and then consists of all \(q\) cycle labels times every real \(x\).
Each core has sum0, source isotropy \(q\mathbb Z\), entire \(H=0\) and extension isotropy \(q\mathbb Z\).
Every height \(h_{\rm phys}\in\mathbb R\) is a distinct physical phase for its source packet.
There is no positive primitive or positive repetition, despite actual source cycles.
For each prime there are continuum distinct full packets and positive, indeed infinite, original measure of periodic points.

### B. Dilation at every actual restart

The only source cycles have fibre \(x=0\), since a full prime scan returns \(x\) to \(2x\).
Indeed every possible period is a positive multiple \(jq\) and would require \(2^jx=x\), forcing \(x=0\).
Their least period is \(q=p-1\); all zero-fibre states and only those states are eventually periodic.
For each prime \(p\) the complete incoming periodic packet is \(\{(s,0):p(s)=p\}\).
Its source isotropy is \(q\mathbb Z\), loop character \(nq\mapsto n\log2\), entire \(H=(\log2)\mathbb Z\), and extension isotropy is zero.
All physical phases are \([h_{\rm phys}]\in\mathbb R/(\log2)\mathbb Z\), since the first-arrival clock \(R(s)\log2\) is already in that group.
The primitive is \(\log2\), with all positive integer repeats; different primes retain different full packets with this same primitive.
This is a multiplicity failure for this control, not arithmetic admission.
Here \(E^\times=Q\times\{0\}\), a nonempty original null set whose clocks are not zeroed out.

For \(x\ne0\), write uniquely \(u_B(z)=2^{j_z}b\), where \(j_z\in\mathbb Z\) and \(1\le|b|<2\).
The complete aperiodic source packets are indexed by \((p,b)\), containing every label with \(p(s)=p\) and every \(x=2^{j-R(s)}b\), \(j\in\mathbb Z\).
There is no nonzero source isotropy, entire \(H=0\), and extension isotropy is zero.
Relative to \((o_p,b)\), an arrow to \(z\) has lag \(h(s)-qj_z\) and clock \((R(s)-j_z)\log2\).
Thus ALL physical phases are the real values
\[
 h_{\rm phys}-(R(s)-j_z)\log2.
\]
No positive physical return exists in these aperiodic packets.

### C. Translation at every actual restart

A full scan sends its reference fibre to \(u+1\), so no actual source cycle or eventually periodic state exists.
Any possible period would be \(jq\) with \(j\ge1\), requiring \(u+j=u\), which is impossible.
Write \(u_C(z)=j_z+\beta\), uniquely with \(j_z\in\mathbb Z,\ 0\le\beta<1\).
The full source packets are indexed by \((p,\beta)\), containing all labels with \(p(s)=p\) and all \(x=\beta+j-R(s)\), \(j\in\mathbb Z\).
Each has source isotropy0, entire \(H=0\), extension isotropy0 and all real height phases \(h_{\rm phys}\).
There is no positive primitive or repetition.
The exact arrow and inverse formulas above still retain every transient label, actual scan phase and infinite common-tail history.
