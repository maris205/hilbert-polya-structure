## 2. 核、块归一化与真实列推进

`build_blocks`使用L2、每轴奇数n的周期端点格，状态以`i*n+j`排列。
每个时间和中间坐标j独立求自己的第一列原始权重及Z；不把Z换成统一
积分常数、不逐行重新归一化、不截核或补正非正权重。

作者经主控确认的周期索引实现与卡的数学核一致。令
`ell=(i+k)%n`，则

\[
q_i+q_k=q_{\ell}+q_0+2L\lfloor(i+k)/n\rfloor.
\]

故sin平方核的周期给出`K[j,k,i]=first[j,(i+k)%n]`。
源码与manifest均披露：先算每帧n²个原始权重，再按周期索引构造全部n³块；
不是对n³个浮点等价角独立计算sin。该实现没有改变亚格位移的j依赖。
每块原始/归一化权重须正有限，Z须正有限；行/列和误差超过1e−12即停止。

前向从完整d×d单位矩阵开始。`reshape(n,n,d).transpose(1,0,2)`把源轴
`[i,j,c]`变为`[j,i,c]`，再以块`[j,k,i]`批量乘法得到`[j,k,c]`。
四次按时间顺序左乘，得到列约定`C=T3 T2 T1 T0`，没有转成行推进、
平均T或借用旧静态谱。C非有限或行/列和及左右常数残差超过1e−10即停止；
下溢为零的小元素只记账，不补正。

A为四帧相同参数；D使用冻结的四个实际映射时刻，并显式固定首末为
`a_parameter`及1.02。没有改成64步或把映射步数当积分细化。

## 3. 单次完整SVD与唯一常数模门

每个前向恰有一次`np.linalg.svd(C, full_matrices=True)`；全部d个σ保存，
训练/后检缓存同次前321左右态，小控制缓存全部49态。保存态时只算残差、
正交性、FFT占据等诊断，不重分解，不形成Gram替代原SVD。

正式读出逐项检查：σ0距1不超过1e−10，前321项正有限降序，
σ320/σ0至少1e−10，σ1小于1且间隙至少1e−8；顶左/右态分别与
±均匀常数向量距离不超过1e−6，两个常数投影符号一致。
仅排除索引0这一维；剩余全部d−1项保留原重数及索引。
`E=-log(sigma[1:])/4`，用首个非平凡能量定标；没有质量、加法偏置、
减基态、实测σ0归一化、对数分支选择或奇偶筛选。
全尾mask没有被宣称为全尾精度证书。

任一训练网格无效则联合罚1e30并禁止参选，同时保留σ、E与原因。
SVD/实现异常则整次停止，不当成普通无效成员继续。
小控制明确标为`CONTROL_ONLY`，不套321项及唯一常数模门。
单步多个守恒通道的态诊断也注明其余态未必全部非恒定，未把任一
单步SVD基向量误认证为唯一常数态。

## 4. 六控制与冻结训练设计

六个n7、epsilon=.30控制全部位于唯一main内，均计一次前向和完整SVD。
单步控制的各块第一行DFT使用默认未归一化前向DFT，其模汇总排序与完整σ比较。
四步零源控制使用自身K，比较`kron(K@K,K@K)`及DFT模平方的所有两两乘积。
反序控制用同一四帧反序，并以坐标交换索引实现`J C.T J`；
A/D的1.02退化控制分别实际计算。谱容差1e−10、矩阵相对Frobenius容差
1e−10均与卡一致，任何硬控制失败即停止。这里尚未实际执行这些控制。

8种子/族、共同`default_rng(20260929)`宽域点、A→D轮转16对调用正确。
各族最佳有效种子启动一次bounded Nelder–Mead，`maxfev=20`、归一化边0.06
且向内、两容差1e−6、`adaptive=False`。最多56对/112训练前向；
同族精确参数缓存仍占调用，不能跨族转移预算。
无有效种子则跳过该族优化，不捏造赢家；全空时主角色为None。
排序依据全部已访问有效成员的`(J,maxM,maxW,G,ID)`，不是最后优化返回点。
两训练网格分别进入M/W及G，全部只使用锁定首100目标。

先保存并哈希赢家身份，再保存每族两个训练网格完整C/同次SVD态，
每有效族4个文件，两族齐全为8文件；其后才解析五份101–320 JSON及
旧B0055完整结果/预测。14输入的预先字节哈希不是提前解析开发目标。
无赢家时仍可冻结空角色/空文件集并输出完整负记录，无缺键依赖。
所有历史参考都是已知数据，冻结次序不把它们变成盲测。

## 5. 后检、消融和完整owner别名
