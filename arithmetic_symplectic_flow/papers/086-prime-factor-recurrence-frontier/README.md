# 086 — Prime-factor recurrence frontier

**Record:** ASFS-FRONTIER-20260914-09  
**Status:** PORTFOLIO FRONTIER — DIRECT FACTOR RECURRENCES RETAIN A0/A1 CONTROLS BUT NO CLASSICAL P0 ADMISSION

This frontier consolidates, without merging, the three distinct direct
prime-factor recurrence outcomes in 083–085: terminal partial dynamics,
a unique small attracting cycle, and an infinite prime-labelled fixed family.
They establish that arithmetic factor rules can own exact recurrence data, but
none supplies the required fixed Hénon/symplectic carrier, positive roof, and
same-object geometry. The next search must therefore be reversible or
intrinsically invertible before it is developed as a classical candidate.
