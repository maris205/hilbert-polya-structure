# Evidence

Primary source: C. Deninger, [*Dynamical systems for arithmetic schemes*](https://arxiv.org/abs/1807.06400), published 2024. The source describes a continuous-time system for normal schemes of finite type over \(\operatorname{Spec}\mathbb Z\), with periodic-orbit packets indexed by closed points and lengths equal to logarithms of residue-field orders. Additional exposition: [*Primes, knots and periodic orbits*](https://arxiv.org/abs/2301.11643).

Nearest geometric comparator: J. Kim, M. Morishita, T. Noda, and Y. Terashima, [*On 3-dimensional foliated dynamical systems and Hilbert type reciprocity law*](https://arxiv.org/abs/1906.02424), constructs and classifies concrete smooth FDS³ examples. It is not evidence that Deninger's arithmetic system has a finite-dimensional symplectic section or the same orbit set.

Geometric-boundary source: [Deninger, *Scaling group flow and Lefschetz trace formula for laminated spaces with p-adic transversal*](https://arxiv.org/abs/math/0603576) describes the zeta-associated laminated-space existence as unknown, except for the elliptic-curve-over-finite-field case. It is used only to delimit the fork; no local model or flow is transferred to this package.
