# 053 — Real-time sieve cellular automaton nonrecurrence screen

**Record:** `ASFS-SCOUT-20260914-39`  
**Status:** `A0 SYMBOLIC POSITIVE CONTROL; PRE-P0 STOP — DESIGNATED SIEVE TRAJECTORY IS NONRECURRENT`

A fixed finite-state, local cellular automaton can implement the Eratosthenes
sieve from one fixed boundary seed, without an externally supplied prime list.
This makes it a sharper endogenous symbolic control than a prime-indexed
operator family. Its designated configuration trajectory nevertheless cannot
be periodic: its left-boundary observation is exactly the nonperiodic prime
indicator. It is neither a reversible action nor a symplectic base, and does
not supply a closed-orbit ledger.
