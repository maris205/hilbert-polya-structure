# Source and evidence — `ASFS-SCOUT-20260914-19`

Source consulted on 2026-09-14:

- Birke Heeren, [*On The Nature Of Primes: A deterministic, endogenous,
  non-stationary S-adic Automaton for the sieve of Eratosthenes*](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6015434), SSRN, dated 2026-04-11.

The SSRN abstract describes a finite-alphabet symbolic system with a growing
tape and sequential shift, expansion, and filtering operators; it calls the
automaton non-stationary and describes prime-dependent substitution rules and
an upper-triangular transition matrix `M_p`.  The full PDF was access-restricted
during this audit, and this is a recent unrefereed preprint.  Accordingly this
record relies only on those limited source descriptions; it does not validate
the paper's claimed prime-classification theorem, numerical experiments, or
spectral/fractal conclusions.

The strictly increasing-coordinate implication used in the screen is proved
locally in [018](../../018-monotone-sieve-clock-obstruction/paper.md).  No
computation was run and no source claims were transferred to an ASFS object.
