# Evidence and reproducibility boundary

## Source

- Jeremy Alm and Taylor Herald, *A Note on Prime Fibonacci Sequences*,
  Fibonacci Quarterly 54 (2016), 55--58; preprint
  [arXiv:1507.04807](https://arxiv.org/abs/1507.04807).  Its abstract states
  the rule and the theorem used here: these sequences always terminate in a
  power of two (while admitting infinite left extensions).

## Exact derivation used here

No numerical search was run.  The sole deduction is: a periodic point would
have arbitrarily many defined forward iterates, whereas the cited theorem gives
a terminal iterate for every positive initial pair.  Hence no periodic point
exists on the partial action defined in the candidate card.

## Limits

The source theorem is used only for the stated positive forward recurrence.  It
does not supply a symplectic realization, a roof, an operator, a zeta function,
or an arithmetic connection beyond the recurrence's prime-factor rule.
