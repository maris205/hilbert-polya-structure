## 1. 问题与最强结论

本包承接 [246 读出归属诊断](../246-spectral-readout-mixing/paper.md)，
检查固定非自治路径与原期望选支读出在邻近空间离散维度上的

54.96826%、40.82490%、68.95543%。首间隙同步改变，原百点拟合
在本次所测固定箱长离散族中具有强网格敏感性，不能晋级为网格稳健
的谱证据。这不否定 N250 的复现，也不证明所有更高 N 不会收敛。

用户要求“继续”后，已具体化为复用 N=250 旧基线，新增 N=260、
280、300 各一次前向。用户随后明确答复“按此执行”，已按原命令
完成三次前向，不调整参数、不重跑 N250、不重试。执行前方法及
授权分别保存在 [原协议](candidate-card-frozen-v1.md)、

## 3. 离散化解释

按原源码，dq=2L/N，dp=2pi*hbar/(N*dq)=pi*hbar/L。固定 L 时
细化空间采样也扩展 FFT 动量截止，并改变矩阵维度。因此本检验不是
提高同一有限矩阵的浮点精度，也不是时间步长收敛检验。

同一排序序号的预测可以比较，但不能称为同一物理态的能级位移。
原解缠偏移界 pi*hbar/300 在所有 N 相同，仍不保证最低期望、首间隙
或定标后预测稳定。前一包已说明原排序低态不是 H_base 的低能态。

## 4. 冻结采集与判断方式

沿用原 solve 和 245 返回事件采集方法，保存每个新 N 的完整矩阵、
本征对、期望、整数分支、排序映射、300 步路径和 100 点残差。
同时报告动量截止、未移零最低值、首间隙与首点尺度；不只看 MAPE。

主比较仍使用各自首点尺度。纯期望读出单独标识为诊断，不替换主
结果。对 N250 和相邻 N 的预测差只是排序输出曲线差，不作态配准。
不以某个较好的 N 重新定义基线；所有预先指定结果或失败均保留。

没有预设宣称收敛的 PASS 数值门槛。四点接近最多支持局部有限范围
稳定；明显漂移则反对该组网格下的稳健拟合解释。两者均不证明或
否定所有更高 N 的连续极限、其他参数或所有可能离散化。

## 6. 控制与未建立的结论

目标仍是全部参与历史选择的百点数据，N250 是历史择参维度；本轮
不产生盲测。首点零误差是规则强制，不是通过稳定性检验。
当前没有重优化静态/动态模型、箱长测试、时间步细化、不同目标或
高精度计算。网格敏感不能证明所有参数、所有读出或所有后续离散化
都失败；也没有证明动态起点无作用。

是否有可解释的无限对象、是否应将 N 作为模型定义而非数值截止、
以及原读出对高动量模式的依赖原因仍 OPEN。必须先区分这些问题，
不能对每个 N 重新调参后将结果包装成原对象的收敛证据。
