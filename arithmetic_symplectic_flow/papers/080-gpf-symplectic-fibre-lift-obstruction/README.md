# 080 — GPF componentwise symplectic-lift obstruction

**Record:** ASFS-SCOUT-20260914-54  
**Status:** PRE-P0 STOP — NO COMPONENTWISE SYMPLECTIC DIFFEOMORPHISM CAN COVER THE NONINJECTIVE GPF MAP

This is a direct classical-lift audit for 078, not a general no-go theorem. If
each discrete GPF state labels one connected symplectic fibre and a
symplectic diffeomorphism sends the fibre over a to the fibre over G(a), then
the induced map on components must be bijective. Since G(1,1)=G(3,1), no such
componentwise owner exists. A connected continuous factor to a discrete state
space is constant, so it does not repair the direct construction.
