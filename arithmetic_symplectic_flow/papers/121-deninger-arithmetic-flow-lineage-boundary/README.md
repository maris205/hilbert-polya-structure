# 121 — Deninger arithmetic-flow lineage boundary

**Record:** `ALF-20260914-DEN01`  
**Status:** `EXTERNAL BROADENED POSITIVE CONTROL — ARITHMETIC PERIODIC-ORBIT PACKETS WITHOUT THE REQUIRED PRIME-SYMBOLIC LINEAGE`

Deninger constructs an infinite-dimensional continuous-time arithmetic dynamical system. For closed points of an arithmetic scheme it has compact packets of periodic orbits of length \(\log N x\); for \(\operatorname{Spec}\mathbb Z\), closed points are primes. This is a genuine broadened carrier with packet multiplicity, not a classical symplectic suspension. It has no documented reconciliation with this project's sieve-symbolic/Logistic/Hénon lineage.
