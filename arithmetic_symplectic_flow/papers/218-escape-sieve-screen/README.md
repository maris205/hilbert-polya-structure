# 218 — Escape-gated sieve screen

**Candidate ID:** ASFS-SCOUT-20260918-ERF01  
**Status:** PRE-P0 STOP — ABSORBING ESCAPE IS A COMPOSITE FIXED ORBIT; STATIC n ALSO FAILS ENDOGENOUS A0.  
**Formal Route coordinates:** UNASSIGNED. **Route B:** NOT INVOKED.

The frozen scan tests divisors while (d^2le n). A prime reaches its
closure state (C_n), while a composite reaches its escape state at its
least divisor. But the frozen rule makes (E_n) fixed, so every composite
has a primitive period-one orbit. Independently, the integer label (n)
is static rather than generated by the dynamics. The screen stops before
P0; changing the escape carrier or adding an (n)-generator requires a
fresh candidate.
