# Evidence — `ASFS-SCOUT-20260914-22`

Primary source: Liang Wang, [*The emergence of prime distribution from
low-dimensional deterministic chaos*](https://doi.org/10.1080/27684830.2026.2684334),
*Research in Mathematics* 13(1), 2026.

The accessible article defines `S_(p_i)` separately for each prime and defines
the cumulative state from the first `k` such operators. It labels topological
admissibility “Hypothesis 3.3” and says a complete rigorous monotonicity proof
is beyond the article's scope. This audit uses no stronger claim.
