# Natural-extension test for one-sided sieve recursion

**Record ID:** `ASFS-SCOUT-20260914-20`  
**Status:** `METHOD STOP RULE — NO ENDOGENOUS BI-INFINITE SIEVE HISTORY; Route B NOT INVOKED`

A formal inverse-limit or natural-extension construction cannot by itself turn
the one-sided primorial/S-adic sieve recursion into a recurrent arithmetic
carrier.  Its faithful stage coordinate has a lower bound and advances by one;
therefore it has no bi-infinite trajectory.  Adding negative stages or choosing
predecessors changes the arithmetic mechanism rather than extending it.

This rule preserves the distinction between a genuine recurrent replacement
and a notation-level removal of time.  Read [the paper](paper.md),
[scope card](candidate-card.md), [claim ledger](claim-ledger.md), and
[evidence](evidence/README.md).
