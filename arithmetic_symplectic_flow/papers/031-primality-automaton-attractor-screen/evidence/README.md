# Evidence — `ASFS-SCOUT-20260914-23`

The source's primality section is [*Computations in Cellular
Automata*](https://sfi-edu.s3.amazonaws.com/sfi-edu/production/uploads/sfi-com/dev/uploads/filer/87/3f/873f8a42-62ef-4bc7-968b-b4e8e41f95eb/01-12-083.pdf).
It states that a supplied encoding for `n` converges to `(0,0)` if `n` is prime
and is trapped in a `4p+2` periodic orbit if least factor `p` is detected, using
Eratosthenes sieve as the primality check. No smooth or analytic realization is
inferred here.
