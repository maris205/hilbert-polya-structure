# Fargues–Fontaine mirror geometry: local symplectic success, global A0 failure

**Record ID:** `ASFS-SCOUT-20260913-06`  
**Status:** `LOCAL SYMPLECTIC CONTROL; P0 NOT ADMITTED`

Lekili–Treumann study a Fukaya-category construction on a symplectic 2-torus whose coefficient monodromy is the \(p\)-power map and relate it to a Fargues–Fontaine curve. This is valuable evidence that arithmetic Frobenius data can coexist with genuine symplectic geometry.

It is nevertheless local: choosing the curve fixes its residue characteristic \(p\). Replacing \(p\) changes the construction, so no single object provides the varying rational-prime relation required by A0. The mirror/categorical relation is also not itself a specified symplectic base map with positive roof and closed-orbit owner. `fork`: retain as a design constraint, not as a candidate.
