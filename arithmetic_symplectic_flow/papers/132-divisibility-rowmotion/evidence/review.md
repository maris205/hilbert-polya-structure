## Exact proof checks

1. **Image and injectivity.** Every element of an upset has a minimal upset
   divisor, since it has only finitely many divisors. Thus the upset is
   generated by its minimal elements, including the empty case. For any
   antichain A, every element of its down-closure lies below a generator,
   and its maximal elements are exactly A, even when A is infinite. These
   identities prove the image characterization and inverse formula. The
   full poset has no maximal element and is nonempty, so it is absent from
   the image. R(P)=empty is consistent with this argument and does not give
   P a predecessor. The empty target has the unique predecessor P.
2. **Rank source orbit.** Divisibility respects total prime-factor count
   Omega. Minimal excluded elements of I_k have exactly rank k+1; any
   higher-rank element has a proper excluded divisor. Every smaller-rank
   integer divides a rank-k+1 integer obtained by multiplying by powers of
   2, so taking the down-closure gives precisely I_(k+1). The first update
   extracts the primes, and the witness 2^(k+1) proves strict escape at
   each stage. The use of factorization in this proof does not introduce a
   prime table into the defining update.
3. **Prime-power height.** For finite height h, the element p^(h+1) is
   minimal outside the downset. No minimal excluded generator can have
   p^(h+2) as a divisor, since it would then have the proper excluded
   divisor p^(h+1). Thus the output height is exactly h+1. Iteration of
   this finite-height identity rules out finite height on a periodic orbit;
   it does not justify any identity at infinite height. The manuscript
   correctly retains that distinction.
4. **No fixed point.** Every proper ideal has a nonempty minimal excluded
   set, which the output contains and the input does not. The remaining
   input P maps to empty. This proves the complete no-fixed-point claim,
