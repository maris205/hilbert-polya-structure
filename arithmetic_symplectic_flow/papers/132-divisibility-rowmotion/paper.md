## Abstract

Let P be the integers at least 2 ordered by divisibility, J(P) the set of
all downsets, and R(I) the downset generated by the minimal elements of P\\I.
This fixed rule internally extracts the prime-indicator support from the empty
state. We prove that R is injective but not surjective on this infinite carrier,
and that its arithmetic rank orbit advances strictly forever. A further exact
necessary condition says that every periodic downset must contain every prime
power. These statements do not classify all periods at least 2 in J(P).
The candidate stops because the full carrier does not support the proposed
reversible action. Finite-poset rowmotion is a comparison source, not a license
to import finite periods or a symplectic realization.

## 4. Exact proof audit

### Proposition 1 — Image and inverse boundary

R is well-defined and injective. Its image consists exactly of the downsets
K satisfying K=downarrow(max K). On that image its inverse is

\[
R^{-1}(K)=P\setminus\uparrow(\max K).
\]

In particular P is not in the image, so R is not surjective.

**Proof.** Every nonempty subset of P has a divisibility-minimal member:
one may take a numerically least member. More specifically, every element of
an upset U lies above a member of min U, by taking a minimal divisor of that
element within U. Thus U=uparrow(min U), including U=empty.

The set A=min(P\\I) is an antichain. For every antichain A, finite or infinite,
max(downarrow A)=A: each point of the generated downset lies below a generator,
and distinct generators are incomparable. Therefore R(I) determines A, which
determines P\\I=uparrow A and hence I. This proves injectivity and the inverse
formula on the image.

Conversely, for any antichain A, I=P\\uparrow A is a downset and
min(P\\I)=min(uparrow A)=A. Hence R(I)=downarrow A, proving the claimed image
characterization. Finally P has no maximal elements, since 2n is a strictly
larger multiple of n for every n in P. Since P is nonempty but
downarrow(max P)=empty, P is not an image. Nevertheless R(P)=empty.
This last relation does not give P a predecessor. QED.

### Proposition 2 — Endogenous prime extraction and rank escape

Let Omega(n) count prime factors with multiplicity, and define

\[
I_k=\{n\geq2:\Omega(n)\leq k\},\qquad k=0,1,2,\ldots.
\]

Then I_0 is empty, R(I_0) is exactly the prime set, and
R(I_k)=I_{k+1} for all k>=0. All I_k are distinct. Thus neither the empty
state nor any member of this arithmetic source orbit is periodic.

**Proof.** Divisibility cannot increase Omega when passing to a divisor, so
each I_k is a downset. The minimal elements of its complement are precisely
those n with Omega(n)=k+1. Such n has every proper divisor in I_k. Any n of
larger rank has a proper divisor still of rank at least k+1 and is not minimal
in the complement.

The down-closure of rank k+1 is I_{k+1}: divisors have rank at most k+1, and
every element of smaller rank can be multiplied repeatedly by 2 to obtain an
element of rank k+1 divisible by it. This proves the update law. For example,
2^{k+1} belongs to I_{k+1} but not I_k, proving strict escape. The use of
Omega describes the consequences of the already fixed divisibility rule; a
prime-factor list is not supplied to select its state or parameters. QED.

### Proposition 3 — Necessary prime-power condition for any periodic state

Fix a prime p. Define h_p(I) as the largest exponent j>=1 for which p^j is in
I, with value 0 if p is absent and infinity if all powers are present. If
h_p(I) is finite, then

\[
h_p(R(I))=h_p(I)+1.
\]

Consequently every periodic downset, if any exists, contains every prime
power. R has no fixed point. Existence of periods at least 2 elsewhere in J(P)
is not decided here.

**Proof.** Write h=h_p(I)<infinity. All proper divisors in P of p^{h+1}
belong to I, so p^{h+1} is minimal in P\\I and belongs to R(I). If p^{h+2}
belonged to R(I), there would be some a in min(P\\I) divisible by p^{h+2}.
But p^{h+1} would be a proper divisor of a outside I, a contradiction.
Down-closure excludes every higher power as well. This proves the identity.

Once a finite height occurs, it increases by one at each further step and
never becomes infinite. It therefore cannot occur on any finite-period orbit.
Apply this to each prime to obtain the necessary condition. Finally, a proper
downset I has a nonempty minimal excluded set, and R(I) contains that set,
which is disjoint from I; hence R(I) cannot equal I. The remaining state P
satisfies R(P)=empty, so it is not fixed either. QED.
