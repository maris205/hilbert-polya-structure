# 051 — Strict-causality periodic-rigidity rule

**Record:** ASFS-METHOD-20260914-05  
**Status:** METHOD THEOREM / PRE-P0 STOP RULE — STRICTLY CAUSAL AUTONOMOUS PRIME CODINGS HAVE NO NONTRIVIAL PERIODIC ORBITS

A strict one-sided causal update fixes every coordinate of any periodic point
by induction from lower coordinates. Thus, once its fixed point is unique, its
entire periodic set is that fixed point. This generalizes the 050 calculation
without claiming to exclude noncausal or genuinely reversible prime dynamics.
