any legal primitive base cycle whose fibre determinant product Q exceeds1

## 4. Decisive finite torsion argument

Take a least base cycle x_0,...,x_(ell-1) and exact monodromy B, Q=abs(det B).
The zero fibre is a genuine full F-cycle of least period ell; H=log Q Z.
If Q>1 is composite this packet already violates the prime-time condition.

Suppose Q is prime. Set the proof modulus m=Q+1, so gcd(m,det B)=1.
This modulus is a proof device, not additional candidate data or a roof.
The adjugate identity and Bezout give an inverse for B over Z/mZ. Therefore
B permutes the complete finite m-torsion group (Z/mZ)^n and its nonzero part.
Take a nonzero torsion point v, and let r>=1 be its least period under B.
The corresponding full F-cycle has least period ell r: base minimality forces
each return time to be a multiple of ell, then fibre minimality forces r.
Every intervening matrix is invertible on this torsion group since its
determinant divides Q, so this core never becomes the zero core.
Equivalently, hitting zero would contradict its nonzero periodic return.

The WHOLE physical group of this second packet is H=r log Q Z. If r=1,
it is a distinct packet with the same prime time as the zero packet. If r>1,
its primitive time is log(Q^r), with composite ordinary integer Q^r. It is
not a repetition of the zero packet, since its full source core is different.
Either way the necessary conjunction fails. No expansion, eigenvalue bound,
root-of-unity exclusion or general periodic-point census was needed.

For Q=1 every factor d along the base cycle equals1, so every full fibre
periodic cycle over it has C=0, with its entire source isotropy retained.
Conversely every positive full periodic cycle projects to a base cycle with
Q>1. Hence if no such base cycle exists, the positive physical ledger is
empty; otherwise the necessary prime-only/unique-packet conjunction fails.
This is the precise sense of the nonempty-target filter in the Outcome.
