**Route state:** `No classical P0 or formal Route-A coordinate; Route B NOT INVOKED`

## Source relation and positive control

Fix (E/mathbb Q). The source defines an elliptic aliquot cycle of length
(L) as distinct primes of good reduction ((p_1,ldots,p_L)) satisfying

\[
p_{i+1}=\#E(\mathbb F_{p_i})\quad(i\bmod L).
\]

This is a genuine prime-to-prime cyclic relation; the source literature also
provides existence results for curves with arbitrarily long cycles. It is thus
a meaningful external A1 positive control, stronger than a terminology-only
``prime orbit'' analogy.

## Same-object failure before P0

| Required owner | What the relation supplies | Boundary |

| Closed packet | a tuple of prime labels related across fibres | not an orbit in one fixed carrier |
| Symplectic base | none specified | a finite-field curve/group is not a fixed ASFS base |
| Roof / suspension / determinant | none | cannot be borrowed |
| Prior-work arrows | no sieve coding, sequential deformation, or Hénon lift | absent |

The fixed equation for (E) does not make the finite-field carrier fixed:
(mathbb F_{p_i}) and (mathbb F_{p_{i+1}}) are distinct characteristics.
The prime restriction is also intrinsic to the *definition of the relation*,
not an arithmetic observable generated by an action on an all-state carrier.
Packaging the disjoint fibres into a set would still require a new global
action and packet convention; none is supplied here.
