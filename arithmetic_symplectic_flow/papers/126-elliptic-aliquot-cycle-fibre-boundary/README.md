# 126 — Elliptic aliquot-cycle fibre boundary

**Record:** `ASFS-SCOUT-20260914-90`  
**Status:** `EXTERNAL A1 POSITIVE CONTROL — PRIME-TO-PRIME ELLIPTIC ALIQUOT CYCLES CHANGE FINITE-FIELD FIBRES AND DO NOT FORM A SIEVE-SYMBOLIC ACTION`

For a fixed elliptic curve (E/mathbb Q), an elliptic aliquot cycle is a
prime tuple with (p_{i+1}=#E(mathbb F_{p_i})). The literature proves that
elliptic curves can possess arbitrarily long such prime cycles. This is genuine
prime-carrying cyclic arithmetic data, but each step is defined over a selected
prime characteristic and changes its finite-field fibre. It supplies neither a
single sieve-derived symplectic map nor the required prior-work lineage.
