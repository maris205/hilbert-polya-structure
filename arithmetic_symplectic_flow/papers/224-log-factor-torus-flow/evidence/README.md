## Terminology correction

An initial shorthand described mixed tori as “nonrecurrent.”  That wording was
incorrect for compact torus translations.  The exact result is **nonperiodic**
(no positive return time), while trajectories are recurrent in the compact
topological sense.  The correction changes no formula or owner.  For two atoms
the trajectory is dense; in higher rank the closure is a subtorus and full
density is conditional on reciprocal-log frequency independence.
