# 072 — ECPP finite-group lineage screen

**Record:** ASFS-SCOUT-20260914-49  
**Status:** EXTERNAL CONTROL — TARGET-INPUT CERTIFICATE CHAIN; FINITE GROUP CYCLES DO NOT OWN A PRIME-SYMBOLIC RETURN

Elliptic-curve primality proving (ECPP) uses genuine finite elliptic-group
operations in each certificate step. It is therefore a strong control against the
mistake “finite group periodicity implies a same-object arithmetic orbit.” The
integer being certified, the selected curve, point, order information, and next
smaller certificate prime are all step data in a target-driven proof chain. No
Eratosthenes/Logistic/Hénon action bridge or fixed symplectic suspension is defined.
