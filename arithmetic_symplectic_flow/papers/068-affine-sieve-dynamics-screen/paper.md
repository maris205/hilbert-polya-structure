## What this source contributes

Affine sieve studies an orbit `O` of an arithmetic/congruence group acting on affine space and applies a chosen integer-valued polynomial `f` to points of that orbit. In appropriate settings it establishes quantitative information about points for which `f(x)` has few prime factors, and in some cases about prime-coordinate phenomena. This is authentic arithmetic dynamics, not a numerical prime fit.

## Why it does not enter the present candidate line

The source object starts with a group, a selected orbit, and a polynomial observable. It does not start with the prior-work prime/composite sieve word or its symbolic admissibility relation, and it provides no coding from that source into the group action. A prime or almost-prime value of `f(x)` is an arithmetic property evaluated on a group orbit; it is not a state produced by a self-contained Eratosthenes update.

Nor is the action one specified return map. The group/semigroup has many allowable generators, and ordering an orbit by a norm or word length is an enumeration convention, not a positive roof on primitive closed trajectories. Group relations, finite quotients, or stabilizers must not be silently substituted for a primitive-flow ledger. No symplectic phase space, exact symplectomorphism, suspension, roof, transfer operator, or same-object dynamical determinant is fixed by this source.

Thus this screen labels the object `EXTERNAL CONTROL` at the lineage gate rather than attempting to use its arithmetic strength to rescue a missing Hénon/conservative bridge.
