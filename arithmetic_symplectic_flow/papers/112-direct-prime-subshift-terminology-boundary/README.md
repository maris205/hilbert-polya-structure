# 112 — Direct-prime subshift terminology boundary

**Record:** `ASFS-SCOUT-20260914-79`  
**Status:** `PRE-P0 STOP — TOPOLOGICAL “DIRECT PRIME” IS NOT A PRIME-ARITHMETIC MECHANISM`

The reversible-CA literature's ``direct prime'' label means that a subshift
does not split as a nontrivial direct product.  It is not a prime-number
observable and supplies no sieve-symbolic source, prime packet, or geometric
owner.  The record prevents a search-keyword collision from entering the
candidate portfolio.
