# ``Direct prime'' subshifts are not prime-number symbolic sources

**Paper ID:** `112-direct-prime-subshift-terminology-boundary`  
**Record ID:** `ASFS-SCOUT-20260914-79`  
**Date / status:** `2026-09-14; PRE-P0 STOP — TOPOLOGICAL “DIRECT PRIME” IS NOT A PRIME-ARITHMETIC MECHANISM`

## Frozen source object

The screened literature calls a subshift \(X\) *direct prime* when every
conjugacy \(X\cong Y\times Z\) has at least one trivial factor.  It studies
reversible cellular automata (bijective sliding-block maps) on symbolic spaces
with this property.  The word ``prime'' refers to direct-product
indecomposability, exactly as it does for an indecomposable algebraic object;
it is not the predicate that an integer has no nontrivial positive divisors.

## Lineage and gate decision

The source can supply a generic symbolic/reversible comparator, but does not
realize the project arrow

\[
\text{prime distribution or prime/composite observable}
\longrightarrow\text{symbolic admissibility}.
\]

No state in the definition distinguishes integer primes from composites, and
no rule produces a prime-side symbolic word.  Attaching a prime-labelled
subshift, a selected finite field, or a sieve output would make a new object
and reintroduce an external input.  Reversibility cannot repair this missing
arithmetic owner.

a no-go theorem about reversible cellular automata.  A future CA candidate
must supply its own prime-symbolic update and its own recurrent packet before
any conservative realization is considered.
