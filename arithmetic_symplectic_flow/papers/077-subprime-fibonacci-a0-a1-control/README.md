# 077 — Subprime-Fibonacci A0/A1 control

**Record:** ASFS-SCOUT-20260914-52  
**Status:** A0 SYMBOLIC POSITIVE CONTROL; A1 PROVES_TOO_MUCH — EVERY DIAGONAL n >= 2 IS FIXED; PRE-P0 STOP

Conway's subprime-Fibonacci rule defines one fixed recurrence on positive integer
pairs. Its prime/composite decision and least-prime-factor reduction are internal
to that rule, and the literature records actual eventual cycles. It also has the
exact nonselective fixed family T(n,n)=(n,n) for every n >= 2, including every
composite n; actual recurrence therefore proves too much to be a prime orbit
ledger. Its carrier is moreover discrete and the map is noninjective, so it cannot
be silently relabelled as a finite-dimensional symplectic/Hénon base or a
classical suspension candidate.
