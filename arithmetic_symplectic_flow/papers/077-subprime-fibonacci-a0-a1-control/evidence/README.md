  cycle behaviour. It does not prove a complete classification or universal
  eventual periodicity; this record does not claim either.
- The noninjectivity calculation is exact and uses only s(3)=3 and s(6)=3.
  The adverse diagonal family is also exact: for every n >= 2, lpf(2n)=2,
  hence s(2n)=n and T(n,n)=(n,n).
- No seed search, cycle computation, prime table, geometric lift, roof,
  determinant, or Route calculation was performed. A future lift must be a new
  frozen object rather than an inherited conclusion.
