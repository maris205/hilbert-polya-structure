## Screened architecture

The source studies the intermittent interval family `T_z(x)=x+x^z mod 1`, with a neutral fixed point at zero, and compares its symbolic orbit statistics to a binary prime indicator.  The comparison is close enough to the project’s Logistic/symbolic ancestry to merit an explicit audit.

But the source defines the prime string first: integer `n` is assigned 1 if it is prime and 0 otherwise.  The map’s orbit is then compared to this input by compression and entropy-information quantities.  It expressly treats the relation as probabilistic/heuristic, observes mismatches in waiting-time behavior, and describes time-dependent model selection as being as hard as prime-counting approximation.

## Controls

1. **Input control.** Shuffling/replacing the external binary series changes the comparison target without changing the map; the arithmetic content is not in the map.
2. **Parameter control.** The source tests selected `z`/perturbed parameters against observed information statistics.  This is not an internal parameter derivation.
3. **Source self-control.** It states that the probabilistic inference need not hold for the actual prime string and reports divergent waiting-time behavior.
4. **Lineage control.** Logistic adjacency alone realizes only a prototype node.  It does not supply the required sieve-to-symbolic-to-conservative/Hénon owner chain.
