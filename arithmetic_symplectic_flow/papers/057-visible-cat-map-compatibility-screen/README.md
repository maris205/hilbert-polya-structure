# 057 — Visible-lattice / cat-map compatibility screen

**Record:** `ASFS-SCOUT-20260914-41`  
**Status:** `PRE-P0 STOP — VISIBILITY AND CAT-MAP PERIODICITY LIVE ON INCOMPATIBLE CARRIERS`

The integral cat matrix preserves primitive lattice vectors on `R^2`, but its
nonzero visible vectors are not periodic. Passing to the symplectic torus
creates periodic orbits while collapsing all integer visible vectors to one
point. Thus the two desirable features do not belong to one frozen object.
