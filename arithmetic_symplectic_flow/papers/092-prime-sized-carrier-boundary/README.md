# 092 — Prime-sized-carrier ownership boundary

**Record:** ASFS-METHOD-20260914-11  
**Status:** METHOD STOP RULE — EXTERNAL PRIME-SIZED CARRIERS ARE NOT ENDOGENOUS ORBIT MECHANISMS

When prime (p) is selected before it fixes a finite carrier, a modulus, or a
network size, subsequent exact cycles belong to that selected finite object.
They do not establish an internal arithmetic selection mechanism.
