# Evidence boundary

- The concrete `a=5` cycle is recorded as a scouting example in the public question [“Does every sequence `s_(i+1)=gpf(a s_i+1)` eventually cycle?”](https://math.stackexchange.com/questions/3654241/does-every-sequence-s-i1-textgpfs-i2k-eventually-cycle).  That page does not prove global eventual periodicity, so no such result is used here.
- Exact audit: `gpf(5·2+1)=11`, `gpf(5·11+1)=gpf(56)=7`, `gpf(5·7+1)=gpf(36)=3`, and `gpf(5·3+1)=gpf(16)=2`.
- For the prior direct-factor lineage/control boundary, see [084](../../084-affine-gpf-two-cycle-control/paper.md) and [086](../../086-prime-factor-recurrence-frontier/paper.md).

Method: symbolic algebra and factorization of the four displayed integers only.  No parameter sweep, finite orbit enumeration, roof, zeta/determinant, symplectic lift, or Route evaluation was performed.
