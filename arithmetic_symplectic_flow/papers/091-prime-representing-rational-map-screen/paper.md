# A prime-representing seed does not make its rational map an endogenous prime dynamics

## Object and source claim

Freeze the map

\[
\mathcal T(x)=\lfloor x\rfloor(1+\{x\}),\qquad x\ge1.
\]

The cited source studies this map because a prior construction supplies an
irrational (x) whose orbit has integer parts equal to successive primes. That
is a property of a selected seed, not a mechanism by which (mathcal T)
chooses it from its own state space.

For every integer (m\ge1), ({m\}=0), so

\[
\mathcal T(m)=m.
\]

Thus the same map has all positive integers as fixed points, including all
composites. This is an exact full-family adverse control, independent of any
finite orbit experiment.

| Sieve/Logistic/Hénon lineage | none supplied | scoped FAIL |
| Roof/flow/determinant | none supplied | NOT EVALUATED |

The source also proves rational-orbit finite-order density statements, but
those do not select the prime seed or convert its floor itinerary into a
closed-orbit ledger. Selecting only its special orbit, or only prime fixed
points, would be post-selection and would change the owner relation.

## Decision

**Portfolio position: stop/fork.** The map is retained as an external
prime-representation control. A future candidate needs its arithmetic rule to
select or generate its prime-symbolic datum inside the frozen action, while
avoiding an all-integer fixed family.
