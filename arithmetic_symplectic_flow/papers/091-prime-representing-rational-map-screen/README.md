# 091 — Prime-representing rational-map screen

**Record:** ASFS-SCOUT-20260914-62  
**Status:** EXTERNAL A0 CONTROL; A1 PROVES_TOO_MUCH — ALL INTEGERS ARE FIXED; PRE-P0 STOP

The map (mathcal T(x)=\lfloor x\rfloor(1+\{x\})) appears in a construction
whose specially chosen irrational seed has successive integer parts equal to
the primes. The map itself fixes every integer, however, and does not select
that irrational seed or generate prime labels. The prime representation is
therefore initial-condition input, while its full periodic set already contains
all integers. It is not an endogenous prime-symbolic or symplectic candidate.
