# 103 — Arithmetic billiard static-input boundary

**Record:** ASFS-SCOUT-20260914-71  
**Status:** PRE-P0 STOP — GCD/LCM BILLIARD PERIODICITY IS SELECTED BY STATIC RECTANGLE INPUT, NOT AN ENDOGENOUS PRIME-SYMBOLIC ACTION

Arithmetic billiards give a geometric gcd/lcm interpretation and genuine periodic reflected paths for selected non-coprime integer rectangles.  But the integers defining the rectangle are supplied before the billiard map acts, and no sieve-derived prime observable, varying-prime mechanism, or prior-work Hénon deformation is present.
