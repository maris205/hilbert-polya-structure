# Direct-lineage search frontier: selection, fixed geometry, and actual return must be owned together

**Paper ID:** 076-breadth-frontier-cycle-08  
**Record ID:** ASFS-FRONTIER-20260914-08  
**Date / status:** 2026-09-14; PORTFOLIO FRONTIER — NO P0 ADMISSION

## Portfolio result

The immediately preceding screens test different ways of preserving the
prime-symbolic to conservative-geometry lineage. Their positive features cannot
be assembled into one object.

| Architecture | Genuine retained feature | Decisive boundary |
| --- | --- | --- |
| Pratt/ECPP certification | explicit prime-recursive arithmetic relation; ECPP also has local finite-group geometry | complete certificate transition strictly descends and cannot return |
| P28 Hamiltonian selector | autonomous polynomial symplectomorphism with endogenous finite selector cycle | one map/dimension per supplied finite word; selector cycle is not a phase-state orbit |
| countable Hénon coding | non-SFT symbolic class that can in principle evade 046 | no fixed area-preserving map linked to the sieve-symbolic source |

The first row cannot donate arithmetic selection to the second; the second cannot
donate a closed-orbit ledger to the third; and the third cannot be declared to
inherit the first row's prime relation. Those would each violate the one-object
invariant.

## Retained admission condition

A future P0 can be admitted only after one specified construction supplies all
of the following before deep A1 work:

1. one fixed finite-dimensional conservative/symplectic map and fixed phase
   space, independent of a chosen finite prime word, target integer, or per-prime
   parameter schedule;
2. a mathematically defined map-internal prime/composite symbolic observable,
   connected by a named deformation, semiconjugacy, or invariant to the
   prior-work sieve/Logistic lineage;
3. an intrinsic nonfinite coding if finite type is insufficient, with proof that
   it belongs to that same map rather than a separately supplied graph; and
4. actual phase-space primitive closed orbits and repetition data, distinct from
   degree, selector, certificate, or fibre cycles.

This is an admission test, not a no-go theorem. It leaves open a construction
meeting these four requirements simultaneously.

## Decision

**Portfolio position: fork.** Do not rescan well-founded certificates,
finite-word-per-map Hamiltonian constructions, or generic countable shifts as
main candidates. Search instead for a fixed-map intrinsic prime-coding mechanism
and reject it promptly if the code, selection, or state-orbit ownership is
external.
