# A causal binary prime sieve owns A0 but has only one periodic point

**Paper ID:** 050-causal-binary-sieve-fixed-point-screen  
**Record ID:** ASFS-SCOUT-20260914-38  
**Date / status:** 2026-09-14; A0 + COMPLETE PERIODIC-SET CONTROL — UNIQUE PRIME-INDICATOR FIXED POINT; PRE-P0 STOP

## Abstract

A 2026 Zenodo preprint defines a causal binary sieve operator on a candidate
binary sequence and proves that the prime-indicator is its unique fixed point.
The TeX source has now been read. The operator consults only its candidate
sequence's earlier active entries, so it supplies an exact endogenous
prime-symbolic mechanism. The same triangular causality also proves a stronger
fact not stated as the source's main theorem: every periodic point equals that
prime-indicator fixed point. Thus A0 and a complete but degenerate periodic
ledger are established on one object. It remains outside P0 because its one
point has no nontrivial primitive/repetition family and no documented
Logistic/Henon/conservative/symplectic continuation.

## 1. Screened object and lineage

The source arrow is:

prime/composite observables -> causal divisibility exclusion -> fixed binary
prime-indicator configuration.

This begins exactly at the project's prime-symbolic origin. It does not,
however, document a deformation into the Logistic prototype, nonautonomous
Henon bridge, conservative map, or symplectic realization.

## 2. Exact defining operator and A0 ownership

For every candidate sequence Q:N->{0,1}, the source defines:

G[Q](n)=1 iff n>=2 and no m with Q(m)=1, 2<=m<=sqrt(n), divides n.

Every tested coordinate is strictly earlier than n. No set of primes occurs in
this definition: active candidate entries are the sole arithmetic input. For
Q=p, a prime has no divisor in this range; a composite has a prime divisor in
it. Hence G[p]=p. Conversely, strong induction proves that any fixed Q agrees
with p at every coordinate. This resolves the apparent block-memory ambiguity:
the later S_K notation is an exposition of the already established fixed
sequence, not a datum needed by G.

## 3. Complete periodic-orbit test

Let G^r Q=Q for some positive r. Strong induction on n proves Q(n)=p(n).
At n=0,1,2, the claim follows directly from the definition. Assuming it for
every lower coordinate, each of the r causal applications of G sees the same
lower prime-indicator data; in particular GQ(n)=p(n). But periodicity gives
Q(n)=G^rQ(n)=p(n). Thus the full periodic set is exactly {p}.

There is one period-one orbit and its formal repetitions remain that same
orbit. This is a complete same-object periodic classification, but it is not
the required nontrivial primitive closed-orbit family or a zeta ledger. No
suspension roof, smooth phase space, or analytic owner is supplied.

## 4. Controls and scope

The defining operator uses no finite numerical prime table or von Mangoldt
data. The source's four-bit block formulation can be evaluated from p, but
does not replace G as the frozen arithmetic owner. Its later von-Mangoldt
spectral refinement is not a license to insert those weights here. Nor may the
fixed binary configuration be embedded into a Henon horseshoe or given a
borrowed roof: either action makes a different object.

## 6. Decision

**Stop/fork.** The source proves its own endogenous fixed-point mechanism, but
the causal triangular structure collapses all periodic points to it. A future
candidate must retain the causal prime-symbolic rule while introducing genuine
recurrence without preloading a finite wheel, attaching an unrelated periodic
component, or borrowing a geometric owner. Any conservative or symplectic
continuation remains a separately frozen object.
