### Complete branch owner and Borel scaling

Integer multiplication on K is injective, with image the corresponding
divisibility cylinder. This follows from residues modulo nm and compatible
division modulo m, not from treating K as an integral domain. Haar scaling
on residue cylinders extends to arbitrary Borel subsets by equality of
finite measures.

For fixed (n,j), write r=rho(n,j). The full two-coordinate branch is

    domain: {n} × (j+nK) × K,
    image:  {r} × K × (j+nK),
    inverse at (r,u,v): (n,j+nu,(v−j)/n),  v in j+nK.

Each branch is a homeomorphism between these exact clopen sets. For a
Borel rectangle A×B in the domain, the first image coordinate has measure
n h(A), while the second has measure h(B)/n. Their PRODUCT is h(A)h(B).
The rectangle identity extends to every Borel subset of the branch.
This is a joint IMAGE calculation, not a marginal or conditional one.

Thus the principal product measure has branch J=1. With fixed positive
finite root weights the forward ratio is w_r/w_n. No claim of global
T-invariance follows when different branch images overlap.

the branch domains form a clopen cover and each routing value is fixed
on one branch. This makes a noncomputable table a defined mathematical
owner, not a computational or endogenous arithmetic mechanism.
