# Sieve-constrained Hénon horseshoes: external language selection is not A0

**Record ID:** `ASFS-SCOUT-20260913-10`  
**Status:** `PRE-P0 REJECTED; Route B NOT INVOKED`

Paper 2 supplies a sharp prime-symbolic object: sieve-stage words and MSS
kneading admissibility, including finite-stage parity-gap defects. A tempting
conservative lift is to use a Hénon horseshoe's symbolic coding and keep only
the sequences satisfying those sieve constraints. This would visibly preserve
the Logistic → symbolic → Hénon lineage and would furnish conventional periodic
horseshoe orbits.

It nevertheless fails before P0. The full horseshoe itself admits a much larger
language; selecting a sieve-defined sublanguage afterward changes the claimed
orbit owner from the map to an external arithmetic filter. The same operation
can select arbitrary languages, so it is both an ownership failure and a
`PROVES_TOO_MUCH` risk. To be admissible, a future deformation must derive the
sieve/MSS language as the intrinsic kneading/Markov language of one specified
map, with no post hoc symbolic restriction.
