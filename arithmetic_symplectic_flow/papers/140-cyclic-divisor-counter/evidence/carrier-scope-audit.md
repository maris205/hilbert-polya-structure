# Carrier-scope audit — ANG-20260915-CDC01

**Date:** 2026-09-15.  
**Audit type:** methodological scope and ownership review, not proof review or Route evaluation.  
**Candidate status:** ADVANCE — EXACT MARKED RETURN SELECTOR, COMPLETE PACKETS, LOCAL ORDINARY ZETA.

## Controlling distinction

The [local plan](../../../plan.md), section 6, forbids a separate object per
prime, external prime selection, supplied target clocks and per-prime fitted
data. It does not prohibit every integer-valued state coordinate or every
invariant all-integer fibre decomposition. The
[broadened-carrier instructions](../../../AGENTS.md) permit a separately
labelled groupoid candidate when its carrier, action, arithmetic mechanism,
clock and complete packet convention are frozen together.

Consequently, a uniformly defined action containing every integer n>=2 and
every state prescribed by its rule may be admitted for T0--T3 investigation.
This differs from choosing prime inputs individually, running separate
calculations and assembling selected outputs into an alleged orbit ledger.
Admission for investigation does not itself establish T0, T1, naturalness,
recurrence or any analytic result.

The earlier [136 construction](../../136-factorization-nonbacktracking-flow/paper.md)
provides a consistent local example of this distinction: all multiplication
labels were included in one frozen groupoid carrier. Its decisive failure
was the absence of prime-product paths, not the mere presence of integer
fibres. No result or gate credit from 136 is transferred here.

## Application to the frozen 140 definition

The [candidate card](../candidate-card.md) specifies the entire disjoint union
of phase-counter fibres for all n>=2, one displayed divisor-test rule, the
same unit roof, and all counter states. The rule updates the scan phase and
counter together. It supplies no selected prime subfamily, completed prime
mask, per-prime initialization or external reset operation. The
[paper](../paper.md) keeps composite fibres and every counter-derived packet
in its stated ledger and ordinary product.

These are definition-level reasons that the forbidden selected-instance
assembly objection does not automatically apply. The card does not promise
that a single chronological orbit enumerates all primes, and the paper does
not claim such a result. Whether the displayed inverse, return calculation,
packet census and convergence proof are correct is a separate mathematical
question; this scope audit is not their verification. Their evidence is
recorded in the [main evidence index](README.md).

## Historical wording and remaining controls

The [031 screen](../../031-primality-automaton-attractor-screen/paper.md)
concerned separately encoded inputs, no specified complete global carrier,
and prime outputs collapsing to a common fixed point. Its closing demand
that a viable object generate its state without separately supplied integer
instances must be read within that scope. Extending it to a blanket ban on
all integer state coordinates would add a restriction absent from the
controlling plan. This note neither revises 031 nor reverses its source-bound
negative result.

Likewise, [011](../../011-reversible-sieve-simulation-control/paper.md) and
[099](../../099-reversible-sieve-computation-boundary/paper.md) reject reliance
on unspecified universal programming, finite external instances or a missing
return owner. They do not establish a no-go theorem for every fully specified
reversible arithmetic action. The
[114 owner boundary](../../114-yellowstone-permutation-owner-boundary/paper.md)
still requires any claimed return to retain the actual generating state,
not merely an output or a derived permutation.

The following obligations therefore remain substantive, even for a uniform
all-integer carrier:

- Arithmetic tests must affect the marked return or packet structure, rather
  than only label a generic cycle. The paper's mechanism controls must bear
  that evidential burden; carrier uniformity cannot replace them.
- Complete state return and every intrinsic packet multiplicity must be
  retained. Selecting an accepting state, zero counter or one prime packet
  changes the stated ledger.
- Fixed arithmetic engineering is not automatically canonical arithmetic
  dynamics. Comparable bounded-witness algorithms remain a
  PROVES_TOO_MUCH/naturalness control, even when no prime table is inserted.
- A marked prime selector is not an unmarked one-packet-per-prime dictionary.
  The retained prime multiplicities, composite packets and nonlogarithmic
  unit-roof clock are genuine limitations, not defects this audit removes.
- Classical symplectic fields remain NOT APPLICABLE. No formal Route
  coordinate is assigned; Route B remains NOT INVOKED.

**Scope conclusion:** the fully frozen 140 carrier is eligible for the
authorized broadened audit and is not rejected merely for its conserved
all-integer coordinate. Any positive T1 or T3 statement must still rest on
the candidate-specific proofs and their explicitly limited claims.
