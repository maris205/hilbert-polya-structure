# 122 — S-adic tiling-to-torus realization boundary

**Record:** `ASFS-SCOUT-20260914-88`  
**Status:** `PRE-P0 STOP — FIXED-SUBSTITUTION GEOMETRIC-REALIZATION THEOREM DOES NOT OWN THE PRIME-DIRECTIVE SIEVE ACTION`

Geometric-realization theorems can semiconjugate a *fixed* substitution tiling
with unimodular hyperbolic expansion to a hyperbolic toral automorphism.  This
is a genuine conservative/symplectic interface in the abstract.  The direct
prime-sieve source, however, is a non-stationary S-adic sequence of
prime-dependent substitutions.  Replacing that directive action by one fixed
substitution or toral map either imports the schedule or changes the object.
