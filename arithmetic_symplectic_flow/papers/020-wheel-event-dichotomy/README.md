# Wheel-event dichotomy

**Record ID:** `ASFS-SCOUT-20260913-17`  
**Status:** `METHOD THEOREM / PRE-P0 STOP RULE; Route B NOT INVOKED`

Adding a cyclic position inside each primorial wheel does not reconcile the
sieve recursion with closed orbits. A closed orbit either never triggers the
stage-update event and is only a fixed finite wheel, or triggers it and advances
the strictly monotone sieve frontier. This screen protects the A1 owner chain
from a misleading local-cycle construction.
