# 071 — Pratt-tree return screen

**Record:** ASFS-SCOUT-20260914-48  
**Status:** PRE-P0 STOP — STRICTLY DESCENDING CERTIFICATE TREE; NO FORWARD RETURN MAP

Pratt certificates give a genuinely prime-indexed recursive factor relation: a prime
p points to the prime factors of p - 1. That relation is structurally unlike a wheel
or finite sieve window, but every nontrivial child is smaller than its parent. It is
therefore a well-founded certification tree rather than a recurrent prime-symbolic
action. No symplectic base, roof, suspension, or all-orbit ledger is supplied, so the
screen stops before P0.
