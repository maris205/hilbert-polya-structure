# Evidence boundary

- The cited Pratt and Pomerance sources support the recursive certificate form:
  certify a prime p using the prime factors of p - 1 and recursively certify
  those factors.
- The only mathematical inference made here is the elementary inequality
  q | (p - 1) => q < p, which yields absence of directed cycles for the exact
  oriented certificate relation.
- No prime list, witness search, simulation, source-code execution, numerical
  orbit table, or external operator was used. The screen does not assess a
  hypothetical reversed or augmented construction.
