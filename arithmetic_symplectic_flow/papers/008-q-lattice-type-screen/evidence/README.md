# Evidence

Connes and Marcolli, [*Q-lattices: Quantum statistical mechanics and Galois theory*](https://authors.library.caltech.edu/records/63zzg-arw72), describes the relevant spaces as noncommutative versions of Shimura varieties and treats the Bost–Connes system as a \(C^*\)-dynamical system. This is a type check, not a transfer of a classical map.
