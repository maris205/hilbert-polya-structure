# 060 — Integral polynomial symplectic gcd-rigidity rule

**Record:** `ASFS-METHOD-20260914-08`  
**Status:** `METHOD THEOREM / PRE-P0 STOP RULE — ORIGIN-FIXED INTEGRAL POLYNOMIAL LIFTS PRESERVE EVERY GCD STRATUM`

For an origin-fixed polynomial automorphism with integral polynomial inverse,
coordinate gcd is invariant in both directions. Thus a proposed visible-lattice
or primitive-vector source is static under the whole map class, not an
internally generated prime mechanism. The rule includes 059 but not maps with
nonintegral inverse, nonzero constant term, or another arithmetic mechanism.
