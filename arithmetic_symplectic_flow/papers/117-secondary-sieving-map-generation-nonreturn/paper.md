## 1. Frozen source construction

Mikoss's Secondary Sieving Map (SSM) acts on an ordered infinite survivor
sequence.  Its pivot is the second entry and its next generation is obtained by
extracting the pivot multiples.  Applied to the positive integers, the first
application gives the odd numbers; subsequent applications retain a generation
of sieve survivors together with the pivots already used.  This is unusually
close to the project's source arrow

\[
\text{prime/composite sieve observables}
\longrightarrow \text{sequential symbolic admissibility}.
\]

The source draws periodic residue/branch patterns in each fixed generation and
states that the period is the product of prior pivots.  It also explicitly says
that a formal proof of that period statement will be published elsewhere.  Its
broader “prime generating,” prime-density, and twin-prime conclusions are not
used as established results in this record.

## 2. Full-state ownership and nonreturn

The source's finite representation keeps seeds and a generation period; the
infinite representation retains the current survivor sequence.  In either
faithful version the next sieve step needs the next pivot and changes the
generation record.  The accumulated pivot product is multiplied by the newly
used pivot, which is at least two.  Hence it is strictly increasing along every
nontrivial forward generation.

Consequently, a repeated residue class pattern *inside* one frozen generation
does not constitute a return of the action that makes the next sieve generation.
The former has fixed prior pivots; the latter has a larger pivot record and a
different period after each update.  Identifying them would reproduce the
finite-period / advancing-sieve owner split already controlled in this
portfolio.
