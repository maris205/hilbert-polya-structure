# Evidence — `ASFS-SCOUT-20260914-32`

Booker and Irvine, [*The Euclid–Mullin graph*](https://arxiv.org/abs/1508.03039), state that their graph encodes Euclid prime extensions and is not a tree.

If `q` divides `1+product(S)`, then `q` is not in `S`: every member of `S` divides the product, so cannot divide one plus it. Thus `S -> S union {q}` raises `|S|` by one. No table, fit, or clock is used.
