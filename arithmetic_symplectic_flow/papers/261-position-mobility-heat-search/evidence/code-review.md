## 2. 同对象与真正动能指数

- B和M分别保持冻结的四/五参数与参数箱；M的
  `g=(2*1.02*q)^2/(1+(2*1.02*q)^2)`只使用固定终端参数，
  不随冷却中点或`a_start`变化。F消融明确替换为常数1。
- `k=p*p/(hypot(m,p)+m)`只含去静质量动能；
  DST-I为标准正交变换。M实际构造`K=R K0 R`，没有改动标准内积，
  没有把合同变换冒充酉变换，也没有把静质量包入R。
- 每个M传播，包括κ=0、Z和非退化F，都走一次完整实`eigh`，
  检查全部ν有限且严格为正；失败停止而非裁剪。
  随后以`(Q*exp(-delta*nu))@Q.T`形成真正的`P_delta`。
  同次传播内共用P，但不跨参数/网格缓存分解。
- M记录原始全K、全ν/Q、P、对称误差、迹及其独立对角恒等式、
  迹与ν之和差量、正交误差、对原始全K计算的特征方程残差。
  没有先显式对称化矩阵后只检验替代矩阵。
- 路径最低值调用259的B多项式接口，以本轮新建精确标量缓存求解；
  没有继承旧最低值表或跨族谱/分数。非有限W或W小于−1e−10停止；
  仅容差内的负W截0，并记数量和最大截量。逐导数根分区的浮点退化根
  局限不因复用源码而消失。
- 每步是`exp(-delta W/2) P_delta exp(-delta W/2)`，
  从实际单位矩阵左乘得到`A_B...A_1`。B仍用DST作用动能，
  未以静态谱、平均K、Gram矩阵或`R exp(-delta K0) R`替代M热乘积。
- 每次传播只有一次完整实SVD；直接使用该次全部σ、
  `E=m-log(sigma)/beta`及`target[0]*E/E[0]`。完整状态保存复用同次SVD
  缓存，不重做SVD。静态对象是自身`mI+K+diag(mean W)`，不是M借用B的K。

以上为源码所有权审查；ν的实际正性、分解残差和控制误差尚未实测。
