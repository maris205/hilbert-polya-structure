# Weil–étale arithmetic-topos flow external control for `Spec Z`

**Candidate ID:** `ATF-20260914-WET01`  
**Status:** `EXTERNAL CONTROL — T0/T1 ESTABLISHED AS TOPOS DATA; T2 FORMAL REPETITION ESTABLISHED; TRACE/DETERMINANT OPEN; NOT AN ASFS / ROUTE CANDIDATE`

This card freezes the Weil–étale topos formulation, in which the carrier is a
topos equipped with a morphism to `B_R`, rather than a point-set flow or a
classical suspension. For the finite closed point `(p)` of `Spec Z`, the source
gives a closed embedding associated with `R/log(p)Z`; its cyclic Weil group
therefore records the times `r log p`. This is genuine arithmetic-topos data,
but it is not a transfer operator or an actual prime-symbolic coding.

It remains an external control: neither a semiconjugacy from the prior sieve
word nor a same-object trace/determinant is supplied.
