# 089 — Dynamical-sieve external-index screen

**Record:** ASFS-SCOUT-20260914-60  
**Status:** PRE-P0 STOP — PRIME-INDEXED PERIODIC FUNCTIONS ARE EXPLICITLY SUPPLIED

Mateos's proposed dynamical sieve defines its displayed prime function by a sum
over (p) already restricted to primes, and introduces a periodic component
starting at each prime time.  It is thus a prime-indexed family of signals, not
one fixed map that endogenously selects its arithmetic data.  The time line is
also a forward decoding procedure, not a returned phase-space orbit.  The
screen records the source exactly as an external control and does not attach a
Hénon lift, roof, zeta, or operator from another object.
