# Evidence and reproducibility — `ASFS-SCOUT-20260913-13`

The factorial-block and periodic-core proofs are recorded in
[paper.md](../paper.md). The latter takes a constant residue-class subsequence
of approximating shifts modulo a prime that does not divide the claimed period.
It requires no prime table or numerical computation. Programme provenance is
the local [prior-work index](../../../docs/prior_work/README.md). This package
makes no claim that the symbolic closure has a finite-dimensional realization.
