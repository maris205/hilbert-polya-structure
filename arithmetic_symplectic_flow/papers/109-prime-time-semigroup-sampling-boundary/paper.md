## Screen

Bergelson and Richter establish ergodic theorems whose corollaries include the prime number theorem and other multiplicative-number-theory statements, and formulate additive/multiplicative semigroup-action disjointness. This is a serious dynamical use of prime distribution, not a numerical fit.

It nevertheless has the logical shape

```text
given action T and given prime set P -> average or sample T^p along p in P.
```

The dynamics is defined independently of the primes. The prime set selects the observation/averaging subsequence. No state of the action produces the next prime, tests primality, or carries a sieve-symbolic survivor rule.

## Decisive controls

1. **Sampling control.** Replacing primes by another selected subsequence changes the theorem’s sampling input while leaving the underlying action unchanged. Thus prime relevance is in the averaging index, not in the action.
2. **Carrier control.** The source treats general semigroup actions; it does not freeze one phase space, reversible return map, roof, or primitive packet ledger that owns the arithmetic selection.
3. **Lineage control.** A prime-time average is not an intertwiner from the project’s sieve/MSS symbolic state to a sequential Hénon/conservative deformation. Borrowing a map or periodic orbit from a chosen example would be cross-object assembly.
