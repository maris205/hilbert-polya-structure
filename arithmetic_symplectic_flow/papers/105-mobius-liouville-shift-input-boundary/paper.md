# Möbius and Liouville subshifts translate a supplied arithmetic word rather than generate it

**Paper ID:** 105-mobius-liouville-shift-input-boundary  
**Record ID:** ASFS-SCOUT-20260914-73  
**Date / status:** 2026-09-14; PRE-P0 NEGATIVE OWNERSHIP AUDIT  
**Route state:** No formal ASFS Route-A coordinate. Route B NOT INVOKED.

## Screen

Let \(\mu(n)\) be the Möbius function and \(\lambda(n)=(-1)^{\Omega(n)}\)
the Liouville function.  Their standard two-sided subshifts are the orbit
closures \(X_\mu\subset\{-1,0,1\}^{\mathbb Z}\) and
\(X_\lambda\subset\{-1,1\}^{\mathbb Z}\), with the invertible left shift.
This is a real prime-factor symbolic observable and hence a meaningful
comparison to the project source; it is not merely a random binary word.

Its construction nevertheless has two different owners:

```text
complete prime factorisation of every n --> fixed word mu or lambda
fixed word --> shift orbit closure and invertible translation action
```

The shift receives the complete arithmetic word as its initial point and only
reindexes it.  It neither carries a sieve state nor computes \(\Omega(n)\),
squarefreeness, or any next prime-symbolic symbol from its own local state.
Thus it does not supply the required source-level sequential deformation,
Hénon/conservative lift, or endogenous ASFS arithmetic mechanism.

## Decisive A0 controls

1. **Word-replacement control.** Replacing \(\mu\) or \(\lambda\) by any
   other prescribed bi-infinite word leaves the shift action unchanged.  The
   arithmetic selection is wholly in the input word.
2. **Factorisation-owner control.** The action has no state component from
   which the prime factors of the translated integer are derived; recovering a
   symbol invokes the precomputed word rather than an action-internal rule.
3. **Lineage control.** The construction reaches
   `prime-factor observable -> symbolic word`, but provides neither an
   Eratosthenes/Logistic sequential rule nor an explicit conservative lift.

These failures occur before any question about periodic points in these orbit
closures.  Such a question is deliberately not used as an A1 substitute: an
arithmetic-looking recurrent limit could not repair the separate A0 ownership
failure.
