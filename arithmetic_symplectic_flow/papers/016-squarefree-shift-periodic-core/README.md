# Squarefree sieve shift: only the zero periodic core

**Record ID:** `ASFS-SCOUT-20260913-14`  
**Status:** `PRE-P0 REJECTED — ONLY DEGENERATE PERIODIC CORE; Route B NOT INVOKED`

The squarefree indicator is a canonical `B`-free enlargement of sieve survival:
an integer survives exactly when no square of a prime divides it. Its symbolic
orbit closure has a sharp periodic-orbit obstruction: every periodic point is
the all-zero point. Hence adding this natural sieve closure does not repair the
prime-symbolic route's A1 problem.
