# Evidence and reproducibility — `ASFS-SCOUT-20260913-14`

The proof is self-contained in [paper.md](../paper.md). For a candidate period
`q`, choose any prime `p` not dividing `q`, pass to a constant residue-class
subsequence of the approximating shifts modulo `p^2`, and use the inverse of
`q` modulo `p^2`. The inclusion of `0^infinity` uses standard factorial
composite blocks. No computation or prime table was used.

The source lineage is [prior work](../../../docs/prior_work/README.md); no
claim is imported from it about this new symbolic closure.
