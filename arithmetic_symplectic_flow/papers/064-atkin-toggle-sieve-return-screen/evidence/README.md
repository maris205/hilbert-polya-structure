# Evidence boundary

- A. O. L. Atkin and D. J. Bernstein, [*Prime sieves using binary quadratic forms*](https://cr.yp.to/papers/primesieves-20020329-retypeset20220327.pdf), *Mathematics of Computation* 73 (2004), 1023–1030. The source describes bounded/segmented prime enumeration via binary quadratic forms, parity toggling, and square-factor removal.
- The stop proof uses only the stated bound/segment ownership and [018](../../018-monotone-sieve-clock-obstruction/paper.md). It is not a complexity claim and does not analyze arbitrary implementations.

No prime table, Riemann-zero input, finite performance run, or imported orbit determinant was used.
