# 116 — LCM prime-recurrence conditional/nonreturn boundary

**Record:** `ASFS-SCOUT-20260914-83`  
**Status:** `PRE-P0 STOP — CONDITIONAL PRIME-INCREMENT CLAIM AND STRICTLY ADVANCING ARITHMETIC OWNER`

The fixed LCM recurrence is a no-table arithmetic update, but its general
``increment is 1 or prime'' assertion is tied to an unproved strong
Linnik-type condition.  Independently of that unresolved assertion, a
faithful state carries its step number and sends it from \(n\) to \(n+1\), so
the arithmetic-generating action has no return.  This is a distinct
conditional-recurrence control, not a candidate.
