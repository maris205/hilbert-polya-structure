## Portfolio result

The current breadth search has not failed merely because one technical construction was incomplete. It has exposed a three-way ownership separation.

| Architecture type | What it genuinely owns | Why it stops |
| --- | --- | --- |
| faithful all-prime sieve evolution | prime-symbolic source, including nonmonotone local toggles | the whole computation advances a stage/bound/window and does not return |
| finite geometric or group-symmetry model | a planar display or finite periodic permutation | the prime selection/problem is chosen before the geometry or symmetry acts |
| external arithmetic-dynamics object | substantial arithmetic relation, sometimes cycles or determinants | no action-level bridge from the prior sieve-symbolic/Logistic/Hénon lineage |

The first row includes the deletion rigidity rule and Atkin’s nonmonotone countercheck. The second includes focal-line geometry and algebraic-sieve symmetry. The third includes the countable coprime renewal benchmark and affine sieve. These are distinct objects; no roof, orbit ledger, determinant, source lock, or route evidence is moved from one row to another.

## Retained admission test

A future P0 may be frozen only if its exact one action meets all of the following before a deep A1 computation:

1. it has a documented deformation of the prior prime/composite sieve-symbolic source, rather than merely a prime-labelled arithmetic space;
2. its own rule generates or changes the arithmetic selection, so the selection is not a finite parameter, graph label, group stabilizer, or post-selected language;
3. it has a nontrivial recurrent packet/return under the same action without encoding an ever-increasing output bound; and
4. a concrete conservative/Hénon-to-symplectic owner is frozen only after the first three rows are present, not borrowed from a comparator.

This is an admission filter, not a no-go theorem. In particular, it leaves open a genuinely non-enumerative cyclic arithmetic mechanism, if one can be supplied with an exact sieve-symbolic interpretation.

## Decision

**Portfolio position: `fork`.** The next scouting lane should not repeat finite window, wheel, group symmetry, countable-gcd, affine-orbit, or generic Hénon architectures. It must target the retained joint mechanism directly. No current object passes A0+A1 as a classical ASFS candidate, and Route B remains `NOT INVOKED`.
