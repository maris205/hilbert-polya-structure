# Evidence — `ANG-20260918-CRS01`

This directory contains the reproducibility record for the finite exact audit.
There is intentionally no generated data file: the complete \(n=8\) and
\(n=10\) ledgers fit in the paper and are regenerated by the command below.

## Exact command

Run from `arithmetic_symplectic_flow`:

```bash
python - <<'PY'
import math

def build(n):
    edges = {tuple(sorted((j, j+1))) for j in range(1, n)}
    for d in range(1, n+1):
        if n % d == 0 and d*d < n:
            edges.add(tuple(sorted((d, n//d))))
    neigh = {v: set() for v in range(1, n+1)}
    for u, v in edges:
        neigh[u].add(v); neigh[v].add(u)
    sigma = {}
    for u, v in edges:
        for a, b in ((u, v), (v, u)):
            L = sorted(neigh[b]); i = L.index(a)
            sigma[a, b] = (b, L[(i+1) % len(L)])
    return edges, sigma

def ledger(n):
    edges, sigma = build(n)
    unseen = set(sigma); out = []
    while unseen:
        x = min(unseen); cyc = []; y = x
        while y in unseen:
            unseen.remove(y); cyc.append(y); y = sigma[y]
        assert y == x
        T = sum(.5*math.log(max(u,v)/min(u,v)) for u,v in cyc)
        out.append((len(cyc), round(T, 12), cyc))
    return edges, sorted(out)

for n in (8, 10):
    edges, out = ledger(n)
    print(n, len(edges), 2*len(edges),
          [(L, T) for L,T,_ in out])
    assert sum(L for L,_,_ in out) == 2*len(edges)

e8, c8 = ledger(8); e10, c10 = ledger(10)
assert [(L,T) for L,T,_ in c8] == [(3, .69314718056),
                                    (7, 2.07944154168),
                                    (8, 2.07944154168)]
assert [(L,T) for L,T,_ in c10] == [(4, .916290731874),
                                     (8, 2.302585092994),
                                     (10, 2.302585092994)]
print('PASS: exact dart partitions, periods, and roof times')
PY
```

The script uses only integer divisibility, sorted neighbour lists, the frozen
successor rule and ordinary real logarithms.  It checks that every dart occurs
in exactly one cycle, then checks the exact finite ledger reported in
`paper.md` (decimal assertions are rounded display values for the exact
logarithmic formulas proved there).

## Scope and controls

The check is finite and exact at \(n=8,10\) up to the displayed decimal
assertions; it is not a global census and does not test a transfer operator.
The chord-deletion and label-shuffle controls in Section 8 of `paper.md` are
defined symbolically and are not silently substituted for the frozen object.
No prime table, zero list, von Mangoldt weight, external model or numerical
parameter fit enters the run.
