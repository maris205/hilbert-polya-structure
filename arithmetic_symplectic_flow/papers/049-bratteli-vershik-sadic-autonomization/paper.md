# Bratteli–Vershik autonomization cannot retain both the S-adic sieve mechanism and periodic orbits

**Paper ID:** 049-bratteli-vershik-sadic-autonomization  
**Record ID:** ASFS-SCOUT-20260914-37  
**Date / status:** 2026-09-14; PRE-P0 STOP — DIRECTIVE-SCHEDULE EXTERNAL OR MINIMAL APERIODIC; NO A0+A1 SAME OBJECT  
**Route state:** No classical candidate; Route A not evaluated; Route B NOT INVOKED

## Abstract

Record 025 stopped the documented S-adic sieve carrier because its completed
update count strictly advances. This screen tests a technically legitimate
autonomization: encode its directive substitutions in an ordered Bratteli
diagram and use the Vershik homeomorphism of the infinite path space. The test
has two independent failures. First, the diagram is fixed before its
homeomorphism acts, so all prime-dependent substitutions are inserted as a
directive schedule rather than generated by the action. Second, if the
representation is the standard properly ordered minimal aperiodic Cantor
system, it has no periodic points at all. Thus the construction does not
supply endogenous A0 and A1 on one object.

## 1. Lineage and proposed object

The retained source arrow is:

prime/composite sieve -> symbolic tape -> sequential S-adic deformation.

Let U_j denote the source's jth prime-dependent tape substitution/update from
025. A Bratteli proposal chooses an ordered diagram B whose level-j edge
incidence and ordering encode U_j. When B is properly ordered, its path space
X_B can carry a Vershik homeomorphism V_B.

This changes the form of evolution from a nonautonomous update to one
homeomorphism, but does not erase the data needed to define that homeomorphism.

## 2. A0 ownership test

The object (X_B,V_B) cannot inspect a future substitution and decide which
sieve prime comes next: every level of B, including the entire prime-dependent
directive sequence, has already been fixed in the graph. Replacing that
directive sequence by another sequence changes the carrier and action while
preserving the Bratteli–Vershik formalism. Therefore the arithmetic source is
a supplied infinite diagram label, not an endogenous output of V_B.

This differs from a valid recurrent arithmetic state: the latter would need
one local transition law that reads and updates its own arithmetic state. No
such law is furnished by the S-adic source or by the representation theorem.

## 3. A1 test in the standard aperiodic realization

A standard route for a recognizable aperiodic S-adic shift is a properly
ordered minimal Cantor Bratteli–Vershik system. If V_B had a periodic point x,
then its finite orbit would be nonempty, closed, invariant, and proper because
the Cantor path space is infinite. That contradicts minimality. Hence this
realization has no periodic point, let alone a primitive closed-orbit/repetition
ledger.

One could instead attach a periodic component, use a finite diagram, or change
the order. None is forced by the prime-sieve S-adic object; each changes the
carrier/action and must be independently frozen and audited. It cannot inherit
arithmetic ownership from 025.

## 6. Decision

**Stop/fork.** Do not use Bratteli–Vershik language as a formal natural
extension of the S-adic sieve. A future reopening requires an explicit local,
recurrent arithmetic transition law whose own state generates the diagram and
whose periodic points preserve that law; merely precomputing the diagram or
adding periodic paths is insufficient.
