## 2. Full action, inverse branches and exact image

### 2.1 Partial exchange and complete inverses

For each permitted integer branch a,b,k, write the real

    R_k^(-1)(s,t)=((1+s^k)/t,s), s>=0,t>0.

    A=(1+B^k)/C a positive integer,

### 2.2 Full image and rigorous finite-predecessor bounds

## 5. All fixed states and full boundary classes

A real fixed state would require x=y=s>0 and
s^2=1+s^k with k=1+floor(s). For 0<s<1,
k=1 and the right side exceeds 1>s^2. For
1<=s<2, k=2 makes equality impossible. For s>=2,
k>=3 and 1+s^k>s^2. Thus ALL main fixed states
are absent, independently of integer root constraints. Terminal points
are not counted as fixed points by an artificial completion.

The interior is preserved by every legal forward and inverse
branch. It cannot be tail-equivalent to a boundary point.
On the boundary, a horizontal point (a,b,x,0), x>0,
has no predecessor because every actual target has second real
coordinate positive. If its permission holds it maps once to
(b,c,0,1/x), then terminates. If permission fails it is
an isolated terminal in the source-tail relation.

A vertical target (B,C,0,t), t>0, has at most
one predecessor: X=1/t determines the unique k=1+floor(X),
and then A=(1+B^k)/C must be integral. If so,
that predecessor is the horizontal point (A,B,X,0); if
not, the target is isolated. Every root's origin is
isolated too. Hence ALL boundary source classes are exactly these
two-point pairs or singletons, not a quotient deleting the axes.

Every boundary state has source/H/extension isotropy zero. For
a permitted horizontal-to-vertical arrow, the literal lag is -1
and the clock is +2*log(x), sending height h to
h+2*log(x). Different pairs or isolated points cannot merge
through any actual inverse excursion. These are the complete boundary
phase relations; zero H does not identify different source classes.
