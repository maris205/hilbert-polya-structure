# Route-B assessment

Use the repository's [Route-B protocol](../../../skills/route-b-evaluator.md) as the scientific definition. Resolve that path from the workspace root if needed: `skills/route-b-evaluator.md`. The original is a versioned, hash-bound reference; do not rewrite it during an assessment.

Read the supplied current Route-A evaluation first when assessing a candidate's entry. Full promotion follows the protocol's entry conditions. A requested limited early audit may answer its listed feasibility questions; it is not full Route-B eligibility.

- For a targeted explanation or limited audit, read the relevant protocol sections and candidate materials, report the specific obligation, and leave unassessed layers unevaluated.
- For a full evaluation, read the complete protocol and required references, assess B1–B5 and adversarial controls, and use the exact schema. The arithmetic, orbit, operator, trace, and determinant evidence must concern one compatible construction.

The current request controls actions. Reviewing evidence does not itself authorize experiments, registry changes, or publishing files. When writes are authorized, preserve prior evaluations and use the protocol's versioned destinations. Report missing evidence or commit identifiers honestly.

Real finite eigenvalues do not prove self-adjointness; a formal or local identity does not prove global divisor equality. Set a Hilbert–Pólya claim only when all of the protocol's explicit conditions are rigorously established.
