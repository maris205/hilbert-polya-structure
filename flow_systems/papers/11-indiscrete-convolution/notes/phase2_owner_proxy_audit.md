## 4. Standard-circle convention dictionary

Put

```text
G=R,          H=L_p Z,          S=G/H=R/(L_p Z).
```

All objects in this section use the ordinary compact Hausdorff topology on
`S`; none uses the actual indiscrete topology.

### 4.1 Paper-11 right action to the BHM left-action groupoid

Paper 11 uses the right point action and range-first arrows

```text
[r] dot t=[r+t],
r([r],t)=[r],       s([r],t)=[r+t].
```

Convert it to the left point action

```text
ell_t([r])=[r-t].
```

Buss--Holkar--Meyer Section 7.1 writes the left-action transformation groupoid
as `R semidirect S`, with

```text
s(t,y)=y,           r(t,y)=ell_t(y).
```

The convention-change map is

```text
K: G_p^std -> R semidirect_ell S,
K([r],t)=(t,[r+t]).
```

It has the correct endpoints: BHM source is `[r+t]` and BHM range is `[r]`.
Because `R` is unimodular, the canonical Lebesgue fibre measures introduce no
left/right modular correction under this dictionary.

Williams printed p. 42 / PDF page 54, equation (2.5), associates to a left
point action the inverse-pullback automorphism

```text
a_t(h)(y)=h(ell_{-t}(y)).
```

For `ell_t(y)=y-t`, this is exactly the Paper-11 sign:

```text
a_t(h)([r])=h([r+t])=alpha_t(h)([r]).
```

Thus BHM Theorem 7.1 matches `alpha` after the explicit arrow convention
change; there is no silent sign reversal.

### 4.2 Paper-11 `alpha` to Williams left translation

Williams Theorem 4.30 uses ordinary **left translation** on `G/H`,

```text
m_t([r])=[r+t],
lt_t(h)([r])=h([r-t]).
```

Hence Paper 11's frozen `alpha_t(h)([r])=h([r+t])` is not literally
Williams's `lt_t`. Let

```text
kappa([r])=[-r],
Q(h)=h o kappa.
```

Then `Q` is an involutive `*`-automorphism and the exact sign conversion is

```text
Q alpha_t Q^{-1}=lt_t.
```

Equivalently, `kappa` intertwines the left point action `ell_t([r])=[r-t]`
with Williams's `m_t([r])=[r+t]`. This gives an equivariant `C(S)`
isomorphism and therefore an isomorphism of the corresponding full crossed
products. Normalized Haar probability is invariant under `kappa`, so the
Hilbert-space measure in the final tensor model is unchanged.

## 6. The frozen measure `mu_p` is admissible, with an exact normalization

Williams equation (4.63), printed p. 138 / PDF page 150, requires a positive
continuous `rho` and the associated quasi-invariant quotient measure:

```text
integral_G f(s)rho(s) ds
  = integral_(G/H) sum_(h in H) f(s+h) dmu_(G/H)(sH)
```

for Lebesgue Haar on `G=R` and counting Haar on `H=L_p Z`. Both groups are
unimodular, so the covariance condition on `rho` is simply `H`-periodicity.
Choose

```text
rho(s)=1/L_p.
```

Then equation (4.63) gives precisely normalized Haar probability on the
circle:

```text
dmu_p([r])=(1/L_p)dr       on a fundamental interval [0,L_p).
```

Therefore Williams Theorem 4.30 applies with the exact frozen Hilbert space
`L^2(S_p^std,mu_p)`. Choosing `rho=1` instead would produce length Haar;
rescaling gives a unitarily equivalent `L^2` space, but that alternative must
not silently replace the protocol's probability normalization.

The theorem supplies an algebra isomorphism, not a canonical or
trace-preserving one. It does not select a transverse trace, a normal
representation, or a preferred measurable cross-section.
