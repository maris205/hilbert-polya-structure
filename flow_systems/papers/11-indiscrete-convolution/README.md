Working title: **Continuous Convolution Collapse on Indiscrete Arithmetic
Orbit Groupoids**.

Status: Phase 1--3 evidence and composition gates PASS; manuscript peer review,

This project starts from Paper 9's exact theorem that every actual inherited
finite-kernel arithmetic time orbit is a nontrivial indiscrete space. It asks
what happens when the source flow action is used to form a transformation
groupoid without replacing the actual unit topology by the ordinary circle
topology. The design separates an author-defined global continuous compact-
support convolution algebra, the applicability gate for locally Hausdorff
groupoid conventions, and the standard-circle proxy.

The final manuscript preserves the owner split. The actual inherited topology
supports only the author-defined global-QC fibre convolution, author
unit-regular reduced record, and separately transported full completion. Raw
HOpen zero is `DIAGNOSTIC_ONLY`; the retained standard actual-groupoid
frameworks are `NOT_APPLICABLE`; and the standard-circle proxy comparison is a
strict test-function monomorphism with proper image `A_const` and no completion
extension. The generic action-blind theorem precedes the rational-Witt
fixed-orbit application. All seven exact Route-A tuples are printed; three are
exploratory negative priors, four are rejected, and Route B is false.
