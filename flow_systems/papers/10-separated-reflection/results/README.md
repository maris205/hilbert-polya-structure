# Generated deterministic artifacts

The ten CSV files are generated by
`../code/separated_reflection_controls.py`:

- `continuous_map_controls.csv`: exhaustive maps from finite indiscrete
  sources to discrete, Sierpinski, and indiscrete two-point targets.
- `measurable_map_controls.csv`: exhaustive maps from the trivial measurable
  ledger to finite discrete measurable targets.
- `dirac_collapse_controls.csv`: all point pairs and all measurable events,
  without promoting proper singletons to measurable sets.
- `indiscrete_group_characters.csv`: finite cyclic and discrete circle-mesh
  homomorphisms, with nontrivial algebraic/noncontinuous controls explicitly
  typed.
- `proxy_direction_controls.csv`: both directions between an indiscrete owner
  and a chosen finite discrete proxy.
- `coproduct_k0_controls.csv`: tagged coproducts with `2,3,5,8` components,
  Borel event counts, and exact Kolmogorov classes.
- `component_mass_controls.csv`: exact nonnegative finite mass vectors,
  including zeros, equal-total distinct ledgers, and common topology
  fingerprints.
- `ell1_gate_controls.csv`: exact finite prefixes separated from symbolic
  summability gates; every row says that a finite prefix is nondecisive.
- `label_neutrality_controls.csv`: prime, composite, and arbitrary labels with
  identical abstract coproduct/reflection signatures.
- `external_log_label_controls.csv`: exact integer lower-bound witnesses for an
  externally attached `log` label, with topology, mass, and actual-source
  credit denied.

`separated_reflection_controls_manifest.json` records row counts, byte sizes,
SHA-256 artifact hashes, exact active-tuple hashes, six implementation hashes,
parameters, deterministic metrics, forbidden-input declarations, and typed
object/interpretation boundaries. It contains no timestamp, so identical
inputs produce identical bytes.

All artifacts are finite, target-free controls. They do not prove any actual
Paper-10 theorem, full-circle character classification, infinite `ell1`
classification, `log p` unboundedness, global-source coproduct statement, or
Route status.
