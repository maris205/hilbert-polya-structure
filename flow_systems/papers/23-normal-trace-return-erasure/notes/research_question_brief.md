# Paper 23 research-question brief

Date: **2026-08-24**
Status: **PHASE-2 RESOLVED — TECHNICAL NOTE / PREFER MERGE INTO PAPER 8**

## Primary question

For the fixed standard-circle proxy representation

```text
M_L^reg = L^infinity(T,m) bar-tensor B(L^2[0,L)),
```

classify the normal semifinite tracial weights whose restriction is defined on
the Paper-8 regular algebra. Which exact dual-rotation, flow-equivariance, or
normalization condition forces such a weight to be the Haar-averaged FNS
trace up to scale and therefore erase every nonzero return coefficient? What
nonconstant central densities retain returns while remaining normal?

No uniqueness or erasure statement is assumed before the weight class and
symmetry action are fully typed.

## Subquestions

1. Classify normal semifinite tracial weights through the center, including
   faithfulness and semifiniteness conditions.
2. Compute their values on the frozen time-kernel domain in Fourier
   coordinates.
3. Identify the exact symmetry whose invariance forces the center density to
   be constant almost everywhere.
4. Prove the equivalence, or find the precise gap, between that invariance and
   annihilation of every nonzero return coefficient.
5. Separate normal weights from lower-semicontinuous `C*` traces, singular
   states, and the Paper-8 point-character trace.

## Owner and nonclaims

- The owner is the standard Hausdorff circle proxy, never the actual
  non-Hausdorff packet.
- No actual-source completion, Haar system, restriction/disintegration map,
  packet trace, arithmetic selectivity, prime trace formula, determinant, or
  Route credit is claimed.
- Normal, FNS, lower-semicontinuous, and singular weights/states are not
  interchangeable.

## Decisions

- **Promote:** a nontrivial classification plus an exact symmetry/erasure
  equivalence not already contained in standard trace theory or Paper 8.
- **Technical note/merge:** the result is correct but routine and adds only a
  central-density restatement.
- **Stop:** the claimed symmetry does not select a unique class or the return
  formula is not defined on the asserted domain.

## Phase-2 resolution

The [trace-weight/source screen](phase2_trace_weight_source_screen.md) shows
that central-density classification is classical and that full circle
translation invariance, not normality alone, selects a scalar Haar weight
(FNS at positive scale) and implies return erasure.  The converse is not
claimed for the whole semifinite class without additional common-domain
hypotheses.  This Paper-8 corollary is suitable only for a technical note or
Paper-8 amendment; no standalone Paper-23 manuscript is authorized.
