## 3. Methodology Blueprint

### Paradigm and method

**Paradigm:** theorem-led critical realism.  “Canonical,” “trace,” “belongs to
the flow,” and “determinant” are typed mathematical assertions.

**Method:** explicit functional-analytic construction, exact proof, source
ownership audit, and adversarial controls.  Deterministic code is a regression
layer only.

**Data strategy:** verified primary mathematical sources plus exact symbolic
artifacts.  No human subjects, statistical sampling, or target-zero data.

### Decomposable mass-family proxy

For each rational prime `p`, freeze

```text
L_p = log p,
B_p = Zhat_(p)^x / p^Zhat,
Y_p = B_p x (R / L_p Z),
mu_p = normalized Haar probability on B_p.
```

Let

```text
Kappa_p = L2(R / L_p Z, du),
Hcal_p = L2(B_p, mu_p) tensor Kappa_p,
M_p = L-infinity(B_p, mu_p) bar-tensor B(Kappa_p).
```

`M_p` acts in the standard decomposable representation on `Hcal_p`.  It is a
**selected decomposable type-I algebra**.  No claim is made that circle
translations alone generate it or that it is the von Neumann algebra of a
flow/action/pair groupoid.

The global algebra is

```text
M = { (A_p)_p : A_p in M_p and sup_p ||A_p|| < infinity },
```

represented on the Hilbert direct sum of the `Hcal_p`.  For every sequence
`0 < m_p < infinity`, define on the positive cone

```text
tau_m((A_p)) = sum_p m_p tau_p(A_p),
tau_p(A_p) = integral_Bp Tr_Kappa(A_p(b)) d mu_p(b).
```

The positive-cone formula defines an extended faithful normal semifinite trace
independently of Dirichlet convergence.  Two domains must be kept distinct:

```text
L^1(M,tau_m) = the full noncommutative L1 space of tau_m-measurable
               affiliated operators,
L^1_tau(M)    = {A in M : tau_m(|A|)<infinity}
               = M intersect L^1(M,tau_m).
```

For a bounded block `A=(A_p)_p`, the relative trace-ideal norm is

```text
||(A_p)||_(1,tau_m) = sum_p m_p ||A_p||_(1,tau_p).
```

The determinant branch uses the Banach ideal `L^1_tau(M)` with relative norm
`||A||+||A||_(1,tau_m)`, not merely the affiliated `L1` completion.

### Branch F — component trace and flat/distributional return record

Fix a Fourier convention and let `U_p(t)` translate the circle factor.  For
`f in C_c^infinity(R)`, define componentwise

```text
C_(p,f) = integral_R f(t) U_p(t) dt.
```

The target component theorem is

```text
C_(p,f) in L1(M_p,tau_p),
tau_p(C_(p,f)) = L_p sum_(r in Z) f(r L_p).
```

The global block `C_f=(C_(p,f))_p` may be bounded but is not called
`tau_m`-integrable unless

```text
sum_p m_p ||C_(p,f)||_(1,tau_p) < infinity.
```

For nonzero smooth compactly supported `f`, the preregistered norm calculation
is

```text
||C_(p,f)||_1
  = sum_n |fhat(2 pi n / L_p)|
  ~ (L_p / 2 pi) integral_R |fhat(xi)| dxi.
```

Consequently the unit-mass global block is expected to fail `L1(tau)`.
This is a theorem target, not assumed evidence.

For `f in C_c^infinity((0,infinity))`, separately define

```text
Theta_m(f) = sum_p m_p tau_p(C_(p,f))
           = sum_p m_p L_p sum_(r >= 1) f(r L_p).
```

Every compact positive-time support meets finitely many `(p,r)`, so
`Theta_m` is locally finite for any sequence of finite individual masses.  It
is called a **componentwise return distribution**.  It is not written as
`tau_m(C_f)` and is not called a groupoid/flat trace extension until a named
extension theorem supplies that domain.

### Branch K — genuine trace-ideal zero-mode record

Let `P_(0,p)=1_Bp tensor |e_0><e_0|`, where `e_0` is the normalized constant
circle mode.  Then `tau_p(P_(0,p))=1`.  Define

```text
K_s = direct-sum_p exp(-s L_p) P_(0,p).
```

The following was the historical Phase-1 target and is preserved verbatim to
make the deviation auditable:

```text
K_s in L1(M,tau_m)
  iff sum_p m_p exp(-sigma L_p) < infinity.
```

That display used `L1` without separating affiliated and bounded domains.  It
is **superseded**, not silently corrected, by the following amended P7-4
target.  For `sigma=Re(s)`,

```text
K_s in affiliated L^1(M,tau_m)
  iff sum_p m_p exp(-sigma L_p) < infinity;

K_s in L^1_tau(M) = M intersect L^1(M,tau_m)
  iff sigma >= 0
      and sum_p m_p exp(-sigma L_p) < infinity.
```

For the conditional specialization `m_p=1`, `L_p=log p`, both conditions
still reduce exactly to `Re(s)>1`; the unit-mass conclusion is unchanged by
the amendment.

Let `sigma_c(m)` be the abscissa of convergence of
`sum_p m_p p^(-sigma)` and put

```text
H_m = {s in C : Re(s) > max(0,sigma_c(m))}.
```

This is the branch's canonical open domain: throughout `H_m` the weighted sum
converges and `||K_s||<1`.  Even if a boundary point happens to satisfy one
of those conditions, no determinant is asserted there without an open
neighborhood on which both hold.  Only after acquiring and verifying the
relevant analytic semifinite determinant theorem may the paper define, for
`s in H_m`,

```text
D_tau^pr(s)
  = exp(tau_m(Log_0(I-K_s)))
  = exp( - sum_(r>=1) tau_m(K_s^r)/r )
  = exp( - sum_p m_p sum_(r>=1) p^(-r s)/r ),
Z_m(s) = D_tau^pr(s)^(-1),
Log_0(I-K_s) = -sum_(r>=1)K_s^r/r.
```

`D_tau^pr` means the **branch-fixed principal trace-log scalar lift** on this
open domain; it is not an unqualified global semifinite determinant.  The
exponential series fixes the logarithm branch and normalization in the proved
relative trace-ideal half-plane.  This is not an ordinary Hilbert determinant,
not a complex Fuglede--Kadison determinant, not the determinant of `C_f`, and
not a primitive-orbit Ruelle determinant.

4. **Mass perturbation:** use deterministic non-unit `(m_p)`.
5. **Arbitrary-clock compiler:** replace `(log p)` by any locally finite
