## 8. P7-8 base/clock blindness module

P7-8 must precede every Route-A promotion and receives a main-text theorem

### 8.1 Required controls

| Control | Replacement | Quantity that may remain unchanged | Required interpretation |
|---|---|---|---|
| singleton base | every `B_p` becomes one point | circle trace, return ledger, rank-one zero-mode trace | transverse packet geometry is unnecessary to the calculation |
| arbitrary probability base | replace `B_p` by any standard probability space with total mass one | decomposable trace of base-constant fiber operators | normalized base enters only through total mass |
| copied component | duplicate a block | trace/distribution/trace-log contribution adds | packet multiplicity is not automatically canonical |
| mass perturbation | replace unit weights by positive finite `m_p` | component theorems and weighted ledgers | within-component symmetry does not select central masses |
| arbitrary clocks | use a locally finite positive list `(L_j)` | positive-time return distribution; zero-mode product where `sum_j m_j e^(-sigma L_j)` converges | the mechanism is a clock-ledger compiler |
| composite clocks | add `log n` for composite labels | analytic construction may still work | arithmetic provenance fails even when analysis survives |

### 8.2 Domain qualification

“Locally finite clock list” is enough for the compact-positive-time return
distribution, because only finitely many `(j,r)` meet a compact support away
from zero.  It is not enough by itself to make
`sum_j m_j exp(-sigma L_j)` finite for any `sigma`.  The zero-mode product may
be stated only on its actual trace-ideal convergence domain, which could be
empty for a badly growing list.

The intended P7-8 conclusion is therefore conditional and two-part:

```text
Branch F: arbitrary locally finite clocks -> locally finite positive-time ledger
Branch K: arbitrary clocks -> trace-log product only where the weighted
          exponential sum converges
```

If the same proof works for singleton, arbitrary-base, and non-arithmetic
clock controls, the manuscript must attach `STOP_SCOPED / PROVES_TOO_MUCH` to
any inference from scalar exactness to packet geometry or the Riemann target.
