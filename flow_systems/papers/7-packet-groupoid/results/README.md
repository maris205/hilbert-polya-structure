# Generated deterministic artifacts

The nine CSV tables are generated by `../code/packet_trace_controls.py`:

- `poisson_convention.csv`: fixes the `2*pi/L` Fourier lattice.
- `trace_norm_riemann.csv`: records both the growing unscaled trace norm and
  its correctly scaled Riemann sum.
- `prime_power_von_mangoldt.csv`: finite prime-power/repetition ledger,
  including zero coefficients away from prime powers.
- `finite_prime_d_z_ledger.csv`: finite-prime repetition tails with both
  determinant and reciprocal quantities: `log_Z=-tau_Log_D`,
  `D=exp(tau_Log_D)`, `Z=exp(log_Z)=D**(-1)`, plus sign, reciprocal, and
  direct-product residuals.
- `mass_copy_controls.csv`: positive non-unit mass and copied-component
  additivity controls.
- `probability_base_blindness.csv`: singleton, arbitrary atomic, and symbolic
  nonatomic probability bases with total mass one.
- `clock_compiler_controls.csv`: prime, arbitrary, and composite-augmented
  positive clock lists; composite clocks retain the analytic compiler while
  explicitly failing rational-prime provenance.
- `hilbert_vs_tau_projection.csv`: ordinary transverse Hilbert multiplicity
  versus the normalized decomposable finite `tau` projection.
- `zero_time_partial_divergence.csv`: unregularized positive finite partial
  sums of `sum m_p log(p) f(0)`.

Every determinant-related table labels `tau_Log_D`, `log_Z`, `D`, and `Z`
explicitly; the positive repetition sum is `log_Z`, not `tau_Log_D`.

`packet_trace_manifest.json` stores row counts, byte sizes, SHA-256 hashes,
fixed parameters, the determinant convention, implementation-file hashes, and
the interpretation boundary. `--verify-only` requires the implementation keys
to match the frozen set exactly and compares each hash with the current file
relative to the Paper 7 root. The manifest itself is excluded to avoid a
self-hash. It deliberately contains no timestamp, so identical code and
parameters yield identical bytes.

These artifacts contain no target-zero data and cannot certify a groupoid,
source-to-proxy transport, canonical mass, determinant provenance, or Route
status. The word `infinite` in the Hilbert table is the exact operator-theoretic
classification of the ordinary projection, not a floating-point value.
