# Paper 22 Phase-3 all-index nonlift theorem

Date: **2026-08-24**

Status: **PROOF PASS — THE FP AND FPPF QUESTIONS HAVE A NEGATIVE ANSWER FOR EVERY `N>1`**

This note closes the frozen Phase-3 kill test.  It works first on the fixed
small absolute site `NoethAffSch_fppf` and then records the finite-flat
(`fp`) analogue separately.  It does not claim a packet, dynamical,
operator, determinant, or Route consequence.

## 1. Frozen owner and statement

Let `C` be a universe-small version of `NoethAffSch`, in the sense used by
Deninger, with the fppf topology and containing the affine schemes and fiber
products used below.  Write

```text
Z = underline Z(O)^sharp,
W = W_rat(O)^sharp,
omega: Z ->> W,
```

where `underline Z(A)` is Deninger's reduced monoid algebra of the
multiplicative monoid of `A`.  The additive big-Witt Verschiebung is

```text
V_N(f)(T) = f(T^N).
```

### Theorem

For every integer `N>1`, there is no additive sheaf endomorphism

```text
tilde V_N: Z -> Z
```

such that

```text
omega o tilde V_N = V_N o omega.
```

For `N=1`, the identity is a lift.  Hence, if

```text
e: 0 -> K -> Z -> W -> 0,       K=ker(omega),
```

then for every `N>1` and every endomorphism `u:K->K`,

```text
u_* e != V_N^* e in Ext^1(W,K).
```

The same nonexistence statement holds on the finite-flat (`fp`) site.  That
last assertion is a separate comparator; it is not used to infer the fppf
case.

## 2. Three elementary sheaf lemmas

### 2.1 Torsion-free lemma

For every positive integer `n`, multiplication by `n` on `Z` is a
monomorphism.  Objectwise, `underline Z(A)` is a quotient of a free abelian
group only by the free direct summand generated by `(0)`, and is therefore
torsion-free.  Sheafification of abelian presheaves is exact, so the
objectwise monomorphism remains monic after sheafification.

### 2.2 Big-Witt detector

For a subcanonical topology, `Y |-> W(O(Y))` is a sheaf and the
Teichmueller map `a |-> [a]=1-aT` is injective.  Consequently, if a section
of `Z` has a nonidentity image in the big-Witt sheaf, that section is
nonzero.  This is the same detector used in Deninger's Example 4.4.

### 2.3 Dedekind fppf-injectivity lemma

If `B` is a Dedekind domain, then

```text
omega_B: Z(B)^sharp -> W_rat(B)^sharp
```

is injective for the fppf topology.

Indeed, take an fppf covering `{Spec C_i -> Spec B}` and, by
quasi-compactness, a finite subcover.  Each `C_i` is a finitely presented
flat `B`-algebra and hence Noetherian.  Replace `C_i` by its finitely many
minimal-prime quotients `C_i/P`.  Flat going-down
([Stacks, Tag `00HS`](https://stacks.math.columbia.edu/tag/00HS)) gives
`P cap B=(0)`.  Thus each domain `C_i/P` is torsion-free over the Dedekind
domain `B`, hence flat
([Stacks, Tag `0AUW`](https://stacks.math.columbia.edu/tag/0AUW)); it is also
finitely presented over `B`.  The irreducible components remain jointly
surjective and refine the original cover.  Every fppf cover of `Spec B`
therefore has a refinement by integral domains, so Deninger's Proposition
4.5 applies.

### 2.4 Actual kernel and extension

Objectwise put

```text
K_0(A) = ker(underline Z(A) -> W_rat(A)).
```

Equivalently,

```text
K_0(A)
  = { sum_i n_i(a_i) : product_i(1-a_i T)^(n_i)=1 in A[T]_S^x }.
```

Exactness of abelian sheafification gives

```text
K = K_0^sharp.
```

Deninger's Theorem 3.4 says that `W_rat(O)` is already an fpqc, hence fppf,
sheaf, and Proposition 4.3 makes `omega` an epimorphism.  Thus the sequence

```text
e: 0 -> K -> Z -> W -> 0
```

is the actual extension in the abelian category of sheaves.  This kernel
description uses only exact sheafification (see
[Stacks, Tag `03CN`](https://stacks.math.columbia.edu/tag/03CN)); it does not
pretend that the resulting sheaf is objectwise trivial.

## 3. Explicit descent obstruction

Fix `N>1`.  Choose a prime divisor `q` and write

```text
N = q^a d,       a>=1,       gcd(q,d)=1.
```

Choose a finite field extension `k/F_q` containing all `d`-th roots of
unity.  Put

```text
A = k[x],
B = k[s],
A -> B,          x |-> s^N.
```

The resulting `Spec B -> Spec A` is a finite free faithfully flat cover of
rank `N`.  Suppose that `tilde V_N` exists and set

```text
z = tilde V_N((x)^sharp) in Z(A)^sharp.
```

Its image in `W(A)^sharp` is `1-xT^N`.  On `B`, define

```text
c(s) = q^a sum_(zeta in mu_d(k)) (zeta s) in underline Z(B).
```

Addition on the Witt side is multiplication of power series, and therefore

```text
omega(c(s))
  = product_(zeta in mu_d(k)) (1-zeta sT)^(q^a)
  = (1-s^d T^d)^(q^a)
  = 1-s^N T^N
  = V_N([s^N]).
```

Here the last binomial identity is in characteristic `q`.  Since `B=k[s]`
is a PID and `omega_B` is injective by Section 2.3, naturality and the
commuting-square requirement force

```text
z|_B = c(s)^sharp.                                      (3.1)
```

Now form the double overlap

```text
R = B tensor_A B
  = k[s_1,s_2]/(s_1^N-s_2^N).
```

The two pullbacks of the global section `z` are equal.  Equation (3.1)
would therefore imply

```text
c(s_1)^sharp = c(s_2)^sharp in Z(R)^sharp.              (3.2)
```

Let

```text
D = k[epsilon]/(epsilon^N)
```

and use the ring map `R->D` given by `s_1 |-> epsilon` and `s_2 |-> 0`.
The difference in (3.2) pulls back to

```text
q^a y^sharp,
y = sum_(zeta in mu_d(k)) (zeta epsilon) in underline Z(D).
```

The big-Witt detector gives

```text
omega_W(y)
  = product_(zeta in mu_d(k)) (1-zeta epsilon T)
  = 1-epsilon^d T^d
  != 1,
```

because `d<N` and `epsilon^d` is nonzero in `D`.  Thus `y^sharp` is nonzero.
Multiplication by `q^a` on `Z` is monic by Section 2.1, so
`q^a y^sharp` is nonzero.  This contradicts (3.2) and proves the theorem.

Notice that its Witt image is nevertheless zero:

```text
(1-epsilon^d T^d)^(q^a)
  = 1-epsilon^N T^N
  = 1.
```

Thus the contradiction is an actual surviving section of `K`, not merely a
formal invocation of an unknown extension class.

More explicitly, on the cover `B/A` the failed descent section is

```text
delta_N
  = q^a sum_(zeta in mu_d(k)) ((zeta s_1)-(zeta s_2)) in K(R),
```

and its restriction to `D` is the nonzero section `q^a y^sharp` above.  If
`partial_e` denotes the connecting obstruction associated with `e`, this
shows

```text
partial_(V_N^*e)([x]) = partial_e(V_N([x])) != 0.
```

Consequently `V_N^*e` is nonzero for every `N>1`; the same failed global
preimage also shows that `e` is nonsplit.  The argument uses a Cech-shaped
failed descent datum only as a detector and does not assume that Cech
cohomology computes the full sheaf `Ext` group.

## 4. First-index specialization

For `N=2`, take

```text
k=F_2,       A=F_2[x],       B=F_2[s],       x=s^2.
```

The unique possible restriction of a lift sends `(x)^sharp` to
`2(s)^sharp`.  On

```text
R=F_2[s_1,s_2]/((s_1-s_2)^2)
```

descent would force `2(s_1)^sharp=2(s_2)^sharp`.  The specialization
`s_1|->epsilon`, `s_2|->0` to `F_2[epsilon]/(epsilon^2)` turns their
difference into Deninger's nonzero class `2(epsilon)^sharp` from Example
4.4.  This is exactly the frozen `N=2` kill test.

## 5. Finite-flat comparator

The same cover `A->B` is finite free, so the proof also runs in the
finite-flat topology.  At the Dedekind ring `B`, the injectivity needed in
Section 3 follows from Deninger's Proposition 4.5 and the finite-flat version
of the domain-refinement argument in Section 2.3.  Example 4.4 applies
because the finite-flat topology is subcanonical.  The same double-overlap
and truncated dual-number specialization give the contradiction for every
`N>1`.

This comparator is recorded separately because the source uses `fp` for the
finite-flat topology and does not identify it with fppf.

### 5.1 Correction forced by the counterexample

This conclusion conflicts with Corollary 4.6 as it is literally printed in
the v1 source.  That corollary claims, on the finite-flat site, that

```text
W_rat(A)=Z(A)^sharp
```

for every Dedekind ring `A`.  Take the Dedekind ring `A=k[x]` used above.
The section

```text
1-xT^N in W_rat(A)
```

has local preimage `c(s)^sharp` on the finite-free cover
`k[x]->k[s]`, `x|->s^N`, but Section 3 proves that this local preimage cannot
descend.  Since the map is injective at `B=k[s]`, no alternative local
preimage can repair the descent.  Hence the displayed section has no global
preimage in `Z(A)^sharp`.

The precise gap in the printed proof is the passage from Proposition 4.3,
which gives an **epimorphism of sheaves**, to surjectivity on the section set
over `Spec A`.  A sheaf epimorphism is only locally surjective in general.
Proposition 4.5 supplies the missing injectivity but cannot turn the failed
local descent datum into a global section.

Thus the valid source inputs are Proposition 4.3 (local/sheaf surjectivity),
Example 4.4, and Proposition 4.5.  Corollary 4.6's sectionwise equality is a
claim corrected by this theorem, not a positive premise used in its proof.
This source correction requires explicit author notification and especially
careful independent review before public circulation.
