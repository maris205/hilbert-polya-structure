\hypertarget{ux7ed3ux8bbaux6982ux8981}{%
\subsection{结论概要}\label{ux7ed3ux8bbaux6982ux8981}}

对每个 (N\textgreater1)，论文利用有限自由根覆盖
(k{[}x{]}\to k{[}s{]})、(x\mapsto s\^{}N)，构造了 Verschiebung
局部前像无法下降的 显式障碍。因此，(V\_N) 在 fppf site 上不存在通过
(\omega) 的加性 sheaf lift；有限平坦 site 的非存在性由独立的
site-specific 论证得到。等价地，对扩张 (e:0\to K\to Z\to W\to0)，不存在
(u:K\to K) 使 (u\_\emph{e=V\_N\^{}}e)。(N=1) 的恒等 lift 是严格对照。

该有限平坦反例还表明 Deninger v1 Corollary 4.6 的 sectionwise
Dedekind-ring 等式按原文表述需要修正；Propositions 4.3、4.5 与 Corollary
4.7 不受该结论否定。这里的 ``lift'' 是 sheaf-extension 意义，不是 Route
A 中的 量子化提升；因此本论文不分配 A0--A4 或 B1--B5 分数。

\hypertarget{ux53efux590dux7528ux7ecfux9a8c}{%
\section{可复用经验}\label{ux53efux590dux7528ux7ecfux9a8c}}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{同一数学结论在不同 site 上必须检查 domain 与 cover closure。}
  fppf 的 argument shape 不能只凭名称移植到 finite-flat。
\item
  \textbf{局部存在不是下降存在。}
  有限自由根覆盖能强迫唯一局部前像，真正的障碍在 overlap
  compatibility；这给出了比抽象``可能不存在''更强的显式 witness。
\item
  \textbf{严格对照要进入定理表述。} \texttt{N=1} 的 identity lift
  防止把所有 Verschiebung 一概写成不可提升。
\item
  \textbf{纠正文献表述必须缩小影响半径。} 只指出被反例击中的 sectionwise
  等式， 同时列明不受影响的命题。
\item
  \textbf{评审应绑定被评文件。} stale PDF 足以使一次 evaluator
  结论无效，即使 TeX 已经正确。
\item
  \textbf{最终 PASS 必须来自重新审计。} 对两项 minor
  应应用受限补丁后重新跑全部 关键门禁，不能在旧报告中改数字。
\item
  \textbf{无期刊 profile 就不声称 venue-ready。}
  一般包完整性、引用闭合和可重复 构建不等于符合某刊投稿细则。
\item
  \textbf{流程证据与学术证据分开。} 模型评审席、协作深度评分和 README
  记录都不 增加定理的数学证据。
\end{enumerate}

\hypertarget{human-vs-ai-value-add}{%
\subsection{Human vs AI value-add}\label{human-vs-ai-value-add}}

人类价值主要体现在目标与责任边界：论文优先级、路线图约束、阶段进入、评审与
修订授权、作者事实、引用格式、内容接受以及下一批治理。AI
独立无法合法替代这些 作者裁决。AI 的主要增量是把目标转成可检验的 descent
obstruction，建立证明与
来源链，执行多轮模拟审查、受限修订、完整性审计和可重复构建。最终质量来自这两类
价值的组合；但可见证据不支持把 AI
生成的证明细节反向写成用户在对话中提出的 原创数学贡献。
