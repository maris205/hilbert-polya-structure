## 3. Exact domain admission

Let `X` be nonempty and indiscrete, let `alpha` be any right action of the
usual additive topological group `R`, and let

```text
G_X^(0) = X,
G_X^(1) = X x R,
r(x,t) = x,
s(x,t) = x.t.
```

Paper 11 already proves that these data form a topological groupoid.  Its
open sets are exactly `X x U`, with `U` open in `R`.

### Proposition 3.1 -- `G_X` is open

For `U` nonempty,

```text
r(X x U) = X.
```

Also choose `u in U`.  Since `x -> x.u` is a bijection of `X`,

```text
s(X x U) contains {x.u : x in X} = X,
```

and hence `s(X x U)=X`.  Empty opens map to the empty set.  Thus source and
range are open, exactly as required by Forssell and by the open-groupoid
input to Protin--Resende.  No Hausdorffness is used.

### Proposition 3.2 -- `G_X` is not etale

No nonempty open neighbourhood `X x U` can map injectively under source.
Choose distinct `u,v in U` and any `x`; then

```text
s(x,u) = s(x.(u-v),v).
```

The two arrows are distinct because their time coordinates differ.  Hence
source is not locally a homeomorphism.  Equivalently, the unit image
`X x {0}` is not arrow-open.  This is an open, non-etale groupoid, so its
open-groupoid quantale is nonunital rather than an inverse quantal frame.

### Proposition 3.3 -- the topological-to-localic pullback is valid here

Paper 11 identifies composable pairs with `X x R^2`.  Therefore

```text
O(G_X^(0)) ~= 2,
O(G_X^(1)) ~= O(R),
O(G_X^(2)) ~= O(R^2).
```

The localic pullback over the terminal base is the locale product of two
copies of `R`.  Since the usual real line is locally compact, its frame
product is `O(R^2)`, agreeing with the actual composable-pair frame.  Thus
the structure maps genuinely define the one-object open localic groupoid
with arrow locale `R`; the audit is not silently applying a sobriety theorem
to the non-sober space `X`.

Domain verdict: **PASS**.

## 4. Topos calculation

### Theorem 4.1 -- actual equivariant-sheaf collapse

For every nonempty indiscrete `X` and every continuous right `R`-action,

```text
B(G_X) ~= Set.
```

There are two independent short proofs.

**Etale-space proof.**  A sheaf on `X` is determined by its value on the
only nonempty open, so `Sh(X) ~= Set`.  The etale space associated to a set
`S` is `X x S`, with opens `X x A` for `A subset S`.  In an equivariant
structure, the action on a fixed sheet `a in S` has a sheet-label map

```text
ell_a : X x R -> S_discrete.
```

Continuity forces `ell_a` to factor through a locally constant map
`R -> S`.  Connectedness of `R` makes this map constant, and the unit axiom
forces the value to be `a`.  Thus every sheet action is trivial and unique.
Every function of sheet sets is automatically equivariant, giving the
claimed equivalence.

**Moerdijk-site cross-check.**  A nonempty open subgroupoid has unit open
`X` and arrow open `X x V`.  The identity, inverse, and composition axioms
make `V` an open subgroup of `R`.  A connected topological group has no
proper open subgroup, so `V=R`.  The only nonempty site generator is
therefore the terminal equivariant sheaf, and its canonical site has sheaf
topos `Set`.

Consequently the actual classifying topos retains none of the cardinality
of `X`, orbit decomposition, action, set stabilizers, prime label, or
numerical `log p`.  The result is stronger than Paper 10's separated-map
collapse but is still a direct consequence of the exact indiscrete owner
and connected time.

### Required negative control

Connectedness cannot be omitted.  With a disconnected or discrete time
group `H`, the same argument gives continuous `H`-sets rather than
necessarily `Set`; for `H=Z` it gives `BZ`, which has nontrivial regular
`Z`-objects.  The final theorem should preferably state the more informative
generic form

```text
B(X_ind rtimes H) ~= BH
```

for a topological group `H`, followed by the connected-`R` corollary.

## 5. Open-quantal-frame calculation

The frame isomorphism

```text
Phi : O(R) -> O(G_X^(1)),
Phi(U) = X x U
```

preserves arbitrary joins and finite meets.  Under the range-first product,

```text
(X x U)(X x V) = X x (U+V),
(X x U)^*       = X x (-U).
```

The first equality follows by composing `(x,u)` with `(x.u,v)`; the converse
uses the same parametrization.  The second uses inversion and the bijection
`x -> x.u` at each time.  Thus, as a multiplicative involutive open quantal
frame,

```text
O(G_X) ~= O(R_group).
```

There is no multiplicative open-set unit because `{0}` is not open.  The
right-sided/base frame is exactly `{empty,R} ~= 2`: if a nonempty open `U`
is right-sided, then `U+R=R` forces `U=R`.

This output is independent of `X` and of `alpha`; trivial, periodic
transitive, and nontransitive actions all give exactly the same quantale.
It therefore loses the actual orbit decomposition and the stabilizer
`(log p)Z`.  It does **not** lose the time group itself: addition, inversion,
and the topology of `R` remain in `O(R)`.

Protin--Resende Theorem 2.45 then reconstructs the resulting **localic**
one-object group `R`.  This is consistent with, rather than contrary to,
their information-recovery theorem.  The points of the non-sober
indiscrete presentation disappeared in the spatial-to-localic passage.

## 6. Standard-circle countercomparison

Let `S_L=R/LZ` with its ordinary circle topology and let
`G_L=S_L rtimes R`.

### 6.1 Topos

Restriction to a basepoint identifies an equivariant sheaf with a discrete
set carrying the stabilizer action.  Conversely, an `LZ`-set `A` produces
the associated etale bundle `(R x A)/(LZ) -> R/LZ`.  Hence

```text
B(G_L) ~= B(LZ) ~= BZ.
```

This is not equivalent to `Set`: the regular transitive `Z`-set is a
connected object that is not terminal, whereas every connected object of
`Set` is terminal.  Thus the standard owner retains abstract integer
isotropy even though all positive `L` give isomorphic discrete groups.

### 6.2 Quantale

The standard arrow frame is `O(S_L x R)`, and its right-sided/base frame is
`O(S_L)`, not `2`.  Protin--Resende reconstruction therefore retains the
standard localic circle action groupoid, including its abstract stabilizer
pattern.  It is not isomorphic to the actual output `O(R)`.

For `c=L'/L`, the dilation

```text
[r]_L -> [c r]_(L'),
([r]_L,t) -> ([c r]_(L'),c t)
```

is an unmarked topological-groupoid isomorphism.  Therefore the plain topos
and plain quantale do not recover the numerical value of `L`.  A strict
time marker `tau([r],t)=t` forbids this dilation unless `c=1`; that marker is
extra structured data and must not be claimed as internal to either plain
interface.

This standard owner is the decisive counterexample to the phrase “topos
and quantale forget orbit/stabilizer information” without an owner
qualification.  The correct theorem is asymmetric:

```text
actual indiscrete owner:
  topos    = Set
  quantale = O(R), base frame 2

standard circle owner:
  topos    = BZ
  quantale = O(S^1 rtimes R), base frame O(S^1)

both unmarked outputs:
  numerical L is not recovered
```
