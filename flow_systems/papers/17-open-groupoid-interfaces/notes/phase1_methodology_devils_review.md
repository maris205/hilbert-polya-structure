## 4. Topos-branch methodology audit

Let `S` be a set.  The étale space associated to its sheaf on a nonempty
indiscrete `X` is

```text
p_S : X x S -> X,
```

with opens `X x A` for `A subset S`.  Conversely, every étale space over
`X` has this sheet form.  For an equivariant structure and one input sheet
`a`, continuity gives a label map

```text
ell_a : X x H -> S_discrete.
```

Since all opens of `X x H` are `X x U`, this map is independent of the
`X` coordinate.  Unit and composition then give a continuous action of
`H` on `S` (with the handedness determined by the frozen range-first
convention).  The same argument on morphisms gives a full equivalence, not
only a bijection on objects:

```text
B(G(X,H)) ~= B_cont(H).
```

For connected `H=R`, every orbit map into a discrete set has connected
image and is constant; the unit law makes the action trivial.  Hence the
real-time corollary is `Set`.  For discrete `H=Z`, the regular `Z`-set is a
counterexample, so `BZ` is nontrivial.

This proof design is complete.  The symbolic proof must still make the
following types visible:

1. whether `B_cont(H)` uses left or right continuous actions;
2. the quasi-inverse functors on objects and arrows;
3. the exact equivalence notion (plain Grothendieck topos/category);
4. the fact that no chosen presentation, point, strict time map, or source
   groupoid is included in that plain output; and
5. the connectedness use only at the final `R -> Set` step.

These are execution checks already implied by the amended protocol, not new
Phase-1 defects.

## 5. Quantale and localic-domain methodology audit

For nonempty indiscrete `X`, the frame map

```text
Phi : O(H) -> O(X x H),      U |-> X x U
```

is an isomorphism.  Direct composition and inversion give

```text
Phi(U) Phi(V) = Phi(UV),
Phi(U)^*       = Phi(U^{-1}).
```

The product `UV` is open in every topological group.  If a nonempty `U` is
right-sided, then `UH=H`; therefore the right-sided/base frame is `2`.
For `H=R`, `{0}` is not open, so this open quantal frame is nonunital.
These calculations are independent of the cardinality of `X`, its orbit
decomposition, its stabilizers, and the chosen action.

The direct calculation does not by itself identify point-set composable
pairs with a localic pullback.  Amendment v2 now isolates the exact missing
comparison:

```text
q_H : O(H) tensor O(H) -> O(H x H).
```

On the registered locally compact domain this is required to be an
isomorphism, by proof or an exact primary-source locator.  Thus the combined
open-quantal-frame/localic-reconstruction theorem has a sound method.  The
symbolic proof must also show, rather than merely assume, either that the
relevant arrow-space local compactness follows for `X_ind x H` or that the
displayed `q_H` is directly sufficient in the selected convention.

The localic owner statement is now correctly asymmetric:

```text
topological presentation:  many indiscrete unit points and its set action
Top -> Loc:                terminal unit locale and one-object localic H
open quantal frame:        fully reconstructs that resulting localic groupoid
```

No conclusion is licensed about recovering the original nonsober
point-set presentation.


## 7. Devil's-advocate and nonredundancy disposition

### Strongest counter-argument

After source subtraction, Paper 17 could be described as two elementary
observations: a sheaf on an indiscrete space is a set, and an open of
`X_ind x H` comes from `H`.  Paper 11 has already classified the same arrow
topology, the composable-pair chart, and an action-blind convolution shadow.
The fixed-prime step then appears to be companion substitution, while the
standard-circle comparison is standard transitive-groupoid theory.  On that
reading the project risks padding a short negative calculation with
framework terminology.

This attack succeeds against a standalone claim but not against the current
Technical Note scope.  The amended project contributes one exact joint
boundary that Papers 9--11 deliberately left open:

1. a valid open non-Hausdorff groupoid framework really accepts the actual
   owner;
2. its plain equivariant-sheaf topos and open-quantal output are both
   computable and both action-blind on the actual owner;
3. the two interfaces retain different information on the standard owner;
4. the apparent point-set loss is localized at `Top -> Loc`, rather than
   misattributed to the quantale reconstruction theorem; and
5. neither plain interface retains the numerical period without a strict
   marker.

That conjunction is a useful negative interface result, but its modest
derivation must remain visible.

## 8. Required symbolic-proof order

The following order prevents the desired collapse from being assumed in its
premises:

1. prove the open topological groupoid claim and the open/non-etale split;
2. classify all étale spaces on `X_ind` and construct the topos equivalence;
3. state and test the connected-real and disconnected-`Z` branches;
4. compute the bare involutive quantale, right-sided frame, and nonunitality;
5. verify `q_H` on the locally compact domain before invoking localic
   reconstruction;
6. prove the topology-isolated actual-orbit/standard-orbit comparison;
7. prove unmarked dilation and strict-time obstruction as two different
   categorical statements; and
8. only then specialize to the actual fixed-prime packet and run the
   action-blind controls.

The proof must fail closed if it needs Hausdorffness, second countability,
an etale-only quantale-sheaf theorem, an imposed standard topology on the
actual owner, or a strict time marker inside a supposedly plain output.
