## Source and normalization lock

Let

```text
Gamma = Gamma_0(11),
f(z) = eta(z)^2 eta(11z)^2 = sum_(n>=1) a_n q^n,
omega_f = 2 pi i f(z) dz,
alpha_f = Re(omega_f).
```

The normalization is `a_1=1`. For a prime `p` not dividing 11, use the
left-coset representatives

```text
beta_b        = [[1,b],[0,p]],  0 <= b < p,
beta_infinity = [[p,0],[0,1]].
```

The induced weight-two operator is frozen as

```text
T_p f(z)
  = p f(pz) + (1/p) sum_(b=0)^(p-1) f((z+b)/p).
```

Equivalently,

```text
T_p omega_f = sum_beta beta^* omega_f.
```

This is the only Hecke normalization used in Round 4. It gives the exact
coefficient rule

```text
coefficient_n(T_p f) = a_(pn) + p a_(n/p),
```

where `a_(n/p)=0` unless `p` divides `n`.

## Theorem 1 — cycle-pushforward eigenperiod relation

Let `C` be an oriented closed 1-cycle on `Y_0(11)` for which the period is
defined, and let `T_(p,*) C` be the cycle pushforward under the above Hecke
correspondence. Then, for every prime `p` not dividing 11,

```text
integral_(T_(p,*) C) omega_f = a_p integral_C omega_f,
integral_(T_(p,*) C) alpha_f = a_p integral_C alpha_f.
```

Evidence token: `[PROVED]`.

### Proof

The standard prime-to-level double coset has the representatives frozen
above. Since `f` is the normalized weight-two eigenform in the one-dimensional
level-11 cusp space,

```text
sum_beta beta^* omega_f = a_p omega_f.
```

Pairing the correspondence with a cycle gives

```text
integral_(T_(p,*) C) omega_f
  = sum_beta integral_(beta C) omega_f
  = sum_beta integral_C beta^* omega_f
  = integral_C T_p omega_f
  = a_p integral_C omega_f.
```

The coefficients `a_p` are real integers, so taking real parts proves the
statement for `alpha_f`.

The one-dimensionality is also enough to identify the scalar without an
external eigenvalue table: `T_p` preserves the cusp space, and the coefficient
of `q` in `T_p f` is exactly `a_p`; normalization by `a_1=1` therefore forces
`T_p f=a_p f`.

## Theorem 2 — explicit closed-geodesic owner decomposition

Let `M in Gamma_0(11)` be hyperbolic and let `sigma_M` be an oriented axis
segment from `z` to `M z`. Right multiplication by `M` permutes the above
left-coset representatives. More precisely, for every branch `beta_j` there
are unique `pi(j)` and `gamma_j in Gamma_0(11)` such that

```text
beta_j M = gamma_j beta_(pi(j)).
```

For a permutation cycle

```text
O = (j, pi(j), ..., pi^(r-1)(j)),
```

define

```text
delta_O = beta_j M^r beta_j^(-1).
```

Then `delta_O` is an integral determinant-one element of `Gamma_0(11)`, is
well-defined up to oriented `Gamma_0(11)` conjugacy when the starting branch
inside `O` is changed, and owns the closed projected geodesic obtained by
concatenating the branches in `O`. Consequently,

```text
sum_(O in cycles(pi)) I(delta_O) = a_p I(M),
I(A) = integral_(C_A) alpha_f.
```

Evidence token: `[PROVED]`.

### Proof

Iterating the gluing identities around a cycle gives

```text
beta_j M^r = (gamma_j gamma_(pi(j)) ... gamma_(pi^(r-1)(j))) beta_j.
```

Thus `delta_O` is exactly the product of the `Gamma_0(11)` gluing matrices.
It lies in the subgroup and closes the concatenated branch path. Changing the
start of the same permutation cycle cyclically conjugates the product. Summing
the branch periods over all permutation cycles is precisely the cycle
pushforward in Theorem 1.

The theorem permits several closed owners on the left. It does **not** state
that `T_p` sends `C_M` to one closed geodesic.

## Theorem 3 — the genus-one same-owner control also passes

Let `beta` be any smooth closed real 1-form on `X_0(11)` and restrict it to
`Y_0(11)`. Then

```text
integral_(T_(p,*) C) beta = a_p integral_C beta
```

for the same prime-to-11 Hecke operators.

Evidence token: `[PROVED]`.

### Proof and kill consequence

The compact modular curve `X_0(11)` has genus one. Its holomorphic cohomology
is generated by `omega_f`; antiholomorphic cohomology is generated by
`conjugate(omega_f)`. The correspondence acts by `a_p` on the first generator
and, because `a_p` is real, by the same scalar on its conjugate. Hence it acts
as `a_p` on all of `H^1(X_0(11), R)`. Exact 1-forms have zero periods on closed
cycles, so the relation holds for every closed real representative.

The executable closed control

```text
beta_control = 3 Re(omega_f) + 4 Im(omega_f)
```

therefore passes by theorem, not by a fitted numerical coincidence. This is a
decisive scope limit:

```text

  = STOP_SCOPED.
```

It remains a valid structural theorem, but it is not discriminative within
the legitimate compactly extending closed-form owner class.
