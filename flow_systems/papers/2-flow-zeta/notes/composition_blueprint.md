## Research question

Can Deninger's source-locked prime packets support a canonical dynamical
zeta/determinant without declaring by hand that each packet has mass one?

## Central thesis

The ordinary individual-orbit Ruelle product is rigorously unavailable because
each prime packet already contains uncountably many primitive orbits of one
length.  Collapsing a packet to one Euler factor is a different measured trace
problem.  The source supplies neither a choice-independent packet
disintegration, relative masses across primes, nor an operator/fixed-point
trace that derives the repetitions.  Therefore the conventional determinant
fails, while measured/groupoid/cohomological replacements remain
`OPEN / NOT_TESTABLE`, not disproved.

## Counterarguments and responses

1. **"Haar probability makes every packet count once."**  Haar probability
   gives N1 only.  It does not provide a canonical packet lift, cross-component
   masses, or an operator trace coefficient.
2. **"Closed points already have counting measure."**  Counting measure is
   canonical arithmetic data, but the missing statement is that its pushforward
   is the flow return trace with the required repeated coefficients.
3. **"Section 11 is the desired convolution algebra."**  It is a convolution
   algebra on an inverse-limit multiplicative group.  The source has no map to
   packet orbit space, no flow representation, and no determinant theorem.
4. **"Clean or foliated trace formulas handle families."**  Existing theorems
   require smooth clean fixed sets, densities, normal return data, operators,
   or simple isolated orbits.  None of these hypotheses is frozen here.
5. **"The no-go rules out all enrichments."**  It does not.  A new enriched
   object with a proved groupoid/cohomological trace would be a new candidate
   version and must be evaluated separately.
