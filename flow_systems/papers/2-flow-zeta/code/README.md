# Code

`packet_trace_controls.py` generates deterministic finite controls for the
normalization classification in the paper. It demonstrates orbit-multiplicity
divergence, packet-weight sensitivity, repetition coefficients, and copied-packet
additivity. It does **not** define a Deninger trace or use Riemann-zero data.

Run the tests with `python3 -m unittest -v test_packet_trace_controls.py`.
