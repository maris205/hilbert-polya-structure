# Generated controls

These files are generated by `../experiments/reproduce.sh`.

- `irreducible_polynomials_f2.csv`: all monic irreducibles through degree 12;
- `closed_point_ledger.csv`: irreducible counts, projective closed-point counts,
  Frobenius fixed-point reconstruction, and periods;
- `zeta_formal_series_identity.csv`: exact coefficient comparison of the orbit
  product with \(1/((1-z)(1-2z))\);
- `repetition_weight_ledger.csv`: endogenous \(1/r\) and period-derivative
  weights;
- `euler_product_convergence_controls.csv`: finite convergence regressions;
- `imaginary_periodicity_controls.csv`: the \(2\pi i/\log2\) software check;
- `clock_intersection_controls.csv`: finite exhaustive instances of the
  same-characteristic theorem;
- `universal_circle_compiler_controls.csv`: unrelated target-encoded length
  products showing the proves-too-much mechanism;
- `frobenius_suspension_manifest.json`: frozen parameters, verdict boundary,
  and SHA-256 hashes.

The numerical rows do not use Riemann zeros and do not upgrade any theorem's
evidence status.
