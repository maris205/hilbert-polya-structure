# Paper 8 source-retention boundary

This directory contains local research copies used for page-level verification.
Citation reproducibility and redistribution permission are different questions.

Public GitHub synchronization must exclude `*.pdf` unless a redistribution
licence has been documented for that exact PDF manifestation. The local files
are not deleted. Public audit material should retain:

- source manifests and checksum ledgers;
- exact titles, versions, URLs, and locators;
- preflight sidecars and their disclosed fallback status; and
- SHA-256 hashes of the locally retained manifestations.

The adjacent `.gitignore` enforces this default for Paper 8. A future licence
review may whitelist an individual file explicitly; it must not remove the
default boundary for the remaining corpus.
