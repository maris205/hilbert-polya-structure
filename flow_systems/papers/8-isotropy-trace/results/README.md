# Generated deterministic artifacts

The nine CSV files are generated by `../code/isotropy_trace_controls.py`:

- `shifted_poisson_convention.csv`: non-even shifted-Gaussian check of
  `(2*pi*n-theta)/L` against the active `exp(+i*r*theta)` return phase; the
  wrong sign is reported as a separate residual.
- `finite_character_grid.csv`: exact modular root-of-unity cancellation plus
  a floating-point regression check.
- `nontrivial_character_phase.csv`: explicit nontrivial phases, including the
  positive imaginary `r=1, theta=pi/2` witness.
- `trace_scale_controls.csv`: regular identity-time versus trivial-character
  ledgers, zero-time exposure, positive-time restriction, and common
  length/probability rescaling.
- `rank_one_corner_peaks.csv`: trace-finite rank-one-corner shrinking peaks;
  point value stays one while Haar mass tends to zero.
- `linfinity_representatives.csv`: zero and singleton-spike representatives of
  the same Haar `L^infinity` class with different literal point values.
- `clock_copy_composite_controls.csv`: arbitrary clocks, copied-clock
  additivity, and composite clocks that preserve the analytic compiler while
  failing rational-prime provenance.
- `transverse_probability_controls.csv`: time-only invariance for normalized
  probabilities and variation of a transverse observable.
- `domain_boundary_controls.csv`: separate local, finite-prime-support, and
  all-prime positive-time scalar domains, with global operator/trace claims
  explicitly false.

`isotropy_trace_manifest.json` records row counts, byte sizes, SHA-256 hashes,
active-tuple hashes, implementation hashes, conventions, deterministic inputs,
and interpretation boundaries. It has no timestamp, so identical code and
parameters produce identical bytes.

These artifacts are finite controls. They do not prove P8-1--P8-9, packet
Hausdorffness, the regular von Neumann decomposition, character-trace
semifiniteness, no-normal-extension, packet transport, source-selected mass,
or any Route result.
