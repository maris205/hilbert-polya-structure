# Figures

This directory contains source-native TikZ figures used by the manuscript.

- `spectral_obstruction.tex` records the exact implication chain from degree
  support to the Route-B Gate-C obstruction.
- `operator_ledgers.tex` keeps the orbit, cohomological Frobenius, and
  Koopman/Stone ledgers visually distinct.

No raster image, target-zero plot, fitted spectrum, or externally generated
figure is used.
