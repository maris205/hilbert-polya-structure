## 4. Independent rederivation of P13-6

### 4.1 Core dependency and the gauge direction

For every registered actual owner, Paper 12 and the frozen core proof give
the unique time factorization

```text
Sigma(x;t,u)=sigma_0(t,u).
```

The core Theorem 5.1 then supplies a normalized continuous
`alpha:R->T` with

```text
sigma_0=delta alpha,
(delta alpha)(t,u)=alpha(t)alpha(u)overline{alpha(t+u)}.
```

I checked the load-bearing direct proof, not only its conclusion. The fixed-
base lift has both axes equal to zero; the cocycle defect is a continuous
`2 pi Z`-valued function on connected `R^3` and is therefore zero; the
commutator of the lifted real cocycle is a continuous alternating
bicharacter and hence vanishes in one dimension; the smoothing step gives a
jointly continuous derivative; and integration yields

```text
q=delta(h-A),
alpha=exp(i(h-A)).
```

The sign is therefore the exact frozen sign. If `beta` is another
trivializer, `beta/alpha` is a continuous character. The support proof does
not substitute Sorkin or a Borel/measurable result for this direct dependency.

The core gauge lemma has the orientation

```text
sigma overline{tau}=delta a
    => U_a:A_sigma->A_tau,
       U_a(f)=af.
```

Thus `sigma_0=delta alpha` gives `U_alpha:A_sigma->A_1`, exactly as the
support/retention record uses. No inverse or conjugate is reversed.

## 6. Independent rederivation of P13-8

### 6.1 Owner, topology, and pullback direction

Assume one common cocompact stabilizer `H=LZ`, `L>0`, and write the nonempty
bare orbit set as `Q=X/R`. Paper 12 constructs

```text
Std(X)=coproduct_(q in Q) O_q,
O_q ~= R/H,
G_std(X)=Std(X) semidirect R.
```

Each `O_q` is a nonempty compact Hausdorff open-and-closed torsor. The
same-carrier identity has the direction

```text
J:G_std(X)->G_actual(X),
```

from the finer standard topology to the coarser actual topology. Therefore
the contravariant function map is

```text
J^*:C(G_actual(X))->C(G_std(X)).
```

The reviewed proof uses this direction throughout; it never assumes that the
reverse identity is continuous.

### 6.2 Actual support and standard support closure

For `f in C_c(R)`, let `K=supp_R(f)`. Paper 11 gives

```text
Phi_actual(f)(x,t)=f(t),
supp_actual(Phi_actual(f))=X x K.
```

The actual time projection is `K`, so the Paper-11 projection criterion makes
this support quasi-compact. The claim is correctly stated as actual
global-QC support, not silently upgraded to Hausdorff compact support.

The pullback is the same pointwise function

```text
Psi_X(f)=J^*Phi_actual(f),
Psi_X(f)(x,t)=f(t).
```

Its standard nonzero locus is
`Std(X) x {t:f(t)!=0}`. For any nonempty space `Z`, a basic-neighborhood
argument gives

```text
closure_(Z x R)(Z x A)=Z x closure_R(A).
```

Consequently the exact standard support is

```text
supp_std(Psi_X(f))
 =Std(X) x K
 =coproduct_(q in Q)(O_q x K).
```

This remains true when `f=0`, with both sides empty.

### 6.3 Exhaustive zero/finite/infinite split

If `f=0`, the support is empty and is compact for every finite or infinite
`Q`. This is the necessary exceptional branch; omitting it would make the
converse false.

If `f!=0`, then `K` is nonempty compact. For finite `Q`, every
`O_q x K` is compact Hausdorff, and the support is their finite union. Hence
`Psi_X(f)` belongs to `C_c(G_std(X))`.

For infinite `Q`, put

```text
S=Std(X) x K,
V_q=S intersect (O_q x R)=O_q x K.
```

Each `V_q` is nonempty and open in `S`; the family covers `S`; and a finite
subfamily misses every component indexed outside its finite index set. Thus
the cover has no finite subcover. The support is not quasi-compact and hence
not compact. No enumeration, countability assumption, finite approximation,
or limiting diagnostic enters this argument.

The three cases prove the exact equivalence

```text
J^*Phi_actual(f) in C_c(G_std(X))
    iff f=0 or Q is finite.
```

Because `Std(X)` is nonempty, `Psi_X` is injective. Therefore, inside the
ordinary continuous-function space,

```text
T_X=J^*Phi_actual(C_c(R)),

T_X intersect C_c(G_std(X))
 =T_X,  if Q is finite,
 ={0},  if Q is infinite.
```

This image/intersection formulation is an exact consequence of the iff and
does not strengthen it beyond its typed domain.

### 6.4 Gauge support

Every allowed gauge `a:R->T` is nowhere zero, so

```text
{t:a(t)f(t)!=0}={t:f(t)!=0},
supp_R(af)=supp_R(f).
```

Multiplication by `a` is an invertible map of `C_c(R)` and satisfies
`M_a Psi_X(f)=Psi_X(af)`. It preserves both `T_X` and the intersection with
`C_c(G_std(X))`. The finite-orbit and infinite zero-intersection branches are
therefore exactly gauge invariant. The proof does not extend this statement
to scalar multipliers allowed to vanish.

### 6.5 Finite-`Q` star map and completion stop

For finite `Q`, the time cocycle pulls back to a continuous standard-owner
cocycle. Direct substitution in the standard range-fibre formulas gives

```text
Psi_X(f) *_sigma^std Psi_X(g)=Psi_X(f *_sigma0 g),
Psi_X(f)^{*sigma,std}=Psi_X(f^{*sigma0}).
```

Core P13-4 puts the scalar right-hand sides in `C_c(R)`, and the finite-`Q`
support theorem puts their pullbacks in the standard compact-support test
space. Hence `Psi_X` is an injective star homomorphism onto the time-only,
unit-coordinate-constant subalgebra. It is not claimed to be onto the full
standard groupoid test algebra.

The proof stops at precisely the licensed point: no norm comparison,
bounded extension, full/reduced identification, Morita statement, or
actual-to-standard groupoid completion follows. For infinite `Q`, the
continuous pullback remains defined, but its time-only image intersects the
standard compact-support test space only in zero, so there is no nonzero map
of this test-space form to extend.

### 6.6 Fixed-prime conditional

For the fixed-prime packet, substituting only
