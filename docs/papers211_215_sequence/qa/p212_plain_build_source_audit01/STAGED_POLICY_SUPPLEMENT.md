The following staged meaning is sufficient to resolve the inconsistency
without changing frozen source or adding another observer. Root must adopt

would require the not-yet-created directory to have already been observed.

P213 authority and not completion of the old P212 B/S contracts.

## One conditional staged grant

1. Before issuing the new grant, root receives and binds the exact eight
   adopted source bytes, whole V3 recipe/request, this supplement, the
   selected P212 global runtime/content manifest, current relevant global
   configuration/search binding, ordinary trusted-tool/namespace boundary,
   controlled thirteen-variable environment, exact output pathname and
   separately prepared/received output parent. Any known required resource
   outside the received finite scope is resolved before grant. The P213
   223-row list alone is not a completeness certificate. Source reception,
   a manifest's existence, or the recipe's execution flag is not authority.
2. A single separately issued root native grant may conditionally authorize
   the exact V3 command. Initially it permits only its fixed preparation:
   exclusive mkdir, manifests/content checks, eight-file copy/cmp/hash and
   actual new-cwd guard. It does not assert these operations have succeeded
   in advance. No existing/failed tree may be cleaned, resumed or reused.
3. The TeX/BibTeX/rendering branch is authorized only if the preceding
   operations and the in-command guard actually succeed. The guard must
   record physical cwd and all dot-inclusive members of COLD and sections;
   require the exact physical pathname, the exact 4/5 members and their
   non-link ordinary file/directory types; reject texmf and .texlive2021
   even as dangling links; and complete the subsequent product-absence
   checks before the first TeX pass. A failed assertion exits under the
   reviewed control flow. A new external observer or a root mid-command
   acknowledgment is not required by this conditional policy.
4. Completion of the command is not artifact acceptance. Root receives the
   full actual native return/session sequence, raw controller/pass streams,
   statuses and COLD_CWD.actual.txt, and independently checks the real cwd,
   complete member records, guard-success marker and source/runtime guards.
   The marker alone is insufficient. If launch/mkdir/redirection fails
   before the EXIT trap is installed, retain the actual native failure;
   do not invent a controller.exit or missing guard record.

Within this grant the recipe's existing ordinary /dev/null redirections,
600-second build and 180-second PDF/page timeouts, TERM plus 10-second
kill-after policy, fixed four passes and complete captures must be expressly
within scope. A timeout/launch supervisor status is not an invented native
TeX exit. Only the actual returned session may be continued; there is no
second launch, automatic repair, retry or reuse of an old consumed grant.

## What remains unchanged

accepted ordinary filesystem and namespace trust. It is not a hostile-race,
ancestor/descriptor, continuous-process or exhaustive installed-source
attestation. The archived unset-HOME relative trees and TEXMFDOTDIR='.'
justify its selected targets only with the separately received current
global configuration binding; the guard does not establish that binding.

Every ordered FLS event, including duplicates and generated-file chronology,
must later be received against P212's own sources and manifest. Unknown
consumed input stops acceptance and grants no host-path follow, resource
installation/generation or retry. Full logs, BibTeX AUX-before/BLG/BBL and
all five keys, warnings/glyphs/fonts/text, actual page count, complete PNG
set and actual all-page views remain necessary. No P213 counts or PDFs
transfer. Initial build, Round0, both nonauthor manuscript reviews and
deltas, required scientific/verifier gates, both terminal cold builds and
final reception remain unwaived. HOLD_EXTERNAL remains.
