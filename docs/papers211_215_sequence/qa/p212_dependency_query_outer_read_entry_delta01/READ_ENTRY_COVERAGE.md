# Author read-entry and lifecycle coverage — source-only check

This is the source author's manual dependency/ordering analysis, not an
independent audit verdict, executed test or operational receipt. It is
intended for a noncontributor auditor's bounded review of the five exact
source files and their frozen contract.

| Entry or operation | Earlier gate / retained evidence | Deliberate boundary |
|---|---|---|
| Python imports / product Bash and env startup | Independent external product_startup/runtime/source receipts and actual product prefix must precede launch | Internal JSON checks cannot attest already-executed startup |
| Selected outer binding | External literal full descriptor; physical nonalias regular file; same opened handle, full bytes, all fourteen stat fields | Descriptor is never included inside its own binding |
| Ordinary source/receipt/runtime read | Exact bound lexical purpose, complete alias/ancestor chain, regular same-purpose referent, full pin, before/after same-handle metadata | No body or query_result role exists in this outer interface |
| Inner binding original | Mandatory configuration input with full pin; entire raw original before Node; complete before/after snapshot | This closes the selected inner binding byte/identity role left to outer by DQD-O1, conditionally on a real future run |
| Pre-Node dependencies | Full snapshot of every finite input plus Python modules/maps/settings and complete native closure receipt | Not inferred from post-Node observation or old runtime counts |
| Node preload | Exact received source, argv, loader flags, ENV8, cwd, umask, physical supervisor binding original | Observes after Node startup; not a substitute for prior external key |
| Node native modules/maps | Every mapped path prelisted and fully byte-keyed; every builtin source fingerprint/version and classified internal binding | Unknown or unreceived lazy binding is HOLD; no continuous loader trace claim |
| cp.spawn | Exactly two ordered literal help/version vectors, exact env/cwd/detached/shell/stdio options | Runtime observations do not accept help text semantics |
| Popen | Prepared independent Node-only request exact match, pre-key and exclusive streams already saved | One spawn attempt; prepared record is not an actual product return |
| Own descendants | Fresh actual subreaper setter/readback; raw own task/children-chain samples and PID/start ticks; actual waitid/waitpid status | Racy discrete observations, not all-SID or exhaustive historical census |
| Final native stream hash | Actual Node exit 0, ECHILD, empty final sampled own chain, only expected Node reaped; inner/preload exact two-call records | Unexpected adoption, race, timeout or nonzero exit stops success |
| Input and selected binding after-key | Full second snapshot, full Python module/map agreement, entire selected-binding raw equality and second external descriptor observation | Atime is allowed to change; other declared projections remain explicit |
| Actual product capture | Exact actual request, every returned object and same-session empty poll; actual closure fields or derived JavaScript catch record (normalized name/message only) | No original exception object, stack, cause or custom fields retained; collector cannot observe enclosing functions.exec transport; root attaches actual outer originals |
| Final outer manifest | No source here generates it; root independently receives whole actual capture and then seals nonself | Neither an inner seal nor a supervisor success is an outer acceptance |
| Runtime-only probes | Separate explicit source/bootstrap receipt arguments and exact no-query/import surface | Enumeration/ABI observations only; no driver/preload or child execution |

Manual source repairs before first freeze removed two potential recursive-key
designs: the Python key now binds orig_argv_prefix rather than embedding the
final outer descriptor; and the inner outer_request_record points to the
prepared Node request independent of actual outer-binding bytes. The after
binding read is now one complete read/metadata observation, not two loosely
coupled calls. Native prctl arguments explicitly use the checked LP64
unsigned-long ABI. Product capture retains a returned live session id before
rejecting malformed/truncated output, so an error does not silently discard
the handle. These are source edits only; there are no corresponding executed
failure incidents or invented regression results.

The own-chain sampler also checks the child's observed parent against the
sampled parent or this adopting subreaper before traversing its tasks and
again afterward. An incomplete/racy sample retains every available partial
row and its actual error in the owned journal before refusal. It remains a
discrete observation, not an assertion that PID reuse is continuously excluded.

The original DQD-S1 Major finding and its accepted revision02 same-reviewer
delta remain immutable. This packet does not reopen, overwrite or broaden
that historical verdict. The prospective source amendment changes only
fixed profile/frontier/driver provenance under a separately required receipt.
The outer source has its own new infrastructure surface and needs actual
independent review. Its author's prior P212 proof/contribution history is
disclosed; this is not a manuscript review.

No automatic intervention is hidden in the lifecycle code. The old
runtime_core.settle_group implementation had automatic TERM/KILL behavior;
it was read as lineage but not imported, copied as an operative helper or
invoked. The new source closes only its own file descriptors. A timed-out
supervisor can leave descendants alive and that state is explicitly UNKNOWN;
root must settle the actual process/session under separate scope before
making any final artifact claim.
