## Native and full-body capture

Each native child uses literal argv, explicit ENV8, exact query cwd and an
actual bound /dev/null descriptor. No shell/PATH search, engine, BibTeX build,
ldd, setup, generator helper, submitted-code evaluation, repair or retry exists.

Before spawn, complete input/configuration maps and ATTEMPT record argv, cwd,
environment, deadline, input-key pin and stdin handle. Exclusive separate raw
stdout/stderr and an fsynced event journal retain actual PID, exit and close
separately from wrapper status. Timeout is 120 seconds without automatic
signal intervention. A 16 MiB post-settlement per-stream memory limit keeps an
oversized original as failure rather than truncating it into success; it is
not a continuous OS quota or disk-space guarantee.

The inner driver requests a detached process group and samples that exact
group after child close. Positive PID, actual exit/close and ESRCH empty
group are required before inner raw hashes. No PID, timeout, remaining group,
spawn failure or unknown sample becomes UNKNOWN/UNCLOSED: retain partial
streams/journal/failure, **no final stream hashes or inner success seal**.
A timed-out detached child may still own raw files. Root must settle it;
neither an empty folder nor an absent PID establishes no writer. No automatic
kill is performed.

enumerate /proc or prove broader session membership. Empty sampled group is
not full session/escaped-writer/OS-hermetic proof. Actual product request and
