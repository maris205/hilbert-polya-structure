\section{Complete one-step fibres}
\label{sec:fibres}

The inverse fixes one register and leaves a multiplication equation in
$I$. The final valuation stratum requires the kernel inside $I$, rather
than the annihilator in all of $R$.

\begin{theorem}[Target fibres]
\label{thm:fibre}
Fix $(u,w)\in I^2$ and set $d=\min\{v(t+u),m-1\}$. The target is
reachable if and only if $w\in t^{d+1}R$. If it is reachable and $x_0$
is one solution of $(t+u)x_0=w$ in $I$, its full predecessor set is
\begin{equation}
 F^{-1}(\{(u,w)\})=
 \{(x_0+k,u):k\in t^{m-d}R\},
 \label{eq:fibre}
\end{equation}
and has cardinality $q^d$.
\end{theorem}

\begin{proof}
The first target coordinate forces $y=u$, so the remaining equation is
$(t+u)x=w$ with $x\in I$. If $d\leq m-2$, write $t+u=t^d e$ for a
unit $e$. Multiplication by $e$ permutes every ideal $t^rR$. Consequently
multiplication by $t+u$ maps $I$ onto $t^{d+1}R$ and has kernel
$t^{m-d}R$. For $w=t^{d+1}w_0$, a concrete solution is $x_0=te^{-1}w_0$;
choosing another lift of $w_0$ changes this solution only by the kernel.
Two solutions differ by a kernel element, and adding any kernel element
preserves the equation. This proves~\eqref{eq:fibre} in this case.

If $d=m-1$, then $t+u\in t^{m-1}R$ and $(t+u)I=0$, including the case
$t+u=0$. The only reachable second coordinate is $w=0$, and every $x\in I$
is then a solution. Here $t^{d+1}R=0$ and $t^{m-d}R=I$, so the same
formula applies. The ideal cardinality in~\eqref{eq:ideals} gives $q^d$.
\end{proof}

\begin{corollary}[Distribution and extreme fibres]
\label{cor:fibrecensus}
For $1\leq d\leq m-2$, exactly
\begin{equation}
 (q-1)q^{2(m-d-1)}
 \label{eq:ordinarycount}
\end{equation}
targets have $q^d$ predecessors. Exactly $q$ targets have the largest
fibre size $q^{m-1}$; they are
\begin{equation}
 (-t+c t^{m-1},0),\qquad c\in\Fq.
 \label{eq:maximizers}
\end{equation}
The image size is
\begin{equation}
 |\im F|=q+(q-1)\sum_{j=1}^{m-2}q^{2j}.
 \label{eq:image}
\end{equation}
All remaining targets have empty fibres. An empty sum is zero.
\end{corollary}

\begin{proof}
Translation $u\mapsto t+u$ permutes $I$. For each ordinary stratum
$1\leq d\leq m-2$, exactly $(q-1)q^{m-d-1}$ values of $u$ give valuation
$d$. For each such $u$, there are $q^{m-d-1}$ admissible values of $w$.
Their product is~\eqref{eq:ordinarycount}. The saturated condition
$t+u\in t^{m-1}R$ instead has the $q$ solutions in~\eqref{eq:maximizers},
each permitting only $w=0$. These fibres are larger than all ordinary
ones. Summing their counts gives~\eqref{eq:image}. At $m=2$ there is no
ordinary stratum: all $q$ reachable targets have $q$ predecessors.
\end{proof}
