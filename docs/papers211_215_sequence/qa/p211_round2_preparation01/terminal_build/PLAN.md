## Native passes and retained evidence

Every build performs the actual ordered sequence:
pdflatex -no-shell-escape -interaction=nonstopmode -halt-on-error
-file-line-error -recorder main.tex; bibtex main; then the same pdflatex
command twice. Actual versions, effective kpathsea queries, optional
amsart.cfg lookup and finite ldd linkage are recorded before/after.
All native errors preserve every output with no auto-fix or lock expansion.

Each pass retains full stdout/stderr, exit codes, actual input before/after
keys and complete log/fls/aux/bbl/blg/out/toc snapshots when produced.
FLS preserves order, duplicates and exact input spellings. A same-pass
generated read has no asserted read-time byte observation: pass-start/end
and record order are all that FLS supports. BibTeX has no fabricated FLS;
its actual aux/style/database and BLG graph are separately checked.

Final measurements include PDF hash/page count, pdffonts embedding rows,
pdftotext page census, undefined/rerun/reference/citation/box/missing-character
diagnostics, BibTeX findings and one actual pdftoppm PNG per page.
The PDF must be nonempty; no generic 100KB threshold or invented venue page
limit applies. Original and copied sources, full host/config keys,
runtime imports/maps and owned-process settlement close after failures too.
Unsettled/incomplete native attempts prevent a package seal.
