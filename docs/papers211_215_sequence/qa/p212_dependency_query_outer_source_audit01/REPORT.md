## Lifecycle and failure argument

outer_contract.py:391–402 sets and reads back a fresh Linux subreaper state
and waitable SIGCHLD disposition before its single Popen attempt. That
mechanism can adopt orphaned descendants while the supervisor remains alive;
it is not inherited automatically by forked children and does not itself
describe arbitrary external writers. [Linux subreaper documentation](https://man7.org/linux/man-pages/man2/PR_SET_CHILD_SUBREAPER.2const.html)

The sampler at 338–389 reads only the supervisor's own task/children chains,
retaining raw proc rows, expected parents and PID start ticks. Available
partial rows and errors are journaled before refusal. Kernel documentation
expressly warns that children listings may omit children during concurrent
exit, so these are discrete observations, not an exhaustive census or a
detector of every race. [Kernel proc section 3.7](https://www.kernel.org/doc/html/latest/filesystems/proc.html)

The 555–589 loop distinguishes nonblocking no-status from ECHILD, uses
WNOWAIT before the actual waitpid status, and requires Node exit 0, actual
ECHILD, an empty final sampled own chain and only the expected Node reaped.
WNOWAIT leaves status waitable; a nonblocking no-status return is not ECHILD.
SIG_IGN differs from waitable default child handling. [Linux wait documentation](https://man7.org/linux/man-pages/man2/wait.2.html),
[Python 3.10 os.waitid](https://docs.python.org/3.10/library/os.html#os.waitid)

Only then do exact successful inner/preload two-command records dominate
the final raw stream hash path at 604–629. Unknown membership, failed spawn,
