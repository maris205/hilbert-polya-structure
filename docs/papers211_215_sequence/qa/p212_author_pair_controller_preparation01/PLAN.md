## Startup, existing-cache and settlement inspection

The controller retains Python's ordinary module-level imports before its
own binding checks. It checks argv count, actual cwd and exact ENV4, then
approved pair authority and input/source pins before compiling/executing the
accepted runtime core. It does not itself assert its interpreter identity,
sys.path, -I/-S/-B flags, cache absence or continuous startup coverage. Root's
separate actual outer invocation and pre-start source/runtime authority must
cover this order. No claim of 'nothing executes before the gate' is made.

The controller constructs the exact adapter argv `/usr/bin/python3.10 -I -S
-B -X pycache_prefix=ATTEMPT/never_created_outer_cache p212_runtime.py outer
BINDING DIGEST ATTEMPT`; the bound vector omits only the separately checked
digest. All five adapter stages run with their own literal cache prefixes.
The adapter's bootstrap imports/core compile occur before its internal
load_binding/settings gate. settings then requires Python 3.10, exact ENV4 /
cwd, isolated/no-site/nonoptimized/no-bytecode flags, exact source-only path,
matching cache prefix and its nonexistence before any scientific child body.
Outer requires the entire attempt absent; each stage requires a new absent
stage directory. Post-hook inherited .pyc/.pyo reads are rejected; module
samples reject loaded bytecode. The after gate requires all five cache paths
still absent. This is bounded sampled/post-hook evidence, not a startup OS
trace or proof about every native/conditional/open path.

The accepted core captures one root AUTHOR_PAIR command in a fresh owned
session with exclusive raw stdout/stderr, DEVNULL, ENV4 and a fixed 1200-second
deadline. It polls, retains actual return and settles that owned process group;
timeout/interruption fails and preserves partial evidence. Unknown pre-return
native outcomes and nonquiescent groups enter UNFINALIZED_NATIVE, so output
hashes/seals are refused. Successful commands require zero exit, complete
streams, empty stderr and no settlement signals. Zombie identities remain
recorded; escaped descendants / OS-wide closure are not certified. The
inherited OSError classification and /proc sampling limitations are unchanged.

The adapter separately receives nested stage seals and tracks unknown
descendant closure. Root controller capture is not the complete runtime or
semantic receiver: successful outer status, recorder census and canonical
equality are preliminary relations, not a replacement for all actual native
receipts, source/configuration/module/map/open keys and final output semantics.
The inherited json.loads(stdout) expects one JSON value: a native heartbeat
line on a sufficiently long run causes capture parsing to fail and preserve
evidence, not silently strip heartbeats or claim success. This limitation was
not changed to enlarge the source delta.
