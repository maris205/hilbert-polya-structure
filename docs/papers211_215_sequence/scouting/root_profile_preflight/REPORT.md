## 2. Circular parking displacement

On $\{0,\ldots,n-1\}^n$, let labelled cars $i=0,\ldots,n-1$ park in that
order, each scanning forward cyclically from its current preference to the
first empty site. Feed back each car's displacement as the next preference.
All cars park and displacement is at most $i$, so the carrier is closed.
On $E_n=\{d:0\le d_i\le i\}$, car $i$ parks at site $i$ by induction,
and the next displacement is $i-d_i$. Thus this is a one-step normalizer
followed by complement. Root independently reached that elementary boundary,
