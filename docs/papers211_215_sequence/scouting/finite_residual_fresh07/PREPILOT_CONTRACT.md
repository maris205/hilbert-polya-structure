integers with sum N. Every index is modulo n. With every value read from
the OLD state, set q_i=min(a_i,a_(i+1)) and

model: each edge sends as much old mass as both endpoints possess. It is a
mathematical flow rule, not a claim of chemically realizable simultaneous
reactions. Parameter n=1 and n=2 are included, not silently excluded.

## Deductive temporal prospect BEFORE execution

F preserves mass and the minimum m, and F(a+m*1)=F(a)+m*1. After subtracting
m, zeros stay zero. In each initial maximal positive run, only its first
positive site can disappear; the rightmost original site stays positive,
gains positive integer mass every nonfixed round of that run, and eventually
holds the entire run mass. Thus only fixed points recur; the terminal vector
is already explicitly determined by original run endpoints and masses.

For n>=4, N>=1 the proposed sharp maximum is N-1, with N=1 fixed and,
for N>=3, witness (N-2,1,1,0,...,0); N=2 uses (1,1,0,...,0).
For n=3 the proposed maximum is ceil(log2 N) for N>=1, since a normalized
two-site run sends (A,B) to ((A-B)_+,min(2B,A+B)); n<=2 is the identity.
N=0 is always fixed. Proof details will be supplied independently of data.

## Independent inverse prospect and explicit failure threshold

For a target after minimum subtraction, each old zero remains zero and a
new zero must have an OLD zero immediately to its left and an OLD positive
site immediately to its right. Consequently a source can hide a positive
site only at the last zero of a target zero-run of length at least two.
Reconstructing each positive target run therefore involves a possible
hidden head and nonlinear min-current inequalities, not merely selecting
a scheduler or counting forgotten labels. The open objective is a fully
evaluated image/fibre law or sharp global extremum and maximizing profiles.

A generic search over flux words, a target DP with no structural collapse,

independent-axis requirement. If no such residual emerges in this fixed
