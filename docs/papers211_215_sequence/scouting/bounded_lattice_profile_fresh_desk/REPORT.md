## Exact historical rule and grid identification

Fix positive integers m,n and the fixed grid
G={0,...,m-1} x {0,...,n-1}, with Manhattan distance d.
The carrier being screened is the nonempty subsets of G. For S in that
carrier, define its distance profile h_S(x)=min_{s in S} d(x,s),
its covering value r(S)=max_{x in G} h_S(x), and the replacement
T(S)={x in G : h_S(x)=r(S)}.
All maximizers are retained simultaneously. No old points are automatically
added back, no tie is selected, and the empty set is not a state.
Thus no artificial empty-state convention is required.

The [old GG08 ledger](../../../papers162_166_sequence/scouting/geometry_group/SCOUT.md)
uses nonempty subsets of an arbitrary fixed finite graph metric.
More decisively, [its actual producer source](../../../papers162_166_sequence/scouting/geometry_group/verify_scout.py)
at source lines 327–330 computes a list of minimum distances, then its
maximum, and returns every index attaining that maximum. Source lines
361–369 use all nonempty subsets in the old path/cycle probes.

The rectangular nearest-neighbor grid graph has shortest-path distance
d((i,j),(k,l))=|i-k|+|j-l|: each step changes one coordinate by one, and a
coordinate-by-coordinate path attains that lower bound without leaving G.
Consequently the proposed grid presentation changes neither the state
operation nor the tie rule; it is an exact parameter restriction of MFS.
The old executable's tested paths/cycles do not restrict its stated
finite-graph literal family. No new test of that executable was run here.
