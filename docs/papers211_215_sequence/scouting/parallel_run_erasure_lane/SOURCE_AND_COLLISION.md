The UVa example is a concrete scheduling counterexample, not only an
analogy. Its word `babbbaaabb` has old runs `b | a | bbb | aaa | bb`.
PRE deletes all three long runs at once, leaving fixed `ba`. The official
statement gives a chosen serial sequence leading instead to empty. Hence
existence of a serial emptying sequence does not classify PRE's basin.

Ordinary run compression keeps one letter per nonempty run and preserves
the support of `aaa` as `a`; it is not PRE. This is a literal comparison,
not an asserted newly verified external compression theorem. Pairwise
free-product cancellation, and deleting a whole arbitrary-length run,
must likewise not be conflated on odd run lengths.
