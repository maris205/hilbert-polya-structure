### Appendix consistency boundary

As returned, the appendix asserts shift conjugacy between
$A=\Sigma_{\{00,010\}}\subset\{0,1\}^{\mathbb Z}$ and
$B=\Sigma_{\{ba\}}\subset\{a,b,c\}^{\mathbb Z}$.

That assertion cannot hold as written. A shift-fixed point is constant.
In $A$, only $1^{\mathbb Z}$ is allowed. In $B$, all three constants
$a^{\mathbb Z},b^{\mathbb Z},c^{\mathbb Z}$ are allowed. A bijection commuting
with the shift maps its fixed set bijectively onto the other fixed set;
one point cannot map bijectively to three. This is a complete deductive
counterexample to that stated conjugacy, not a computational test.

No correction, replacement entropy value, or full-paper invalidation is
asserted. The preceding restriction-to-shift argument and the Cauchy
formula are separate source claims. We do not import the disputed
conjugacy or its derived entropy value into any theorem contract.
The objection concerns the extracted statement; visual confirmation was
not obtained: one screenshot call returned only a reference without
accessible image content, the other timed out, and experimental HTML
returned 404. Those limits are preserved instead of asserting a visual
page inspection. The obstruction itself does not create a fresh map.

## 3. Why a generic inverse construction is not a second axis

Erica Jen, *Enumeration of Preimages in Cellular Automata*:
[publisher abstract](https://www.complex-systems.com/abstracts/v03_i05_a02/).
The complete abstract was read. It states rule-general exact preimage
enumeration for arbitrary spatial sequences. The PDF endpoint initially
reported a 36-page document, but body reopening timed out and searches
for periodic/trace returned no match. Thus no PDF-body theorem, periodic
trace formula or rule172 maximum is attributed to that source.

For precision, the following generic ring identity is an author deduction,
not a claim to new mathematics. Let $f:\{0,1\}^3\to\{0,1\}$ be any fixed
nearest-neighbor local rule, and let the ring length be $n\ge1$. For
$b\in\{0,1\}$ use a matrix indexed by the four binary pairs, with entry
$M_b[(a,c),(c,d)]=1$ precisely when $f(a,c,d)=b$, and all other entries zero.
For a labelled target $y$, its one-step fibre has size

$$
\operatorname{tr}(M_{y_0}M_{y_1}\cdots M_{y_{n-1}}).
$$

Proof: a source $x$ determines the anchored closed path with vertices
$(x_{i-1},x_i)$, and its $i$th edge has label $y_i$ exactly when the update
holds there. Conversely, pair overlap and closure reconstruct a unique
labelled source. This remains true at $n=1,2$: closure enforces the repeated
coordinates; no free boundary sites are introduced. The trace counts
anchored closed paths, not cycles modulo rotation. This proves the iff
and count, but does not evaluate the maximum over targets or identify all
maximizers. A specialized matrix product alone supplies no independent
inverse/extremal residual for this desk.
