It documents why even a correct inverse cannot repair the source-owned

If a predecessor has head a, then necessarily `1 <= a <= l` and

    lambda_1=a,  lambda_(i+1)=mu_i-1_{i<=a}.

The residual must have nonnegative connected positive support (trailing
zeros allowed). Conversely each such a produces exactly one positive
composition predecessor, because its mass is a+(N-a)=N. Distinct a give
distinct predecessors, so this is a bijection, not an implicit search over
all compositions.

For `a<l`, the residual ends positive and therefore is connected exactly
when every `mu_1,...,mu_a` is at least two. For `a=l`, it is connected exactly
when every entry equal to one occurs in a trailing suffix; an all-zero
residual is allowed. Hence, writing `f(mu)=|OM^{-1}(mu)|`:

- If no part is one, `f(mu)=l`.
- Otherwise let p be the first position with `mu_p=1`. Then
  `f(mu)=p-1+1_{all mu_p,...,mu_l equal 1}`.

In particular the image consists precisely of compositions whose first part
is at least two, together with the all-one compositions. The sole N=0
state has its own singleton fibre.
