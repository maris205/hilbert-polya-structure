## 2. Even/odd domino-face toggling

On domino tilings of a $2\times n$ rectangle, first flip every flippable $2\times2$ block with even starting column, then every flippable block with odd starting column. Within each half-step the blocks are disjoint; the second half uses the intermediate tiling. This composition is one autonomous update.

Each half-step is an involution: a flippable block changes between its two tilings, and a nonflippable block is unchanged. Thus the full map is bijective, with inverse given by odd flips followed by even flips. All finite states are recurrent and every target fibre is one. This is a proof of the elementary inverse, not an orbit classification.

## 3. Delete edges in an odd number of triangles

This direction uses the opposite retention predicate from the old OTP map, and was not silently discarded as identical. On all labelled simple graphs on $[n]$, retain an old edge $uv$ precisely when its number of common neighbours is **even**:

$$T(G):\qquad E(T(G))=\{uv\in E(G):|N_G(u)\cap N_G(v)|\equiv0\pmod2\}.$$

The vertex set remains fixed, including isolated vertices. All tests are simultaneous. If $A$ is the adjacency matrix over $\mathbb F_2$, the off-diagonal formula is

$$T(A)_{ij}=A_{ij}+A_{ij}(A^2)_{ij}.$$

### Established deductions

An edge appears in this sum exactly when it is deleted by $T$, while each triangle contributes two incidences at each of its vertices. Thus the deleted edge set has even degree everywhere. A nonempty such simple graph contains a cycle and at least three edges. Consequently

$$h(G)\le\lfloor |E(G)|/3\rfloor.$$
