# Citation-title correction after first documentary collection

At the final direct check of archived primary response 3, the title for
arXiv:1610.00837v1 was found to be **Phase transition in firefly cellular
automata on finite trees**. The first `BOUNDARIES.md` had incorrectly typed
*Synchronization of finite-state pulse-coupled oscillators*. The arXiv URL,
version, author, rule and zero-literal disposition were unchanged. This is
an author citation metadata error, not a revised theorem or an unobserved
source claim.

The first documentary collection had already executed four read-only native
commands. Its `NATIVE_EVIDENCE.json` is preserved unchanged. Two full initial
source files are saved byte-for-byte at:

- `initial_draft/BOUNDARIES.md`: the version pinned as the root-level
  `BOUNDARIES.md` in `collector_inputs`.
- `initial_draft/capture.py`: the actual collector version pinned as the
  root-level `capture.py` in that same receipt.

The current boundary note corrects the title and links this explanation.
The current capture adapter changes only final directory membership (eight
payloads), exclusion of exactly the root manifest, and the explicit historical
resolution for these two pre-correction collector inputs. It does not alter
native output, original source pins, scientific predicates or the six browser
returns. Other collector inputs still resolve to their unchanged original
paths. `verify` checks all these byte bindings, and the new complete nonself
manifest covers both historical files as well as current ones.

No native command was replayed to hide the error; no scientific run occurred.
The first receipts prove what was actually collected, not that every drafted
citation was already correct. The originally proposed five-payload size grew
to eight solely to preserve and bind this correction.
