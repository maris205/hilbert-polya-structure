## Exact mathematical boundary

For every $N\geq1$,

$$
P_N(X_N)=\{0,\ldots,\lceil N/2\rceil-1\}.
$$

For $1\leq r<N$, the predecessor set is exactly the divisors of $N-r$
that exceed $r$; zero has itself and all positive divisors of $N$ as
predecessors. Target $N$ has no predecessor.
These are complete one-step counts, not a claim about higher-step fibres.

Every positive step strictly decreases. This proves one fixed recurrent
state and $h_N(a)\leq a$, but not a new sharp full-carrier clock.

$m,m-1,\ldots,1,0$ has depth $m$. Generic congruence constructions receive
no standalone temporal credit.

whereas target one has size five. No full extremum theorem is inferred.
