## FTH contract, precisely

The rule threads each increasingly ordered fibre into a directed path,
retaining its old target at the final vertex. It keeps the old labels and
acts on all endofunctions, including the empty function and loops.

The full proof is `FTH_PROOF_PACKAGE.md`. Every old directed walk expands
to a new walk, so every iterated vertex-image set expands. On a recurrent
whole-function orbit these sets freeze. Fixed backward-height labels then
make each coordinate's target height nonincreasing, ruling out every
finite-height sibling successor. This forces the exact recurrent carrier:
unchanged cycles, disjoint unbranched tails, at most one tail per cycle
vertex, and each tail-final label below the least label of its cycle.
Tail attachments rotate one predecessor backwards. The exact period is
the LCM of the lengths of those cycles carrying a tail; bare cycles are
fixed under the whole-function update.

The separate inverse is a bijection with admissible subsets of increasing
arrows in the target. Selected heads and endpoint target values must each
be distinct. Reconstruction assigns the endpoint value to its whole path.
There are at most `n−1` optional arrows, giving the sharp fibre maximum
`2^(n−1)`. Equality forces the unique cyclic successor target
`(1,2,...,n−1,0)`. The empty target has one source.

The observed height sequence `0,0,1,2,3,4` for `n=0,...,5` is **not** an
all-size sharp-clock theorem. The proposed contract excludes the unproved
`n−1` entrance clock. Neither generic finite-state eventual periodicity
nor the observed histogram is being substituted for the structural proof.
