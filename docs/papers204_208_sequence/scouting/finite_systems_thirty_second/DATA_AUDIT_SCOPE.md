pilot. This sidecar consumes only the two existing byte-identical full
pilot outputs and does not call, import or reimplement the ONI update.

formula for every complete-bipartite-plus-isolates target in the unchanged
$n=0,\ldots,5$ boxes. It also checks isolated-set preservation on every
recorded source/target pair. It prints every such target's complete
predecessor list and formula value. It asserts all relevant recorded
predecessors have nested, nonzero biadjacency rows/columns.

Exactly one execution, expected below one CPU second. This is a data audit
of the original pilot, not another original-state pilot, a larger box,
an all-size proof, a new ONI execution or independent verification.
