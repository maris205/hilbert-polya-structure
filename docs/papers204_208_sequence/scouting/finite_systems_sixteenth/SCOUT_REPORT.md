## Strongest author theorem, and why it still does not earn a seat

D2LC's all-parameter proof is in `PROOF_AND_DISPOSITION.md` Sections 2–3.
An active pivot survives its own involution, so the minimum active label
never rises and every nonfixed recurrent orbit has period two. A strict
drop caused by adding an edge enters that recurrent core after one step.
A strict drop caused by deleting an edge can cause exactly one further
drop: the triangle-with-leaf configuration with the prescribed decreasing
labels. Thus two is a sharp universal entrance-time bound for n >= 4.

For any active target H, write u for its least degree-two vertex. Only
degree-two pivots in `{u} union N_H(u)` can produce predecessors. A direct
target-degree criterion determines exactly which of these at most three
choices are accepted. Three predecessors occur exactly when the component
containing u is an isolated triangle T and every degree-two vertex outside
T has label greater than `max T`. Targets without degree-two vertices have
only their own fixed-loop predecessor. All boundary cases are proved.

These are genuine sharpenings of a crude priority bound, but the whole
temporal residual is a frozen-environment lift of at most four vertices.
The ambient graph supplies only unchanged boundary degrees and labels.
The three-parent bound/equality test is the corresponding bounded adjacent
pivot calculation. The proof explicitly does **not** claim a global fixed
three-vertex semiconjugacy or import P200's rectangle-specific sharp clock
or inverse extremum. The finite sidecar verified the narrower four-vertex
description on every original graph, not a stronger factor claim.
Author value subtraction therefore removes both residuals; no independent
candidate gate is needed merely to decorate this fixed local gadget.
