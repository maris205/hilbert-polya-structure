# Fifth cross-domain intake — declared before pilot

2026-09-05 UTC. Scope: graph_algebra_fifth only; six literal maps below.
All listed boxes are full carriers, not random samples. No paper/reserve
is assigned. These are proposals to test, not theorem or owner claims.

| Code | Literal finite carrier and update | Fixed initial boxes |
|---|---|---|
| GHD | G^2, (g,h) -> (gh,g^(-1)h) | G=S_d, d=2,3,4,5 |
| TQP | G^2, (g,h) -> (g^2h,gh^2) | G=S_d, d=2,3,4,5 |
| XCY | (F_p^3)^4, simultaneous u_i -> u_i cross u_(i+1), cyclic indices | p=2,3 |
| DCP | Canonical polynomials of degree<p over F_p, f -> canonical representative of f' composed with f modulo X^p-X | p=2,3,5 |
| UOP | S subset of a finite group G, output z iff exactly one ORDERED pair (a,b) in S^2 has ab=z; diagonal pairs included | G=S_3,D_8,Q_8,A_4; C_3,C_4 are abelian controls |
| WPP | R_p^2 with R_p=F_p[X]/(X^p), (f,g) -> (f'g-fg',fg) | p=2,3 |

Differentiation in DCP is applied to the unique canonical representative,
not freely to arbitrary representatives modulo X^p-X. In WPP it is
well-defined on the quotient because the derivative of X^p is zero.
All zero vectors/polynomials/empty subsets are original algebraic states,
not extra failure sinks or selectively held singular branches.

The largest predeclared box is XCY p=3 (3^12 states); this is an initial
full box, not a later rescue enlargement. WPP p=5 would have 5^10 pair
states and is not in the intake. UOP on S_4 is likewise not in the intake.

## Desk exclusions, not extra executed rules

- Mutual conjugation (g,h)->(ghg^-1,hgh^-1) is exactly old G02/MCF in
  papers172_176_sequence/scouting/fresh_nonlinear_algebra.
- Exact-two-secant polarity on projective point subsets is exactly old
  XSD in papers162_166_sequence/scouting/open_fresh_p166_round6.
- Pentagram/diagonal-intersection polygon updates are an explicit old
  direct-owner kill; no finite-field/zero completion wrapper is used.
- Binary quartic Hessian feedback, including its affine coefficient
  lift, is already in the old BHD desk-rejection record. It is excluded.
- Mutual sandwich (aba,bab) has the old product-cubing reduction and is
  not one of the six new rows.

UOP is not the old elementary-abelian-two UPR literal: that map counts
unordered DISTINCT pairs, while UOP counts ordered pairs and includes
squares, on noncommutative groups. This is a literal distinction only,
not contribution credit. XCY's two-step determinant/scaled-shift identity
will be subtracted if it collapses the temporal mechanism to old monomial
dynamics. No word-statistic, closure, erasure rule or power wrapper is
preselected for admission.
