# Exact control snapshots, not scientific originals

Only the three central control files are copied here before recorded
title/claim searches. The native copy command pins the originals before
and after. CONTROL_ROLES.json will bind the original absolute paths to
their direct physical copies and captured hashes; later control changes
must never be resolved by silently substituting current central bytes.
Links inside these snapshots are metadata, not permission to read their
targets. No complete scientific or copy-of-copy package is mirrored.
