# Execution and archival scope

This lane has **one literal / zero original pilots / zero scientific
producer executions**. It wrote and read a proof, ran documentary searches,
retrieved one public source, extracted text, performed raw documentary
comparisons and ran an author read-only artifact audit. There is no
numerical canonical output, no finite-box theorem evidence and no
scientific replay or hermetic-runtime claim.

## Append-only provenance

`capture.py` records actual argv, cwd, timestamps, exact stdout/stderr,
exit, explicit input pins before/after and equality. It uses the inherited
environment and is not a hermetic recorder. `evidence/named_tools.json`
pins the named tool binaries and their actual resolutions; no full dynamic
library or Python-import closure is claimed for these documentary commands.
All scientific code/proof/runtime preflight obligations for a new pilot
would still be mandatory **if** a pilot were started; none was started.

The first harness version omitted argv-named files from the implicit input
set of three **derived documentary filters**: `history_focused`,
`local_pdf_candidates`, `local_pdf_relevance`. Their originals remain
unchanged. This is an input-coverage defect, not an assertion that those
files changed and not a protected-scope failure. The initial harness bytes
are physically preserved as `history/capture_initial.py`; old pins to the
live `capture.py` name resolve to that explicit alias. The final harness
adds every existing argv-named file to before/after pins. It reran all three
exact filters in separately named `_v2` receipts with full input coverage.
Three real `cmp` commands compared each original/v2 stdout pair and all
exited zero. No first receipt or its pins was refreshed. Original scientific
content searches already had every selected file explicitly pinned.

The initial missing helper-path command and mixed-semantic control capture
are preserved in `INTAKE.md`. The helper failure occurred before the
recorder existed and is disclosed as a tool-result narrative, not a
contemporaneous recorder receipt. The exact actual stderr was:


Exit: 2. The later `rg --files` lookup resolved `capture.py`, whose entire

## Author audit and seal

`audit.py` is a read-only artifact checker. Its recorded execution is in
`evidence/audit_checked/`; it checks actual pin referents, historical
copies, complete selected/excluded scope, every full search argv, all raw
command streams and the three original/v2 byte comparisons. It does not
evaluate MCC or independently review the proof. The final direct
`audit.py --manifest` additionally checks the complete nonself seal and
rehashes every actual path it consumed before returning. Interpret PASS
only from those real executions, not from this description.

`SHA256SUMS` covers every file recursively except itself. Its own digest
is reported separately to root after sealing. The author audit establishes
bounded archival consistency, not global novelty, independent gate
acceptance, new runtime reuse, paper admission or five-paper completion.
