## D2 / MFI: maximal facet-incidence representatives

vertex set $V\subseteq[n]$, every vertex present, and all faces closed under
subsets. Write $\mathcal F(K)$ for the facets. For $v\in V$ let
$S_v=\{F\in\mathcal F(K):v\in F\}$. Among the distinct sets $S_v$, keep
only inclusion-maximal ones; for each of these keep the least-labelled
vertex with that signature. Call the selected vertex set $R(K)$ and define

$$T(K)=K[R(K)],$$

the full induced subcomplex. A nonempty finite signature family has a
maximal member, so the output remains in the declared carrier.

$N^2(K)$, with the representative choice in Barmak--Minian Proposition 3.4
made deterministic. Every removed vertex is dominated by a retained one,
