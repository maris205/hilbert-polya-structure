# Kill ledger: graph / relation / random-local lane

Gate frozen against the 16 candidates in `CANDIDATES.md`.  A survivor needs
(i) a literal update not owned by an earlier package or a standard named
process, (ii) an explicit route to a uniform theorem, and (iii) a second axis
such as all-target fibres or a kernel spectrum.  `SURVIVE` means only “retain
for theorem-spike review”; it does not mean novel, publishable, or assigned to
a paper.
