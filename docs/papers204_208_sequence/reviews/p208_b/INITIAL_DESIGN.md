Carrier: a bit for every labelled internal chord, ordered by its endpoint
pair. Enumerate size n-3 crossing-compatible subsets by increasing bit index,
not recursive binary trees, triangulation faces, or adjacency BFS. A local
flip locates the two opposite vertices using the four boundary/chord sides
of the cyclic quadrilateral, and toggles its two crossing diagonals.

Forward rule: take the initial bit positions in increasing order, replace
each exactly once; newly inserted bits are not added to the agenda.

Independent inverse attack: reconstruct the scheduler backwards. At each
step flip a present chord g back to a candidate original chord e; the e's
must strictly decrease in endpoint-pair order, and already restored original
edges cannot be flipped. At exactly n-3 reverse steps, require the restored
original bits to be exactly the recovered source. This tests the complete
source set without using the manuscript's geometric cut decoder. Necessity
is the reverse of the original schedule. Sufficiency follows because the
restored bits are precisely the recovered original agenda, in reverse order;
local flips are involutions. Duplicate histories would have the same source
and hence the same deterministic original agenda, so cannot be distinct.

Scope: all n=3,...,10, total 2,055 labelled triangulations. No larger polygon
calls. Full canonical includes labelled transitions, all target predecessor
sets, cycle components, and individual entrance depths. Exhaustive data are
pressure tests, never an all-size proof. Later proof inspection/rederivation
must disclose any shared structural reductions needed for all-size results.
