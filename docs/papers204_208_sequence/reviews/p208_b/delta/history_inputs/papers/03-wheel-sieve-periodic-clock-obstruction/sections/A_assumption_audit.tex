The direct-image theorem requires neither Hausdorffness nor continuity.  The
closure theorem does require a frozen topology on both target and clock.
Measurability alone does not replace continuity: the defect-shift decoder
with an arbitrary boundary value can be Borel measurable while the fixed
point persists.
