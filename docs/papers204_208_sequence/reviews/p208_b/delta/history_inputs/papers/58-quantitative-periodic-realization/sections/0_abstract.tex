\begin{abstract}
We give two explicit finite-period certificates for shifts of finite type.
First, for a nonempty $\ZZ^d$ shift presented by coordinate-reflection-
invariant nearest-neighbour rules, a thickness-two common-shell construction injects
independently chosen local blocks into points of prescribed period $2n-2$.
The injection gives a two-sided bound for the normalized periodic-point count
with a fully specified $O_d(n^{-1})$ error from entropy, together with an
anisotropic rectangular variant.  Second, for a primitive nonnegative
integral matrix with Perron root greater than one, Perron spectral separation
and M\"obius inversion give an explicit lower bound for the number of points
of least period $n$.  The bound yields a conductor computable from algebraic
spectral data beyond which every integer occurs as a least period.  We
separate the underlying standard mechanisms from the residual quantitative
claims, state a range-two obstruction to the reflection argument, and use
exact finite computations only as falsification controls.
\end{abstract}
