\section{Conclusion}

Exact level separation turns the random substitution
$a\mapsto\{a^\ell,b^\ell\}$, $b\mapsto\{a^pb^{\ell-p}\}$ into a homogeneous
count map and then into a scalar projective system.  This reduction exposes
more than a convenient numerical algorithm: the order of the projective
fixed point splits entropy convergence into a parabolic regime with an
$M^{-1}$ correction and a superattracting regime with double-exponential
projective decay.  The same orbit supplies certified finite-level intervals,
and the entropy is strictly ordered by the mixed-block parameter.

The corrected binary value is an immediate consequence, but it is not the
organizing theorem.  The reusable conclusion is methodological: once
distinct-word decoding produces an exact homogeneous count map, projective
dynamics determines both the entropy cocycle and the strength of its
a posteriori certificate.
