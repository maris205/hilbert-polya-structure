The source code is frozen before evaluation.  Prime, square, Fibonacci,
random, hash, and arbitrary-inventory labels belong to post-freeze controls.
No Riemann-zero data, Euler-coefficient fit, cutoff-dependent branch rule,
or hidden prime return is admissible.

The finite polynomial complex supplies exact characteristic-polynomial
certificates.  The infinite Bergman theorem uses nuclear word traces and
does not assert boundedness of \(d:A^2(\D)\to A^2(\D)dz\).  The equality of
the graded ratio and a cohomology determinant is a theorem for this frozen
pair, not a blanket assertion for arbitrary unbounded complexes.

The following statements are explicit nonclaims:
\begin{itemize}
  \item no universal obstruction to all signed, anisotropic, nontensor, or
  nonlocal transfer constructions;
  \item no intrinsic prime selector in the Elias code or affine translations;
  \item no identification of the graded ratio with an ordinary ungraded
  Fredholm determinant;
  \item no identification of shared and disjoint recurrence;
  \item no identification of digit and completed-return markers;
  \item no same-object continuation into the critical strip;
  \item no functional equation, Riemann divisor, RH implication, or
  Hilbert--P\'olya operator.
\end{itemize}
