\section{Definitions and imported facts}
\label{sec:preliminaries}

All subshifts are two-sided subshifts over finite alphabets, with shift map
$\sigma$.  A cellular automaton between subshifts is a continuous map that
commutes with $\sigma$; equivalently, it is a sliding block code.  Standard
one-dimensional SFT, graph, entropy, and fixed-point conventions follow
\cite{lindMarcus2021}.

Two points $x,y$ are \emph{homoclinic}, written $x\sim_h y$, when they differ
on finitely many coordinates.  A cellular automaton $T:X\to Y$ is
\emph{preinjective} if its restriction to every homoclinicity class of $X$ is
injective.  A subshift $X$ is \emph{Myhill} if every preinjective endomorphism
$X\to X$ is surjective.

For subshifts $U,V$, we write

\begin{equation}
  U\pito V
  \label{eq:pi-arrow}
\end{equation}

when a preinjective cellular automaton $U\to V$ exists.  The arrow records
existence, not a distinguished map.  It is reflexive whenever $U$ is nonempty
because the identity is preinjective.

We import two results for strongly irreducible sources.  If $G$ is amenable,
$U\subset A^G$ is strongly irreducible, $V\subset B^G$ is any subshift, and
$T:U\to V$ is preinjective, then

\begin{equation}
  \ent(T(U))=\ent(U).
  \label{eq:entropy-preservation}
\end{equation}

This is the arbitrary-target statement of
\cite[Theorem~5.1]{ceccheriniCoornaert2012}; it is not restricted to
endomorphisms of $U$.  The same source proves that every strongly irreducible
subshift over an amenable group is Myhill
\cite[Theorem~1.1]{ceccheriniCoornaert2012}.  For one-dimensional sofic
shifts, topological mixing is equivalent to strong irreducibility
\cite[Corollary~1.3]{ceccheriniCoornaert2012}.  Consequently a mixing
one-dimensional SFT is Myhill, and \eqref{eq:entropy-preservation} applies to
every preinjective map out of it.

For $n\geq1$, let

\[
  \Fix_X(\sigma^n)=\{x\in X:\sigma^n x=x\}.
\]

This is a fixed-by-$n$ set, not the set of points having minimal period $n$.
For a primitive adjacency presentation $A$ of a mixing SFT $M$, conjugacy and
the closed-walk count give

\begin{equation}
  |\Fix_M(\sigma^n)|=\tr(A^n).
  \label{eq:trace-fix}
\end{equation}

We use \eqref{eq:trace-fix} only to decide whether the set is empty.
