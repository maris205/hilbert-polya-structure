Boundary conventions are literal, not repaired after computation. CRS sends
the empty set to the whole field because the derivative of the empty product
1 is the zero polynomial; the whole field maps to empty because
(X^p-X)'=-1. CCS ignores collinear triples and includes empty/small sets.
UEX has no self-neighbours; k=0 and k=n have an edgeless one-vertex Johnson
graph. IDR tests naturally labelled posets, not all order relations on
arbitrary labels counted as separate states.

## Breadth and collision subtraction

Before fixing the six literal pilots, the desk scan excluded the exact old
farthest-point rule RX01, cyclic adjacent-sum ranks ASR, orbit-cardinality
feedback OCF (including the existing zero-based minus-one version), and
descending-run pop-stack sorting PPS. The old Newton cubic neighbourhood
was also not pursued. These desk exclusions are not extra executed pilots.

The closest older internal mechanisms are P163's Boolean-union Johnson
dilation for UEX, P161's orthocentre sliding window for CCS, and old strict
poset squaring for IDR. The first two are not asserted to be conjugacies:
exactly-one neighbourhood aggregation is not Boolean OR, and an all-triples
set map is not a three-point sliding window. For IDR, only a proved
containment in relation powers is used; equality with poset squaring is
false in general. The strongest actual adapter in this lane is DPF's
complete prescribed-depth parent-choice inverse, spelled out in
[PROOF_BOUNDARIES.md](PROOF_BOUNDARIES.md).
