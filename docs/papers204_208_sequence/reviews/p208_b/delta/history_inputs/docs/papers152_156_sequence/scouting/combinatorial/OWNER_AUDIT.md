## Search protocol

Before any candidate was eligible for promotion, the search used four layers:

1. exact literal-map phrases;
2. selector plus `iterate`, `standardize`, `orbit`, `image`, or `fibre`;
3. the static statistic or classical construction; and
4. the closest P1–P151 proof mechanism.

A direct literal owner kills.  A static owner subtracts the static fact and
leaves only genuinely dynamical conjunctions eligible.  A bounded non-hit never
raises the verdict by itself.
