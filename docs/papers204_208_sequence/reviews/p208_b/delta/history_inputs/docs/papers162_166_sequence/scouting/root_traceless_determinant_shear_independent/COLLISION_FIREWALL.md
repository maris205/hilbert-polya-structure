## 1. Decisive internal comparison: P115

P115, *Bounded Cartier-Operator Dynamics*, explicitly conjugates its bounded
coefficient map to an inverse-Frobenius permutation times nilpotent coordinate
shifts.  It then derives:

- exact iterates;
- all-time image sizes and uniform fibres;
- a nilpotent/invertible product decomposition;
- exact depth CDF and sharp height;
- fixed iterates, exact cycles, and zeta data; and
- a parameter-recovery axis tied to the bounded Cartier specialization.

P115 also expressly assigns generic finite linear-system decomposition,
kernel/image counts, Frobenius cycles, attached trees, Möbius inversion, and
zeta conversion zero contribution credit.

For the present candidate the bijection

```text

```

gives exactly the same proof engine in a still more degenerate form:

```text

```

Unlike P115, no bounded operator-specific residue remains.  The two extra
coordinates are passive multiplicity only, and every proposed statistic is
a direct kernel/image/primary-decomposition consequence.  This is a fatal
proof-engine collision under the current Route-A rules.

## 4. Literal versus proof-silhouette result

No prior paper in P1--P165 uses the exact displayed rule
`A -> A+det(A)I` on traceless `2 x 2` matrices.  This literal noncollision
does not rescue the candidate.  The stronger fact is an exact conjugacy to a
standard linear map, and P115 already records the complete product-linear
functional-graph engine as zero-credit territory.

The following proposed axes are therefore not independent:

```text
iterate -> image/fibre -> depth/core -> fixed counts -> Mobius periods
```

They are all outputs of the same cyclic `F_2[z]` module.  The target
condition `R_t(D)e in im D^t` is even equivalent to the simpler
`e in im D^t`; it introduces no separate inverse grammar.
