# Five-paper batch after P203 — scope and inherited contract

Question: Which five finite autonomous deterministic maps, beyond the known,
rejected and reserved internal surface through P203, yield both an all-parameter
temporal/recurrent theorem and a separate inverse, fibre, enumeration or
extremal theorem using a materially different mechanism?

Current user authorization: five papers per round; breadth within the current
dynamical type; clear progress in every paper; no routine intermediate
confirmation; timely scoped private Git synchronization. This is not the HP
arithmetic admission problem, and no Route B or external release is authorized.

The maintained [workflow](../research_state/WORKFLOW.md) controls execution.
The prior batch's [promotion criteria](../papers197_201_sequence/PROBLEM_ANCHOR.md)
and [two-review contract](../papers197_201_sequence/HOSTILE_REVIEW_PROTOCOL.md)
are inherited with the internal subtraction boundary extended through P203.
Use exactly two real process-separated paper reviews with disclosed provenance,
accepted deltas and physical freezes; author/A/B canonical replay pairs;
two source-only final builds per paper; actual all-page inspection; complete
input and package integrity checks. No old evidence is rewritten for a new layout.

At scouting, finite experiments are counterexample pressure, not proofs.
Test cheap explicit maps before expensive cutoffs. Deduct conjugacy, factor,
complement, parameter restriction and existing proof mechanisms. A weak,
duplicate or broken candidate is replaced; every numbered rejected manuscript
keeps its identity. Five candidate notes do not count as five completed papers.

This batch uses the current configured model in distinct working processes.
The project-specific workflow takes precedence over optional generic skill
templates, old provider defaults and routine confirmation recipes. External
review APIs, manuscript uploads and notices are not invoked. GPU-training
pilots are inapplicable; exact finite CPU pilots are recorded with their bounds.
The research outcome is uncertain: no fixed token/runtime budget or success
prediction is asserted, and the requested five-paper standard is not reduced.
