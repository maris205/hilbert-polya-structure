# C152 hostile audit

Each semantic mutation is written to a temporary evidence file and receives a
repaired canonical hash before rejection by the independent checker.  A stale-
hash control is separate.  Attacks include collision deduplication, a false
spectral-trace identity, altered density/asymptotic constants, and forbidden
Route-B authorization.  No external reviewer is claimed or simulated.

Seven-mode release audit: source leakage **PASS** (unit-square directions
only); train/test or parameter overfit **NOT APPLICABLE** (no fit);
confounding conventions **PASS** (positive ordered quadrant and axes frozen);
independence **PASS** (direct producer, sieve checker, SymPy third path);
metric integrity **PASS** (collisions retain multiplicity); reproducibility
**PASS** (byte replay and fixed-date build); claim inflation **PASS** (wave,
isolated-determinant, Dirichlet-spectral, target, arithmetic, and Route-B
nonidentities explicit).
