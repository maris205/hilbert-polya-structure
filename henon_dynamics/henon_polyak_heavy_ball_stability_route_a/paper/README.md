# C201 paper build

LuaLaTeX uses embedded Latin Modern and Droid Sans Fallback fonts,
`SOURCE_DATE_EPOCH=1787788800`, and suppressed optional PDF metadata.
`CRevisionRound=0,1,2` produces the three substantive preserved rounds;
round 2 equals `main.pdf`.

Release requires two fresh byte-identical final builds, a clean log,
extractable theorem/scope text and visual inspection of every page.
