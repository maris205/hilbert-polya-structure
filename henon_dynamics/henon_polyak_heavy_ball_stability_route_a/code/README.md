# C201 exact certificate code

- `c201_heavy_ball_producer.py` emits the rational Jury, optimum, Jordan,
  rotated-SPD and finite-order ledger.
- `c201_heavy_ball_checker.py` independently rebuilds it and enforces exact
  recursive key sets.
- `c201_heavy_ball_sympy_crosscheck.py` supplies a separate symbolic path.
- `c201_heavy_ball_replay.py` requires byte identity.
- `c201_heavy_ball_mutation.py` rejects repaired-hash, stale-hash,
  unknown-key and mathematical attacks.
- `c201_release_manifest.py` closes 27 payloads and excludes itself.

Finite controls validate conventions; the all-real parameter theorem is the
algebraic proof in the paper, not a conclusion from the finite ledger.
