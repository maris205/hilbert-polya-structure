# C193 hostile audit

This is an internal artifact-bound audit, not external peer review and not an
independent error process.

The suite recomputes the canonical payload hash after each semantic attack.
It rejects 156 repaired-hash mutations spanning identity, date, source
commit, evaluator provenance, scope, every source-lock and attribution field,
all eight theorem statements, all Route-A qualifications, all scope flags,
all six progress boundaries, every nonclaim, all three source records, finite
totals, level populations, representative tree rows, bounded solutions, and
descent traces.  One additional stale-hash mutation is rejected before
semantic validation.

High-risk rejected attacks include:

- promoting the frozen Route-A tuple or enabling Route B;
- deleting a tree row, child, bounded solution, or descent-trace step;
- reordering the canonical tree ledger or altering a parent/child edge;
- weakening the open-frontier declaration into a closed finite-tree claim;
- replacing the source-owned orbit theorem with finite-enumeration evidence;
- claiming Frobenius uniqueness from unique parenthood;
- importing mod-prime graphs, target tables, local arithmetic data, Euler
  factors, root numbers, automorphy, a target divisor, or Hilbert--Polya;
- conflating the three labelled involutions with the autonomous terminating
  descent.

The independent checker reconstructs the full stored quotient-tree prefix and
uses an alternate quadratic variable for the bounded collision oracle.  The
SymPy path supplies a third exact symbolic route.  Manual hostile review found
no blocker in the full quotient-tree claim once the source-attributed orbit
theorem, open depth-eleven frontier, and Frobenius boundary are kept explicit.
These layers increase implementation confidence without becoming a novelty
certificate, a proof of the open Frobenius conjecture, or external review.
