# C162 narrative report

C157 located `-3/2` branch points but deliberately stopped short of assigning a
canonical amplitude to the full trace.  C162 supplies that missing structure.
At every nonzero shell time, multiplying the full Abel trace by
`epsilon^(3/2)` yields an explicit finite coefficient whose phase is fixed by
the principal branch and whose magnitude is the aggregate source shell
multiplicity.

The result remains valid when a boundary-subtraction pole lies at the same
time because a simple pole is lower order under this normalization.  A uniform
`|m|^-3` domination argument, rather than finite numerics, controls the other
shells.  This is a clean-family normalization theorem, not an isolated-orbit
stability formula.
