# C162 hostile audit

Repaired-hash mutations target the positive and negative phases, source shell
multiplicity, branch scaling, infinite-tail domination, coincident-pole order,
Weyl term, hard gate, natural operator, Route-A tuple, upstream hash, scope,
and nonclaims.  A stale internal payload hash is rejected separately.  Finite
shell and floating rows are not substituted for the analytic proof.  The final
count is 23 repaired-hash rejections plus one stale-hash rejection.
