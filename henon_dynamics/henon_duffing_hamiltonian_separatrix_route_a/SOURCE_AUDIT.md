# Source and claim audit — C232

- Source object: the polynomial Duffing Hamiltonian in `THEOREM_PACKAGE.md`.
- Parameters: rational regression values with the all-parameter theorem
  `beta>0`, `delta in R`.
- Clock: physical continuous Hamiltonian time.
- Normalization: action `I=(2 pi)^(-1) int v dx` on one connected oval.
- Allowed data: potential identities, turning roots, quadratures and local
  linear rates.
- Forbidden data: target primes/zeros, local arithmetic, Euler factors, root
  numbers, automorphy, target divisors, Hilbert--Polya operators and Route B.
- Numerical values are generated deterministically at 80 working digits and
  checked independently; they are not used to fit a theorem.

The Route-A evaluation is source-local and records the continuous-energy
obstruction explicitly.
