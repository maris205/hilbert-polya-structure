  60-iterate evidence producer.
- `c375_lps_nonbacktracking_checker.py`: independent four-square, alternate
  projective gauge, left-action group and trace checker; imports no producer.
- `c375_lps_nonbacktracking_sympy_crosscheck.py`: exact quaternion, quadratic
  trace, `K7`, Möbius, chamber and scope checks.
- `c375_lps_nonbacktracking_replay.py`: two isolated byte-identical builds.
- `c375_lps_nonbacktracking_mutation.py`: repaired-hash semantic, parser,
  route, source, ownership and scope attacks.
- `c375_release_manifest.py`: all-lane release, frozen-wrapper bilingual
  abstract/keyword gates, deterministic PDF, and exact payload-ledger gate.

certificate.
