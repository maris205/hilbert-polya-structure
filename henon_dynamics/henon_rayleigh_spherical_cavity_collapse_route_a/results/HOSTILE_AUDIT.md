The mutation harness changes the theorem Beta constant, pressure row, clock,
terminal coefficient, regime labels, boundary label, route verdict, Route-B
lock, scope literal/flag, source commit, an unknown nested theorem key, and an
unknown top-level key; it also applies a stale payload hash.  The independent
checker rejects every repaired or stale mutation (15/15).
The scope mutation set includes the A3 failure lock: a source Beta clock is
not target continuation/divisor/counting law.
