# Complete projective Möbius cycle atlas

Let `q=p^r`, let `X=P^1(F_q)`, and let `g=[A] in PGL_2(F_q)`. Matrices differing by a nonzero scalar define the same map. One application of `g` is one source-time update.

## Main theorem

Exactly one row applies. In the semisimple rows, `d` is the order of the eigenvalue ratio (over `F_q` or `F_{q^2}` as appropriate).

| type | restriction | cycle multiset on `X` | `F_n=#Fix(g^n)` | source zeta |
|---|---|---|---|---|
| identity | `g=1` | `1^(q+1)` | `q+1` | `(1-t)^(-(q+1))` |
| nontrivial unipotent | order `p` | `1^1 p^(q/p)` | `1+q 1_(p|n)` | `(1-t)^(-1)(1-t^p)^(-q/p)` |
| split semisimple | `d>1`, `d|(q-1)` | `1^2 d^((q-1)/d)` | `2+(q-1)1_(d|n)` | `(1-t)^(-2)(1-t^d)^(-(q-1)/d)` |
| nonsplit semisimple | `d>1`, `d|(q+1)` | `d^((q+1)/d)` | `(q+1)1_(d|n)` | `(1-t^d)^(-(q+1)/d)` |

For every `m>=1`, the exact number of points of least period `m` and primitive `m`-cycles is

`P_m = sum_(e|m) mu(m/e) F_e`,  `C_m=P_m/m`.

Thus the table is also a complete primitive-orbit classification, with no cutoff.

For every `d>1` the exact element counts are

- identity: `1`;
- nontrivial unipotent: `q^2-1`;
- split order `d|q-1`: `q(q+1) phi(d)/2`;
- nonsplit order `d|q+1`: `q(q-1) phi(d)/2`.

Empty divisibility channels contribute zero. For odd `q`, `d=2` belongs to both divisibility lists: split involutions have two rational fixed points and nonsplit involutions have none. In characteristic two, `q-1` and `q+1` are odd, so all nonidentity projective involutions are unipotent.

## Proof of the four rows

Cayley--Hamilton gives `A^2-tr(A)A+det(A)I=0`. If `A` is scalar, `g` is the identity. If the characteristic polynomial has one eigenline and `A` is not scalar, a projective conjugacy sends `g` to `x -> x+1`. It fixes infinity, has order `p`, and partitions the `q` affine points into `q/p` translation cycles.

If the characteristic polynomial has two distinct roots in `F_q`, conjugate the two rational eigenlines to `0` and infinity. Then `g(x)=rho x`, where `rho` is the eigenvalue ratio of order `d|q-1`. The two eigenlines are fixed. Multiplication by `rho` acts freely with orbit length `d` on `F_q^*`, giving the split row.

If the characteristic polynomial is irreducible, its two eigenlines lie in `P^1(F_{q^2})` and are exchanged by Frobenius. Their ratio `rho` satisfies `rho^q=rho^(-1)`, so `d|(q+1)`. No proper nonidentity power of `g` can fix an `F_q`-line: such a fixed line would make that power split, while `rho^n != 1` keeps its two eigenlines equal to the original nonrational pair. Hence the cyclic group generated by `g` acts semiregularly on all `q+1` rational projective points, proving the nonsplit row.

The fixed formulas now sum the lengths of cycles whose lengths divide `n`. Möbius inversion gives `P_m`; division by `m` gives cycles. Finally,

`zeta_g(t)=exp(sum_(n>=1) F_n t^n/n)=product_cycles (1-t^L)^(-1)`,

which specializes to the displayed rational functions.

## Characteristic-two classifier

Suppose `p=2`. A nonidentity class with `tr(A)=0` has a repeated characteristic root and is the unipotent face. If `tr(A)!=0`, scale the characteristic polynomial to

`y^2+y+u`, where `u=det(A)/tr(A)^2`.

The Artin--Schreier equation `y^2+y=u` has a solution in `F_q` exactly when the absolute trace `Tr_(F_q/F_2)(u)` is zero. Therefore absolute trace zero is split and absolute trace one is nonsplit. This replaces the invalid odd-characteristic discriminant-square test.

## Type census, including involutions

All nonidentity unipotents form one conjugacy class with centralizer size `q`, hence `|PGL_2(F_q)|/q=q^2-1` elements. For split order `d>2`, unordered ratios `{rho,rho^(-1)}` give `phi(d)/2` classes, each with split-torus centralizer `q-1`; for `d=2`, the normalizer doubles the centralizer and gives the same formula `q(q+1)phi(2)/2`. Replacing the split torus by the nonsplit torus of size `q+1` gives `q(q-1)phi(d)/2`, with the same normalizer correction at `d=2`. Summing all rows using the divisor identity `sum_(d|N) phi(d)=N` gives `q(q^2-1)`.

## Exact reversors and Koopman closure

Every nonscalar `A` is cyclic. In a cyclic basis write

`C=[[0,-delta],[1,tau]]`,  `H=[[0,delta],[1,0]]`,

where `tau=tr(A)` and `delta=det(A)`. Direct multiplication gives `H^2=delta I` and `H C H^(-1)=delta C^(-1)`. Therefore `[H]` is a projective involution and `[H]g[H]^(-1)=g^(-1)`. The identity is trivially reversible. This is an exact reversor for every class and every characteristic.

On `ell^2(X)` with counting measure, `U_g f=f o g` is a permutation unitary. Each cycle of length `L` contributes every `L`-th root of unity once and

`det(I-t U_g)=product_cycles (1-t^L)=zeta_g(t)^(-1)`.

This is a canonical finite source quantization. It is not a target spectral identification.
