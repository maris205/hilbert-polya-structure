# Hostile audit

Forty mutations recompute the evidence payload hash and then corrupt one semantic field. Targets include source/evaluator locks, frozen phase space/map/clock/determinant, all four cycle rows, fixed/primitive/zeta/Koopman/reversor contracts, the characteristic-two rule, type census, field coverage, direct counts, a field-row histogram, a canonical record hash, Route-A coordinates, forbidden flags, citations, exact identities, and nonclaims.

The independent quick preflight rejects 40/40. The unmutated receipt passes first. This matters because merely breaking a stored hash would test serialization, not mathematical contract enforcement.
