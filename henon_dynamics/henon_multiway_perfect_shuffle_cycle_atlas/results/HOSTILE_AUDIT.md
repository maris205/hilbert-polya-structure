# Hostile-audit checklist

The release gate rejects altered fixed counts, exact-period counts, cycle
lengths, modular orders, packet-interleave rows, spectral factors, theorem
fragments, route verdicts, scope flags, citation fields, unknown keys, stale
hashes, row counts, and missing rows.  Repaired-payload-hash cases ensure the
semantic checker—not merely the digest—detects drift.  The final suite is
`PASS 44/44`; this audit is reproducibility evidence and does not promote an
arithmetic or target-divisor claim.
