# C194 code

- `c194_holte_producer.py`: digit-polynomial convolution producer.
- `c194_holte_checker.py`: independent slack-variable inclusion--exclusion,
  permutation Eulerian census and Faddeev--LeVerrier checker.
- `c194_sympy_crosscheck.py`: separate symbolic matrix oracle.
- `c194_replay.py`: isolated byte-for-byte producer replay.
- `c194_mutation.py`: repaired-hash semantic attacks and one stale-hash attack.
- `c194_release_manifest.py`: 27-payload, self-excluded release ledger.

All arithmetic is exact.  The finite range is a regression oracle; it is not
the proof of Holte's all-parameter theorem.
