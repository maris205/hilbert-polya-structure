\section{The universal projective monomial group}
\label{sec:universal-group}

Our convention is
\[
\Dih(C_m)=
\langle r,s\mid r^m=s^2=1,\ srs=r^{-1}\rangle,
\]
which has order \(2m\).

\begin{theorem}[Universal source group]
\label{thm:universal-group}
For every \(n\ge2\),
\[
G_n:=\PMon(C_n,Q_{n,\rho})
\cong\Dih(C_{3n}),\qquad |G_n|=6n.
\]
The support map gives an exact sequence
\[
1\longrightarrow C_3\longrightarrow G_n
\longrightarrow\Dih(C_n)\longrightarrow1,
\]
where the support image consists of the even rotations and odd reflections
of the \(2n\)-cycle.
\end{theorem}

\subsection{The edge recurrence}

Let \(E_j=\{j,j+1\}\), with indices modulo \(N\), and set
\[
c_j=\begin{cases}
1,&j=N-1,\\
0,&0\le j<N-1.
\end{cases}
\]
For the normalized map \eqref{eq:normalized-map}, write the forced quadric
scale as \(\rho^q\) using \eqref{eq:q-derived}.  Coefficient comparison on
the image of \(E_j\) gives
\begin{equation}
e_{j+1}=q+c_{\sigma(E_j)}-c_j-e_j\pmod3.
\label{eq:edge-recurrence}
\end{equation}
For fixed \(\sigma,q,e_0\), this recurrence has at most one phase solution.

\begin{lemma}[Closure parity]
\label{lem:closure-parity}
Let \(j_*\) be the unique index such that
\(\sigma(E_{j_*})=E_{N-1}\).  The solution of
\eqref{eq:edge-recurrence} closes at \(e_N=e_0\) if and only if \(j_*\)
is odd.
\end{lemma}

\begin{proof}
Iterating the recurrence gives
\[
e_N-e_0=
\sum_{j=0}^{N-1}(-1)^{N-1-j}
\bigl(q+c_{\sigma(E_j)}-c_j\bigr).
\]
Because \(N\) is even, the alternating sum of the \(q\)-terms is zero.
Only \(j_*\) contributes to the first closing-edge indicator, and only
\(N-1\) contributes to the second.  The remaining expression is
\[
(-1)^{N-1-j_*}-1.
\]
It vanishes exactly when \(j_*\) is odd.
\end{proof}

For a rotation \(\sigma(i)=i+k\), the preimage index is
\(j_*=N-1-k\).  The closure condition is therefore \(k\) even.  For a
reflection \(\sigma(i)=k-i\), the preimage index is \(j_*=k\), so \(k\)
must be odd.  There are \(n\) surviving supports of each type.  The closure
condition is independent of \(q\), and each \(q\in\F_3\) yields one
normalized lift.  Hence the exhaustive list contains
\begin{equation}
3(n+n)=6n
\label{eq:group-count}
\end{equation}
elements.

\subsection{Generators and presentation}

Define
\begin{equation}
(rx)_i=\rho^{a_i}x_{i+2},\qquad
a_i=
\begin{cases}
1,&i=N-2,\\
2,&i=N-1,\\
0,&\text{otherwise},
\end{cases}
\label{eq:r-generator}
\end{equation}
and
\begin{equation}
(sx)_i=\rho^{b_i}x_{1-i},\qquad
b_i=
\begin{cases}
1,&i=1\text{ or }(i\ge2\text{ even}),\\
0,&\text{otherwise}.
\end{cases}
\label{eq:s-generator}
\end{equation}
The phases cube to one.  Edge substitution gives
\[
Q_{n,\rho}(rx)=Q_{n,\rho}(x),\qquad
Q_{n,\rho}(sx)=\rho Q_{n,\rho}(x).
\]
Thus \(r,s\in G_n\).

The support of \(r\) has order \(n\), while phase accumulation gives
\begin{equation}
r^n=\operatorname{diag}(1,\rho,1,\rho,\ldots,1,\rho)
\quad\text{in }\operatorname{PGL}_N.
\label{eq:r-power-n}
\end{equation}
The right side has order three, so \(r\) has exact order \(3n\).
Direct support and phase composition gives
\[
s^2=1,\qquad srs=r^{-1}.
\]
Every element of \(\langle r\rangle\) has rotation support, whereas \(s\)
has reflection support.  Hence \(s\notin\langle r\rangle\).  Since \(r\)
has order \(3n\), the elements
\[
r^k,\quad r^ks,\qquad 0\le k<3n,
\]
are \(6n\) distinct elements of \(\langle r,s\rangle\).  This subgroup
lies in the exhaustive \(6n\)-element stabilizer list, so the two sets
coincide.
This proves the group isomorphism in
Theorem~\ref{thm:universal-group}.

The support kernel is
\(\{1,r^n,r^{2n}\}\cong C_3\).  The support image has order \(2n\) and
is the subgroup of even rotations and odd reflections, isomorphic to
\(\Dih(C_n)\).  This proves the exact sequence.

\begin{remark}[Quantifier scope]
Theorem~\ref{thm:universal-group} is equation algebra in characteristic
zero.  It neither assumes nor proves that \(X_n\) is smooth, and it does not
classify nonmonomial projective automorphisms.
\end{remark}
