# Paper build

The manuscript is compiled with LuaLaTeX under
`SOURCE_DATE_EPOCH=1788134400`.  Each of three substantive rounds is compiled
twice from fresh state and must be byte-identical within the round.  The final
`main.pdf` is byte-identical to `main_round2.pdf`.

See `COMPILE_REPORT.md` for hashes, page count, font embedding, and settled-log
checks.
