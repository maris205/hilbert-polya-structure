# Paper

`main.tex` is a self-contained short mathematical note.  Build with

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

The draft is intentionally anonymous and does not claim that the established
orbital-polynomial formulas are new.  Its contribution is the invariant-sector
projection identity, the exact period-six genus-zero certificate, and the
resulting scoped candidate closure.  It explicitly does not treat cyclic
phase quotienting as an obstruction to ordinary autonomous orbit zeta.
