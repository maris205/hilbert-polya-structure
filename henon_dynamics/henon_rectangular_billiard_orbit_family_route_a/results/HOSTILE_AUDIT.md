# C147 hostile audit

Every semantic mutation is applied in a temporary file and its canonical
payload hash is repaired before the independent checker is expected to reject
it.  Targets include source conventions, ledger rows, primitive counts,
degeneracy data, square-65 witness, family multiplier, scoped measure,
irrational-aspect control, quantization boundary, Route-A tuple, Route-B
permission, and claim flags.  A separate stale-hash receipt is also rejected.

The audit changes no frozen artifact and claims no external reviewer.
