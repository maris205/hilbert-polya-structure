# HCS-C258 — mixed congruential full-period atlas

This package closes the all-modulus Hull--Dobell theorem for the finite
affine dynamics x maps to a x+c modulo m.  The result includes necessity,
prime-power sufficiency, CRT assembly, the exact count of admissible
parameters, the unique primitive cycle, all fixed counts, source
Artin--Mazur zeta, and canonical unitary Koopman spectrum.

The independent checker enumerates all 299,535 affine parameter pairs for
moduli 2 through 96.  SymPy, byte replay, and repaired-hash hostile mutations
provide separate gates.  The all-modulus theorem is proof-driven; finite
enumeration is a regression oracle.

The arithmetic relation is explicitly weak.  There is no rational-prime
orbit dictionary, logarithmic prime clock, target local datum, Euler factor,
root number, automorphy object, target divisor, Hilbert--Polya operator, or
Route-B authorization.  The final paper is paper/main.pdf.
