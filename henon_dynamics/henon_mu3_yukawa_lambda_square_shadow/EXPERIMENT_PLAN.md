# HCS-C62 exact experiment plan

This is a target-lock plan, not evidence.  All values generated by pilots are
non-authoritative until rebuilt by the release checker.

1. Rebind C61's released `W(E_6)` element arrays and the labelled 320-point
   actions.
2. Generate canonical 2-subset and multiset carriers, enumerate all orbits,
   and independently reconstruct stabilizers from complete element sets.
3. Evaluate the lambda character formulas on every conjugacy class and verify
   exact degree totals 51,040 and 51,360.
4. Group orbit fields only after core, normal-closure, and extension criteria
   have passed; never use a table-of-marks locator as a field definition.
5. Construct product-form resolvents and test all orbit values at the
   released split prime `p=692717`.
6. Run both independent arithmetic and hostile mutation lanes, then compile
   a paper only after G0--G7 pass.

The first pilot is CPU-only finite-group enumeration.  A missing or collapsed
branch is a result, not permission to enlarge the scope.
