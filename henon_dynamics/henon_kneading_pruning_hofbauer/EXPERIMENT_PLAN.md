# Experiment plan

1. Freeze the kneading prefix, comparison convention, period cutoff, and
   unresolved-word policy.
2. Run producer, independent checker, symbolic check, replay, and mutations.
3. Compare accepted counts with shuffled-bound and neighboring-prefix controls;
   do not fit a clock or any target zeros.
4. Upgrade only after an infinite coding theorem and a positive-recurrent
   Hofbauer tail estimate are supplied.
