# C105 — Hénon kneading/pruning prefix and Hofbauer determinant gate

This package is the first Route-A candidate of the new dynamics-variant
round.  It freezes a finite lexicographic kneading pair, enumerates all words
whose comparisons are decided by that pair, and constructs the corresponding
finite trace/determinant prefix.

The object is deliberately **not** promoted to a complete Hénon coding.  The
finite prefix is a reproducible A2 diagnostic; unresolved comparisons are
excluded and reported.  The official verdict is therefore `A1_OPEN` and
`A2_CERTIFIED_PREFIX`.  No primes, Riemann zeros, Euler factors, automorphy,
or Hilbert–Pólya operator are claimed.

## Frozen object

The alphabet is `{0,1}`.  A source-locked morphic seed is expanded to 32
symbols.  Five initial symbols on each side leave an interior comparison
window; the remaining non-eventually-periodic tail is the pruning witness.
For a periodic word (w), every cyclic suffix must lie between the lower and
upper frozen bounds.  A comparison that reaches the prefix boundary is
`UNRESOLVED`, never an admission.

For the accepted cyclic language, (t_n) is the number of rooted periodic
words of length (n).  Primitive necklace counts (p_n) satisfy

\[
t_n=\sum_{d\mid n}d p_d,
\qquad
D(z)=\exp\left(-\sum_{n\ge1}t_nz^n/n\right).
\]

The producer records these data through (n=12), and the independent checker
reconstructs them without importing producer functions.  A SymPy series check,
byte-for-byte replay, and five hostile structural mutations are included.

## Reproduce

```bash
cd henon_dynamics/henon_kneading_pruning_hofbauer
python3 code/c105_kneading_producer.py
python3 code/c105_kneading_checker.py
python3 code/c105_sympy_crosscheck.py
python3 code/c105_replay.py
python3 code/c105_mutation.py
```

The LaTeX paper is `paper/main.tex`; the compiled artifact is
`paper/main.pdf`.  The release ledger is generated by
`code/c105_release_manifest.py`.

## Boundary

This is a finite-prefix language certificate, not a theorem that the selected
pair is the kneading invariant of the full Hénon repeller.  A future upgrade
requires a source-backed infinite coding theorem, a positive-recurrent
Hofbauer graph, and a tail/nuclearity bound for the same transfer object.
