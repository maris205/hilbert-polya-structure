# Research question

Can a genuinely three-branch polynomial Hénon candidate support a
chronology-preserving primitive-orbit ledger and a nontrivial,
independently checkable transfer determinant prefix without silently replacing
the dynamics by an averaged or post-hoc finite matrix?

## Frozen candidate

\[
H_{1/7}(x,y)=(x^3-3x+1/7-y,x).
\]

The intervals \((-∞,-1),(-1,1),(1,\infty)\) provide three candidate branch
labels. The current package freezes the full one-sided shift on those labels
only as a pilot. It does not assume every finite word is realized by a bounded
Hénon orbit.

## A1 target

The eventual geometric A1 target is a certified bijection between bounded
primitive Hénon cycles and primitive branch necklaces, including repetition,
orientation, monodromy, and a completeness bound. C104 reaches only the
symbolic half: 196 primitive necklaces are enumerated exactly through length
six. The geometric bridge remains an explicit open obligation.

## A2 target

The eventual A2 target is a source-native transfer operator on a specified
function space whose Fredholm determinant is independently owned and whose
zero-count protocol survives cutoff, precision, and parameter controls. C104
checks only the finite trace identity for a frozen 6 by 6 block matrix. It is
not evidence of nuclearity or a Fredholm determinant for \(H_{1/7}\).

## Falsification-first pilot

The next geometric experiment must freeze a compact candidate set and use two
independent cycle finders. It fails immediately if a primitive word has no
matching orbit, if a repeated word is counted as primitive, or if the proposed
operator changes when the branch partition is relabelled. No zero fitting is
allowed before those gates pass.
