# C160 narrative report

C155 showed that almost every periodic Rule-90 state has full period on
Mersenne circumferences, but it covered the short-period set by all `L-1`
proper clocks.  C160 identifies the finite cyclic time group behind that
bound.  Every short orbit is fixed by a maximal proper subgroup, and all
overlaps are again fixed spaces at explicit gcd clocks.  This yields exact
inclusion--exclusion at every Mersenne length.

On a Mersenne-prime source size greater than three there is only one maximal
proper subgroup.  The potential fixed eigenmodes have order three, cannot fit
the circumference, and leave only the zero state.  All other `2^(L-1)-1`
states have full period, so the probability and finite zeta are exact rather
than bounded.

The result is a clear finite-source advance.  It is not a statement about the
existence of infinitely many Mersenne primes, and the source-length factors
are not target arithmetic local data.  No Route-A target or operator layer is
established.
