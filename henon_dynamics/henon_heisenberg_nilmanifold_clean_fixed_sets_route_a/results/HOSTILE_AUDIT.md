# C146 hostile audit

Each semantic mutation is written to a temporary evidence file, its canonical
payload hash is repaired, and the independent checker must still reject it.
The suite targets schema, source lock, matrix powers, Lucas and determinant
rows, fixed-circle receipts, stability and Lefschetz values, the no-lift
counterexample, verdicts, Route-B permission, and claim flags.  One additional
receipt carries a deliberately stale payload hash.

The audit never modifies the frozen evidence and makes no probabilistic or
external-review claim.
