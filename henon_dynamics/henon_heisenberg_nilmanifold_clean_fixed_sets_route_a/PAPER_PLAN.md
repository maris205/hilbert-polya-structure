# C146 paper plan

## Title

Clean fixed circles obstruct isolated-orbit determinants on a Heisenberg
nilmanifold.

## Claims/evidence map

1. **Well-defined object:** upper-triangular group law, integer lattice, and
   exact correction `q`; proved by polarization and lattice integrality.
2. **Clean periodic geometry:** the central circle is a connected fixed
   component for every iterate; proved using horizontal hyperbolicity.
3. **Two exact obstructions:** stability determinant and Lefschetz number are
   zero at every iterate; proved by derivative and cohomology calculations.
4. **Negative control:** the horizontal torus has `L_(2n)-2` isolated fixed
   points; exact ledger through `n=20`.
5. **Claim repair:** an explicit period-two cocycle witness refutes the naive
   total component count.
6. **Route-A boundary:** the Haar Koopman unitary is intrinsic but lacks an
   orbit-weight bridge, so A1/A2/A3 fail and A4 is only a formal hint.

## Section structure

1. Frozen lattice automorphism.
2. Clean fixed component and determinant obstruction.
3. Lefschetz cancellation and toral control.
4. Rejected component lift, validation, and scope.

No external citations or figures are needed because every claim is derived
from the frozen object and checked by exact code.
