\subsection{Complete relative rows}

The field order in each relative entry is
$(\Fplus,\Fzero,\Fthree,L)$.  A base row is an absolute
$(n,e,f,d)$ row of $M$; each following entry is a relative $(g,e,f,d)$ row,
where $g$ is the number of factors over the fixed base prime.  The final
multiplicity counts base primes of that pattern.

\input{figures/paper_calls/tab_tom206_complete.tex}

In every relative table entry, $gef$ is $2$ for a quadratic intermediate and
$4$ for the top.  Summing $m f_M g f d$, where $m$ is the displayed
multiplicity and $f_M$ is the residue degree in the base row, gives the four
relative different totals $8,16,8,32$ in either table.  The
factor totals are obtained by summing $g$ with multiplicity and equal
$(36,28,36,56)$ and $(18,14,18,28)$, respectively.
