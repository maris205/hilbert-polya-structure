\subsection{Bounded source statement}

The literature roles used here are intentionally narrow.  Perlis supplies
the character/zeta bridge \citep{perlis1977equation}; Bosma--de Smit supply
arithmetic-equivalence context \citep{bosmadesmit2002small}; James supplies
the complete $350/339/11$ census \citep{james2022bayesian}; Stauduhar and
Fieker--Kl\"uners supply the classical resolvent and invariant framework
\citep{stauduhar1973determination,fiekerklueners2014computation}; and
Elsenhans--Jahnel supply broad cubic-surface realization context
\citep{elsenhansjahnel2015moduli}.  None of these sources is cited for the
specific common normalizer, carriers, field diamond, or relative arithmetic.
The bounded search ending 2026-08-16 found no source containing that exact
conjunction.  This negative search record supports the stated distinction
from prior work; it is not a proof of absolute priority and is not converted
into a ``first'' claim.
