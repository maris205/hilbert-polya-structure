# Seven canonical failure-mode audit

Population: claims N1–N7, two verified references, the frozen finite evidence grid and the actual internal workflow.

1. Implementation bug passing AI self-review — CLEAR within the executed exact lanes: independent integer-lattice return recount and generic symbolic identities agree; separate-agent repaired-hash type probes reject. This is not a universal absence-of-bugs claim.
2. Hallucinated citation — CLEAR for both registered references: primary author/publisher pages verify their metadata and the precise limited citation contexts.
3. Hallucinated experimental result — CLEAR for reported finite totals: evidence is generated from exact arithmetic and totals are checked from actual rows; future release numbers are not invented.
4. Shortcut reliance — CLEAR for the tested mechanism: irrational/rational regimes, signed modes, clock/phase-space distinctions and natural-owner noncompactness prevent a sampled or changed-clock shortcut.
5. Implementation bug reframed as novel insight — CLEAR for N1–N7: proof was completed and reviewed before evidence; classical priority is acknowledged and no surprising regression output is advertised as a new theorem.
6. Methodology fabrication — CLEAR for the recorded lanes: actual methods are Fraction/group arithmetic, exact SymPy identities and two working-directory byte replay, not high-precision numerics, copied independent trees or external-model review.
7. Frame-lock at early pipeline stage — CLEAR for the final framing: the paper accepts failure of A0–A3 and retains only a source A4 formal hint instead of forcing the source into a positive target route.
