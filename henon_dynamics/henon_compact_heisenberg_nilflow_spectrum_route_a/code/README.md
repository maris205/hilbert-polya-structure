# Independent exact validation lanes

The producer evaluates rational return phases. The checker independently composes group elements and searches all integer times through 12q, then recursively validates the full exact typed JSON tree; it never imports the producer. Negative times, half-integer nonreturns, zero/negative slopes, primitive tori, signed m and exact domain labels are retained.

SymPy verifies generic formulas, replay compares two working directories invoking the same frozen producer, and repaired-hash mutation attacks semantic fields as well as ten hostile YAML forms. Tests are deterministic, exact, CPU-only and do not require target data. Requirements are listed at package root.
