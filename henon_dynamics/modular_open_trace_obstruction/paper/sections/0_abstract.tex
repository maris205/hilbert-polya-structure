\begin{abstract}
We test whether modular cusp scattering retains genuinely open arithmetic when
one closes it by an ordinary trace or determinant.  The test changes the
mathematical object in two ways left open by a previous final-denominator
obstruction: it retains boundary endpoints, and it retains every cusp channel
of squarefree congruence surfaces.  First, unoriented open scattering
geodesics have an explicit Dirichlet--Laplace series containing both a totient
zeta quotient and a \(\chi_{-4}\) term; this provides a non-Selberg positive
control.  On the rational endpoint action groupoid, however, every
section-induced absolute projective automorphy cocycle of the specified form
is an algebraic coboundary.  The affine value
\(2\log|c|\) is exactly an endpoint denominator-gauge difference.  Enlarging
the boundary creates loops with nonzero automorphy period, but those periods
are precisely the signed hyperbolic translation lengths.  Independently, the complete standard
scattering family for squarefree \(\Gamma_0(N)\) has a fixed
Walsh--Hadamard eigenbasis.  We preserve and multiply the matrices in a frozen
order, then prove that the product is permutation-invariant because the source
algebra is commutative.  The spectral parameter is not asserted to be
dynamical time.  Endpoint projectors restore parameter-to-edge assignment and
path sensitivity, delimiting the obstruction.  Exact arithmetic through
denominator 2000 and 80-digit matrix checks through the 16-cusp level
\(N=210\) audit the formulas without zero tables or fitted parameters.  These
results reject the frozen rational ordinary-loop construction and conditional
bare-product proposal, not off-diagonal kernels or separately derived
operators.
\end{abstract}
