# Round 0 proposal

Retain the rational endpoints forgotten by \(P\backslash\Gamma/P\), define a
local additive denominator cocycle on the endpoint action groupoid, and seek a
Fredholm determinant whose primitive objects remain open scattering paths.

Promotion requires a non-coboundary periodic clock, a source-derived trace,
and a divisor not already equal to Selberg or a classical Kloosterman zeta.
The candidate is killed if the cusp cocycle is gauge-trivial or if all
nonzero boundary loops carry the classical translation length.
