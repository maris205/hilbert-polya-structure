# Route-A evaluation

The frozen HCS-C18 evaluation is stored in
`hcs_c18/evaluation.yaml`. It separates four mathematical objects rather
than assigning one gate verdict to a mixture of them:

1. the rational-endpoint ordinary loop trace;
2. the full-real-boundary period enlargement;
3. bare squarefree scattering-matrix products at different spectral
   parameters;
4. projector-resolved finite path amplitudes.

The overall Route-A verdict is rejected for the frozen constructions. This
does not refute projector-resolved kernels; that branch is not testable beyond
the finite assignment/path-sensitivity gate.
