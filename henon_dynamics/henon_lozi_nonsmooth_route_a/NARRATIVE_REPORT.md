# Narrative report — C116

C116 moves Route A to a nonsmooth, absolute-value Hénon subtype.  The map is
affine on each open half-plane, but a candidate branch word is meaningful
only when its return point follows every declared sign.  Exact rational
enumeration therefore separates algebraic solvability from geometric
admissibility.  The surviving rooted words fall from the full binary count
beginning at period three, and 37 primitive cyclic classes remain through
period eight.

A finite direct sum of the certified cycles supplies an auditable weighted
trace prefix without pretending that a global Markov partition has been
proved.  This distinction is the paper's main methodological point: the
nonsmooth orbit evidence is partial but certified, while the analytic and
arithmetic route gates remain closed.
