# C144 narrative report

The Thue--Morse system is a useful adversarial case for the assumption that a
rich recurrent symbolic language must generate a useful primitive-orbit
layer.  The substitution is primitive enough to make every allowed factor
return with bounded gaps.  Nevertheless, a direct residue-compatible binary
argument excludes every proposed shift period.

The key certificate for period `p` is `d=p(2^k-1)` with odd `k` larger than
the binary length of `p`.  Its binary digit count is exactly `k`, so aligned
dyadic blocks contain two different symbols at offsets congruent modulo `p`.
This produces a finite forbidden-window bound for every `p` and transfers
from the fixed point language to every point of the two-sided subshift.

The finite approximants tell a complementary story.  Each circulated `w_k`
has least period `2^k` and can mimic the intrinsic language on bounded windows;
the replay ledger finds no invalid rooted windows through width 16.  At the
macroscopic stress width `2^(k+1)+1`, however, all rooted windows are invalid
for audited levels 2 through 9.  This scale separation prevents the controls
from being mistaken for periodic points of the limiting subshift.

The result is explicit progress because it proves a reusable negative prior:
minimality and uniform recurrence do not imply Route-A primitive orbits.
Accordingly A1 fails, the source Artin--Mazur zeta is one, and downstream
layers remain failed rather than being decorated with unsupported structure.
