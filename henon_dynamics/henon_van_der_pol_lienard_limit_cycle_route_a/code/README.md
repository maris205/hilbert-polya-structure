# C249 code contract

`c249_vdp_producer.py` emits a deterministic JSON receipt.  It stores eight
analytic parameter rows and five positive-\(\mu\) Poincaré return probes.  The
finite probes use SciPy DOP853 with fixed tolerances and are explicitly not an
all-state numerical census.

`c249_vdp_checker.py` is producer-independent: it checks the closed schema,
the frozen model and theorem strings, all exact identities, row semantics,
and (unless `--quick` is given) re-integrates every return probe.
`c249_vdp_sympy_crosscheck.py` reconstructs the vector field, Liénard
primitive, energy, divergence, time reversal, frequency scaling, and rational
controls symbolically.  `c249_vdp_replay.py` compares clean-process bytes.
`c249_vdp_mutation.py` runs 40 repaired-hash semantic attacks.  The release
manifest closes the 27 payload files and the fixed-epoch PDF contract.

All scripts are safe to run with `python3 -B` and
`PYTHONDONTWRITEBYTECODE=1`; no generated bytecode or build sidecar belongs in
the package.
