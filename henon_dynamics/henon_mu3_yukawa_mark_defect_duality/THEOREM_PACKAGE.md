# HCS-C68 theorem package

Let `M` be the exact C64 self-mark matrix and put

```text
C = Z^16 / M Z^16.
```

For the C65 saturation vectors define `D` as the subgroup generated by their
classes in `C`.  The exact relations are

```text
M z1 = 8 u1,    M z2 = 2 u2,    M z3 = 2 u3.
```

The theorem is

```text
D ~= Z/8 + Z/2 + Z/2,
C/D ~= (Z/2)^8 + (Z/4)^2 + Z/12 + Z/144.
```

Equivalently, the Smith invariants of the augmented matrix `[M | U]` are

```text
[1,1,1,1,2,2,2,2,2,2,2,2,4,4,12,144].
```

For

```text
A = {y in Z^16 : z1.y = 0 (mod 8), z2.y = 0 (mod 2),
     z3.y = 0 (mod 2)},
```

the explicit basis computation gives `M^T Z^16 subset A`, index `32`, and

```text
A / M^T Z^16 ~= (C/D)^vee.
```

The row-side quotient has the same Smith invariants.  This is a restricted
integral duality statement; it does not assert a canonical Smith basis or
any arithmetic/local conclusion.
