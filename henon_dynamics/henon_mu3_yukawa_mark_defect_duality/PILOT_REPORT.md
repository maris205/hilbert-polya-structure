# C68 pilot report

The fresh exact pilot found an embedded defect subgroup
`D ~= Z/8 + Z/2 + Z/2` in the C66 cokernel.  The augmented matrix
`[M | u1 | u2 | u3]` has Smith invariants

```text
[1,1,1,1,2,2,2,2,2,2,2,2,4,4,12,144].
```

The row-side congruence lattice has index 32 and yields the same quotient
invariants.  This separates C68 from C65 (the defect subgroup), C66 (the
ambient cokernel), and C67 (coordinate-wise inverse denominators).
