# Explicit limitations

The proof is for finite nonnegative impedance and homogeneous coefficients.
It neither includes eta=infinity nor interior damping. The exact
pseudospectral half-planes are for the transparent face only. All source
spectral points are proved analytically, but no target spectrum is compared.

The Riesz condition number is for one specified multiplication similarity.
Schatten membership is invariant under bounded invertible similarity;
individual singular values are only stated at zero real part by unitary gauge,
not at arbitrary complex spectral parameter. Ordinary determinant obstruction
is not a claim against all regularizations. The named det2 is trivial.

Finite high-precision calculations lack outward-rounded error enclosures.
Mutations cover declared attacks, not every possible corruption.
Internal single-family AI review is not external peer review.
The optional source-PDF structural preflight was UNAVAILABLE (pypdf absent),
so no certified local-page-anchor or human-read claim is made. Source content
was nevertheless retrieved from the author's repository and read as text.
No literature-priority or submission-readiness claim is made.
