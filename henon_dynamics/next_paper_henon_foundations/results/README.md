# Results artifact contract

This directory is intentionally empty of scientific results at roadmap time.

Every future result must include:

- an immutable run config;
- source and input hashes;
- a manifest;
- convergence tables;
- per-orbit action/stability/Maslov records;
- Fourier branch, action gauge, global/subprincipal phase, adjacency
  orientation, cutoff type and margins, stationary-support certificate, and
  trace-class theorem version;
- complex quantum and periodic-orbit traces;
- all preregistered control outputs;
- a machine-checked gate verdict;
- a short human-readable interpretation that distinguishes theorem,
  numerical observation, and failure.

Finite determinant roots must be labeled by period cutoff, \(\hbar\), cutoff
family, and quadrature. They may not be described as zeros of an infinite
determinant without a proved tail/contour bound.

Finite localized-operator eigenvalues are not labeled physical resonances
until a cutoff/escape-function invariance theorem justifies that language.
