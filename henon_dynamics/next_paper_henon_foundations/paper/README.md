# Manuscript contract

The manuscript will be created only after gates G0--G4 pass or a reproducible
negative result reaches paper quality.

Required front-matter declarations:

1. exact quantized Hénon maps are prior work;
2. the Paper-5 quartic operator is a surrogate, not the exact map
   quantization;
3. the certified object is a local four-state survivor, not the full Hénon
   repeller;
4. localized/open traces are not a self-adjoint Hilbert--Pólya spectrum;
5. no Riemann zeros are used in parameter selection or validation.
6. the classical canonical relation does not uniquely determine a quantum
   spectrum; the paper studies one frozen natural quantization.
7. Weickert's continuous-spectrum theorem and Shudo--Ikeda's Hénon WKB work
   are core prior art, with applicability to the exact \(H_6\) convention
   stated only after verification.

Required appendices:

- coordinate/Fourier convention audit;
- quantization-gauge, adjacency-orientation, trace-class, and cutoff-support
  audit;
- quartic Weyl-law proof;
- Hessian--monodromy identity;
- orbit/action/Maslov artifact table;
- complete numerical error budget;
- legacy low-parameter audit.
