# HCS-C365: Gelfand--Tsetlin (U(3)) integrability and quantization

This package proves a single theorem-scale closure from a classical Hermitian coadjoint orbit to its no-half-form Borel--Weil quantization. In particular, a linear-flow closure is the translated coset $\theta_0+K_\nu$, and it equals $K_\nu$ exactly when $\theta_0\in K_\nu$ (not only when $\theta_0=0$). It contains an analytic proof, exhaustive finite regression receipts, an independent checker, symbolic cross-checks, isolated replay, hostile mutations, three substantive paper revisions, and a deterministic release manifest.

The full statement is in `THEOREM_PACKAGE.md`; `paper/main.pdf` is the final article. The scope is exactly `NO_BAD_EULER_OR_ROOT_NUMBER`.
