# C184 source and ownership audit

## Verified classical source

Masatoshi Fukushima and Tadashi Shima, “On a spectral analysis for the
Sierpiński gasket,” *Potential Analysis* 1(1), 1–35 (1992), DOI
`10.1007/BF00249784`.

The DOI, title, authors, journal, volume, issue, pages, and year were checked
against the publisher/DOI metadata.  The source explicitly owns the
spectral-decimation method and complete spectrum for finite graph
approximations of the Sierpiński gasket.  This package therefore labels the
map \(R(t)=t(5-t)\), the exceptional 2/5/6 series, and their multiplicities
as classical, not new.

## Claim-level boundary

- Classical source ownership: finite-gasket spectral decimation, complete
  spectral series, exceptional continuation, and multiplicities.
- Package proof and synthesis: one all-level statement joins the complete
  lineage ledger to dimension closure, an exact characteristic recurrence,
  the closed determinant, heat trace, finite spectral zeta, independent
  executables, and a content-addressed release.
- Package boundary result: the inverse-branch genealogy changes graph level
  and is not an autonomous physical-time orbit on a fixed phase space.
- Not claimed: universal novelty, priority for the classical theorem,
  infinite-gasket zeta regularization, target matching, external peer review,
  journal acceptance, or a literature-wide novelty certificate.

The bibliography population is exactly one.  No source supplies target
zeros, target prime tables, arithmetic local data, Euler factors, root
numbers, automorphy, or Route-B inputs.
