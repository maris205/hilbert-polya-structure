an independent error process.

attack.  It rejects 70 repaired-hash changes covering candidate/date/commit
identity, path base, scope, evaluator path/version/hash, every source-lock
field, the decimation map, exceptional values, forced 6-series continuation,
characteristic recurrence, determinant theorem, all finite-ledger counts,

The mathematical attack focused on four failure-prone boundaries:

1. Removing the three boundary vertices must not recompute interior degree;
   every interior diagonal remains 4.
2. A 6-series born at the terminal level is the value 6, while a continued
   series first takes 3.  Allowing the singular preimage 2 would overcount
   by exactly the old 6-series multiplicity.
3. The characteristic recurrence is polynomial only because
   \(R(t)-6=-(t-2)(t-3)\) supplies exact cancellation.
4. The inverse-branch genealogy changes graph level and is not an
   autonomous physical-time orbit on a fixed phase space.

The finite spectral zeta is an entire finite sum.  The audit rejects any
upgrade to an infinite-gasket regularized zeta, target divisor, functional
equation, arithmetic clock, Hilbert–Polya operator, or external-review claim.
