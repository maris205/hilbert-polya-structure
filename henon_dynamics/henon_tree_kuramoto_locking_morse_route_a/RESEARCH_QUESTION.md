# Research question

For a finite connected tree with positive edge couplings and arbitrary
heterogeneous natural frequencies, can one classify every phase-locked
Kuramoto state modulo diagonal rotation, including the exact existence
chamber, branch multiplicity, reduced Morse index, stable branch, saturated
faces, and violated-cut obstruction?

The frozen question is deliberately narrower than a global classification of
all unlocked trajectories.  It asks for a complete theorem about relative
equilibria on trees.  It does not ask for inference from oscillator data,
extensions to cyclic graphs, a target determinant, or any Route-B object.

The source clock is physical oscillator time.  The only literature source is
Kuramoto's original model paper; the cut-flow and inertia results are proved
inside this package and are not attributed to that source.
