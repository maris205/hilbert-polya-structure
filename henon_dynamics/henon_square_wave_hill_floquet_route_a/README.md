# HCS-C262 — two-step Hill Floquet--Jordan atlas

This package closes the complete stability geometry of the periodic
two-segment Hill oscillator `y''+k(t)y=0`, allowing positive, zero, or negative
segment coefficients and zero-duration boundary faces.  Entire segment
functions give an exact `SL(2,R)` monodromy, discriminant, multiplier and
Chebyshev iterate law.  The parabolic boundary is split correctly between
`M=+/-I` and nontrivial Jordan growth.

The executable receipt contains 900 all-sign transfer rows and six exact
identity/Jordan/hyperbolic witnesses.  A producer-independent power-series
checker, SymPy reconstruction, byte replay, and repaired-hash mutations are
release gates.  Finite rows validate formulas; the continuum classification
is proof-driven.

No arithmetic origin, target orbit census, Euler factor, root number,
automorphy object, target determinant, Hilbert--Pólya operator, or Route-B
input is claimed.  The final paper is `paper/main.pdf`.
