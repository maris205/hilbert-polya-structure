# Paper plan

## Thesis

The Brown--Diaconis chamber walk is an unusually complete finite dynamical
system: its entire spectrum, operator determinant, stationary sampler, mixing
bound, and reducible boundary are available uniformly for every finite real
hyperplane arrangement.  Precisely because that structure is so complete, it
provides a clean Route-A falsification: formal operator structure alone does not
create target arithmetic semantics.

## Final organization

1. Define sign-vector face products and the chamber Markov operator.
2. State the source-owned spectrum theorem and derive the finite operator
   identities.
3. state the separation criterion, exact sampler, coupling bound, and the strict
   SST terminology boundary.
4. classify the nonseparating stationary simplex and delimit the oriented-
   matroid extension.
5. report the independent finite regression census.
6. apply each Route-A gate and record the exact rejection tuple.
