# Code

- `c254_monod_producer.py` emits 18 exact positive-parameter receipts and five boundary contracts.
- `c254_monod_checker.py` independently reconstructs every threshold, equilibrium, spectrum and invariant identity.
- `c254_monod_sympy_crosscheck.py` derives the reduction and separated laws from fresh symbols.
- `c254_monod_replay.py` compares two producer runs byte for byte with the release.
- `c254_monod_mutation.py` rehashes and rejects more than twenty semantic corruptions.
- `c254_release_manifest.py` closes all executable, PDF, font, scope and content-addressing gates.

Run from the package root with Python 3.  No random seed or target arithmetic
data is used.
