## Uniform release gates

### G0 -- independent paper ownership

Every package records its literature theorem owners and nearest workspace
collisions.  Workspace `NEW` is source-local bookkeeping, never a priority
claim.  The five papers must retain different mathematical owners and may not
refer to one another as installments.

### G1 -- analytic completeness

Every all-level, all-prime, all-flux, arbitrary-mean, all-finite-size,
if-and-only-if, full-spectrum, or sharp-rate headline must be proved under
explicit hypotheses.  Finite evidence audits identities and conventions; it
does not establish an unbounded theorem by sampling.

### G2 -- independent executable evidence

Each package has a canonical producer, a checker importing no producer code,
a separate symbolic lane, isolated two-directory byte replay, repaired-hash
hostile mutations, and smoke tests.  Every executable refuses optimized
Python so assertions cannot silently disappear.

### G3 -- strict serialization and frozen evaluator

JSON rejects duplicate keys and nonfinite constants.  YAML rejects duplicate
or non-string keys, anchors, aliases, merges, implicit dates, unknown fields,
and type substitutions.  Candidate ID, full 40-character baseline, epoch,
evaluator digest, strict tuple, Route-B lock, obstruction ID, and scope flags
are invariant.

### G4 -- hostile mathematics

Tests attack the Kummer intersection character and restriction kernels; LPS
projective gauges, arithmetic chambers, and determinant exponents; magnetic
flux orientation, zero-field metric slope, Landau shifts, degeneracy and
revival phases; CLM Hilbert signs, mean strata, arccot branch and degenerate
zeros; and Dyson covariance, Vandermonde orientation, energy shifts,
partition labels and gap normalization.

### G5 -- substantive deterministic manuscripts

Every package retains three mathematically distinct paper rounds from one
conditional LaTeX source.  Each round is built twice in fresh directories
with two LuaLaTeX passes at the frozen epoch.  Bytes must agree, settled logs
must be warning-free, all fonts embedded and subset, extracted text clean,
and every page rasterizable.  `main.pdf` must equal Round 2.

### G6 -- exact content closure

Each package has one self-excluding content-addressed manifest and an exact
payload/physical-file ledger.  The release program reruns all evidence lanes,
PDF audits, forbidden-claim checks, evaluator locks, optimized-mode refusals,
and membership checks while rejecting build sidecars.

### G7 -- adversarial cross-review and integration

Authors exchange packages.  Every mathematical blocker and release mismatch
is repaired and reviewed again.  Integration runs all five release gates
from the final bytes, updates the batch report and both global registries,
stages only C374--C378 and their global index entries, synchronizes with
origin, commits and pushes, verifies `HEAD==origin/main`, and stops for the
next user checkpoint.
