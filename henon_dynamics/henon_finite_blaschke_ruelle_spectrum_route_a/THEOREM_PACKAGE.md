# Theorem package

T1. Expansion bounds `2/(1+a)<=psi'<=2/(1-a)`; all circle fixed counts `2^n-1`; primitive Mobius inversion; signed/oriented repetition and stability ledger. Only 0 and infinity are off-circle periodic points.

T2. An explicit annular extension factors the angular Perron operator through a trace-class Hardy restriction. Invariant positive and negative Laurent sections give spectrum 1 simple, `(-a)^k` twice for each k>=1, and zero.

T3. `D_a=(1-u) product_(k>=1)(1-(-a)^k u)^2`, entire; `Tr P_a^n=(1+(-a)^n)/(1-(-a)^n)`. A separate rational index proof identifies the weighted periodic trace and the primitive product on |u|<1.

T4. Uniform log-tail `2R a^(N+1)/((1-a)(1-Ra^(N+1)))`, exact inclusive source root count, locally uniform a->0 limit. At a=0 Perron is not rank one. At a=1 the cancelled rotation is noncompact and even fixed sets are infinite.

See the full proof for quantifiers and boundaries. These are source results, not target Route-A success.
