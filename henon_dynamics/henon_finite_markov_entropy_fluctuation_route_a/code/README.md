- `c361_markov_entropy_producer.py` emits canonical exact evidence from frozen rational rate panels.
- `c361_markov_entropy_checker.py` independently reconstructs every ledger and owns the full JSON/YAML schema.

- `c361_markov_entropy_mutation.py` attacks hashes, schemas, nested rows, coordinates, evaluation semantics, and optimized mode.
- `c361_release_manifest.py` closes the 27-payload release, deterministic PDF builds, fonts, text, rasterization, and sidecars.
