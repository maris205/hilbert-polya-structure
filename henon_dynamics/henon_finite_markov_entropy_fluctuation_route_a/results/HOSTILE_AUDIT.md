# Hostile audit

The suite changes identity, date, epoch, source commit, scope, evaluator authority/hash, YAML path, model, theorem contract, collision boundary, nonclaims, sources, Route-A tuple/verdict, Route-B lock, scope flags, panels, trees, edges, cycles, tilted coefficients, path ledgers, boundary rows, and count ledgers. Targeted cases reverse the RN derivative, replace the \(1-\lambda\) transpose partner, and corrupt total, medium, and endpoint path ratios independently. Payload and section hashes are repaired after semantic attacks.

It separately attacks stale payload hashes, duplicate and nonfinite JSON, and YAML duplicate keys, merge keys, non-string keys, anchors/aliases, implicit timestamps, unknown fields, scalar types, evaluator authority, evidence status, and artifact paths. All 53 attacks are rejected, including 40 repaired-payload cases. This establishes semantic ownership beyond digest consistency; it does not enlarge the mathematical theorem.
