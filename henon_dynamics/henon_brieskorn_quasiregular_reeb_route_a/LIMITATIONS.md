# Limitations

- Quasiregularity creates an uncountable principal family. The three
  exceptional circles do not make the entire orbit set discrete.
- The package computes fixed strata and elementary transverse indices, not
  contact homology, symplectic homology, or Floer differentials.
- CZ and RS values depend on trivialization. Only the two explicitly declared
  conventions are covered.
- The finite receipt checks integer times within one common period. The
  analytic support theorem handles arbitrary real time.
- The evidence cutoff (q\le101) tests code and formulas; it cannot establish
  a theorem for unbounded weights.
- A contact distribution and symplectic return map provide only a formal
  quantization hint. No natural same-clock self-adjoint quantization is built.
- The integer exponents are not assigned rational-prime semantics.
