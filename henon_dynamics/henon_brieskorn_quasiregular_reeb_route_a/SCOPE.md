# Scope

Literal scope: `NO_BAD_EULER_OR_ROOT_NUMBER`.

The object is the source-local contact flow on (Sigma(2,p,q)). Intrinsic
integer weights, lcm periods, isotropy orders, and indices justify only
`A0_WEAK_ARITHMETIC_RELATION`. Three exceptional orbit circles justify only
`A1_WEAK`, because the principal orbit space is two-dimensional.

The package stops before target determinant, analytic target, or operator
bridges. All target arithmetic-local, Euler-factor, root-number, automorphy,
target-divisor, target-functional-equation, target-zero, Hilbert--Pólya, and
Route-B flags are false in both YAML and JSON.

The route result is

```text
(A0_WEAK_ARITHMETIC_RELATION,A1_WEAK,A2_FAIL,A3_FAIL,A4_FORMAL_HINT)
ROUTE_A_EXPLORATORY
```
