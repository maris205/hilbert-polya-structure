## 两类有用的精确反例

对特征 3 的 `H(x,y)=(y,y^3+y^2-x)`，令
`N_n = # {z : H^n(z)=Frob_3^n(z)}`（代数闭包上的仿射几何点）。
所得 `N_1=6, N_2=54, N_3=378`；由头两项猜的
`2*3^(2n-1)` 在第三项给出 486，已经失败。特征 2、`q=4,m=3`
的二周期也给出 176，而不是对应常密度猜测的 192。
协调者用反向变量序和 F5B 算法独立核对这两个失败例，见
[实际命令与边界](ROOT_INDEPENDENT_CHECK.md)。

对复数域的 `H(x,y)=(y,-x+y+1/y^2)`，三周期有 9 个不同仿射点，
但相应循环理想长度为 18：三个原固定点在三次迭代下各贡献重数 4，
另六个点简单。这个差别阻止直接把带局部交数的迹式当成普通点数。
