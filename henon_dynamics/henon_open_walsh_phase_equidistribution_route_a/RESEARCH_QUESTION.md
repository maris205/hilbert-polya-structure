# C163 research question

For the frozen open Walsh gate of C148/C153/C158, let
`C_k=B_k^k=A^(tensor k)` be the exact `k`-tick full-cycle map.  If every
nonzero eigenvalue is sampled with algebraic-multiplicity weight, does its
unit phase have a source-native growing-`k` limit?  Can that limit be coupled
to C158's central-limit log-modulus fluctuation without discarding either
coordinate?

## Hard progress gate

The paper is admissible only if it proves, for every `k` and without a
finite-table inference:

1. an exact Fourier formula for the full-cycle phase measure;
2. an unconditional classification of the frozen phase ratio as torsion or
   non-torsion;
3. the resulting phase limit and a joint phase/log-modulus theorem.

A merely conditional phase theorem or a finite phase plot triggers a pivot
to a different natural open quantum map.  The frozen gate clears all three
requirements, so no pivot is used.

The question is source-side only.  It does not ask for a target divisor,
arithmetic data, self-adjoint realization, or Route-B comparison.
