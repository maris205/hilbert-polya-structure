# Paper build

The canonical source is `main.tex`; its default revision is round 2. LuaLaTeX is
run twice with

```bash
SOURCE_DATE_EPOCH=1787788800 FORCE_SOURCE_DATE=1 TZ=UTC \
  lualatex -interaction=nonstopmode -halt-on-error main.tex
```

The archived versions are generated by defining `\CRevisionRound` to 0, 1, or 2
before input. Round 0 contains the global conjugacy, round 1 adds the complete phase
portrait/asymptotic/spectral theorem, and round 2 adds the executable and hostile
scope audit. Thus the revision PDFs are intentionally content-distinct; `main.pdf`
must be byte-identical to `main_round2.pdf`.

Build logs and auxiliary files are audited and then removed from the release payload.
See `COMPILE_REPORT.md` for reproducibility, fonts, page rendering, and hashes.
