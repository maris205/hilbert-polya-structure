\begin{abstract}
We make the scalar Coulomb oscillator unambiguous at zero velocity by freezing
the maximal-monotone Sign graph together with a viability rule.  For
\(\dot x=v\), \(\dot v=-\omega^2x-c\xi\), the static interval is
\(|x|\le a_f=c/\omega^2\).  Each slip branch is a shifted harmonic
oscillator, giving \(\dot E=-c|v|\), an exact rest half-cycle map, an integer
finite-capture formula for \(c>0\), and closed first-turn phases for arbitrary signed
velocity.  The \(c=0\) harmonic face is separated because it has no capture.
This is a source-local nonsmooth-mechanics theorem: it supplies no arithmetic
owner, target determinant, or Hilbert--Pólya claim.
\end{abstract}

\section{Inclusion and selection law}
Write
\begin{equation}
 \dot x=v,\qquad \dot v=-\omega^2x-c\xi,
 \qquad \xi\in\operatorname{Sign}(v),\quad \omega>0,\ c\ge0, \tag{1}
\end{equation}
where \(\operatorname{Sign}(0)=[-1,1]\).  Put
\(a_f=c/\omega^2\).  At \(v=0\), the selected viability law sticks exactly
when \(|x|\le a_f\); an exterior rest releases inward.  This convention is
part of the model and removes the otherwise ambiguous zero-velocity branch.

\begin{theorem}[Global trajectory and energy]
The selected maximal-monotone trajectory exists uniquely for all forward
times.  Backward uniqueness is not asserted after capture into the sticking
set.  On every slip interval,
\[
 E=\tfrac12(v^2+\omega^2x^2),\qquad \dot E=-c|v|, \tag{2}
\]
while on a sticking interval \(\dot E=0\).
\end{theorem}
\begin{proof}
For \(v>0\), (1) is the smooth equation
\(\ddot x+\omega^2x+c=0\); for \(v<0\) it is
\(\ddot x+\omega^2x-c=0\).  The Sign graph is maximal monotone, and the
viability selection keeps a rest in the closed static interval.  Standard
one-dimensional maximal-monotone uniqueness then concatenates the smooth
slip arcs and the sticking intervals without a Zeno ambiguity.  Multiplying
the slip equation by \(v\) gives (2).
\end{proof}

\section{Rest starts and exact capture}
Assume \(c>0\).  For \(x(0)=A>a_f\), \(v(0)=0\), the first motion has \(v<0\), center
\(+a_f\), and
\begin{equation}
 x(t)=a_f+(A-a_f)\cos(\omega t),\qquad x_1=2a_f-A. \tag{3}
\end{equation}
If \(A_k\) is the signed turning point after the \(k\)-th complete moving
half-cycle, then
\begin{equation}
 A_k=(-1)^k(A-2ka_f),\qquad |A_{k+1}|=|A_k|-2a_f. \tag{4}
\end{equation}
Consequently the exact number of moving half-cycles for \(A>a_f\) is
\begin{equation}
 n=\left\lceil\frac{A-a_f}{2a_f}\right\rceil, \tag{5}
\end{equation}
and the stopping turn \(A_n\) lies in \([-a_f,a_f]\).  A rest already in
that interval has \(n=0\).  Negative rests follow by reflection.

\begin{proposition}[Work check]
The first-turn energy drop from a positive rest is
\(E(A,0)-E(2a_f-A,0)=c\,|A-(2a_f-A)|\), exactly the friction work.
\end{proposition}

\section{Arbitrary velocity: a partial first arc}
Assume \(c>0\).  If \(v_0>0\), the first branch has center \(-a_f\), radius
\[
 R=\sqrt{(x_0+a_f)^2+(v_0/\omega)^2},
\]
phase \(\theta_0=\operatorname{atan2}(-v_0/\omega,x_0+a_f)\), first-turn
time \(\tau_0=-\theta_0/\omega\), and next turn \(X_1=-a_f+R\).  If
\(|X_1|>a_f\), the remaining complete half-cycle count is
\[
 r=\left\lceil\frac{|X_1|-a_f}{2a_f}\right\rceil,
\qquad \tau_{\rm stop}=\tau_0+r\pi/\omega. \tag{6}
\]
If \(|X_1|\le a_f\), the first arc itself stops in the static interval.

For \(v_0<0\), replace the center by \(+a_f\), use
\[
 R=\sqrt{(x_0-a_f)^2+(v_0/\omega)^2},\quad
 \theta_0=\operatorname{atan2}(-v_0/\omega,x_0-a_f),
\]
with first-turn time \((\pi-\theta_0)/\omega\) and next turn
\(X_1=a_f-R\).  The same ceiling rule applies.  The first segment here is a
partial slip arc, not a complete half-cycle; only \(r\) is an integer count of
later complete half-cycles.  At an exterior rest, the positive side has center
\(+a_f\), phase zero, and time \(\pi/\omega\); the negative side has center
\(-a_f\), phase \(\pi\), and the same time.
