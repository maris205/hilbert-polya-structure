# C314 executable lanes

- `c314_angenent_producer.py`: deterministic 90-decimal evidence.
- `c314_angenent_checker.py`: independent strict JSON/YAML, analytic and
  quadrature reconstruction; it imports no producer code and locks both
  raw evaluation bytes and the canonical full-document YAML semantics.
- `c314_angenent_sympy_crosscheck.py`: symbolic identities.
- `c314_angenent_replay.py`: isolated two-run byte replay.
- `c314_angenent_mutation.py`: repaired-hash, stale-hash, parser/YAML and
  optimized-Python attacks.
- `c314_release_manifest.py`: exact ledger, PDF and deterministic-build gate.
