# C148 exact validation plan

## Claim/evidence matrix

| Claim | Infinite proof | Exact sentinel | Independent failure test |
|---|---|---|---|
| contraction and one-step rank | partial-isometry Gram matrices | `k=1,...,5` rank ledger | direct surviving-column reconstruction |
| `B_k^k=A^(tensor k)` | pure-tensor tracking | all 363 basis sources through `k=5` | checker action versus tensor action |
| all-period gcd trace | factor-permutation cycle identity | 60 direct sparse traces | literal SymPy matrices for `k=1,2` |
| exact secular polynomials | Newton identities plus zero multiplicity | 67 field coefficients for `k=1,...,5` | SymPy recurrence and direct low-`k` matrices |
| complex primitive product | rooted-walk grouping | 510 rooted paths and 71 primitive cycles | independent path enumeration |
| defect geometry and controls | exact Gram/projection algebra | closed/order/hole receipts | matrix-level SymPy reconstruction |

## Execution

1. Freeze the DFT sign, projector, gate order, shift direction, clock, basis,
   and determinant convention.
2. Generate canonical exact JSON and record its payload hash.
3. Run the standard-library checker with no producer import.
4. Run the separate SymPy reconstruction.
5. Replay the producer into a temporary directory and demand byte identity.
6. Repair the payload hash after every semantic mutation, plus test one stale
   hash, and demand rejection.
7. Compile round 0, perform two real internal theorem/scope/presentation audits,
   implement each repair, and retain all PDFs.
8. Perform two isolated fixed-epoch final builds, font and warning scans, and
   visual inspection of every page.
9. Generate the self-excluded manifest only when exactly 27 payload files
   exist.

## Stop rules

Stop or downgrade if the shift convention fails a direct matrix, if
`rank(B_k)` is conflated with `rank(B_k^k)`, if the gcd exponent fails, if an
order control is advertised as geometry-sensitive despite isospectrality, if
any repaired-hash mutant survives, or if a target/arithmetic/Route-B claim
enters the package.
