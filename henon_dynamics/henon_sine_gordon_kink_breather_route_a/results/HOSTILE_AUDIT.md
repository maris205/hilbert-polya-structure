# Hostile-audit checklist

The release gate rejects every altered kink, breather, Hessian, Lorentz, or
boundary cell; theorem and clock edits; route and scope promotion; citation
title/venue/DOI edits (including the wrong issue 3); unknown nested/top-level
keys; stale payload hashes; row-count and missing-row mutations.  Semantic
edits are rehashed before checking, so rejection is not merely a digest test.
The final mutation command reports `PASS 41/41` with every generated attack
caught.
