## Claim boundary

The sources establish lineage, not workspace priority.  This package
rederives the frozen normalization, Krawtchouk basis, endpoint propagator,
exterior-power spectrum, mirror sign, and revival faces.  It does not claim
that these facts are new to the literature.  The evidence JSON is a
regression certificate and not a substitute for either source reading or
the analytic proof.

No source is used to support an arithmetic Euler factor, root number,
automorphy statement, target divisor/counting law, target functional
equation, target-zero match, Hilbert--Pólya operator, or Route-B invocation.
