# Experiment plan

1. Hash-bind canonical C88 evidence and manifest, plus C89 evidence for the independent moment rebound.
2. Decode each 65,536-bit C88 target indicator and count pivotal boundary edges at ranks 1--16; complete each edge with `(t-1)!(16-t)!` permutations.
3. Form exact integer and rational polynomial coefficients, support/degree/gcd spectrum, and derivatives through order six.
4. Recover ordinary moments with Stirling numbers of the second kind and compare every order to C89.
5. Rebuild the receipt independently, run SymPy polynomial checks, clean replay, and hostile mutations.
