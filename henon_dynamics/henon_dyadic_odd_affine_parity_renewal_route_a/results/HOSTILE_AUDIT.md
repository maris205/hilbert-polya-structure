This is an internal artifact-bounded audit, not an external peer review and not a publication-readiness or novelty certificate.

## Mathematical hostile tests / 数学敌对测试

1. **Clock erasure.** Treating return symbol \(k\) as one original tick would give the wrong object. The roof \(r(k)=k\) is explicit, and the zero orbit is restored separately.
2. **Exceptional-set understatement.** The exceptional set is not merely \(-b/a\); it is the countable set of odd points with eventually-zero parity strings. The theorem states both the full set and its Haar-null status.
3. **Infinite fixed-set laundering.** The countable-alphabet return map has infinitely many time-one fixed points. No finite or regularized Artin–Mazur substitute is silently inserted.
4. **Parameter fitting.** All odd \(a,b\) are theorem parameters. The 36-pair grid is frozen and only tests regression; no target data selects parameters.
5. **Stability sign/valuation.** The exact identity uses \(|1-a^{s_n}/2^n|_2=2^n\), since \(2^n-a^{s_n}\) is odd. The reciprocal weight is \(2^{-n}\), not \(2^n\).
6. **Operator overreach.** Haar composition is a proper isometry, not a unitary on the frozen one-sided phase space. Its inverse-limit unitarization changes phase space.
7. **Collatz leakage.** The \((3,1)\) cycle through \(1/5\) is a \(\mathbb Z_2\) cycle outside the positive integers; no positive-integer conjecture claim follows.
8. **Prior-work laundering.** The parity conjugacy is explicitly attributed to Bernstein–Lagarias and excluded from C174 novelty claims.
