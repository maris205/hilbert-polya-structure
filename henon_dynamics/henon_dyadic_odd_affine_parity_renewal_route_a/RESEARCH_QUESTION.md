# Research question / 研究问题

## English

For arbitrary odd integers \(a,b\), what information survives when the odd-affine parity map on \(\mathbb Z_2\) is accelerated to first returns to the odd coset? In particular:

1. Can one classify the exceptional set and obtain a complete return-time symbolic model?
2. Can the original branch clock be reconstructed exactly from the accelerated system?
3. Do unweighted fixed-point counts or reciprocal 2-adic derivative weights retain any dependence on \(a,b\)?
4. Does the resulting orbit or Koopman structure satisfy Route-A arithmetic and operator gates?

The source object, parameter domain, clock, Haar measure, and both zeta normalizations are frozen before validation. The hard gate is not whether an elementary rational zeta can be written; it is whether the renewal construction preserves parameter-specific arithmetic information.

## 中文

对任意奇整数 \(a,b\)，把 \(\mathbb Z_2\) 上的奇仿射奇偶映射加速到奇数陪集的首返后，究竟还能保留哪些信息？核心问题是：

1. 能否严格分类异常集并给出完整首返符号模型？
2. 能否从加速系统精确恢复原始分支时钟？
3. 无权不动点计数与二进导数稳定性权重是否保留任何 \(a,b\) 依赖？
4. 相应的轨道与 Koopman 结构能否通过 Route-A 的算术和算子关卡？

在验证前冻结源对象、参数域、时钟、Haar 测度和两种 zeta 归一化。硬门槛不是“能否写出一个初等有理 zeta”，而是 renewal 构造是否保留参数特异的算术信息。

## Falsifiable outcomes / 可证伪结局

- A parameter-sensitive return or stability law would preserve a possible source discriminator.
- Exact parameter blindness across all odd \(a,b\) is a decisive negative result for arithmetic specificity.
- A0 failure forces overall Route-A rejection even if A1 has a complete primitive-orbit theorem.
- 对所有奇参数的严格盲性是算术特异性的决定性反证；A0 失败时，即使 A1 有完整周期轨道定理，整体仍必须拒绝。
