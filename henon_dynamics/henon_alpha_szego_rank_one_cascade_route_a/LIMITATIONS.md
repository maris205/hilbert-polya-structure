# Limitations
The threshold is classical (Xu); the model is classical (Gerard--Grellier). Repository completeness does not establish novelty.

Rank one is an invariant manifold with infinitely many Fourier modes, but not all Hardy space. No higher-rank or generic primitive census is claimed.

High-precision ODEs and finite sums are numerical regression, not interval arithmetic or proof substitutes. No target-zero experiment is performed.

The auxiliary Fredholm polynomial misses even bounded versus cascading dynamics. Route B remains disabled.
