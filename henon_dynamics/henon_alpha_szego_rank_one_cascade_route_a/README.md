# C386: alpha-Szego rank-one cascade
The complete rank-one nonlinear flow has a sharp energy-defect dichotomy. At positive alpha, zero defect is exactly the noncompact cascade level, with an explicit two-sided sech-squared radial law. Off that level trajectories are compact. Every alpha <= 0 and every rank-zero boundary is classified separately.

The increment within this repository is a turning-point-safe proof, an exact Sobolev growth exponent, quantitative off-threshold control, and an auxiliary-determinant blindness theorem. Xu's threshold and Gerard--Grellier's model are credited; this is not a new-discovery claim.
