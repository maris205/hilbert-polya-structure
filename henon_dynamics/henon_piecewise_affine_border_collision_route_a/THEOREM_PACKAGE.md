# Theorem package — C112

**Finite affine-orbit proposition.** For every binary word `w` of length
`1 <= n <= 8`, the affine return of the frozen branch maps has a unique
fixed point away from `x = 0`, and direct iteration verifies the branch
itinerary. Primitive words are quotiented only by cyclic rotation.

**Finite transfer identity.** With destination weights
`rho_0 = 1/2` and `rho_1 = 2/3`, the 4-by-4 block transfer matrix reproduces
the weighted trace prefix and has

```text
det(I - z A) = (49 z^2 + 210 z + 36) / 36.
```

These are finite exact statements. They do not imply a complete geometric
Markov theorem or analytic nuclearity.
