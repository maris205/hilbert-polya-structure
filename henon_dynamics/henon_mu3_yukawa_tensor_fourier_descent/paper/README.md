# C61 manuscript

`main.tex` is the post-machine manuscript for HCS-C61.  It is deliberately
additive: the 13 target-lock Markdown files and the live Route remain frozen
inputs to the source-stable producer/checker.  The manuscript reports the
official clean refresh and mandatory replay, contains the complete 36-row
tensor atlas, 18 Q types, 8 P types, mixed 160/12/8 dictionary, Fourier
diamond, global arithmetic, both ToM branches, and the explicit scope
firewall.

Build from this directory with:

```text
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

No paper claim promotes the certificate to an analytic, automorphic, RH, or
Hilbert--Polya statement.  Both local branches are retained.
