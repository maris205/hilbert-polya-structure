# Source and scope audit

## Source model

Every vector, speed, cone, and time is generated by the declared Euclidean
control system \(\dot x=W+u\), \(|u|\le c\). Rational finite test inputs are
source-side regression parameters. They are not rational-prime labels or
target arithmetic coefficients.

## Owner attribution

- E. Zermelo, “Über das Navigationsproblem bei ruhender oder veränderlicher
  Windverteilung,” DOI `10.1002/zamm.19310110205`.
- D. Bao, C. Robles, and Z. Shen, navigation/Randers geometric context, DOI
  `10.4310/jdg/1098137838`.

These sources establish lineage only. No novelty or historical priority is
claimed for the classical problem or the constant-drift solution.

## Scope firewall

Frozen scope: `NO_BAD_EULER_OR_ROOT_NUMBER`. The package imports no target
arithmetic local datum, Euler factor, root number, automorphy claim, divisor
law, functional equation, target zero set, or Hilbert--Pólya operator. The
HJB equation is a source control identity, not an operator bridge. Route B is
not invoked.

## Collision boundary

C222 is a second-order double-integrator bang--bang system. C270 concerns
Heisenberg sub-Riemannian control and noncommutative horizontal geometry.
C268 is an uncontrolled constant-electromagnetic-field Lorentz flow. C305 is
instead first-order controlled, translation-invariant Euclidean navigation
across all wind chambers and all finite dimensions.
