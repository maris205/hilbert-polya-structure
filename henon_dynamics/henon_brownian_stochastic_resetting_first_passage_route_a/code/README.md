# C214 code

`c214_brownian_producer.py` emits the canonical JSON certificate.  The checker
does not import it: it recursively locks every schema key and recomputes the
heat-kernel/renewal quantities with independent high-precision quadrature.
`c214_brownian_sympy_crosscheck.py` verifies symbolic PDE, renewal, transform,
moment, and optimum identities.  `c214_brownian_replay.py` checks clean-process
byte reproducibility; `c214_brownian_mutation.py` attacks repaired hashes,
stale hashes, semantic fields, and unknown keys.  The release script closes
the file ledger, three-PDF distinction, text/font checks, and sidecar firewall.

All scripts use only source-local rational sentinels.  They never read prime or
zero data and never call a target-fitting routine.
