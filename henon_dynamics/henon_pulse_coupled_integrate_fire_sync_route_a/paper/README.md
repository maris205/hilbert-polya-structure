temporary trees under `SOURCE_DATE_EPOCH=1788048000`.  The release keeps three
content-distinct PDFs (`main_round0_original.pdf`, `main_round1.pdf`, and
`main_round2.pdf`); `main.pdf` is byte-identical to round 2.  The manuscript
states the exact transformed event map, avalanche closure, pairwise cluster
coarsening, synchronized primitive cycle, finite-probe boundary, and strict
Route-A/scope limitations.  It does not claim an exhaustive continuous-state
census or arithmetic target construction.
