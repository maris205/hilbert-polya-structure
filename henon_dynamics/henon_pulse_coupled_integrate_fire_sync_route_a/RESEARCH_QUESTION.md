# Research question

Can an all-to-all excitatory integrate-and-fire network with a strictly
concave rise law be represented by an exact rational event certificate that
separates cluster coarsening and the synchronized primitive cycle from any
unproved global synchrony claim?

At the frozen (r,epsilon,N) grid the answer is yes: transformed event maps,
avalanche closure, equality partitions, and the all-equal one-event return are
computed with `Fraction` arithmetic and independently recomputed.  The result
is finite source-local evidence, while almost-everywhere synchrony remains a
separately cited theorem.
