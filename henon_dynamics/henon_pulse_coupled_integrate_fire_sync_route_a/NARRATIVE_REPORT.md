# Narrative report

The exponential coordinate (u=e^{-aphi}) removes the transcendental part
of free flight from the event map.  A threshold event is simply the common
rescaling that sends the smallest coordinate to (r=e^{-a}).  In membrane
coordinates a pulse adds (epsilon); in (u) it subtracts the rational amount
(c=(1-r)epsilon), with clipping at (r).  Thus rational (r,epsilon) and
rational event states remain rational through an entire avalanche.

Identical oscillators receive identical free rescaling and identical pulses.
An equal-coordinate block therefore stays equal; when one member reaches the
threshold, the whole block reaches it, and reset/avalanche closure keeps the
block together.  The equality partition can coarsen when different blocks
are recruited into the same avalanche, but cannot refine.  The all-equal state
returns after one simultaneous (N)-fold firing, giving the primitive source
event word ([N]).

The receipt records 441 deterministic probes, their exact avalanche
generations, cluster partitions, and any detected return period.  The
Mirollo--Strogatz almost-everywhere synchrony theorem is a literature result
under its own hypotheses; this package reports it as context and does not
claim a complete continuous-state cell census.  Ties and singular pulse/rise
limits are explicit boundary cases.

No arithmetic clock or target determinant is present.  Consequently A0, A2,
and A3 fail; A1 is the finite analytic event certificate and A4 is only a
formal generator/lift hint.
