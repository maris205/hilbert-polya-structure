# Narrative report

The moving position and the lamp configuration initially make the chain look
like a single \(n2^n\)-dimensional object.  Fair rerandomization is the decisive
simplification.  In a Walsh lamp character indexed by \(A\subseteq C_n\), a
switch at position \(x\) either preserves the character when \(x\notin A\), or
averages it to zero when \(x\in A\).  Each switch is therefore the coordinate
projection \(D_A\), and the entire chain becomes \(D_AQ_nD_A\) block by block.

Deleting a nonempty subset of a cycle leaves disjoint path runs.  The killed
lazy path has diagonal \(1/2\), off-diagonal \(1/4\), and the discrete-sine
spectrum
\[
\frac12+\frac12\cos\!\left(\frac{\pi j}{\ell+1}\right).
\]
This gives more than a gap estimate: it gives every eigenvalue, zero
multiplicity, eigenvector and characteristic-polynomial factor.  The slowest
nonconstant mode deletes one vertex, leaving a run of length \(n-1\), so its
multiplicity is the number \(n\) of possible deleted vertices.

The result is structurally different from independent hypercube bit flips,
random transpositions, chamber walks, and Wilson cycle popping.  Its finite
self-adjoint source operator remains only a Route-A formal hint; no arithmetic
interpretation is supplied or implied.
