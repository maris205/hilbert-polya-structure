# Exact evidence plan

The evidence generator enumerates all lamp-character supports for
\(1\le n\le10\): exactly \(2^{11}-2=2046\) Fourier blocks.  For every block it
records the deleted set, cyclic run lengths, zero multiplicity and monic
rational characteristic polynomial.  Cycle and killed-path polynomials are
generated by independent Chebyshev and continuant recurrences.

For \(1\le n\le6\), a second lane constructs the full
\(n2^n\)-state transition kernel with exact rational probabilities and checks
row sums, symmetry, and the first two spectral traces against the block ledger.

The checker does not import the producer.  It reconstructs the coordinate
sets and all quantities from its own implementations.  A separate SymPy lane
checks symbolic continuants, full matrices through \(n=5\), eigenvector
residuals, and the exceptional cycles.  Byte replay runs the producer twice in
separate temporary directories.  Hostile tests repair outer hashes after
semantic corruption, attack strict JSON/YAML parsing, truncate coordinates,
and include one stale-hash control.

The finite range is a regression receipt only; the proof in
`THEOREM_PACKAGE.md` bears the universal quantifier.
