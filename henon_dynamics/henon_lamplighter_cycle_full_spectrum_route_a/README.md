# HCS-C341: Lamplighter cycle full spectrum

This independent package freezes a fair switch--walk--switch chain on the
finite cycle and proves its complete spectrum.  Walsh transformation in the
lamp variables turns the transition operator into every vertex-deleted lazy
cycle block; those blocks split into killed paths with explicit sine spectra.

The theorem, proof, finite regression evidence, independent checker, symbolic
lane, byte replay, hostile mutations, three manuscript revisions, and release
manifest are all local to this directory.  The finite computation is a
convention receipt and is not used as proof of the all-\(n\) result.

Route-A status is exploratory only: the source-side self-adjoint Markov
operator earns at most `A4_FORMAL_HINT`.  It supplies no arithmetic local data,
target Euler factor, root number, target zero match, or Route-B invocation.

Run the final gate with:

```bash
python code/c341_release_manifest.py
```
