# HCS-C161 finite cyclic quadratic Birkhoff package

This package proves an every-iterate odd-modulus quadratic Gauss evaluation for
finite cyclic rotations, an exact prime zero-level discriminant law, and a
same-clock finite-unitary identity.  It records why the initially proposed
Heisenberg continuation was rejected at the proof gate.

Run the producer, independent checker, SymPy crosscheck, replay, mutation test,
and release manifest from the repository root.  The release scope is
`NO_BAD_EULER_OR_ROOT_NUMBER`; `route_b_invocation_allowed=false`.
