# C198 compile report

The final manuscript is built with LuaLaTeX under a fixed epoch.  Release
closure verifies three content-distinct rounds, `main.pdf == round2`, two fresh
byte-identical builds, embedded fonts, extractable theorem/safety text, a log
without warnings or bad boxes, and visual inspection of every page.

Exact final hashes, byte size and page count are recorded by the release
manifest to avoid a self-referential PDF rebuild cycle.
