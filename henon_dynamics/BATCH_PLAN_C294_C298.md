## Uniform release gates

### G0 -- collision and ownership

Every paper identifies its direct literature owner and nearest workspace
collision.  Workspace novelty is not literature priority.  The five systems
must retain distinct state spaces and proof mechanisms.

### G1 -- theorem proof and hostile repair

Each all-parameter, all-period, or all-event headline is proved analytically.
Finite enumeration is only regression evidence.  A failed statement is
weakened or replaced before release: in particular, C296 must state a
rotation-reduced shape theorem because the naive full-circle free quotient
fails already for one translating rod.

### G2 -- independent executable evidence

Every package has a canonical sorted-JSON producer with a self-excluding
payload hash, a checker importing no producer code and reconstructing the
result independently, a separate SymPy lane, two isolated byte-identical
replays, and hostile repaired-hash attacks plus a stale-hash control.

### G3 -- strict serialization and evaluation

JSON loaders recursively reject duplicate keys and non-finite constants.
Evaluation YAML loaders reject duplicate and non-string keys, anchors,
aliases, merges, implicit timestamps, unknown/missing fields, type changes,
tuple changes, scope escalation, and Route-B authorization.  Source commit,
date, epoch, evaluator hash, obstruction ID, scope, tuple, and false claim
flags are locked.

### G4 -- boundary completeness

No-eclipse equality, circles and center crossings, cyclic-cut/global-rotation
cocycles, both exceptional sheets, eigenrays, repeated eigenvalues, nongeneric
Schubert strata, zero states, and singular parameter limits are separate
faces.  No hidden quotient, genericity assumption, or clock normalization may
pass.
