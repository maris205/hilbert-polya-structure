# Code map

- `c292_sticky_producer.py`: exact rational event/PAVA evidence and canonical
  self-excluding payload hash.
- `c292_sticky_checker.py`: strict duplicate-rejecting exact JSON/YAML
  schemas, a canonical evaluation-YAML semantic hash, and an independent
  exhaustive-contiguous-partition/event reconstruction.
- `c292_sticky_sympy_crosscheck.py`: separate symbolic conservation,
  dissipation, isotonic, and weak-balance identities.
- `c292_sticky_replay.py`: two isolated byte-identical evidence productions.
- `c292_sticky_mutation.py`: 66 stale/repaired-hash, raw duplicate, schema,
  cell-grid, exact-type, and evaluation-YAML hostile specimens (45 JSON and
  21 YAML).
- `c292_release_manifest.py`: reruns all gates and six fresh PDF builds before
  writing the exact release ledger.

Use Python 3 with SymPy and PyYAML; the scripts import no package-local
producer module inside the checker.
