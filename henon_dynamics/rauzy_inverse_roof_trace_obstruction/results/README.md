# HCS-C30 results

This directory contains the frozen exact outputs for the inverse-roof and
trace-obstruction round.

- `c30_certificate.json` -- deterministic producer certificate;
- `c30_independent_check.json` -- path-free independent semantic audit;
- `RESULTS.md` -- mathematical findings and scope;
- `VALIDATION_REPORT.md` -- gate-by-gate validation;
- `TEST_REPORT.md` -- regression, mutation, and isolated-run report;
- `MATERIAL_PASSPORTS.md` -- inputs, arithmetic, literature, and AI disclosure;
- `ARTIFACT_HASHES.sha256` -- read-only release manifest.

The JSON artifacts are generated by `code/run_c30.sh --refresh-manifest`; the
default runner recomputes into a temporary directory and verifies them without
rewriting the release.
