used in \Cref{sec:cone}.  It makes the result reproducible without treating
the producer's verdict as a proof oracle.

\subsection{Independent raw-product replay}

For each raw path rotation $e_1\cdots e_n$, reconstruct the symbol matrix by
\[
 \mathsf B(e^\varepsilon)=
 \begin{cases}
 B(e),&\varepsilon=1,\\
 B(e)^{-1},&\varepsilon=-1,
 \end{cases}
\]
where the inverse is computed by exact unimodular elimination.  Form the
later-on-left product
\[
 \mathsf B(e_n)\cdots\mathsf B(e_1).
\]
It must equal $I_4$ for every cyclic rotation.  The $W_{24}$ product is also
reconstructed from the frozen $A,B,C$ matrices before its arrow expansion is
used.  This double replay distinguishes a source identity from a finite-field
or change-of-frame artifact.

\subsection{Phase enumeration and action order}

For $w=e_1\cdots e_n$, define the left rotations
\[
 R_j(w)=e_{j+1}\cdots e_ne_1\cdots e_j,
 \qquad 0\leq j<n.
\]
For each $R_j(w)=a_1\cdots a_n$, perform the following two independent
replays.

\begin{description}[style=nextline,leftmargin=2.9cm]
\item[Length replay.]
Use application sequence $a_1,\dots,a_n$ and set
\[
 P_k=\mathsf B(a_k)^{-\mathsf T}P_{k-1},\qquad P_0=I.
\]

\item[Transfer replay.]
Use application sequence $a_n,\dots,a_1$ and set
\[
 Q_k=\mathsf B(a_{n+1-k})^{\mathsf T}Q_{k-1},\qquad Q_0=I.
\]
\end{description}

The terminal prefix must be $I_4$ in both replays.  For feasibility, collect
the four rows of $I_4$ at step zero and the four rows of every subsequent
prefix, ordered lexicographically by
$(\mathrm{step},\mathrm{coordinate})$.

\subsection{Canonical Farkas descriptor}

Given the ordered row list, apply this deterministic selection rule.

\begin{enumerate}[label=\arabic*.,leftmargin=2em]
\item Choose the first nonzero row $r$ with $r_i\leq0$ for all $i$, if one
  exists.  The machine-readable certificate expands it as
  \begin{equation}
    r+\sum_{i:r_i<0}(-r_i)e_i=0,
    \label{eq:neg-row-expanded}
  \end{equation}
  where the $e_i$ are the step-zero rows.  Every coefficient displayed in
  \eqref{eq:neg-row-expanded} is a positive integer.
\item Otherwise scan supports of size $2,3,4,5$, in lexicographic row order.
  For each support, solve
  \begin{equation}
    \sum_jc_jr_j=0
    \label{eq:null-relation}
  \end{equation}
  by exact rational row reduction.  Accept the first one-dimensional
  nullspace whose generator has all coordinates of one sign; orient it
  positively, clear denominators, and divide by the coefficient gcd.
\end{enumerate}

The support bound five is complete for a minimal positive dependence in
$\mathbb R^4$.  Every accepted descriptor is checked by recomputing the
weighted row sum and applying \Cref{lem:exact-infeasibility}.  Producer and
checker independently reconstruct the matrices, rotations, prefix rows, and
primitive coefficients; the checker does not import producer functions.
