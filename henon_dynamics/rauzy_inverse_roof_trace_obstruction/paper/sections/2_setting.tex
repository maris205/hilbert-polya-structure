\section{Chronology and the three matrix actions}
\label{sec:setting}

\subsection{Source convention}

We work with a finite directed Rauzy-labelled graph.  An oriented token $e$
has source and target $s(e),t(e)$, an integral invertible matrix $B(e)$, and
frozen change-of-frame matrices $S_v$.  A formal inverse token has reversed
endpoints and exact matrix
\[
B(e^{-1})=B(e)^{-1}.
\]
For a path word $w=e_1\cdots e_n$, chronological composition is
\begin{equation}
  B_w=B(e_n)\cdots B(e_1).
  \label{eq:chronology}
\end{equation}
Thus later events multiply on the left.  The fixed-frame cocycle is
\begin{equation}
  g_e=S_{t(e)}^{-1}B(e)S_{s(e)}.
  \label{eq:fixed-frame-edge}
\end{equation}
This is also the definition for inverse tokens.  The following elementary
telescoping identity identifies exactly what the finite-group calculation
knows.

\begin{proposition}[Closed-path frame telescoping]
\label{prop:frame-telescope}
If $w=e_1\cdots e_n$ is a closed mixed path based at $v$, then
\[
  g_w=g_{e_n}\cdots g_{e_1}=S_v^{-1}B_wS_v.
\]
Consequently, for a closed path, $g_w=I$ if and only if $B_w=I$.
\end{proposition}

\begin{proof}
Substitute \eqref{eq:fixed-frame-edge}.  At every intermediate vertex the
adjacent factors cancel because $t(e_k)=s(e_{k+1})$.  Closedness identifies
the two surviving endpoint frames.  Conjugation preserves the identity.
\end{proof}

The closed-path hypothesis is essential.  For an open path the endpoint
frames differ, and $g_w=I$ need not be equivalent to $B_w=I$.

\subsection{Forward lengths}

For Rauzy induction, the source convention for the length coordinate is the
inverse transpose of the incidence matrix.  In the notation of
\citet[Sections~3.1.3--3.3]{AvilaGouezelYoccoz2006}, a legal positive path has
\begin{equation}
  \lambda_k=B(e_k)^{-\mathsf T}\lambda_{k-1}.
  \label{eq:length-action}
\end{equation}
The source positive cone is not optional: a word describes a branch only when
one initial vector has every required prefix in that cone.  A positive token
$a$ uses $B(a)^{-\mathsf T}$, while a formal inverse token $a^{-1}$ uses
\[
B(a^{-1})^{-\mathsf T}=B(a)^{\mathsf T}.
\]
For a chosen cyclic rotation $e_1\cdots e_n$, define
\begin{equation}
 P_0=I,\qquad P_k=B(e_k)^{-\mathsf T}P_{k-1}.
 \label{eq:length-prefix}
\end{equation}
The strict length-cone feasibility question is
\begin{equation}
 \exists x\in\mathbb R_{>0}^4
 \quad\text{such that}\quad
 P_kx\in\mathbb R_{>0}^4\quad(1\leq k\leq n).
 \label{eq:length-feasibility}
\end{equation}
For a closed identity word, $P_n=I$; this endpoint fact says nothing about the
intermediate inequalities.

\subsection{Contravariant transfer branches}

A transfer or inverse-branch convention has the opposite application order.
For the same raw rotation $e_1\cdots e_n$, put
\[
u_1\cdots u_n=e_n\cdots e_1,
\]
and define
\begin{equation}
 Q_0=I,\qquad Q_k=B(u_k)^{\mathsf T}Q_{k-1}.
 \label{eq:transfer-prefix}
\end{equation}
The corresponding strict feasibility gate is
\begin{equation}
 \exists x\in\mathbb R_{>0}^4
 \quad\text{such that}\quad
 Q_kx\in\mathbb R_{>0}^4\quad(1\leq k\leq n).
 \label{eq:transfer-feasibility}
\end{equation}
Equations \eqref{eq:length-prefix} and \eqref{eq:transfer-prefix} must be
tested separately.  Merely transposing each matrix without reversing
chronology tests a third object.

\subsection{Raw covariant homology control}

The experiment also retains the recurrence
\begin{equation}
 H_0=I,\qquad H_k=B(e_k)H_{k-1}.
 \label{eq:homology-prefix}
\end{equation}
This is a raw covariant action on homology or cocycle coordinates.  It is not
the AGY length evolution \eqref{eq:length-action} and is not the transfer
action \eqref{eq:transfer-prefix}.  A positive vector for
\eqref{eq:homology-prefix} is therefore a convention sentinel, not evidence
of a Rauzy-length orbit.

\subsection{The three frozen witnesses}

The source-locked words are
\begin{align}
C_1&=(0t,1b,0t^{-1},0b,3t,0b^{-1}),
\label{eq:C1}\\
C_2&=(4t,6b^{-1},6t,5b,6t^{-1},6b),
\label{eq:C2}
\end{align}
and a length-twenty-four word $W_{24}$ obtained by chronological expansion of
the frozen $A,B,C$ relation.  Exact integer multiplication, performed both in
the raw arrow alphabet and directly in the $A,B,C$ alphabet where applicable,
yields
\begin{equation}
 B_{C_1}=B_{C_2}=B_{W_{24}}=I_4.
 \label{eq:three-identities}
\end{equation}
Equation \eqref{eq:three-identities} is a source-level statement, not a
finite-field accident.  It is nevertheless only a holonomy statement.  A
kernel word of the matrix representation need not be the unit arrow of the
free path groupoid, and an identity endpoint does not certify any positive
prefix domain.
