# C92 experiment plan

1. Rebind the canonical C88 evidence and manifest by SHA-256.
2. Decode each target's 65536-bit hitting indicator.
3. For each label and hitting support, count the permutations for which that
   label is the last pivotal prefix element.
4. Aggregate exact pivotal probabilities, rank and rank-square contributions.
5. Reconstruct the same atlas independently, then run symbolic checks,
   deterministic replay and hostile mutations.
6. Compile the short theorem paper twice in isolated deterministic builds.

The only allowed scope is `NO_BAD_EULER_OR_ROOT_NUMBER`.
