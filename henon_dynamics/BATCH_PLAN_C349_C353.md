## Uniform release gates

### G0 -- ownership and collisions

Each package records primary source owners and nearest workspace mechanisms.
The five owners have different state spaces, evolution laws and proof engines;
`NEW` means only absence of an existing workspace owner.

### G1 -- analytic completeness

All headline all-parameter and asymptotic statements receive analytic proofs.
Finite evidence cannot prove invariant-torus topology, continuum PDE
instability, recurrence of an infinite CTMC, whole-line spectral type, a strong
law, CLT or Poisson limit.

### G2 -- independent evidence

Each package has a canonical exact producer, a checker that imports no
producer code, a separate symbolic lane, isolated two-directory byte replay,
and repaired-hash hostile mutations.  Every executable rejects optimized
Python so scientific assertions remain active.

### G3 -- strict serialization and evaluator lock

JSON rejects duplicate keys and nonfinite constants.  YAML rejects duplicate
or non-string keys, anchors, aliases, merges, implicit dates, unknown fields
and type changes.  Candidate identity, baseline, date/epoch, evaluator digest,
tuple, Route-B lock and every false scope flag are semantic invariants.

### G4 -- hostile mathematical boundaries

Tests attack Uhlenbeck signs and Lax residues; Turing root endpoints and strict
integer counts; Jackson routing transposes, self-routing and output-time
orientation; Dirac factorization signs, ladder indices, thresholds and Jost
phases; and Ewens multiplicities, innovation probabilities, mixed moments and
finite-versus-limit independence.

### G5 -- manuscripts and substantive revisions

Every package retains three PDFs built from one conditional LaTeX source.
Rounds 1 and 2 add mathematical content.  Every round is rebuilt twice in
fresh directories with two LuaLaTeX passes at the fixed epoch; bytes must
match, settled logs must be warning-free, fonts embedded/subset, extracted
text clean, and every page rasterizable.  `main.pdf` equals Round 2.

### G6 -- exact package closure

Every package contains exactly 27 content-addressed payloads plus one
self-excluded manifest.  The release gate reruns evidence, checker, symbolic,
replay, mutation, PDF and membership audits and rejects build sidecars.

### G7 -- cross-review and integration

Authors swap packages for mathematical review.  Every blocker and major issue
is repaired and re-reviewed; useful minor corrections are folded into the
release.  The final integration runs all five release gates twice, checks 135
payloads and 140 physical files, updates global indices, stages only this
round, synchronizes with origin, commits and pushes, verifies
`HEAD==origin/main`, then stops for the user checkpoint before C354.
