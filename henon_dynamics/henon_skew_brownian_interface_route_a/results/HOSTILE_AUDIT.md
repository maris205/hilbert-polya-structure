# Hostile audit

Sixteen adversarial changes are rejected.  They cover a stale payload hash,
candidate/source/epoch/evaluator/scope locks, Route tuple and verdict, Route-B
authorization, a forbidden target flag, symmetric-versus-right local time,
the reversed interface derivative ratio, the Lebesgue reference measure,
kernel density, exit side probability, and occupation mean.

For every semantic mutation except the dedicated stale-hash control, the
outer SHA-256 is repaired before checking.  Passing therefore requires the
independent mathematical and policy checks, not merely hash consistency.

An additional read-only theorem audit found that the resolvent formula was
correct but its proof described the source normalization imprecisely: the
$x$-derivative jump is $-2$, so $-(1/2)$ times the jump produces the unit
delta.  It also found two stale equation-number references and an incomplete
description of the source's correction history.  Round 2 now fixes all three
textual defects, cites the 2011 correction and 2024 second errata, and states
explicitly that no corrected multivariate formula is used.  Independent
stable-ratio normalization and mean checks reconfirmed the occupation law.
