# Paper plan

## Claim hierarchy

1. Freeze symmetric local time and construct the process by excursion signs.
2. Prove the Lebesgue kernel and generator interface condition.
3. Separate reference measures and prove speed-kernel symmetry.
4. Integrate the kernel to the complete resolvent.
5. Solve the harmonic, Helmholtz, and Poisson interface BVPs for all exit
   observables.
6. Derive the generalized arcsine occupation density from stable
   subordinators.
7. Close `p=0,1/2,1`, collision, executable, and Route-A boundaries.

## Figure decision

No empirical figure is needed.  The decisive relationship is an exact table
mapping each observable to its reference measure and interface condition; a
plot would add sampling without strengthening the theorem.

## Revision gates

- Round 0: SDE, kernel, generator, and resolvent.
- Round 1: speed symmetry plus the complete two-sided exit atlas.
- Round 2: occupation law, endpoint faces, executable counts, collision audit,
  and strict Route-A stopping theorem.
