# Manuscript artifacts

The source file is paper/main.tex.  The files
main_round0_original.pdf, main_round1.pdf, and main_round2.pdf are
content-distinct fixed-epoch revisions; main.pdf is a byte copy of round 2.
The revision focus is recorded in PAPER_IMPROVEMENT_LOG.md and the build,
hash, and font audit is in COMPILE_REPORT.md.

The manuscript is intentionally self-contained and Latin-script so that the
embedded Latin Modern fonts are deterministic across builds.  DOI links
identify the classical sources; no priority claim is made.
