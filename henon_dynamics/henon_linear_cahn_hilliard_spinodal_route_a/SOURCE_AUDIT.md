# Source and scope audit

## Source model

All numerical and symbolic data come from the source PDE
\(u_t=-\kappa\Delta^2u-\alpha\Delta u\), its Fourier lattice on the
\(2\pi\)-torus, and declared rational test parameters. The shell
multiplicity \(r_d(n)=\#\{k\in\mathbb Z^d:|k|^2=n\}\) is Fourier geometry,
not arithmetic target data.

functional equation, target zero, or Hilbert--Pólya operator is imported or

shell spectrum is not identified with any target zero set. Route B remains
