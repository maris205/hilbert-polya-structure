# Source audit

## Verified sources

1. Fred Solomon, “Random Walks in a Random Environment,” *The Annals of
   Probability* **3**(1), 1--31 (1975).
   DOI: <https://doi.org/10.1214/AOP/1176996444>.
   Publisher record: <https://projecteuclid.org/euclid.aop/1176996444>.
   This is the primary owner of the one-dimensional iid direction and speed
   theorem and the stationary crossing-time route.

2. Ofer Zeitouni, “Random Walks in Random Environment,” Saint-Flour lecture
   notes, *Lecture Notes in Mathematics* **1837**, Springer (2004), 189--312;
   DOI: <https://doi.org/10.1007/978-3-540-39874-5_2>.
   This is used as an authoritative secondary check on quenched/annealed
   notation, the crossing-time expectation, and the zero-speed chamber.

The DOI, title, journal, volume, year, pages, and Project Euclid identifier for
Solomon were checked against the publisher/official record.  Zeitouni's author,
title, LNM volume, year, pages, and chapter DOI were checked against Springer
metadata.  In particular, this audit does not attach the unrelated arXiv record
`math/0503089` to Zeitouni.

## Claim ownership

This package makes no priority claim.  Its contribution is a source-local,
self-contained reconstruction that joins the finite scale formula, direction,
finite- and infinite-mean speed proof, Beta atlas, exact regression evidence,
and release boundary in one auditable artifact.  The finite evidence is not
represented as a reproduction of Solomon's infinite theorem.

## Citation boundary

No source is cited for a theorem it does not support.  No source supplies target
arithmetic data, Euler factors, root numbers, automorphy, a target functional
equation, target zeros, or a Hilbert--Pólya operator.  The words “potential,”
“product,” and “stationary” refer only to the declared RWRE.
