# Technical note

`main.tex` is a concise technical note recording the corrected pinning
convention, signed three-dimensional candidate vector kernel, exact finite
residue algebra, unresolved nuclear/all-word gates, and prior-art closure.
The alternating determinant and meromorphic continuation are conditional;
the note is not presented as a completed Ruelle theorem or a new
Hilbert--Pólya construction.

Compile with:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```
