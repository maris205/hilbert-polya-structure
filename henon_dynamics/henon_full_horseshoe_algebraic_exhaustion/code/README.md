# Code

theorem ledger, full-shift point counts, odd reflection degrees, rational
Sturm isolators through period 13, dependency hashes and 26 hostile
mutations.

`independent_check.py` does not import the primary implementation.  It uses
Cartesian binary words and a separate recurrence/root implementation through
period 11.

Run the complete package with:

```bash
bash code/run_c62.sh
```
