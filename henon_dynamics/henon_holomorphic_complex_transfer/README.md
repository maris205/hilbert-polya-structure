# C108 — Holomorphic complex Hénon transfer ownership gate

This package tests the explicitly frozen polynomial automorphism

\[
F(z,w)=(w,w^2-\tfrac14 z).
\]

The period-one and period-two fixed-point equations are solved exactly. The
Jacobian weights (1/\det(I-DF^n)) give an exact two-term trace/determinant
prefix. A separate degree-growth calculation for the inverse pullback shows
why a finite polynomial Galerkin space is not automatically a source-native
Fredholm owner.

The package is intentionally conservative: `A1_OPEN` and
`A2_CERTIFIED_PREFIX`. It does not claim a global complex repeller, analytic
nuclearity, prime correspondence, Riemann zeros, or Route B.

## Reproduce

```bash
cd henon_dynamics/henon_holomorphic_complex_transfer
python3 code/c108_holomorphic_producer.py
python3 code/c108_holomorphic_checker.py
python3 code/c108_sympy_crosscheck.py
python3 code/c108_replay.py
python3 code/c108_mutation.py
```

The paper is in `paper/main.tex` and `paper/main.pdf`; the content-addressed
release ledger is generated by `code/c108_release_manifest.py`.
