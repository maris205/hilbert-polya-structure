# C200 paper build

`main.tex` is compiled with LuaLaTeX, embedded Latin Modern and Droid Sans
Fallback fonts, `SOURCE_DATE_EPOCH=1787788800`, and optional PDF metadata
suppressed.  `CRevisionRound=0,1,2` produces the preserved substantive rounds;
round 2 equals `main.pdf`.

The final release requires two fresh byte-identical builds, a clean log,
extractable theorem and scope text, and visual inspection of every page.
