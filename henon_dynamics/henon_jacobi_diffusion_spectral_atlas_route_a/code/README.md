# C200 exact certificate code

- `c200_jacobi_producer.py` emits the deterministic rational certificate.
- `c200_jacobi_checker.py` independently reconstructs every polynomial,
  moment and Gram identity and enforces recursive exact key sets.
- `c200_jacobi_sympy_crosscheck.py` is a separate symbolic route.
- `c200_jacobi_replay.py` requires byte-for-byte evidence reproduction.
- `c200_jacobi_mutation.py` launches repaired-hash, stale-hash, unknown-key
  and mathematical attacks.
- `c200_release_manifest.py` closes the 27-payload release ledger while
  excluding its own generated manifest.

The finite ledger tests formulas and conventions.  The continuum-parameter
theorem is established by the manuscript proof, not by enumeration.
