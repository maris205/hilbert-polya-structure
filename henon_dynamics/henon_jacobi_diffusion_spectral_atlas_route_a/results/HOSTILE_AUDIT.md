# C200 hostile audit

The audit explicitly attacked the source commit, evaluator hash, realization,
clock ownership, Route tuple, forbidden-claim flags, source DOI, equality
boundary, eigenvalue, eigenpolynomial coefficient, stationary moment, summary
count and schema closure.  Repaired hashes did not rescue semantic mutations;
an unrepaired payload was rejected as stale.

The theorem-level hostile finding was that “no recurrence” is false without a
qualifier.  The canonical process is positive recurrent.  The valid spectral
statement is `P_T f=f => f constant` for `T>0` in `L2(pi)`.  The paper retains
both statements and never substitutes one for the other.
