# Selection and collision audit: C394–C398

Selection date 2026-09-05. Full source contracts are in the batch plan.
This is a theory feasibility/ownership screen, not a numerical novelty score.
Search scope: tracked and visible Markdown/TeX/Python in henon_dynamics,
flow_systems and symbolic_dynamics; other tracks were read-only.

## Retained mechanisms

1. **C394: analytic p-adic time, not just finite congruence tables.** Poonen's
   analytic interpolation is classical. The concrete nonlinear symplectic
   family admits an all-parameter orbit/quotient theorem. Symbolic P23 cites
   Bell for linear-recurrence zero sets but explicitly does not implement this
   analytic-arc mechanism. C166/C174/C258 finite Pascal/parity/congruential
   sources have different objects. Effective Strassmann certificate algorithms
   are not claimed as new here.
2. **C395: parabolic horocycle return, not another hyperbolic continued fraction.**
   BCZ/Athreya–Cheung own the Farey triangle. Full rational layers and their
   physical roof have a different clock and stability class from Mayer/Gauss
   and quadratic-unit cycles. A floor-wall itinerary matrix is not a two-sided
   derivative. Totient periods use one copy of each cyclic denominator pair.
3. **C396: transparent PDE generator, not a finite spectral matrix.** The
   Driscoll–Trefethen absorbing-string source is classical. C287 concerns
   closed-wave HUM control and explicitly excludes damping; C272 is infinite
   age transport with renewal. Neither closes the finite-interval empty-spectrum,
   exact extinction and pseudospectrum contract.
4. **C397: Salem/nonexpansive arithmetic, not a cat-map parameter table.**
   Mandatory new source coverage includes the trivial homoclinic group and
   explicit nonconstant primitive/cumulative asymptotic distributions.
   Existing Anosov and C388 rank-two algebraic packages do not own this family.
   The pressure-weighted Abel-law package has an abstract Salem stress
   polynomial, not this source dynamics; IDEA_C179_C183 rejected generic
   toral proposals, so fixed counts alone would not justify this paper.
   Lind, Waddington, and Lindenstrauss–Schmidt are explicit classical owners.
5. **C398: genuine logarithmic confinement and a rigorous residual obstruction.**
   Pólya's order-zero phenomenon and Lagarias's half-line Morse family own the
   analytic background. The project's full-line Morse package has finitely
   many bound levels plus a continuum; C391 has a nonsemibounded inverse-square
   domain. Neither is the compact-resolvent positive exponential wall here.
   A classical S(T) oscillation theorem, explicitly imported via Dobner's
   verified primary paper, rules out exact counting after every allowed fixed
   normalization; the two leading coefficients alone are not the decision.

## Screened but not retained

- Squarefree/B-free symbolic systems collide with P01/P43.
- Markoff descent collides with C193; Lattès multiplication with C180.
- Bost–Connes has a symbolic P35 owner/firewall; ordinary Gauss/Mayer already
  has owners. Reusing those sources without a new complete contract was rejected.
- Boole's parabolic rational map remains a possible later subtype, not a sixth
  authorized paper. Interior point damping remains a later alternative; doing
  it beside the impedance string would overweight one PDE class.
- Scalar p-adic near-identity maps would duplicate the stronger C394 mechanism.
