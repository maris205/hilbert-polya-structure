# C185 paper plan

**Working title:** Global Sorting, Morse Indices, and the Route-A Boundary of
the Brockett Double-Bracket Flow

**Type:** short all-parameter theorem and obstruction certificate

**One-sentence contribution:** For every simple real symmetric orbit and
strict diagonal target, the paper closes the global flow, all permutation
equilibria and pair modes, generic sorting, and recurrence obstruction, then
proves that none supplies Route-A arithmetic origin.

## Claims–evidence matrix

| Claim | Evidence | Status |
|---|---|---|
| global existence and isospectrality | compact orbit and skew Lax proof; six exact rational sentinels | proved for all `n` |
| exact Lyapunov identity | trace calculation; rational and symbolic reconstruction | proved for all `n` |
| `n!` equilibria and pair rates | commutant argument and tangent linearization | proved for all `n` |
| Morse index equals inversion count | sign of every pair rate | proved for all `n` |
| generic sorting and no recurrence | compact gradient convergence, stable manifolds, strict monotonicity | proved for all `n` |
| repeated spectra require a separate boundary | exact `3x3` collapsed-label/stabilizer control and a target-degenerate tangent-zero-mode family | scoped sentinel, not full classification |
| Route A fails | no arithmetic origin, periodic carrier, determinant, global analytic match, or fixed quantum operator | stopped by rubric |

## Structure

1. English and Chinese abstracts state the all-size result and strict stop.
2. Frozen family and theorem define assumptions before claims.
3. Lax/Lyapunov proof closes global dynamics.
4. Pair modes, inversion index, convergence, and recurrence give the main step.
5. Repeated spectra and Route-A evaluation state exact boundaries.
6. Reproducibility, limitations, declarations, and the single verified source
   close the paper.

No figure is necessary: the key relationship is more compactly shown by a
three-column theorem table.  The manuscript uses no decorative or synthetic
plot.

## Citation plan

The sole cited source is Brockett 1991, DOI
`10.1016/0024-3795(91)90021-N`.  It owns the classical equation, gradient
sorting framework, and diagonalization application.  The Route-A evaluation
and exact artifact ledger are explicitly separated.
