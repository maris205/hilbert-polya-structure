# C186 research question

For every free rigid body with strictly ordered principal moments
\(0<I_1<I_2<I_3\), can one put the complete reduced Euler flow---not one selected orbit---into a single exact theorem that includes both elliptic regimes, all six axial rotations, the intermediate-axis separatrix, action--angle coordinates, and every fixed set of a sampled time map?

The large-step requirement is the full parameter and energy atlas. A formula valid only near one stable axis, a numerical trajectory, or a period table would not qualify.

The Route-A question is separate: does this exact Hamiltonian system intrinsically encode rational primes, a logarithmic prime clock, or a target divisor? The frozen expectation is no. The useful positive output is a canonical KKS/Koopman owner and a sharp explanation of why continuous resonant orbit families invalidate an ordinary isolated-orbit Artin--Mazur census.

Scope is exactly `NO_BAD_EULER_OR_ROOT_NUMBER`. Target zero/prime tables, arithmetic local data, Euler factors, root numbers, automorphy, target functional equations, Hilbert--Pólya operators, and Route B are excluded.
