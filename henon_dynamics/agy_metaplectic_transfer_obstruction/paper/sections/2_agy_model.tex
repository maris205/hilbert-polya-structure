\section{The source-specified AGY induced return model}
\label{sec:model}

\subsection{Rauzy chronology}

Let \(\cA=\{1,2,3,4\}\).  A labeled permutation is displayed as two ordered
rows.  At every irreducible state, the rightmost top and bottom labels are
distinct.  A top arrow has the top label as winner and the bottom label as
loser; a bottom arrow reverses those roles
\citep{yoccoz2010}.  Following AGY, an arrow with
winner \(w\) and loser \(\ell\) carries
\begin{equation}
 B_e=I+E_{\ell,w}.
 \label{eq:edge-matrix}
\end{equation}
If \(\gamma=e_1\cdots e_n\) is chronological, then later arrows multiply on
the left:
\begin{equation}
 B_\gamma=B_{e_n}\cdots B_{e_1}.
 \label{eq:chronology}
\end{equation}
This convention is also the natural length-visitation convention after
transposition.  No frequency or transition average appears.

For a state \(\pi\), let \(\Omega_\pi\) be its crossing form in fixed label
order.  Every open edge transports the changing form,
\begin{equation}
 B_e\Omega_{\rm src}B_e^T=\Omega_{\rm dst}.
 \label{eq:form-transport}
\end{equation}
A closed path at \(\pi\) therefore satisfies
\(B_\gamma^TJ_\pi B_\gamma=J_\pi\), where
\(J_\pi=\Omega_\pi^{-1}\).  In the four-letter reversal class all crossing
forms have determinant one, so relative and absolute homology have the same
four-dimensional rank.

To make the pathwise lift precise, use the base-state form
\(J_0=J_{\pi_*}\) as a fixed reference and, for each Rauzy state \(\pi\),
choose an integral frame
\(S_\pi\in\operatorname{GL}(4,\Z)\) satisfying
\[
 S_\pi^T J_\pi S_\pi=J_0.
\]
Such frames exist because the forms are integral, alternating, and
unimodular.
For an edge \(e:\pi_{\rm src}\to\pi_{\rm dst}\), put
\begin{equation}
 g_e=S_{\pi_{\rm dst}}^{-1}B_eS_{\pi_{\rm src}}.
 \label{eq:edge-trivialization}
\end{equation}
Inverting \eqref{eq:form-transport} gives
\(B_e^TJ_{\rm dst}B_e=J_{\rm src}\), hence
\(g_e^TJ_0g_e=J_0\).  Moreover the intermediate frames telescope:
\[
 g_\gamma=g_{e_n}\cdots g_{e_1}
 =S_{\pi_{\rm end}}^{-1}B_\gamma S_{\pi_{\rm start}}.
\]
Thus every \(g_e\) lies in
\(\Sp(J_0,\Z)=\{g\in\operatorname{GL}(4,\Z):g^TJ_0g=J_0\}\), which is
integrally conjugate to the standard \(\Sp(4,\Z)\).  After one fixed real
identification of \((\R^4,J_0)\) with standard phase space, we
choose a lift of every \(g_e\) and compose those lifts chronologically in
the corresponding metaplectic group.  Their oscillator images
\begin{equation}
 U_\gamma=\mu_{\rm osc}(\widetilde g_\gamma)
 \quad\hbox{on}\quad \cF=L^2(\R^2)
 \label{eq:fiber-unitary}
\end{equation}
are unitary.  The central sign is retained.

\subsection{The AGY induced map}

AGY chooses a strongly-positive neat loop \(\gamma_*\) at a Rauzy state and
uses it to define a precompact first-return section \citep{agy2006}.  The
base is a bounded John domain \(\Delta\), equipped with its induced
Lebesgue measure \(m\), and partitioned modulo measure zero into countably
many open sets \(D_\gamma\).  In particular \(m\), and hence every measure
with a positive density relative to \(m\), is nonatomic.  Each forward branch
\(T:D_\gamma\to\Delta\) is a \(C^1\) diffeomorphism.  We write
\(h_\gamma:\Delta\to D_\gamma\) for the inverse branch,
\(r_\gamma=r\circ h_\gamma\) for the branch roof, and
\(j_\gamma=\operatorname{Jac}h_\gamma\) for the inverse Jacobian.

The source estimates provide constants independent of \(\gamma\) such that
\begin{equation}
 \|Dh_\gamma\|_\infty\le\kappa<1,
 \qquad
 \|D\log j_\gamma\|_\infty\le C_J,
 \qquad
 \|Dr_\gamma\|_\infty\le C_r.
 \label{eq:agy-bounds}
\end{equation}
For \(d=|\cA|\), the projective formula is
\begin{equation}
 h_\gamma(x)=\frac{B_\gamma^Tx}{\|B_\gamma^Tx\|_1},
 \qquad
 r_\gamma(x)=\log\|B_\gamma^Tx\|_1,
 \qquad
 j_\gamma(x)=e^{-d r_\gamma(x)}.
 \label{eq:branch-formula}
\end{equation}
For the AGY return branches, \(r_\gamma\ge\log2>0\).
The roof has exponential tails: for some \(\sigma _0>0\),
\begin{equation}
 \int_\Delta e^{\sigma _0r}\,dm<\infty.
 \label{eq:tails}
\end{equation}
The map preserves a probability measure \(d\mu=\rho\,dm\), where
\begin{equation}
 0<c_\rho\le\rho\le C_\rho<\infty,
 \qquad \rho\in C_b^1(\Delta).
 \label{eq:density}
\end{equation}

The scalar weighted operator used by AGY is
\begin{equation}
 (L_su)(x)=\sum_\gamma
 e^{-sr_\gamma(x)}j_\gamma(x)u(h_\gamma x),
 \qquad \Re s>-\sigma _0,
 \label{eq:agy-transfer}
\end{equation}
on \(C_b^1(\Delta)\).  The metaplectic extension below keeps the same base
weight and inserts \(U_\gamma\) without smoothing.

\subsection{A deterministic four-letter section}

The explicit reversal seed \((1234)/(4321)\) generates seven labeled states.
We choose the AGY-admissible section base
\[
 \pi_*=(1342)/(4321).
\]
At this state, set
\begin{equation}
 \eta=tbttbtbb,
 \qquad
 \gamma_*=t^{64}\eta^8.
 \label{eq:gamma-star}
\end{equation}
The loop \(\eta\) is complete: its winners contain all four labels.  The
decomposition \((t^{64}\eta)\eta^7\) therefore consists of eight complete
paths.  Since \(3d-4=8\), the AGY criterion proves strong positivity.  The
maximal initial top run has length 65, at least half of
\(|\gamma_*|=128\), and the final arrow is bottom.  This is AGY's sufficient
shape for neatness.  An exact scan also finds no nonempty proper word that
is both a prefix and suffix.

The chronological matrix is
\begin{equation}
B_{\gamma_*}=
\begin{pmatrix}
18540&1210580&11430&27373\\
24020&1568410&14783&35450\\
50233&3279928&31130&74253\\
38803&2533625&24020&57343
\end{pmatrix}.
\label{eq:gamma-matrix}
\end{equation}
It is entrywise positive, has determinant one, and, at the base state,
satisfies
\[
B_{\gamma_*}\Omega_*B_{\gamma_*}^T=\Omega_*,
\qquad
B_{\gamma_*}^TJ_*B_{\gamma_*}=J_*.
\]
This project-chosen word is a deterministic AGY-admissible existence
witness; none of the operator theorems depends on choosing it from a finite
periodic scan.
