# Hostile audit: HCS-C360

All 60 attacks were rejected.  The suite changes identity, provenance,
evaluator, metric equation, theorem language, collision ownership, references,
individual cells in every evidence section (including the explicit horizontal
Ricci wall), section hashes, counts, Route-A status, and forbidden scope flags.
For semantic attacks it recomputes the
outer payload hash, so rejection cannot be credited to stale checksums.

It also removes, duplicates, and extends section rows; deletes or adds
top-level fields; supplies a stale payload digest; injects duplicate and
nonfinite JSON; changes the JSON root type; and tests YAML duplicate keys,
anchors, aliases, merge keys, non-string keys, implicit dates, unknown fields,
wrong scalar types, altered provenance, a promoted A1 verdict, unlocked Route
B, and a redirected artifact path.

The test establishes fail-closed behavior for the frozen finite contract.  It
does not turn finite data into a proof of the continuum theorem.
