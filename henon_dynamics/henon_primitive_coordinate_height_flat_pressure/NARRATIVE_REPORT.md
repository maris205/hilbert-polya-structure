# Narrative report

P62 made the mixed-axis primitive divisor honest: all roots are real, simple,
and of exact least period.  That invited an all-period Galois-height pressure.
The first definition, however, weighted each root by its ordinary Weil height
without multiplying by the orbit length.  P63 shows that this choice cannot
change exponential root growth.

The reason is geometric and arithmetic at once.  Integral cyclic coordinates
make every root an algebraic integer, full-horseshoe exhaustion makes every
conjugate another real periodic coordinate, and the recurrence itself bounds
every coordinate uniformly.  The height is therefore `O(1)`, while the root
population grows like `2^(n/2)`.  Any fixed height weight changes the partition
by only an `O(1)` factor.

This is a useful failure: it removes a wrongly normalized bridge before a
large pressure calculation is attempted.  The next paper should test an
extensive packet observable, beginning with the normalized logarithmic
Mahler mass and the equidistribution of the complete reflection-root ensemble.
