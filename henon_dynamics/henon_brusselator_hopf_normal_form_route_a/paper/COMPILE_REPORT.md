# C311 compile report

All rounds use isolated two-pass LuaLaTeX builds with
`SOURCE_DATE_EPOCH=1788393600`, `FORCE_SOURCE_DATE=1`, and `TZ=UTC`.  Exact
PDF hashes, page counts, font rows, and raster sizes are frozen by
`C311_RELEASE_MANIFEST.json`.  A settled layout/reference/citation/rerun/
missing-character warning or a nonembedded font is a release failure.
