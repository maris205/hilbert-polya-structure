# C330 computation lanes

The producer enumerates all ternary words through depth eight and writes exact
Pythagorean, Möbius, cylinder, quadratic-fixed-point, multiplier, and period
count certificates.  The checker independently rebuilds every matrix and
coordinate without importing the producer.  SymPy checks Lorentz-form
preservation, branch conjugacies, sampled quadratic fixed equations, and the
source zeta series.  Replay regenerates the 6 MB evidence in isolation;
mutation attacks repaired hashes and strict parsers; release owns the exact
27-file payload.
