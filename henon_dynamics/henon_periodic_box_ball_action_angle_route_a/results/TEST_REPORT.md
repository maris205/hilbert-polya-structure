## Independence boundary

The checker does not import producer code.  It uses rational Gaussian elimination rather than Bareiss elimination for determinants and translation orders.  Its strongest check is not another implementation of angle variables: it independently executes the physical periodic carrier on every binary state through `L=9`, recovers soliton content from carrier energies, and compares complete permutation cycles.  SymPy is a third implementation for determinants, Smith forms, Möbius counts, minimal orders, primitive points, and cycle determinants.

## Seven mandatory integrity modes

1. **Implementation bug passing self-review — CLEAR.**  Independent rational algebra, actual-carrier enumeration, SymPy, replay, and semantic mutation attack the implementation.
2. **Hallucinated citation — CLEAR.**  Both references, metadata, theorem roles, and formula-bearing source text were verified; the paper distinguishes imported and derived claims.
3. **Hallucinated experimental result — CLEAR.**  Every reported count is regenerated by a saved deterministic command with exit status zero.
4. **Shortcut reliance — CLEAR.**  The theorem is all-parameter; finite sentinels are explicitly not proof.  Boundary and matched finite-translation controls are included.
5. **Implementation bug reframed as novelty — CLEAR.**  No unexpected numerical behavior is called a discovery; KTT/Takagi ownership is explicit.
6. **Methodology fabrication — CLEAR.**  The methods and counts match the executed producer, checker, SymPy, replay, mutation, build, and manifest commands.
7. **Frame-lock — CLEAR.**  A full Brockett-flow fallback was precommitted if the internal-symmetry sectors could not be rigorously closed.  The box--ball model was retained only after the complete sector and multiplicity theorem was source-locked.

This is an internal integrity audit, not external peer review and not an independent stochastic error process.
