# Paper build

`main.tex` contains three conditional, substantively different versions selected by `CRevisionRound=0,1,2`. LuaLaTeX is run twice in a fresh directory with fixed epoch `1788393600`. `main.pdf` is byte-identical to `main_round2.pdf`; all rounds must be deterministic, warning-free, rasterizable, text-safe, and use embedded subset fonts.
