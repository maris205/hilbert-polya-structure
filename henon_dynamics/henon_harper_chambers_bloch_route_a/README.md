# HCS-C371 -- anisotropic Harper--Chambers Bloch atlas

This package proves one all-parameter theorem for the square-lattice Harper
Hamiltonian at every reduced rational magnetic flux.  In a fixed
`det(EI-H)` convention it derives Chambers' two-phase identity, the full
two-dimensional spectral preimage, the algebraic band-edge and closed-gap
criterion, Aubry duality, flux reversal, parity, the forced even-denominator
central contact, and direct `q=1,2` boundary fibers.

The all-denominator central value is mapped explicitly to Lamoureux--Mingo,
Theorem 2.5 and Corollary 2.6, under `lambda_LM=2 lambda`.  The package-owned
advance is the convention-locked reconstruction, the real endpoint-fiber
edge factorization, and the executable atlas, not priority for the object or
formula.

The package contains exact cyclotomic checks and a dense independent Bloch
ledger.  It does not claim novelty for classical Harper/Chambers/Hofstadter
or Lamoureux--Mingo theory, does not claim that all gaps are open, and makes no Chern,
irrational-flux, target-arithmetic, or Hilbert--Polya assertion.

Start with `THEOREM_PACKAGE.md`, then see `SOURCE_AUDIT.md`,
`REPRODUCIBILITY.md`, and `paper/main.pdf`.
