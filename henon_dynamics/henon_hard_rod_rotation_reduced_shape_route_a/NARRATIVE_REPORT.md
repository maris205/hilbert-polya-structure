# Narrative report

The tempting circular version of the usual hard-rod compression contains a
topological trap.  On an interval or ordered cover, subtracting `(i-1)a`
removes excluded volume.  On a circle, changing which rod starts the cyclic
list also translates every compressed point by `a`.  A quotient by labels
alone therefore does not make the map single valued.  The one-rod return
period gives the shortest counterexample.

The corrected owner removes constant global spatial rotation on both sides.
Rod shapes are cyclic free-gap vectors summing to `L=ell-N*a`; compressed free
points have exactly the same gaps, modulo their common translation and pair
permutation.  Equal-mass impacts merely exchange velocities, so the
collision-glued hard-rod flow is the free crossing flow in these coordinates.
This resolves binary, disjoint simultaneous, and multiple contacts at once
and gives an elementary compact-interval no-Zeno bound.

The quotient also changes recurrence correctly.  A return may include one
common translation `c`; omitting it would test an unremoved angle.  Splitting
points by velocity turns return into an intersection of finite circle-
stabilizer cosets.  Generalized CRT produces the exact lcm criterion and
explains why symmetric repeated-velocity classes can return sooner than a
generic distinct-velocity state.  The result is a complete shape-flow theorem
and a precise obstruction to upgrading it to the full physical circle.
