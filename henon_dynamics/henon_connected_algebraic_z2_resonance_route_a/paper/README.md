# Paper revisions

The default main.tex selects round two. Each wrapper selects one revision.
Round zero contains quotient presentations and resonance. Round one adds the
integer covolume theorem and the version-specific correction. Round two adds
primitive torus strata, arithmetic entropy and ordinary orbit-count failure.

The final main.pdf must be byte-identical to main_round2.pdf. The release
driver compiles each wrapper twice in fresh directories with epoch 1788566400
and preserves the settled TeX log as compile_round0/1/2.txt. The compile report
records page counts, font embedding and actual visual inspection separately
from successful rasterization. No conference acceptance is claimed.
