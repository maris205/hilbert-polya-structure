\section{The remaining H\"older gate}

For one-sided symbolic metric \(d_\vartheta(x,y)=\vartheta^k\), the P56
ladder pairs orbits whose long zero runs agree except near a bounded number
of seams.  If one H\"older observable of exponent \(\alpha>0\) realized all
excesses, its variation estimate would force
\begin{equation}\label{eq:holder-necessary}
 |\Delta_m|\le C(4m+4)\vartheta^{\alpha m}
 \qquad(m\ge3)
\end{equation}
for one fixed \(C>0\).

The new value \(\Delta_5\ne0\) is not a contradiction to
\eqref{eq:holder-necessary}: a constant \(C\) can absorb any finite number of
indices.  The asymptotic gate is therefore precise.

\begin{quote}
Determine the leading stable-tail mode of the two reflection chains and show
either that \(\Delta_m\) obeys a compatible exponential law or that an
infinite subsequence violates every bound of the form
\eqref{eq:holder-necessary}.
\end{quote}

The recurrence has a negative fixed-point tail, so the natural next attack
is to linearize the closing equations about that fixed point and compare the
two reflection boundary conditions.  This is a whole-family theorem, not a
request for another isolated period.  Computing \(B_8\) is useful only as a
falsifier for the predicted leading eigenmode.

For a two-sided H\"older observable, a future-dependent representative would
first require a cohomological reduction.  We make no such reduction here.
Liv\v{s}ic theory tests equality modulo coboundaries between already-defined
H\"older observables; it does not construct an observable from arbitrary
periodic totals \citep{Livshits1972}.
