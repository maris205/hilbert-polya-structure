# Narrative

The entire bounded-orbit set has an explicit uniform inverse-sequence
contraction, giving complete coding without extrapolating a finite table.
The resulting matrices vary with the word, unlike a constant affine
horseshoe. Signed reciprocal stability is retained in a separate flat-trace
germ. Integer parameters produce quadratic units, which exclude exact
rationally rescaled log-integer instability periods. This is a source theorem
and a concrete arithmetic limitation, not target Route-A success.
