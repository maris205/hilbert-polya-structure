# Code ledger

- `c300_euler_producer.py`: deterministic 20-case, 437-cell evidence generator.
- `c300_euler_checker.py`: producer-free reconstruction of every root, wave sign, fan, shock, Lax gap, entropy value, scaling pair, and boundary probe.  It enforces exact recursive JSON/YAML trees, exact row key sets and primitive types, ordered unique case identifiers, canonical numeric strings, and refuses optimized Python.
- `c300_euler_sympy_crosscheck.py`: exact characteristic, entropy, Rankine--Hugoniot, fan, and pressureless identities.
- `c300_euler_replay.py`: two fresh producer outputs must match the archive byte for byte.
- `c300_euler_mutation.py`: 110 repaired-hash semantic and hostile parser attacks, including the independent survivor corpus from both red-team passes.
- `c300_release_manifest.py`: closed-world hashes, six PDF rebuilds, document contracts, and exact evaluation semantics.

The scripts require Python plus `mpmath`, `sympy`, and `PyYAML`; they use no network access or training data.
