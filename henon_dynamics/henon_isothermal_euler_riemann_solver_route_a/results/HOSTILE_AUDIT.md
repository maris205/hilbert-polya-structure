# Hostile audit — HCS-C300

## Machine attacks

All 110 attacks were rejected:

- 93 repaired-hash semantic mutations attacked provenance, scope, Route-A flags, theorem guards, collision/source ownership, count spectra, all 20 family-order gaps, 24 branch-specific fan/shock/zero speeds, exact object and row keys, primitive types, ordered unique case IDs, and canonical rational/decimal receipts.  They include the nine JSON attacks that survived the first red-team pass.
- 4 hostile JSON inputs tested stale hashing, duplicate keys, a nonfinite token, and a wrong top-level type.
- 13 hostile YAML inputs tested duplicate keys, anchors, aliases, merge keys, a wrong root type, epoch string coercion, verdict promotion, scope escalation, and the five title/dynamics/failure/artifact/scope substitutions that survived the first red-team pass.

## Mathematical attacks

1. **Wave-sign swap.**  Rejected: family 1 uses the negative Hugoniot root and family 2 the positive root; independent jump residuals and Lax gaps fix the orientations.
2. **A naked typesetting token treated as mathematics.**  Rejected: all three bare `qquad` defects were removed and the extracted/rasterized equations were inspected.
3. **Entropy asserted from Lax by slogan.**  Rejected: both shock families reduce to the same explicit production \(a^3\rho_0\sqrt r[\log r-(r-r^{-1})/2]\), and the derivative proof makes it strictly negative for \(r>1\).
4. **Intermediate-state nonuniqueness.**  Rejected: each branch is \(C^1\), strictly increasing, and the sum ranges from \(-\infty\) to \(+\infty\); every ordered Lax solver must use those exhaustive curves.
5. **Hidden vacuum.**  Rejected: no-vacuum is stated only for \(a>0\), positive input densities, and finite velocities; the logarithmic branch forces a positive root.
6. **Pressureless limit smuggled into the theorem.**  Rejected: exact symmetric separating and compressive families tend oppositely to zero and infinity, demonstrating nonuniformity; no \(a=0\) solution claim is made.
7. **Zero wave double-labeled.**  Rejected: equality is one zero-strength boundary, not simultaneously a shock and rarefaction.
8. **Density scaling overlooked.**  Rejected: four exact pairs preserve velocity, ratio, wave type, and speed under common positive scaling.
9. **C195 relabeling.**  Rejected: C195 is scalar periodic viscous Burgers; C300 is an inviscid two-field Riemann system with two families and nine pattern faces.
10. **Finite cases or PDE symbols promoted to arithmetic evidence.**  Rejected: evidence is regression only and every target arithmetic/operator flag is false.

11. **Truth-preserving prose and type substitution.**  Rejected: the complete evidence and evaluation semantic trees are checked recursively with exact key sets and primitive types; strings cannot be replaced by false/affirmative text, numeric strings by integers, or canonical receipts by equivalent noncanonical spellings.
12. **Optimized execution erases assertions.**  Rejected: the checker has no Python `assert` statement in its acceptance path and explicitly refuses optimized mode.

No surviving branch-sign, entropy, vacuum, pressureless, parser, tree-shape, primitive-type, canonicalization, collision, or scope-escalation attack remains after two substantive paper-improvement rounds and the final release hardening pass.
