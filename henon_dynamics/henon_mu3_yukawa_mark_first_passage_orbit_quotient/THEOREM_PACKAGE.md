# C93 theorem package

The five C76 generator permutations generate a faithful group of order 1920,
distinct from the ambient lifted order 11520.  Acting on the C88 support
indicators induces permutations of the twenty actual target closures.  For
each generator (g), the target law satisfies

\[
\Pr(T_H=k)=\Pr(T_{gH}=k),
\]

and the C92 pivotal-rank row for label (S_i) is transported to the row for
the label (gS_i) at target (gH).  The target action has sixteen orbits,
with twelve singleton orbits and four two-element orbits.  This is a quotient
of the finite atlas, not a classification of the full Burnside ring.
