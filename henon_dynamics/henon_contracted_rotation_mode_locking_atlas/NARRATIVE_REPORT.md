# Narrative report

The fractional-part map looks elementary, but the jump at one makes endpoint
conventions decisive.  We freeze a half-open branch rule and turn every binary
carry itinerary into an affine contraction.  Its return slope is
\(\lambda^n\), so the return equation has one and only one candidate point.

The candidate is physical precisely when each intermediate state lies in
\([0,1)\) and the corresponding affine input lies in the declared carry
interval.  Since all coefficients are rational for the frozen slopes, these
conditions reduce to an exact intersection of rational half-lines in
\(\delta\).  The resulting lower endpoint is closed only when all active
constraints are lower inequalities; every upper endpoint is audited separately
because a carry equality changes the branch.

Primitive words remove repetitions and cyclic duplicates.  Their carry average
is a rotation-number label, allowing a finite mode-locking ledger.  We report
the union of certified word components for each label, but do not infer that it
is a maximal plateau.  This distinction matters near endpoint collisions and
is checked by mutation tests.

An independent high-precision iteration starts from a fixed rational seed,
recovers a repeated suffix when numerical contraction has settled, and compares
its affine fixed point with the exact row.  The check is intentionally a
control: the theorem remains the Fraction interval certificate at the declared
cutoff.  The package closes a strong source-local piecewise-contraction result.
No global one-periodic-orbit theorem is claimed: the cited general two-branch
piecewise-contraction theorem gives only an at-most-two bound under its
hypotheses.  The lack of an arithmetic clock therefore forces A0 and
target-determinant claims to fail.
