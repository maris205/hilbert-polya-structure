# Hostile audit

Fifty-three attacks must be rejected.  The suite repairs the payload hash after
semantic changes, so a checksum alone cannot pass the gate.  Mutations cover
identity, source commit, scope, evaluator, model, every theorem clause,
collision ownership, nonclaims, reference roles, Route-A tuple, each open,
edge, threshold, periodic, boundary, propagator, and quench class, individual
cells, row labels, one-cell convention, enumeration, and an extra metadata
field.  Two dedicated repaired-hash attacks globally rescale the first OBC
row `(3,2)->(6,4)` while synchronizing its polynomial and determinant, and
falsify the strictly positive sampled gap of the odd critical `M=3` ring.

Raw parser attacks add duplicate JSON/YAML keys, a JSON `NaN`, root arrays,
and a YAML anchor.  Further YAML attacks alter the source, route lock, scope
flag, theorem status, and source-owner list; an equivalent-whitespace attack
exercises the raw-byte digest after the semantic digest.  The checker uses no Python
`assert`; optimized execution is explicitly refused.

Result: `C318 hostile mutation suite: PASS 53/53`.
