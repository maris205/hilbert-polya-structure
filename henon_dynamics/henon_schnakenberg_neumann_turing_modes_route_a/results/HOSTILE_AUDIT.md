# C350 hostile audit

The hostile suite runs 60 attacks.  Forty-six mutations repair the canonical
payload hash after changing theorem data, modal rows, boundary rows, source
metadata, scope flags, Route-A verdicts, evaluator authority, the
complexification contract, both endpoint witnesses, the count-formula value,
and every evaluator evidence-status field.  One stale-hash control changes
data without repairing the hash.  Four malformed JSON attacks cover duplicate
keys and non-finite constants.  Nine YAML attacks cover raw/semantic drift,
duplicate keys, anchors, authority, version, evidence status, tuple, and scope
drift.

All attacks are rejected by independently recomputing the frozen formulas or
by exact schema and provenance locks.  The checker does not import or name
the producer.  Finite receipts remain explicitly subordinate to the analytic
proof.
