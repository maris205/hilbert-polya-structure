# Failure-mode audit

- Tangency is used only in the direction `tangent => multiplier +1`; no false
  converse is asserted.
- Uniform hyperbolicity is applied only to certified survivor roots.
- A formal residual degree is never called a distinct-root count.
- Numerical band tests are supplementary to the all-period proof.
- Primitive necklace/root multiplicity uses odd-period axis uniqueness.
- No arithmetic or operator conclusion is inferred from transversality.
