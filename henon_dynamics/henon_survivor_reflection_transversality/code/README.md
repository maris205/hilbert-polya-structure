# Code

`c61_transversality.py` independently reconstructs the mixed-axis quotient
chain, isolates every real primitive root through odd period 11 by rational
intervals, certifies the survivor band and nonzero closure derivative, locks
the all-period reversor/hyperbolicity theorem, and rejects 22 theorem/scope
mutations.

`independent_check.py` uses a different route: Cartesian enumeration of the
four-state symbolic system and high-precision numerical root classification.
It imports no code from the primary checker.

Run everything with:

```bash
bash code/run_c61.sh
```
