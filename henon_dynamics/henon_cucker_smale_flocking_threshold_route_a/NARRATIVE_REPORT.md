# Narrative report

The decisive quantity is not a fitted decay exponent or a numerical order
parameter.  It is the exact communication tail available beyond the initial
spatial diameter.  Diameter inequalities turn that tail into a barrier: if it
can pay the initial velocity diameter, the flock remains confined and the
communication coefficient stays uniformly positive.  Alignment is then
exponential.

For `beta <= 1/2` the tail is infinite, including the logarithmic endpoint,
so every initial configuration flocks.  For `beta>1/2` it is finite.  The
two-agent outward scalar reduction is important because it closes the logical
boundary: below the tail budget the separation converges, at equality the
relative speed tends to zero while separation diverges, and above it a
strictly positive relative speed survives.  Thus the arbitrary-`N` condition
is a sufficient theorem, while its threshold is genuinely sharp on a frozen
subfamily.

The model is a source-local dissipative population dynamics.  Its interaction
events and continuous parameters have no rational-prime semantics, no
primitive-orbit product, and no target analytic bridge.  The complete
mathematical result therefore survives an all-fail Route-A evaluation.
