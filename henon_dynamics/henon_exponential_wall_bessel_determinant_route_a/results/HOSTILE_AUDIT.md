# Hostile gate design

Metadata/source baseline, scope upgrades, literal false typing, numeric bool/float substitution, missing/duplicate mathematical populations and wrong source coefficients are attacked after payload SHA repair. The independent checker, not digest mismatch, must reject them. JSON duplicate/nonfinite values and nine YAML parser/semantic attacks are tested. Two additional disposable complete package copies call the actual release --write entry with repaired evidence; a sentinel manifest must remain unchanged and the failure must reach the independent checker. Optimized Python modes are separately refused for all six entry points.

Actual counts and output are part of the release lane receipts; no unexecuted test is promoted by this description.
