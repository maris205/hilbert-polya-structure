# Code

`c59_reflection_counts.py` proves the transfer-matrix formulas, applies the
divisor-sensitive reflection Möbius inversion, enumerates primitive necklaces
through period 16, and emits the exact period-32 census.

`independent_check.py` rederives the fixed-word counts from matrix powers and
uses a separate Cartesian-product enumerator through period 12.  Run all
checks with `bash code/run_c59.sh`.
