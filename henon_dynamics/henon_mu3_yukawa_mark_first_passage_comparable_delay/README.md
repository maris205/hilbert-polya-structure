# C95: Comparable-target conditional first-passage delay atlas

C95 freezes the C88 subgroup first-passage variables and the C90 joint-survival receipt.  It enumerates all 102 ordered comparable target pairs from the C88 inclusion relation, including reflexive pairs.  For each pair, two-sided finite differences of the C90 survival cells (with C88 marginal boundary cells at threshold -1) give the exact joint PMF of `(T_i,T_j)` over all `16!` label permutations.

The package certifies the pointwise order `T_i <= T_j`, unconditional delay laws for `D_ij=T_j-T_i`, conditional delay laws given every lower-target time, conditional means/second moments/variances, and C88 marginal identities.  Target 0 is the trivial subgroup and has time zero deterministically.

All artifacts are deterministic and bound to the frozen C88/C90 evidence and manifests.  Scope is finite combinatorics under `NO_BAD_EULER_OR_ROOT_NUMBER`; arithmetic or local data, Euler factors, root numbers, automorphy, a full Burnside ring/table of marks, and a Hilbert-Polya operator are not claimed.

Run from this directory:

```text
python -B code/c95_comparable_delay.py
python -B code/c95_comparable_delay_checker.py
python -B code/c95_sympy_crosscheck.py
python -B code/c95_replay_checker.py
python -B code/c95_mutation_test.py
```

The release manifest is generated by `code/c95_release_manifest.py` after the PDF has been compiled.
