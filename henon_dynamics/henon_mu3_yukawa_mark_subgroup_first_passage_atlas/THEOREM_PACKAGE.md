# C88 theorem package

Let `L` be the sixteen frozen labels, let `Phi(A)` be the subgroup of
`Q = Z/9 + Z/3 + Z/2` generated by `A`, and let `H_0,...,H_19` be the twenty
actual subgroups in C75 order.  For a uniform random permutation of `L`, put
`A_k` equal to its first `k` labels, with `A_0` empty, and define

```text
T_H = min{k : H <= Phi(A_k)}.
```

For `0 <= k <= 16`, write

```text
F_H(k) = #{A subset L : |A|=k and H <= Phi(A)}.
```

## Theorem: exact subgroup first-passage atlas

For every actual target `H`:

1. `P(T_H <= k) = F_H(k) / binom(16,k)`.
2. If `p_H(S)` is the number of labels `ell in S` for which
   `H` is not contained in `Phi(S\{ell})`, then for `k >= 1`

   ```text
   #{pi : T_H(pi)=k}
     = sum_{|S|=k, H<=Phi(S)} p_H(S) (k-1)! (16-k)!.
   ```

   For the trivial target the count at time zero is `16!`.
3. The survival and mean are

   ```text
   P(T_H > k) = 1 - F_H(k)/binom(16,k),
   E[T_H] = sum_{k=0}^{15} P(T_H > k).
   ```

4. If `H <= K`, then `T_H(pi) <= T_K(pi)` for every permutation `pi`.
   Hence the corresponding CDF, survival, and expectation inequalities all
   hold.  The finite atlas verifies all `102` comparable ordered pairs.
5. `T_H0=0` for the trivial target.  The complete row for the top target
   `H_19=Q` is entrywise identical to the final frozen C83 assembly law.

## Proof

The unordered prefix `A_k` of a uniform permutation is uniform over the
`binom(16,k)` subsets of size `k`, which proves the CDF formula.  A permutation
first hits at time `k>=1` exactly when its size-`k` prefix support `S` is a hit
and its `k`th label is pivotal.  For every pivotal pair `(S,ell)`, the other
`k-1` members of `S` can be ordered before `ell` in `(k-1)!` ways and the
remaining labels in `(16-k)!` ways.  This proves the pivotal identity.

The survival formula is the complement of the CDF.  Summing the tail of an
integer-valued random variable supported on `{0,...,16}` gives the expectation
formula.  If `H <= K`, containment of `K` in any prefix closure implies
containment of `H`; therefore the first hit of `H` is pointwise no later than
the first hit of `K`.  The trivial and top statements follow from
`Phi(empty)=H_0` and `H_19=Q`, respectively.

## Certificate split

The producer enumerates all closures and obtains each first-passage count
twice: by consecutive exact CDF values and by pivotal edges.  The independent
checker directly expands finite point sets, finds every inclusion-minimal
support generating above each target, reconstructs all hit supports by
antichain containment, and rebuilds the full receipt.  SymPy separately checks
all rational identities and probability generating functions.

This theorem concerns up-set first passage only.  It does not claim an atlas
for exact closure equality, arithmetic/local data, Euler factors, root
numbers, automorphy, a full Burnside ring or table of marks, or a
Hilbert--Polya operator.
