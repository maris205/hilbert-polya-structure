# HCS-C261 — periodic Airy cubic-Talbot atlas

This package proves an all-time operator theorem for the periodic Airy flow
`u_t+u_xxx=0`.  It closes the strongly continuous unitary group, the least
full-space return time, every rational-time translated-copy revival, exact
strobe order, sampled fixed subspaces, finite-Fourier-support state periods,
and the irrational-sampling boundary.

The executable receipt covers 2,806 reduced rational strobes through modulus
96, 101 high-precision cubic DFT reconstructions, and ten independent state
supports.  Independent modular/DFT checks, SymPy, byte replay, and repaired-
hash mutations are release gates.  The finite rows verify implementation;
the Hilbert-space statement is proved analytically.

The canonical unitary generator earns only source-local Route-A credit.
There is no arithmetic origin, rational-prime orbit dictionary, target
determinant, Euler factor, root number, target divisor, Hilbert--Pólya
operator, or Route-B input.  The final paper is `paper/main.pdf`.
