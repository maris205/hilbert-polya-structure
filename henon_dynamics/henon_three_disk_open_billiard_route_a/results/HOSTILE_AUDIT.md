# Hostile audit

The mutation suite repaired each JSON payload hash before asking the
independent checker to reject altered semantics.  It attacked candidate and
obstruction identity, source commit, epoch, scope, evaluator hash, clock,
parameter chamber, the
periodic-ray-iterate convention, fixed-count and zeta formulas, uniqueness
and finite-evidence roles, count rows, reversal, zeta coefficients, optical
determinant/trace, no-eclipse, symmetric monodromy, Route-A
tuple/verdict/lock, forbidden flags, and source owners.  Missing, unknown,
and duplicate JSON keys were also rejected.

The YAML lane attacked candidate and obstruction IDs, scope, overall verdict,
Route-B lock, A1 and A4 verdicts, epoch type, and theorem status.  Duplicate,
unknown, and missing top-level YAML keys were rejected.  Integer lookalikes
for booleans, altered axis prose/artifacts, and an unknown nested axis key
were also rejected by the exact semantic tree.  All 49 attacks failed closed.

An additional canonical-row pass rejects Boolean or floating-point
lookalikes for integer count, word-length, zeta, geometry, and Route-B fields;
it also freezes the full optical grid and directly exhausts the tenth word
row instead of trusting the producer's last entry.  With those eight attacks
included, all 57 attacks fail closed.
The final scope-polarity attack replaces a canonical nonclaim with an
affirmative target Euler-factor/root-number claim while repairing the payload
hash; exact nonclaim locking rejects it.  Thus all 58 attacks fail closed.

Additional release checks reject non-finite JSON constants, JSON/YAML
duplicate keys, YAML anchors/aliases/merge keys, unexpected sidecars, producer
imports in the checker, stale evidence or evaluation hashes, altered PDFs,
nonembedded fonts, missing round-specific text, and settled LaTeX warnings.

The strongest hostile question is mathematical rather than digital: can a
finite word table prove the coding theorem?  The answer is no.  The proof
uses compact minimization for arbitrary period, no-eclipse to force boundary
vertices, strict convexity to force uniqueness, and the constrained first
variation to recover non-grazing reflection.
