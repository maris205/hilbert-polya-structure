# C176 code

- `c176_sandpile_producer.py`: deterministic graph, sink, recurrent and translation evidence producer.
- `c176_sandpile_checker.py`: producer-independent burning, Leibniz, toppling-order, torsor, orbit and reversal checker.
- `c176_sympy_crosscheck.py`: Smith decomposition, adjugate order, cyclic spectrum and reversal checks.
- `c176_replay.py`: fresh-directory byte replay.
- `c176_mutation.py`: repaired-hash plus stale-hash adversarial tests.
- `c176_release_manifest.py`: self-excluded 27-file release closure.

Python 3 and SymPy are sufficient. No network, target table, fitted parameter, or random seed is used.
