# C220 hostile audit

The mutation harness changes source/evaluator locks, the fixed epoch, scope
literal, headline, generator and DEHP algebra, theorem strings, Route-A
verdict, citation DOI, grids, weights, normalization, currents, nullspaces,
absorbing supports, and phase rows.  It repairs the payload hash after each
change, so rejection tests schema and semantic closure rather than merely a
checksum.  Unknown top-level and nested keys are also rejected.  A separate
stale-hash mutation is retained.

Expected result: 28 repaired-hash semantic/schema rejections plus one stale
hash rejection.  The phase mutation set includes the explicit
`CRIT_CORNER` row, and the boundary assertions distinguish the affine
dimension of the normalized double-zero simplex from the linear nullspace.
The coexistence mutation also enforces the positive-rate condition
`0<alpha=beta<1/2`, keeping `(0,0)` on the zero-rate branch.
No mutation may silently turn a finite sentinel into a thermodynamic proof or
an arithmetic/operator claim.
