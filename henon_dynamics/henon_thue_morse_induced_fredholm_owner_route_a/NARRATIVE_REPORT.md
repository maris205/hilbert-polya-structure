# C164 narrative report

C159 left an exact recurrent source zeta with a natural boundary, but no
operator owner.  Simply writing its inverse zeta as a scalar determinant
would not advance that gate: the scalar could be chosen after the answer was
known and would hide every return branch.

C164 retains the code branches as Hilbert coordinates.  A fixed
subexponential diagonal gauge makes both the return vector and the analytic
coefficient functional square summable.  The operator decomposes in trace
norm into one rank-one contribution per source return branch.  Gauge factors
cancel in every branch trace, and multiplication of return choices produces
the complete power law `Tr(K_z^m)=F(z)^m`.  The direct-sum fixed-orbit block
then owns exactly the C159 inverse zeta.

The negative half is equally important.  No diagonal weight can make the
uninduced time-one adjacency compact once it is bounded: compactness would
force successive weights to decay to zero, while the infinite return row
forces the same weights to diverge along the Thue--Morse set.  Thus the
positive owner is honestly induced, not a disguised trace-class realization
of the original one-step adjacency.  The source natural boundary also
prevents trace-class meromorphic continuation across the circle.

This closes one precise operator-owner gate but supplies neither a unitary or
self-adjoint realization nor any target comparison.  The release therefore
remains `ROUTE_A_EXPLORATORY`, with Route B disabled.
