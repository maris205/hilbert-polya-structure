# C164 claim-driven experiment plan

## Hard gate

- Reject a one-dimensional scalar chosen solely to reproduce the known
  denominator.
- Require source return branches as coordinates, uniform trace-norm
  convergence on every compact subdisk, and all trace powers.
- Audit the uninduced adjacency for all diagonal positive weights, not only
  the standard norm.
- Treat the degree cutoff as a sentinel, never as proof of holomorphy,
  compactness, or a natural boundary.

## Deterministic evidence

1. Generate 128 Thue--Morse bits and the associated return branches.
2. Record 32 branch-resolved rank-one traces.
3. Rebuild `F^m` for `1<=m<=6` through degree 48.
4. Rebuild `(1-z)(1-F)` coefficientwise.
5. Audit five branch truncations and the exact bounded control `w_n=2^n`.
6. Retain eight dyadic boundary rows only as regression sentinels.

## Independent validation

- The standard-library checker reimplements digit parity and every formal
  convolution without importing the producer.
- SymPy constructs a symbolic branch matrix with arbitrary nonzero gauges,
  checks trace powers, the determinant lemma, and diagonal similarity.
- Replay requires canonical byte equality.
- Every repaired-hash semantic mutation and the stale-hash control must fail.
- Release requires content-distinct paper snapshots, fixed-epoch double PDF
  identity, embedded fonts, clean logs, rendered-page inspection, and exact
  manifest disk closure.
