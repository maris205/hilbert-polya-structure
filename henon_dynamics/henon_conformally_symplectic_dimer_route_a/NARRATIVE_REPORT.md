# Narrative report — C118

C118 joins dissipation and lattice coupling without pretending that the
symplectic C106/C111 arguments remain unchanged.  Damping replaces exact
symplecticity by an explicit conformal factor, and the determinant changes from
one to `1/4` per step in four dimensions.

The chosen rational parameters preserve two simple fixed witnesses and one
primitive synchronous period-two orbit.  Because synchrony kills the coupling
in the orbit equations, the orbit remains simple while the transverse Hessian
mode still detects coupling.  The resulting trace difference is therefore a
clean tangent control, not evidence for a global operator.
