# C169 verification plan

This is a theorem package, so no GPU or statistical experiment is appropriate.

1. Freeze the affine map, irrational-parameter quantifier, clock, Haar normalization, Fourier convention, and zeta convention.
2. Prove the iterate and empty-fixed-set statements for every \(n\ge1\).
3. Prove the Fourier action and sector decomposition, including the multiplicity count.
4. Prove reversal, antiunitarity, noncompactness, non-Schatten membership, and the ordinary-determinant obstruction.
5. Generate exact finite rows for affine coefficients, Fourier index transport, and sector residues.
6. Check the JSON independently, cross-check identities in SymPy, byte-replay the producer, and require rejection of repaired-hash and stale-hash mutations.
7. Compile three materially distinct manuscript rounds; require deterministic final PDF bytes, embedded fonts, and no layout or glyph warnings.
8. Close a self-excluded manifest over exactly 27 payload files.

Falsifier: one positive fixed count for irrational \(\alpha\), an incorrect Fourier index or phase, a failed reversor identity, a trace-class assertion for \(U\), or any scope flag set true rejects the package.
