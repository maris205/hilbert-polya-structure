# C312 hostile audit

Semantic attacks alter the confidence radius, a boundary initial point,
termination time, theorem bound, trajectory cell, trajectory hash, graph
change count, cluster multiplicity, mean drift, Route-A tuple, and scope
flags.  Each altered payload receives a valid repaired hash before checking.

Malformed inputs add duplicate/nonfinite/wrong-root JSON and duplicate,
anchored, scope-escalated, or Route-B-enabled YAML.  All 26 attacks must fail.
This specifically protects the closed `<=epsilon` convention and prevents a
row-stochastic matrix from being silently promoted to mean-preserving.
