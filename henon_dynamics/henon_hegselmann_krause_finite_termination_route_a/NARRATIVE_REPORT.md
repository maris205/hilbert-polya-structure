# C312 narrative report

This subtype changes the graph while it evolves, so static consensus
intuition is unreliable.  The one-dimensional order makes the dynamics
tractable: once a gap exceeds the confidence radius it cannot close, and the
leftmost active block provides a monotone progress certificate.  The
two-step lemma upgrades asymptotic convergence to literal finite stopping
with a cubic bound.

The second advance is structural.  Fixed states are not arbitrary graph
consensus vectors; they are exactly point clusters separated by strict gaps.
Inside each strict graph cell the map is rational and row-stochastic, but
crossing a threshold changes the matrix.  A three-agent rational example
shows that the global arithmetic mean can drift, so no false doubly
stochastic invariant enters the proof.

Finite termination is also the decisive Route-A obstruction: every orbit is
eventually fixed, hence no nontrivial primitive-cycle ledger survives.
