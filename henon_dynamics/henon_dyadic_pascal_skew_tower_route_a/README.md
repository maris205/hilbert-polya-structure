# HCS-C166 dyadic Pascal skew tower

This package proves the exact fixed-point clock, least periods, primitive
cycles, Artin--Mazur zeta, finite Koopman determinant, and truncated-ring time
reversal for every dyadic Pascal skew tower `q=2^r`, `r>=1`, `d>=2`.

Run the producer, producer-independent checker, SymPy reconstruction, replay,
hostile mutation suite, and release manifest from this package directory.
The release scope is `NO_BAD_EULER_OR_ROOT_NUMBER`; finite tables are only
sentinels and `route_b_invocation_allowed=false`.
