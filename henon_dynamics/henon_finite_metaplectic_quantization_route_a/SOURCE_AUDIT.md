# Source audit

The classical matrix, finite Weyl system, Fourier convention, chirp, unitary,
and antiunitary are explicitly defined in this package.  All finite-level
claims are proved by exact arithmetic in
`Q(zeta_7,sqrt(7))`; floating arithmetic is used only by an independently
written checker.

The even-modulus control is scoped to the frozen half-phase formula.  It proves
only that `1/2 mod 8` does not exist; it does not claim that every even-level
Weil or metaplectic construction is impossible.

No prime table, zero table, target spectrum, fitted parameter, Euler factor,
root number, or external data source is used.  The word "natural" refers only
to the finite metaplectic/Weyl covariance established here.  It does not mean
Hilbert--Pólya, target matching, or Route-B readiness.

No literature novelty review or external referee score has been performed,
and none is claimed.
