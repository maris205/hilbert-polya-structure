## Major issues

- **Type:** scope / construct validity.
- **Problem:** negative-time coordinates in a natural extension do not insert

- **Impact:** without an explicit object change, the claimed reopening would

- **Resolution:** theorem (6) closes the periodic-product trace-log germ built

  a new two-sided transfer operator.  All inverse-edge results are labeled
  symmetric Rauzy groupoid results.

### 2. There is no intrinsic positive roof yet

- **Type:** methodology / relevance.
- **Problem:** the AGY roof changes sign under time reversal, while absolute
  value or unit length creates a new clock.
- **Impact:** the current object cannot yet satisfy a strong Route-A orbit law.
- **Recommendation:** Phase 2 may certify only the combinatorial determinant
  germ.  The following large gate must derive a geometric reversible roof or
  stop this route.

### 3. C26 nuclearity is one-sided

- **Type:** analytic scope.
- **Problem:** inverse branches expand on the C26 complex domain.
- **Impact:** a symmetric edge matrix is legitimate, but it is not a
  two-sided AGY Bergman transfer operator.
- **Recommendation:** require a stable--unstable bidisk, anisotropic space or
  independently proved flat-trace theorem before any analytic promotion.

### 4. The general determinant framework is prior art

- **Type:** novelty.
- **Problem:** twisted Ihara determinants, group traces and matrix-weighted

- **Impact:** presenting the framework itself as new would fail novelty review.
- **Recommendation:** claim only the exact C25/C26 relation, the normalized
  finite-Weil limit in this frozen system and the semantic firewall.
