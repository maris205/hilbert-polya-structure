## Uniform release gates

### G0 -- ownership and collision firewall

Every package records primary theorem owners, nearest workspace mechanisms,
and why its state space, clock, and proof engine are independent.  Workspace
`NEW` is never represented as literature priority.

### G1 -- analytic completeness

Every arbitrary-parameter, if-and-only-if, all-prime, all-return-time,
all-flux, all-mode, quantization, or revival headline is proved under explicit
hypotheses.  Finite ledgers audit formulas and branch conventions only and are
never described as continuum or all-parameter proof.

### G2 -- independent executable evidence

Each package contains a canonical producer, a checker importing no producer
code, a separate SymPy lane, isolated two-directory byte replay, and
repaired-hash hostile mutations.  Every executable explicitly refuses
optimized Python.

### G3 -- strict serialization and evaluator lock

JSON rejects duplicate keys and nonfinite constants.  YAML rejects duplicate
or non-string keys, anchors, aliases, merges, implicit dates, unknown fields,
and type changes.  Candidate identity, baseline, date/epoch, evaluator digest,
strict tuple, Route-B lock, and scope flags are invariant.

### G4 -- hostile mathematics

Tests attack arithmetic/geometric Frobenius inversion and the ramified fibre;
Reeb normalization, missing-coordinate rotations and trivializations;
Harper phase/sign/coupling powers and repeated-edge denominators; vortex
rotation sign, modal exponents and the aspect-three wall; and Higgs action
factors, hemisphere boundary, spectrum shift and rational-revival parity.

### G5 -- substantive manuscripts

Each package retains three mathematically distinct PDFs from one conditional
LaTeX source.  Every round is built twice in fresh directories with two
LuaLaTeX passes at the frozen epoch; bytes must match, settled logs must be
warning-free, fonts embedded/subset, extracted text clean, and every page
rasterizable.  `main.pdf` equals Round 2.

### G6 -- exact package closure

Each package declares and enforces one exact content-addressed payload ledger
plus a self-excluded manifest.  The richer ARS layout retains assumptions,
claims, scope, limitations, references, reproducibility, requirements, and a
smoke test instead of deleting useful artifacts to match an older file count.
Its release gate reruns every evidence lane, all PDF audits, the manifest
ledger, the forbidden-claim firewall, and optimized-Python refusal while
rejecting build sidecars.

### G7 -- adversarial cross-review and integration

Authors swap packages.  Every blocker, major issue, and useful minor
correction is repaired and re-reviewed.  The integration pass runs all five
release gates twice, checks every declared payload and physical file, updates the
global candidate and obstruction registries, stages only C369--C373, syncs
with origin, commits and pushes, verifies `HEAD==origin/main`, and stops for
the user checkpoint before C374.
