# C315 executable lanes

- `c315_goldfish_producer.py`: deterministic exact-coefficient and
  100-decimal evidence.
- `c315_goldfish_checker.py`: producer-independent strict JSON/YAML,
  rational/Sturm and high-precision reconstruction; it imports no producer
  and locks both raw evaluation bytes and canonical full-document semantics.
- `c315_goldfish_sympy_crosscheck.py`: symbolic polynomial identities.
- `c315_goldfish_replay.py`: isolated two-run byte replay.
- `c315_goldfish_mutation.py`: repaired-hash, stale-hash, parser/YAML and
  optimized-Python attacks.
- `c315_release_manifest.py`: exact ledger, PDF and deterministic-build gate.
