# Manuscript builds

main.tex selects round two by default. main_round0.tex, main_round1.tex and main_round2.tex set the revision macro before including that file. Their PDFs are main_round0_original.pdf, main_round1.pdf and main_round2.pdf; main.pdf is byte-identical to round two.

Each round adds substantive mathematical content. Deterministic two-directory LuaLaTeX builds, font/text/raster audits and actual settled .txt logs are controlled by the release script. These are technical source-theorem manuscripts with no submission or external peer-review claim.
