# C391: supercritical inverse-square domains and scale cycle

This package closes all unit-modulus self-adjoint boundary conditions for the strictly supercritical half-line inverse-square Hamiltonian. The single theorem joins the classical finite-collision atlas, every negative bound level, the complete continuous spectral resolution, scattering, the domain dilation cycle, and specific ordinary heat/determinant obstructions.
