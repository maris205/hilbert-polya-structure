# Independent verification lanes

Producer: pure integer permutation determinant and gcds of all minors. Independent checker: Newton power sums, separate SymPy matrix powers and Smith normal form. Symbolic lane: all-parameter form/reversal/exterior identities and exact moments; mpmath root formulas at 70 digits. No checker import of the producer.

The checker does not import the producer. Common serialization/release structure is adapted from C392, not claimed as a newly designed algorithm. Duplicate JSON/YAML keys, alias/anchor/tag/merge YAML, numeric booleans/floats and scope integer-zero substitutions are rejected. The evaluator's entire semantic payload is SHA256-locked. Mathematical arrays are reconstructed with strict types and membership. The release entry performs this independent gate before any write, then exact file membership, all lanes and fresh deterministic PDF comparisons.
