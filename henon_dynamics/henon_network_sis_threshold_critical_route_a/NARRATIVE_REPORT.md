# Narrative report

The strict threshold cases of a cooperative SIS network are structurally
clean, but the equality face contains the sharper dynamical information.  The
linear Perron mode is neutral there, while infection saturation supplies the
first nonzero drift.  Projecting that quadratic term onto normalized left and
right Perron vectors produces the exact coefficient
`kappa=beta*w^T*diag(v)*A*v` and the vector limit `t*x(t)->v/kappa`.

The same source owner also supports a complete supercritical statement.  Strict
subhomogeneity forbids two positive equilibria, order squeezing gives global
attraction, and a positive-vector test makes the endemic Jacobian Hurwitz.
Thus the paper advances from a threshold sign to a complete all-chamber flow
theorem.  It remains Route-A rejected because none of these network objects
provides arithmetic primitive cycles or a target determinant.
