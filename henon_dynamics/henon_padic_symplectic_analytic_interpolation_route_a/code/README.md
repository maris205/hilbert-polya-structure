# Code lanes

The producer uses sparse integer polynomial arithmetic, shell formulas, and sequential modular shears. The independent checker discovers every cycle of the expanded polynomial permutation, reconstructs differences by symbolic substitution, and compares every data node with exact types. No producer module is imported by the checker.

The SymPy lane checks exact inverse, reversal, symplectic and scaling identities and the finite trace/coefficient normalization. The replay lane has two fresh working directories. The hostile lane repairs payload hashes before attacks, tests strict JSON, and invokes actual copied release writes under ten invalid YAML variants. The release reproduces all finite lanes, all six-script optimized-mode refusals, and every PDF build before reconstructing the exact file ledger.

See `../REPRODUCIBILITY.md` for the complete commands and `../results/TEST_REPORT.md` for actual output. No floating-point, high-precision interval, statistical, or external-model claim is made.
