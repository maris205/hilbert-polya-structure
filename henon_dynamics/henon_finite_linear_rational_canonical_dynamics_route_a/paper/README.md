# Paper build

Build with LuaLaTeX and `SOURCE_DATE_EPOCH=1787788800`.  Set
`\CRevisionRound` to 0, 1, or 2; the final `main.pdf` equals round 2.  The
release audit requires two independent byte-identical builds, embedded/subset
fonts, extractable text, and no LaTeX warning, overfull, or underfull records.
