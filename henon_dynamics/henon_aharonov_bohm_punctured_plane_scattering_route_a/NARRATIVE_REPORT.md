# Narrative report

The complete result is an operator-to-scattering-to-obstruction theorem. Starting with the Friedrichs form prevents an unspecified origin extension from changing the object. The Hankel transform proves that no channels or spectral components are missing. Incoming/outgoing phases then determine an angular operator whose forward singularity must be treated as a distribution.

The crucial global check is stronger than observing a stable symmetric determinant cutoff. Symmetric windows give exp(-i pi beta), while a shifted exhaustive window gives one; both are exact for every cutoff. The missing trace-class hypothesis is independently exposed by a noncompact orthonormal sequence. The heat kernel supplies a second instance of the local/global distinction: a convergent local series exists although the full heat operator has infinite trace.

Finally, physical time reversal has a position-preserving definition. At generic flux a reflection-composed antiunitary exists but does not satisfy that definition. This distinction blocks an abstract spectral symmetry from being interpreted as a physical one. These connected boundaries, rather than additional sampled phase values, are the main package increment.
