# Executable lanes

The producer uses exact fractions for angular, gauge, symmetry and cutoff rows, then fixed-precision modified-Bessel and cross-section values. The independent checker imports no producer and reconstructs phases piecewise, gauge identities through squared momenta, heat values through ordinary-Bessel spectral integration, and cross sections through complex amplitudes.

SymPy is a separate exact identity lane. Replay copies only the producer and evaluation into two fresh directories. Mutations repair their payload hashes before the independent checker is called. The release script checks all lanes, strict fixed file membership, deterministic PDF rebuilds, embedded/subset fonts, text extraction, raster rendering, and false scope flags. It is non-writing without explicit build/write switches.

All release modes invoke the checker's hard raw-hash and strict-parsing YAML gate before generation. Three isolated unknown-key, false-to-zero, and unquoted-date attacks run the actual `--write` entry point and require rejection before any manifest exists. The mutation total is 19/19. Real settled compiler logs are retained as `.txt` files to avoid Git's ignored `.log` pattern.
