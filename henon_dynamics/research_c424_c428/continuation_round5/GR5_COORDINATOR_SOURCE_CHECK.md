## 两个实际主来源

1. Lee–Silverman，*GIT Stability of Henon Maps*。
   [arXiv 元数据](https://arxiv.org/abs/1907.13247) 仅列
   v1，2019-07-30；[v1 HTML](https://arxiv.org/html/1907.13247v1)
   实读摘要、引言、Definition 1.1、Theorem 1.2、Remark 1.3。
   HTML 的动态排版 Date 显示 2026-08-24，不用它取代版本历史。
   Brown 作者机构条目确认期刊为 Proc. AMS 148(10) (2020),
   4263–4272；未读取出版社最终正文，未核其全部证明。

   所求是特征零代数闭域上有理映射参数空间的 $\mathrm{SL}_3$
   GIT 稳定性，非整数环局部模型分类。其 $d\ge3$ 不稳定结论
   不能当成 regular good reduction 不存在：模型
   $(x,y)\mapsto(y,y^d-x)$ 正反映射皆整系数、约化次数均为 $d$，
   两不定点各为 $[1:0:0]$ 和 $[0:1:0]$，在每个有限处满足本题
   三条件，而它在上述 GIT 意义下不稳定。这是直接定义区分，
   不是新论文结果；GIT 文献其他未读部分不作绝对缺失断言。

2. *Hénon maps: a list of open problems*，2024-08-13，
   [期刊主站 §11](https://amj.math.stonybrook.edu/html-articles/Files-2015-2024/23-70/index.html)。
   实际打开页面，查找 reduction，并读取 §11 的数域段至该节
   结束。其涉及好约化的段落在已选广义 Hénon 坐标下要求系数为
   S-整数、首项与 Jacobian 为 S-单位，然后研究原生整除序列。
   这个段落不提供任意仿射好坐标的必要性及非主理想全局拼接；
   不把“列出问题的综述”视为本题全球开放性的证明。
