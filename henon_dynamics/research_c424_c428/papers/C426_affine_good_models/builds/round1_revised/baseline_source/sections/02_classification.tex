\section{The classification}\label{sec:classification}

Fix a number field $K$, put $R=\OO_K$, and take $a\in K^\times$
and $f\in K[Y]$ of degree $d\ge2$. Let
\begin{equation}\label{eq:Fq}
 F(x,y)=(y,f(y)-ax),\qquad
 q(Y)=f(Y)-aY=\sum_{j=0}^d q_jY^j.
\end{equation}
Write $b=q_d\ne0$. For a finite place $v$, let $E=K_v$, let
$O=\OO_{K_v}$, and normalize $v:E^\times\to\ZZ$.
The residue field is $\kappa_v$. A coordinate map $T$ sends the new
coordinates to the original ones, so its model is $G=T^{-1}FT$.

\begin{definition}\label{def:good}
An affine map $T\in\Aff(\mathbb A^2_E)$ is a \emph{good coordinate
map} if $G$ and $G^{-1}$ have coefficients in $O$, both coefficient
reductions have degree $d$, and their degree-$d$ homogenizations have
disjoint indeterminacy sets in $\PP^2_{\overline{\kappa_v}}$.
A global good coordinate map is a $T\in\Aff(\mathbb A^2_K)$ satisfying
these conditions at every finite place.
\end{definition}

The geometric condition in Definition~\ref{def:good} is checked over
the algebraic closure of the residue field. The coordinate map itself
must remain over $K_v$ or $K$ as specified; extending the field is not
allowed. Write $\Aff_2(O)=\GL_2(O)\ltimes O^2$, and similarly for $R$.
All ideals below are nonzero fractional ideals.

\begin{theorem}[All affine good models]\label{thm:main}
For the map \eqref{eq:Fq}, the following statements hold.
\begin{enumerate}
\item At a finite place $v$, good coordinates exist if and only if
\begin{equation}\label{eq:localconditions}
 v(a)=0,\qquad k_v=-\frac{v(b)}{d-1}\in\ZZ,
 \qquad Q_{s,r}(Y):=\frac{q(sY+r)-r}{s}\in O[Y]
\end{equation}
for some $r\in E$, where $s\in E^\times$ is any fixed element with
$v(s)=k_v$. The leading coefficient of $Q_{s,r}$ is then a unit.
Set
\begin{equation}\label{eq:candidates}
 r_0=-\frac{q_{d-1}}{db},\qquad e_v=v(d),\qquad
 r=r_0+\frac{s}{d}\beta\quad(\beta\in B_v),
\end{equation}
where $B_v$ is any full set of representatives for $O/dO$.
It suffices to check the $|\kappa_v|^{e_v}$ candidates in
\eqref{eq:candidates}; at most one passes modulo $sO$.
\item If $(s,r)$ passes, define
$S_{s,r}(x,y)=(sx+r,sy+r)$. The entire set of local good
coordinate maps is
\begin{equation}\label{eq:localcoset}
 S_{s,r}\Aff_2(O).
\end{equation}
Every such map has image lattice $(r+sO)^2$, and this disc is unique.
The expression \eqref{eq:localcoset} is a left coset, or equivalently
one orbit under right composition by the integral affine group.
\item If all local tests pass, put
\begin{equation}\label{eq:scaleideal}
 I=\prod_{v\text{ finite}}\mathfrak p_v^{k_v},
 \qquad (b)I^{d-1}=R.
\end{equation}
There is an $r\in K$ for which every local good disc is
$r+I\OO_{K_v}$. A global good coordinate map exists if and only if
\begin{equation}\label{eq:obstruction}
 I\oplus I\text{ is free over }R
 \quad\Longleftrightarrow\quad I^2\text{ is principal}
 \quad\Longleftrightarrow\quad [I]^2=1\text{ in }\Cl(R).
\end{equation}
When these conditions hold, all global good coordinate maps are exactly
\begin{equation}\label{eq:allglobal}
 \left\{z\longmapsto Az+c:
 A R^2=I\oplus I,\quad c-(r,r)\in I\oplus I\right\}.
\end{equation}
This set is one left coset of $\Aff_2(R)$. In every such model,
both the map and its inverse have coefficients in $R$.
\end{enumerate}
All tests and descriptions are independent of the choices of local
scale generators, residue representatives and patched centre.
\end{theorem}

The theorem separates four exhaustive failure branches: a nonunit
Jacobian, a nonintegral scale exponent, failure of every local centre
candidate, and a nonprincipal ideal square after all local tests pass.
There is no imposed bound on degree, ramification or the class group.

\begin{remark}
The polynomial $q$ is an algebraic device for identifying the good
coordinate disc. Its iterates will occur in one uniqueness proof; they
do not replace the native iterations of the H\'enon map. The observable
classified in this article is the set of good models, not periodic
orbits or their counts.
\end{remark}
