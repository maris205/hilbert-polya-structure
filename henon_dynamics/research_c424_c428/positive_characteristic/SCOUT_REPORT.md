## PC424-D: where the proposed source route stops

The shortcut “the components are geometrically irreducible, therefore
the standard dynatomic polynomial is irreducible” changes the quantified
object. D2 in the audit explicitly prevents that inference.
The frozen question needs a count and classification of all components,
not a field-of-definition theorem for each already chosen component.

The second shortcut is equally invalid: singularity or bad reduction
does not imply more than one irreducible component. A source supplying
a singular point has not supplied a factorization. Conversely, generic
characteristic-zero irreducibility cannot be carried through a singular
special fibre without an additional argument.

The cheap test therefore failed at the required place: no all-$(p,e)$
transitive wild-specialization mechanism has been derived. One would
need, for example, a proved transitivity statement for the surviving
inertia action, or another uniform component argument accounting for
all wild collisions. Neither the accessible source hypotheses nor a
new hand argument here establish it. The exceptional smallest pair
$(p,e)=(3,1)$ remains inside the original contract, not silently removed.

The required increment could be substantial if proved, but scope and
source gaps make this **not ready for admission**. No finite factor

## PC424-L: exact elementary checks and the missing implication

The original map is $T_{c,h}(x,y)=(x^2+c,y+h(x))$ on the full affine
plane over $k=\overline{\mathbb F}_p$. Its forward base clock is not
Frobenius, and its fibre update is not the old $y^p+P(x)$ update.
Every sum below is on an ordinary primitive base orbit.

The short hand checks establish:

1. $B_c\subseteq K_c$, and the elementary lifted-period rule is $r$ or
   $pr$ according to whether the primitive orbit sum is zero.
2. $h\in K_c$ is equivalent to existence of an arbitrary function
   $U:k\to k$ with $U\circ f_c-U=h$. On each finite extension it gives
   a polynomial transfer **only as a function on that finite field**,
   with an interpolation degree bound growing with field size.
3. As $k$-vector spaces,
   $k[x]=B_c\oplus(k\oplus xk[x^2])$. Thus the unresolved problem is
   detection of every nonzero normal-form class by a primitive orbit sum.
4. $h^p\in B_c$ if and only if $h\in B_c$. The proof differentiates a
   putative transfer and uses the unequal degrees in
   $2xQ'(x^2+c)-Q'(x)$. This rules out direct reuse of the old radicial
   ambiguity, not all possible defects.
5. Fixed points and a genuine two-cycle eliminate nonzero linear
   elements of $K_c$, including the parabolic parameter $c=1/4$.
   This is a boundary check, not a theorem for unbounded degree.

The missing implication has a concrete form. A transfer bound independent
of the finite-field extension degree would turn the finite interpolation
identities into a polynomial identity by root counting. The construction
only gives degree less than the field cardinality, so it does not supply
that bound. No cancellation theorem for all odd-support polynomials and
all primitive orbit lengths was proved.

After subtracting the elementary functional-graph/cohomology facts,
the proposed paper-level regularity theorem remains entirely open in
this scout. A complete defect classification would also answer the
frozen alternative, but none is derived. The real hyperbolic Livšic
analogy does not repair this gap. **NOT CURRENTLY JUSTIFIED** is a
proof-status statement, not a universal impossibility result.
