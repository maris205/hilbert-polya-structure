[原合同](FROZEN_QUESTIONS.md)，本文件不直接宣称新篇准入。
令 `A=|a|`，使用原生 `F=F_(n,a)` 与不变量 `K=K_(n,a)`。

## 1. 主张 V4-H：每一整数层的显式完整周期高度界

对任意 `n>=3`、`a,D in Z`，每个满足 `K(P)=D` 的普通整数周期点
及其整个轨道均属于盒

`[-R,R]^n,  R=2n²(A+|D|+n+2)`。                         (H0)

所有零、符号、单位、退化层均包含。这个界依赖层 D，不是跨所有层
同时有界，也不声称最优。

### 1.1 最大高度处的两次更新

`h(P)=sum |x_i|`。在真正有限的周期轨道上选 h 最大的一点
`P=(y,z_1,...,z_(n-2),x)`，记

`u=|x|, v=|y|, Q=product z_j, S=u+v, M=max(u,v,|z_j|)`。

前一个 F 状态由先更新 P 的最后坐标 x，再循环排列得到；后一个
状态由先更新第一个坐标 y，再循环排列得到。因此 h 的最大性给出

`|Qy+a-x|<=u,  |Qx+a-y|<=v`。                           (H1)

这里两条不等式在同一个 P 上成立，不假定其他 Vieta 因子也下降。
三角不等式相加给出经典 fork 估计的强迫版

`(|Q|-2)S<=2A`。                                         (H2)

当 `|Q|=2` 时，两条不等式还给出

`|u-v|<=A/2`。                                            (H3)

以下分情况证明

`M<=B,  B=2n(A+|D|+n+2)`。                              (H4)

由于轨道任一点的单坐标绝对值不超过其 h，而 `h<=h(P)<=nB`，
(H4) 即推出 (H0)。选 h 最大而不是单坐标最大的区别保留了这个 n 因子。

### 1.2 Q=0

整坐标乘积为零，故

`D=sum x_i²-a sum x_i >= M²-nAM`。

若 `M>nA+|D|+1`，则 `M(M-nA)>|D|`，与上式矛盾。
因此 M 小于 (H4) 的宽松上界。无需假定后续乘积继续为零。

### 1.3 |Q|>=3

若 S=0，(H1) 强制 a=0，此时 `D=sum z_j²>=M²`。
若 S>0，由整数性 `S>=1`，(H2) 给出

`S<=2A,  |Q|<=2+2A`。

Q 非零，所以每个整数 z_j 非零且 `|z_j|<=|Q|`；于是
`M<=2+2A`。两个子情况均受 (H4) 控制。

### 1.4 |Q|=1

所有 `|z_j|=1`。利用 `|xy|<=(x²+y²)/2`，有

`D=x²+y²-Qxy+sum z_j²-a(x+y+sum z_j)`

`  >= M²/2-nAM`。

若 `M>2nA+2|D|+2`，则 `M(M-2nA)>2|D|`，矛盾。
这也严格小于 B。

### 1.5 |Q|=2：小坐标、符号与同号强迫

每个 `|z_j|<=2`。若 `min(u,v)<=A+1`，(H3) 立即给出
`M<=max(2,3A/2+1)<B`。

以下假定 `u,v>A+1`。实数恒等式

`|b-x|<=|x|  iff  b 位于 0 与 2x 之间`

表明 `Qy+a` 与 x 同号（此时不为零），`Qx+a` 与 y 同号。
因为 `2u,2v>A`，其符号不受 a 改变，故 `Qxy>0`。

若 Q=2，写 `x=σu, y=σv`，`σ in {±1}`。(H1) 化为

`0<=2v+σa<=2u,  0<=2u+σa<=2v`，

所以 `σa<=-2|u-v|`。当 a 非零时，`σa=-A`，于是

`D=(u-v)²+A(u+v)+sum(z_j²-a z_j)`

` >= A(u+v)-2A(n-2)`。

因 A 为正整数，`u+v<=|D|+2(n-2)`；M 再次受 B 控制。
当 Q=2 且 a=0 时，上述两式强制 u=v，而且 x、y 两个更新都固定。

### 1.6 |Q|=2 的剩余退化方向不能维持最大高度

对于 Q=-2，写 `x=σu, y=-σv`。(H1) 化为

`0<=2v+σa<=2u,  0<=2u-σa<=2v`。

因此 `σa=2(u-v)`，即 `x+y=a/2`。直接代入可见 x、y 的
两个更新也各自固定；奇数 a 时这个整数子情况自动为空。
上节 Q=2,a=0 的残留与此处都具有：

- x、y 固定，且 (H3) 成立；
- `|z_j|<=2`，Q 非零；
- 下一次原生 F 更新 y 后，紧接着更新 z_1。

更新 y 没有改变 P 的数值，只循环了坐标。因此下一次更新 z_1 为

`z'_1=(Q/z_1)xy+a-z_1`。

`Q/z_1` 是非零整数，故

`uv-A-2 <= |z'_1| <= h(P) <= u+v+2(n-2)`。

第二个不等式来自两次 F 后仍在同一周期轨道，并非假定 z_1 下降。
整理得到

`(u-1)(v-1)<=A+2n-1`。                                   (H5)

若 `max(u,v)>A+2n+3`，则由 (H3)，两个左因子分别严格大于
`A+2n+2` 与 `A/2+2n+2`，其积大于 `A+2n-1`，矛盾。
所以最后情形仍有 `M<=A+2n+3<B`。全部情况穷尽，(H0) 得证。

### 1.7 有效性推论与实际执行边界

全局逆映射为
`F^(-1)(x_1,...,x_n)=(product_(j=1)^(n-1) x_j+a-x_n,x_1,...,x_(n-1))`。
以任一坐标 t 为变量时，K 中的变动部分是 `t²-(Q_i+a)t`，
其中 Q_i 是其余坐标之积；替换 `t -> Q_i+a-t` 保持此二次式。
K 还对循环排列不变，故 F 保持 K，全部整数层均适用。

对给定 n,a,D，精确枚举盒 `[-R,R]^n` 中 K=D 的点，保留目标也在
此有限集合中的 F 边。所有循环顶点恰是该层全部普通周期点；每个
图循环长度就是原生最小周期。正、逆映射均为整系数多项式，故无需
约分、smoothness 或局部可逆例外。

甚至无需枚举整盒来判定一个给定 P：先算 D 和 R，若 P 出盒则不周期；
否则迭代，首次回到 P 得到最小周期，首次出盒排除周期。若始终未出盒，
至多 `(2R+1)^n` 次后必有状态重复；F 的全局双射性使首次重复只能
回到起点，不存在不周期前尾。因此这是每个整数输入都终止的判定算法。
也可直接建完整有限层图，获得准确点数、周期数与有限普通 zeta 乘积。
这些是标准有限图推论，不分拆新篇。

**尚未运行任何上述大盒或迭代程序。** 定理证明的是所有 n,a,D 的
统一终止规则，不是一张已经算出的全参数周期表。所给界也不导出
只依赖 n,a 的最小周期统一上界。

## 2. 主张 V4-Z：整个“每步乘积皆零”子域的显式分类

令 `J_a(x_0,...,x_(n-1))=(x_1,...,x_(n-1),a-x_0)`，
有 `J_a^n(P)=a·1-P`、`J_a^(2n)=id`。给定 P，定义长度 2n 的循环字

`w=(x_0,...,x_(n-1),a-x_0,...,a-x_(n-1))`。

下列两条等价：

1. 原生 F 轨道的每一次更新乘积均为零。
2. w 的每个循环连续长度 n-1 子字都包含零。

证明：1 使每步 F=J_a，故整个轨道就是该 2n 循环字，得到 2。
反之，2 在第一个更新成立，F=J_a；此后对循环字移位归纳即可，
包含无限前后时间。等价地，w 的相邻零位置之间的最大循环间距
不超过 n-1。无零集合不满足条件。

因此整个子域上的点都周期，最小周期恰是 w 的最小正循环移位周期，
是 2n 的因数；可逐个检查 2n 的约数得到精确值。

### 2.1 a=0：原有两零子域，无新所有权

此时零位置成相距 n 的配对。条件恰为初始 n 个坐标至少两个为零：
若只有一个零，循环间距为 n，失败；若有至少两个零，每段间距都
至多 n-1。于是得到 n-2 维坐标平面的有限并；这是已有 unforced
dihedral 结构和本批首轮控制，不宣称本轮首次发现。

### 2.2 a 非零：至多 n-3 维，且达到此维数

每对相距 n 的位置最多一个为零。枚举集合

`Z subset {0,...,2n-1}`，

要求 Z 不含一对相距 n 的位置，且相邻 Z 元素的最大循环间距≤n-1。
对每个这样的 Z 施加以下坐标约束，其他坐标任意为整数：

`x_i=0` 若 `i in Z`；`x_i=a` 若 `i+n in Z`（`0<=i<n`）。

得到的有限个整数仿射坐标子空间之并，恰是完整零乘积子域。
这里维数指这些子空间中最大自由整数参数数，等价于其 Zariski
闭包的维数；“零乘积”始终指每次更新中的 n-1 个坐标乘积。
允许自由坐标后来也等于 0 或 a；这只增加零位置，不破坏条件。
每个输入都被其实际零位置所对应的一个子空间覆盖。

覆盖圆周 2n 且每个间距至多 n-1 需要至少三个零；所以每个上述
子空间维数≤n-3。n=3 时只可能是 `Z={0,2,4}` 及其一次移位，
恰得到交替 0,a 的两点。
n>=4 时选 `Z={0,n-2,2n-3}`：间距为 n-2、n-1、3，均≤n-1，
且无相距 n 的一对。因此有 n-3 个自由整数坐标，界达到。

特别是 n=4，对任意 `a!=0` 和 t，

`P=(0,a,0,t)`，

`w=(0,a,0,t,a,0,a,a-t)`

具有精确最小周期 8：已知周期整除 8，而第四次 J_a 把首坐标 0
变成非零 a，排除 1、2、4。这是任意非零 forcing 都存在的无界族。
所以把固定非零 a、D 任意的全格点周期集装入一个只依赖 n,a 的
高度盒也是错误的；固定 D 的界 (H0) 不受此反例影响。

在这个子域，整坐标乘积为零，K 就是 `sum x_i(x_i-a)`。
因此固定 D 的部分是显式正定二次等式的整数点，仍有限。

## 3. 闭合边界，不把不同强度偷换

(H0) 覆盖**所有**整数周期点，不仅仅零乘积子域；因此已经得到
全 n,a,D、全部整数输入的有效逐层周期判定与精确最小周期程序。
(V4-Z) 则只参数化全程乘积为零的子域，不声称涵盖所有无界族。

原冻结合同还明确要求跨所有层穷尽无界通道并给出有限余部；这不是
可选标准，这部分仍未完成。尚无所有“有些步骤乘积非零”的无界
周期族参数化，也无与 D 无关的有限余部；此外尚无只依赖 n,a 的
最小周期上界。不能将逐层有限程序改名成已得到这种全局结构。
V4-H 的全输入逐层有效判定已经完成，不因原结构合同尚未闭合而
回退为未证。数学闭合强度和独立实质性必须分开裁决。
