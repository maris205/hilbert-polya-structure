# C96 code

`c96_coverage_order_statistics.py` produces the exact receipt.  `c96_coverage_order_statistics_checker.py` independently decodes all source bitsets and rebuilds it.  `c96_sympy_crosscheck.py` verifies all twenty PGFs, moments, and 340 factorial certificates.  `c96_replay_checker.py` runs the checker in a clean deterministic environment.  `c96_mutation_test.py` rejects 15 hostile semantic changes.  The release ledger is generated by `c96_release_manifest.py`.
