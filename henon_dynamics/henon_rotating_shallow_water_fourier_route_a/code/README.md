# C217 verification code

The producer writes the finite deterministic Fourier ledger.  The independent
checker reconstructs every block with NumPy/SciPy and checks the characteristic
polynomial, projector algebra, exponential, unitarity, shell counts, boundary
faces, and scope closure.  The SymPy script is a separate exact algebra path;
replay checks byte identity and mutation checks repaired/stale hashes plus
recursive unknown-key closure.
