# Narrative report

The advance is a complete operator atlas for a PDE owner.  Rather than listing
normal-mode frequencies, the package gives a canonical projector resolution at
every lattice mode, exact same-clock propagators, shell multiplicities, and the
degenerate stationary spaces.  It also separates a true finite-support
periodicity statement from the nonperiodic infinite-dimensional unitary group.

The numerical ledger is a finite algebraic control, not a claim of arithmetic
meaning.  The strict scope firewall rejects target primes, zeros, Euler
factors, root numbers, automorphy, and Hilbert--Polya operators.
