# C107 — Open-hole Hénon survivor and escape determinant

C107 freezes the certified four-state local H6 symbolic interface and removes
the geometric rectangle/state `3` before every iterate. The resulting survivor
matrix is an exact open transfer pilot:

\[
B=\begin{pmatrix}1&0&1\\1&0&0\\0&1&0\end{pmatrix},
\qquad \det(I-zB)=1-z-z^3.
\]

Primitive survivor counts, traces, alternative-hole controls, independent
reconstruction, SymPy, replay, and mutation checks are all shipped.

The result is deliberately bounded: `A1_PARTIAL_CERTIFIED` for the frozen
symbolic survivor and `A2_CERTIFIED_PREFIX` for the discrete open determinant.
It is not an analytic open Hénon Fredholm theorem, and makes no arithmetic,
zero, or Route-B claim.

## Reproduce

```bash
cd henon_dynamics/henon_open_hole_route_a
python3 code/c107_open_hole_producer.py
python3 code/c107_open_hole_checker.py
python3 code/c107_sympy_crosscheck.py
python3 code/c107_replay.py
python3 code/c107_mutation.py
```

The paper is `paper/main.pdf`; the release ledger is generated by
`code/c107_release_manifest.py`.
