# Theorem package — C107

**Finite survivor proposition.**  With

[
A=\begin{pmatrix}1&0&1&0\\1&0&0&0\\0&1&0&1\\0&1&0&0\end{pmatrix}
]

and frozen hole state (3), the survivor matrix is

[
B=\begin{pmatrix}1&0&1\\1&0&0\\0&1&0\end{pmatrix},qquad
\det(I-zB)=1-z-z^3.
]

For (t_n=\operatorname{tr}(B^n)) and primitive necklace counts (p_n),
(t_n=\sum_{d\mid n}d p_d).  The producer and independent checker certify
these identities through (n=12).

**Boundary.**  This is a finite matrix statement.  It does not imply that a
geometric open Hénon repeller has this coding or that an analytic Fredholm
operator owns the determinant.
