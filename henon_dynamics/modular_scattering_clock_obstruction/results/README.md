# Result artifacts

All files are regenerated by `python code/modular_clock.py --output results`
unless stated otherwise.

| File | Role | Proof status |
|---|---|---|
| `exact_certificates.json` | source lock, exact witnesses, positive rigidity family, Chebyshev identities | finite exact certificate for separately proved theorems |
| `double_coset_counts.csv` | \(\varphi(c)\) classification through \(c=80\) | regression, not proof of all levels |
| `gauss_word_clock_audit.csv` | canonical primitive even words through length 6, digits 1--3 | finite incidence audit |
| `homogenization.csv` | exact formula evaluated at 80 digits through power 24 | numerical regression for an exact identity |
| `dirichlet_convergence.csv` | totient partial sums at frozen points and cutoffs | bounded-tail numerical regression |
| `summary.json` | compact machine-readable verdict and metrics | derived summary |
| `independent_check.json` | independent reimplementation and artifact checks | generated by `code/independent_check.py` |

No prime table, Riemann-zero table, fitted scale, or trained parameter is read.
Integer matrix identities are exact.  `mpmath` is confined to frozen
high-precision evaluations of analytically proved formulas.
