# Code

`c72_essential_ladder.py` certifies the Möbius/repetition regrouping, the
nonzero channel coefficient, the positive singularity ladder, dependency
hashes, and claim firewalls. `independent_check.py` reconstructs the channel
coefficient without importing the main module. `test_c72.py` compares the
primitive-product and regrouped coefficients through degree 100.

Run `bash code/run_c72.sh` from the project directory or its parent.
