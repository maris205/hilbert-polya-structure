# Hostile audit

Attacks change candidate, obstruction, source, date, evaluator authority,
evaluation digest, Route-A verdict and forbidden flags; weaken the strict
threshold; alter DOI ownership; inject unreduced rationals; change reflection
determinants, event states, regulators, active axes and complementarity;
corrupt fixed-point, pause and Picard ledgers; erase critical nonuniqueness or
no-solution witnesses; and falsify enumeration counts.

Separate parser attacks introduce duplicate and nonfinite JSON plus YAML
timestamp coercion, duplicate/non-string keys, anchors, aliases, merges,
unknown/missing fields, tuple changes, artifact-path changes and scope
escalation.  Every semantic evidence mutation is tried with both its stale
payload hash and a repaired canonical hash.  The fixed-point initial-value
closure is now a directly mutated theorem field.  All 70 attacks are rejected.
