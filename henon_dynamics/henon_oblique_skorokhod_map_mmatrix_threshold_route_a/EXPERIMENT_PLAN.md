# Experiment plan

Finite computation is a convention and implementation receipt, not the proof
of the all-input theorem.

1. Freeze six rational reflection matrices spanning positive two-way coupling,
   both triangular faces and normal reflection.
2. Drive them by exact cadlag step paths containing single-axis and simultaneous
   negative jumps, corner contact, release and repeated nodes.
3. Solve every event by an exhaustive rational active-set LCP and independently
   verify state nonnegativity, regulator monotonicity and post-jump
   complementarity.
4. Reconstruct the running-supremum fixed point, pause-expanded time changes and
   nine Picard iterates for each positive two-way fixture.
5. Lock critical nonunique regulator families and three critical/supercritical
   negative-jump no-solution certificates.
6. Run a producer-independent checker, a larger SymPy grid, two isolated byte
   replays, stale and repaired-hash hostile mutations, strict JSON/YAML parsing,
   optimized-Python refusal and the deterministic three-round PDF release gate.
