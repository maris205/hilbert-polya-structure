# C149 hostile audit

The mutation harness changes semantic fields, repairs the payload hash, and
requires rejection by the independent checker.  It covers source/date/scope,
Thue--Morse certificates, cycle lengths and successor edges, fixed and exact
counts, zeta coefficients, minimality, Route-A coordinates, scope flags, and
nonclaims.  All 41 repaired-hash cases and the separate stale-hash case are
rejected.  This tests semantics rather than transport integrity alone.
