# Executable evidence plan

The computation is a regression certificate for the convention-sensitive
finite examples; it is not the proof of the all-rank theorem.

1. The producer builds exact integral Cartan matrices for `A1--A4`, `B2--B3`,
   `C2--C3`, `D4`, `G2`, and `A2+A1`, then exhausts every complete legal firing
   word for 23 strict/wall/zero cases.
2. It records exact case summaries, every branch, every depth level, and eight
   boundary statements under a canonical JSON payload hash.
3. The independent checker imports no producer code.  It constructs each root
   orbit, selects positive roots, enumerates the Weyl group, computes inversion
   lengths, `w_0`, `Phi_J`, `w_J`, `W^J`, `w_0w_J`, and the quotient weak-order
   path DAG.  It compares that reconstruction with the receipt while also
   rejecting duplicate JSON keys at every depth and locking exact schemas,
   strict scalar types, complete unique grids, order, and every contract value.
4. The SymPy gate verifies simple-reflection involutions, Cartan determinants,
   braid orders, characteristic polynomials, root counts, length formulas, and
   endpoint products independently at the matrix level.
5. The replay gate produces the canonical evidence twice in distinct fresh
   directory trees and demands byte identity with the archived receipt.
6. The hostile audit applies raw duplicate-key attacks and repaired-hash
   semantic, schema, strict-type, missing, unknown, and drop-replace mutations
   across metadata, contracts, cases, branches, levels, boundaries and Route
   fields, plus a stale-hash control.  Every attack must be rejected.
7. The release gate performs all code checks, duplicate-key-safe YAML parsing,
   exact 27-payload/28-physical ledger closure, and two fresh deterministic
   LuaLaTeX builds of each substantive paper round.

Expected frozen counts are 23 case rows, 3332 complete branch rows, 143 level
rows, and eight boundary rows: 3506 regression rows in total.  The independent
checker must report 19056 assertions, the SymPy gate 577 checks, and the hostile
audit 84/84 rejections.
