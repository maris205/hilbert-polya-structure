# Narrative report

The experiment treats a two-phase Hénon cocycle as a clocked dynamical
object.  A block contains one branch choice at phase 0 followed by one at
phase 1, so the product `B_1 B_0` is retained rather than commuted.  The
frozen adjacency supplies a small admissible language; it is intentionally
declared a symbolic pilot.  Exact enumeration yields 24 primitive necklaces
for block periods 1--6 (counts 3, 0, 2, 4, 6, 9).  The chronological transfer
trace vector is `(-4,74,-184,2214,-7604,73538)`.  Reversing the phase order
changes the vector from period 3 onward to `(-4,74,8,1702,4556,34370)`, while
the same-phase control gives `(-2,38,202,-986,10538,-26626)`.  Seventeen
primitive rows already witness a nonzero chronological-minus-reversed trace.

The result is therefore a useful structural control: non-autonomous ordering
is not erased at the finite word level.  It is not evidence of prime coding,
global zeros, or an analytic determinant.  All such claims remain outside the
scope firewall.
