# Preserved C421 mathematical evidence

These preserve the already accepted IR1 proof-stage artifacts, not new
executions. All mathematical proofs, programs, machine outputs, summaries
and proof-review reports are byte-identical to their originals. Only two
repository-context navigation links in the copied coordinator
`integral_return_review/SOURCE_AUDIT.md` were rebased for this deeper
package location; its scientific/source text is unchanged. The original
source audit outside this package was not modified. The relative
`integral_return/` and
`integral_return_review/finite_core/` layout is deliberately retained:
the independent certifier resolves its author input using that layout.

The article prints the analytic reduction, both complete mathematical
algorithms and the full primary certifier. The complete raw output and
the independent implementation are here so that finite certification
is reproducible, not hidden behind aggregate counters.

Do not run these scripts in this frozen evidence tree: they write outputs
beside their source. To reproduce, copy this supplement into a fresh
scratch directory and run the primary script with ordinary Python
without `-O`, followed by the independent script. The primary script
uses assertions; the independent uses explicit exceptions. Historical
runtime fields naturally differ on a new execution and are not semantic
cycle identifiers. No rerun is needed for manuscript compilation.

The review files document internal AI-assisted mathematical checks,
not human peer review or the forthcoming two manuscript review rounds.

The historical source-proof headers saying draft or candidate are kept
unchanged. Acceptance is recorded by the accompanying coordinator review
and the batch admission decision, not by editing those historical bytes.
