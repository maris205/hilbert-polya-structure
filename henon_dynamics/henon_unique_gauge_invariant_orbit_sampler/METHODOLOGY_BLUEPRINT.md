# Methodology blueprint

1. Model a normalized sampler on a primitive `n`-cycle by real weights `w_j`.
2. Compute the adjoint of the cyclic coboundary incidence matrix exactly.
3. Prove its normalized left kernel contains only `(1/n,...,1/n)`.
4. Produce one-site witnesses for every nonuniform sampler.
5. Import P64's primitive orbit-averaged equidistribution and entropy law.
6. Derive the universal pressure, finite gauge invariance, and Lipschitz law.
7. Lock all claims with independent rational-arithmetic checks and mutations.
