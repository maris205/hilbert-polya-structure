\begin{abstract}
We give an operator realization of the field-degree-normalized H\'enon Euler
germ previously shown to converge on $\RePart s>1/2$.  At each split prime we
assemble all Galois-conjugate $\mu_3$ sectors in a graded finite algebra with
field-degree-normalized positive trace and associated supertrace.  The global
prime block $X_s$ satisfies the sharp criterion $X_s\in L^q$ if and only if
$q\RePart s>2$.  It is not $\tau$-trace class near the Riemann critical
abscissa, but it lies in $L^4(\mathcal M,\tau)$ throughout the proved
half-plane.  We show exactly that the H\'enon germ equals a fourth-order
regularized graded determinant multiplied
by three explicit local chronological counterterm series.  Order four is
minimal for this positive-ideal realization.  A positive Fuglede--Kadison
determinant retains only modulus and cannot replace the analytic
superdeterminant.  This upgrades the germ to a genuine regularized operator
determinant while leaving continuation, a functional equation, and a
self-adjoint generator open.
\end{abstract}
