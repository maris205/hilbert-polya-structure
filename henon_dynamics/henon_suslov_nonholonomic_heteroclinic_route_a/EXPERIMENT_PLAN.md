# Experiment plan

| Gate | Exact object | Independent route |
|---|---|---|
| G0 | source/evaluator/scope locks | literal plus payload hash |
| G1 | positive-definite inertia | Schur complement and determinant |
| G2 | reduced equations and energy | fresh rational vector field and SymPy |
| G3 | two explicit heteroclinics | independent tanh/sech differentiation |
| G4 | permanent rotations | endpoint direction, energy scale, exponent |
| G5 | clean `SO(3)` reconstruction | speed and `T^2/pi^2` receipts |
| G6 | Poisson density and reversor | bracket generation and divergence |
| G7 | principal/zero boundaries | four principal rows plus face ledger |
| G8 | hostile integrity | at least 20 rehashed semantic mutations |
| G9 | manuscript release | three revisions, deterministic PDFs, manifest |

The checker does not import the producer.  Square roots and `pi` are never
rounded: the JSON stores their exact rational squares or coefficients.  No
finite row is promoted into a proof of the all-energy theorem.
