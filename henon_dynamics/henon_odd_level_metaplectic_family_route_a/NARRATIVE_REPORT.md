# Narrative report

C128 supplied one exact level-seven metaplectic lift but left open whether its
phase convention was a one-level accident.  C131 removes that ambiguity.  The
same half-phase, Fourier sign, chirp, clock, and antiunitary work for every odd
modulus, including composite levels.  Nine exact receipts cover 25,313 Weyl
observables while the proof is quantified over all odd `N>=3`.

The second advance is a scalable pre-alias statement.  The recurrence for
`A^n` gives an explicit integer threshold below which reduction modulo `N`
cannot erase the classical action.  Choosing larger odd levels makes this
certified window arbitrarily long.  It remains an adjoint-action statement;
finite-dimensional traces are not reinterpreted as classical orbit sums.

The result reaches the narrow natural-quantization subgate.  It does not join
the levels projectively, prove a semiclassical limit, match a target divisor,
or authorize Route B.
