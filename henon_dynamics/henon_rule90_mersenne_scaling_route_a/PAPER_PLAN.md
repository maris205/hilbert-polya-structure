# C150 paper plan

## Title and thesis

**Mersenne Scaling and One-Step Periodic Images in Cyclic Rule 90.**  The
Mersenne family has an exact half-size periodic image, whereas the matched
power-of-two family is nilpotent.

## Claims--evidence matrix

| Claim | Proof or evidence |
|---|---|
| `a^(L+1)=a` for `L=2^r-1` | Frobenius and exponent reduction |
| image codimension one | squarefree modulus and polynomial gcd |
| periodic set equals image | one-step image plus `a^L=I` on image |
| primitive counts | multiplication-kernel lemma and Möbius inversion |
| power-of-two nilpotency | Frobenius cancellation |
| implementation | matrix checker, SymPy, replay, mutations |
