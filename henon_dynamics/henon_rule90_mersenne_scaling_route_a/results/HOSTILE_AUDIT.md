# C150 hostile audit

The mutation suite rewrites semantic fields and repairs the payload hash before
requiring independent rejection.  It covers the source lock, Frobenius and
rank claims, image/periodic equality, divisor rows, aggregate counts,
power-of-two nilpotency, Route-A coordinates, scope flags, and nonclaims.  All
44 repaired-hash cases plus the stale-hash case are rejected.
