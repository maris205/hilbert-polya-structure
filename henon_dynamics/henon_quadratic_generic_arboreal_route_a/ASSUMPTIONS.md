# Frozen assumptions

Base field Q(t) with t transcendental; f(X)=X²+1 and the rooted preimage tree. Characteristic-zero inertia is tame. At height n only primes outside B_n=2 product_(i<j)(c_j-c_i) are declared good; B_n includes c_0=0. Finite-field Chebotarev/Weil for regular covers is an explicitly imported classical theorem.

A transcendental generic basepoint is not every numerical specialization. Each fixed height has finitely many bad primes; no prime stays good at every height. The limiting argument fixes height before taking the prime limit, then sends height to infinity.
