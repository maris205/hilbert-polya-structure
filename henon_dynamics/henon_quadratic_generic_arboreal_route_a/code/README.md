# Code ownership

Producer: exact finite formulas. Checker: separate arithmetic reconstruction,
strict schema/types, canonical rational coordinates and evaluator semantics.
Symbolic lane: a different backend, with SYMPY_GROUND_TYPES=python to avoid the installed flint factor-sort incompatibility.
Replay: two directories, exact bytes. Mutation: repaired outer digests and
hostile serialization. Release: every lane, optimized refusal, double fresh
manuscripts, font/text/raster checks and exact physical membership.

No checker imports the producer. No decimal lane is an interval certificate.
