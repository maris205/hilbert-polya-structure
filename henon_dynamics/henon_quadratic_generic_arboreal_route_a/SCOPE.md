# Scope firewall

`NO_BAD_EULER_OR_ROOT_NUMBER`. All nine target/Route-B flags are literal false.
No target arithmetic local data, target Euler factors, root number, automorphy,
target counting law/divisor, target functional equation, zero matching,
Hilbert–Pólya operator or Route B invocation is claimed.

A transcendental generic basepoint is not every numerical specialization. Each fixed height has finitely many bad primes; no prime stays good at every height. The limiting argument fixes height before taking the prime limit, then sends height to infinity.

Changing the determinant, time, boundary domain or generic base field creates
a new candidate. Such a change is not an achieved repair of this frozen source.
