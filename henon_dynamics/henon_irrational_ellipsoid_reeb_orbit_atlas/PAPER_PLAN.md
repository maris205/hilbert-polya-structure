# C242 paper plan

**Question.** What is the exact closed-orbit and index atlas for the standard
ellipsoid Reeb flow, including the rational degeneration?

**Theorem spine.** Define the contact model; classify closure; derive action,
period, transverse multipliers and disk-trivialized CZ indices; prove the
integer-square floor certificates; state the rational Morse--Bott alternative.

**Evidence spine.** The JSON receipt contains 48 irrational rows and six
rational coordinate rows. An independent checker recomputes all rows, SymPy
checks the flow/return identities, replay checks bytes, and hostile mutations
test the schema and scope locks.

**Integrity spine.** Cite Hutchings (arXiv:1303.5789) and Hofer--Wysocki--
Zehnder (DOI 10.2307/120994); distinguish source conventions from proved
calculations; report A0_FAIL, A1_PASS_ANALYTIC, A2_FAIL, A3_FAIL and
A4_FORMAL_HINT. No target arithmetic claim is permitted.
