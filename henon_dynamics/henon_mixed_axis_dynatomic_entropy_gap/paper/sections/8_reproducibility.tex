\section{Reproducibility and hostile controls}

The primary checker locks seven predecessor artifacts, generates all odd
closures through period fifteen, computes every divisor remainder, constructs
the quotient chain, runs squarefree gcds and exact rational factorizations,
and rejects twenty claim mutations.  A second implementation imports no
primary research code and reconstructs the recurrence, quotient degrees and
coefficient hashes.  Eight unit tests lock the degree sequence, P58 match,
formal/effective boundary and Route-A/Route-B scope.  Run
\begin{verbatim}
bash code/run_c60.sh
\end{verbatim}
from the project directory.  Exact factorization of the degree-$246$ quotient
is the slow step.  No floating-point root, prime table or Riemann-zero data is
used.
