# Source audit

- Morton--Silverman (1994) is the classical one-variable rational-map
  dynatomic reference. Its theorem is context, not a direct attachment to the
  H\'enon symmetry-line quotient.
- Hutz (arXiv:1011.5155) proves effectivity for nondegenerate morphisms of
  nonsingular projective varieties using graph--diagonal intersection
  multiplicities. The current H\'enon map has a birational projective
  extension and P60 imposes a reversor-line slice, so those hypotheses do not
  certify P60 effectivity.
- Yamaguchi--Tanikawa (2005) studies symmetric periodic orbits of the
  area-preserving H\'enon map and supplies historical context for symmetry
  lines. It does not state the present polynomial divisibility or entropy
  formula.

The new claims are proved directly from the frozen recurrence and exact
factorizations. Literature is used to set scope and prevent novelty or
effectivity overstatement.
