# HCS-C76 finite support-closure orbit atlas

C76 enumerates the action of the effective label symmetry on every support of
the sixteen frozen named coordinates from C75.  The ambient core is

```text
Q = Z/9 + Z/3 + Z/2,
```

and a support `A` is a subset of `{S1,...,S16}`.  Its closure is
`Phi(A) = <x_i : S_i in A>`.  The C75 lifted group has order 11520, but its
ambient C6 factor acts trivially on the sixteen labels.  C76 therefore uses
the faithful effective label group generated by

```text
z5 = (S5 S6 S10 S13 S14)
z2 = (S5 S6)
a  = (S3 S11)
c  = (S7 S15)
u  = (S1 S16)(S3 S4)(S11 S12).
```

Direct permutation closure gives an effective group of order `1920`; GAP
identifies its structure as `C2 x S5 x D8` (equivalently `S5 x C2 x D8`).
The exact order distribution is
`1:1, 2:311, 3:20, 4:584, 5:24, 6:460, 10:264, 12:160, 20:96`.

Headline results:

```text
all supports                         2^16 = 65536
support orbits under the effective group       3024

```

All full-core minimal supports have cardinality three.  Their representative
