# C76 theorem package

## Theorem 1: effective label action

Let `H` be the permutation group on the sixteen labels generated by

```text
z5 = (S5 S6 S10 S13 S14),  |z5|=5,
z2 = (S5 S6),              |z2|=2,
a  = (S3 S11),             |a|=2,
c  = (S7 S15),             |c|=2,
u  = (S1 S16)(S3 S4)(S11 S12), |u|=2.
```

Direct closure gives

```text
|H| = 1920.
```

The recorded element-order distribution is

```text
1:1, 2:311, 3:20, 4:584, 5:24, 6:460,
10:264, 12:160, 20:96.
```

GAP identifies the finite-group structure as `C2 x S5 x D8`, equivalently
`S5 x C2 x D8`.  The order and structure check is kept separate from the
support enumeration.

## Theorem 2: complete support orbit atlas

The induced action of `H` partitions all 65536 supports into exactly 3024
orbits.  The orbit-size spectrum is

\[
\begin{array}{c|rrrrrrrrrrr}
|O|&1&2&4&5&8&10&16&20&40&80&160\\\hline
\#O&128&256&416&128&192&384&16&672&608&208&16.
\end{array}
\]

The number of support orbits by cardinality `k=0,...,16` is

```text
1, 7, 27, 73, 151, 252, 352, 424, 450,
424, 352, 252, 151, 73, 27, 7, 1.
```

The orbit-size weighted sum is 65536, so the atlas is a partition rather than
an orbit sample.

## Theorem 3: closure atlas

The closure map `Phi` takes values in the twenty subgroups of `Q`.  Aggregated
by subgroup order, the exact support and orbit counts are

\[
\begin{array}{c|rrrrrrrr}

\#\text{supports}&32&32&256&256&2080&2080&30400&30400\\

The evidence retains the finer subgroup-index table, not only this aggregate.

## Theorem 4: minimal support counts

A support is closure-minimal when it is empty or every single-label deletion
changes its generated subgroup.  There are 98 such supports, distributed by
cardinality as

```text
k=0: 1,  k=1: 11,  k=2: 48,  k=3: 38.
```

They form 34 `H`-orbits with orbit-size spectrum
`1:10, 2:8, 4:14, 8:2`.

Among them, exactly 25 supports generate all of `Q`.  Every full-core minimal
support has cardinality three; they form seven orbits with spectrum
`1:1, 2:2, 4:3, 8:1`.  Canonical representative masks are

```text
261, 265, 321, 324, 385, 448, 33025.
```

## Boundary and nonclaims

The C75 order-six ambient factor is a kernel of the label action.  Including
it would produce the 11520-element lifted object rather than the effective
support action.  C76 therefore claims a finite label-support atlas only.  No
full table of marks, full Burnside ring, arithmetic/local theorem, Euler
factor, root number, automorphy, or Hilbert--Polya operator is claimed.
