# Reproducibility

The package requires Python 3, PyYAML, SymPy, LuaLaTeX with TeX Gyre fonts, and Poppler. It uses exact `Fraction` Gaussian arithmetic, deterministic sorted JSON, no random source, no external data, and no floating-point tolerance.

The producer enumerates every frozen cell. The checker imports no producer code and independently reconstructs Fourier convolution, Hilbert multipliers, Möbius algebra, one-mode regimes, and profile coefficients. SymPy differentiates both Riccati formulas and verifies the pole/profile algebra. Replay requires byte identity in a fresh directory. The hostile suite repairs hashes after semantic mutations.

The release gate builds the three checked-in round wrappers twice each in fresh directories under the fixed epoch, rejects settled warnings, checks embedded/subset fonts including the Chinese abstract font, extracts and validates gated bilingual abstracts and keywords, rasterizes each page, reruns every code lane, closes exactly 38 payload files, and writes a self-excluded thirty-ninth-file manifest.
