# Paper plan

1. **Object.** Define NC(n), the permutation model for K, orientation, and the
   actual versus abstract CSP clock order.
2. **Structural theorem.** Prove/combine cardinality, rank reversal,
   K^2=rotation, order boundaries, and dihedral reflections.
3. **Fixed ledger.** State the type-A order-2n CSP and reduce all root values to
   the displayed binomial formula, including the n=2 kernel.
4. **Finite dynamics.** Apply Mobius inversion to exact periods and cycles,
   derive the finite zeta and Koopman determinant, and diagonalize cycle blocks.
5. **Evidence.** Describe independent enumeration, q-polynomial/SymPy checks,
   replay, mutation tests, and deterministic build closure.
6. **Boundary.** Explain why this is a complete combinatorial advance but not
   an arithmetic Route-A candidate; compare explicitly with C187.
