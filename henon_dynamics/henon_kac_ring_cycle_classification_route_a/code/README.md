# C170 code

- `c170_kac_ring_producer.py`: exact family and exhaustive marker evidence.
- `c170_kac_ring_checker.py`: independent enumeration and release-schema checker.
- `c170_sympy_crosscheck.py`: symbolic permutation-determinant and spectrum checks.
- `c170_replay.py`: byte-identical temporary replay.
- `c170_mutation.py`: repaired-hash and stale-hash adversarial mutations.
- `c170_release_manifest.py`: self-excluded 27-file manifest.

Only Python 3 and SymPy are required. Runs are deterministic and offline.
