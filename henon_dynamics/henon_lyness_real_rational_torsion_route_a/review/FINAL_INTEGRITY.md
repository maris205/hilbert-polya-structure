# Final integrity protocol

The self-excluding release reconstructs the actual physical ledger and
every SHA256. Unknown payload files, symlinks, control bytes, unknown YAML
fields or type drift fail in both write and nonwrite modes. The evaluator
authority itself is pinned. All nine target/Route-B flags must be boolean
false; optimized Python cannot bypass assertion checks.

Producer/checker/SymPy/replay/mutations/smoke are actual release lanes.
Three substantive PDFs must have strictly increasing page counts, exact
English/Chinese keyword counts and distinct content markers. The main PDF
must equal round two. Fresh double builds must reproduce each PDF byte
for byte. Actual settled TeX logs, embedded subset fonts and per-page
raster controls are retained. Full-page visual inspection is recorded in
paper/COMPILE_REPORT.md; successful rasterization alone is not called
visual review.

The final manifest is the execution receipt, not this protocol prose.
A source-only release PASS does not change the rejected Route-A verdict.
