# Manuscript artifacts

main.tex contains the common source and substantive revision switches.
main_round0.tex, main_round1.tex and main_round2.tex are exact wrappers.

- main_round0_original.pdf: all positive ovals, Abel rotations and return matrices.
- main_round1.pdf: smooth elliptic fibers and rational torsion restrictions added.
- main_round2.pdf: real/rational prime-period contrast and operator/cardinality
  obstructions added.
- main.pdf is byte-identical to main_round2.pdf.

Each is double-built with LuaLaTeX in distinct fresh directories at epoch
1788566400. Settled compilation logs are compile_round0.txt,
compile_round1.txt and compile_round2.txt. COMPILE_REPORT.md records actual
page/font/raster and visual inspection receipts. Publication priority and
journal acceptance are not claimed.
