# Exact verification plan

This is a theory package, not an ML experiment. No GPU, learned split, random
seed or significance test is applicable.

Frozen grid: a=1/4,1/2,1,2,7,11; r=a+2+t for t=1/2,1,2,4;
twelve iterations of each upper-diagonal point. The a=1 seed square
{1/2,1,2,3}² is canonicalized into ten distinct full cycles. The GMX a=7
nine-cycle and five rational centers are separate controls.

Five source-only intervals between classical rotation endpoints use a
Machin arctangent certificate for pi and alternating cosine bounds.
Every denominator 2 through 257, prime or composite, is enumerated with
all reduced numerators strictly inside the selected interval.

Independent checking uses scalar dual differentiation rather than the
producer's Jacobian multiplication. Symbolic checks and 90-digit Abel
quadrature are distinct. Two fresh directories replay exact bytes.
Repaired-hash semantic changes, JSON ambiguity, YAML unknown keys and
boolean/date type drift must all be rejected. Every release mode enforces
the same strict evaluation pin and exact physical membership.
