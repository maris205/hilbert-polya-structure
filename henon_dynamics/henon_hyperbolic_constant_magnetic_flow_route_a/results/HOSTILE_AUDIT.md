# Hostile audit

The checker rejects duplicate JSON keys before semantic loading, exact-schema additions/deletions, wrong primitive types, incomplete or duplicate parameter grids, repaired-hash changes to model/theorem/proof/Route contracts, modified classifications or periods, source-owner corruption, all scope escapes, and a stale-hash control.  It does not import producer code.

Mathematical failure modes specifically tested or proved away are: replacing `b/v` by `b`; reversing the Lorentz sign; inferring critical nonclosure from full-frame nonidentity instead of the explicit basepoint tangent component `kappa v t`; inferring nilpotency from eigenvalues without checking `A^2!=0`; inferring primitive position return from full-frame return without the sine/cosine basepoint equations; omitting the primitive-period factor; treating `v=0` with a unit tangent; promoting finite enumeration to an all-parameter proof; or upgrading a merely formal quantum hint.

The Route-A YAML is parsed with a duplicate-rejecting loader and an exact semantic hash.  Unknown/missing keys, tuple, Route-B, orbit-cutoff, schema, and raw duplicate-key mutations are release-blocking.

Release status is determined by `python3 code/c289_release_manifest.py`, not by this narrative.
