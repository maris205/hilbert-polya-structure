# Proof package

## 1. Frozen dynamics

In scaled integral coordinates,

```text
H(x,y)=(6-x^2-y,x),       J(x,y)=(x,6-x^2-y),
```

with `J^2=1` and `J H J=H^(-1)`. P62 supplies a compact uniformly
hyperbolic chain recurrent set `Lambda` conjugate to the full two-shift.

At the Devaney--Nitecki anchor, the sign itinerary is one-to-one and obeys

```text
symbol_k(Jz)=symbol_(-k)(z)
```

because `J` preserves the first coordinate and
`H^k J=J H^(-k)`. Along Arai's connected hyperbolic plateau, structural
continuation can be chosen uniquely close to the identity. Both
`J_a h_a J_10` and `h_a` are such continuations, hence agree. Therefore the
continued conjugacy `pi` satisfies

```text
pi sigma = H pi,          pi rho = J pi,
rho(s)_k=s_(-k).
```

## 2. Odd reflection packets

Let `n=2m+1`. A sequence in `Fix(sigma^n) cap Fix(rho)` is determined by

```text
s_0,s_1,...,s_m,
```

and has cyclic word

```text
(s_0,s_1,...,s_m,s_m,...,s_1).
```

Thus there are `2^(m+1)` marked reflection points. P62's mixed-axis closure
has exactly this many simple roots and every root yields such a point, so
the two families coincide.

The exact-period subset has cardinality

```text
D_n = sum_(d|n) mu(n/d) 2^((d+1)/2).
```

Every proper divisor of odd `n` is at most `n/3`. Hence the fraction removed
from the full half-word family is at most

```text
tau(n) 2^(-n/3).
```

It follows that primitive subtraction is negligible in total variation.

## 3. Marked-axis limit

Let `eta_n` be uniform on primitive reflection words with the axis marked at
zero. For every fixed radius `r`, the nonnegative coordinates
`s_0,...,s_r` are asymptotically independent fair bits, while
`s_(-k)=s_k`. Therefore

```text
eta_n -> eta_J,
```

where `eta_J` is generated by iid fair variables `xi_k`, `k>=0`, and
`s_k=s_(-k)=xi_k`.

This is not the fair two-sided Bernoulli measure. Indeed
`eta_J{s_-1=s_1}=1`, while fair Bernoulli gives `1/2`. It is not even shift
invariant: after one shift the same event becomes `{s_0=s_2}`, of
`eta_J`-probability `1/2`.

## 4. Orbit-averaged limit

Define

```text
bar_eta_n = n^(-1) sum_(j=0)^(n-1) (sigma^j)_* eta_n.
```

For a cylinder of radius `r`, a shifted window fails to contain distinct
free reflection pairs only if

```text
2j = -(a+b) mod n
```

for some `a,b in [-r,r]`. There are at most `4r+1` such centers. Every other
center sees independent fair bits. Together with primitive subtraction,

```text
|bar_eta_n(C)-mu_B(C)|
 <= (4r+1)/n + tau(n)2^(-n/3),
```

so `bar_eta_n -> mu_B`, the maximal-entropy Bernoulli measure.

## 5. Mahler averages and pressures

Push the measures through `pi` and let `phi(z)=log^+|x(z)|`. The horseshoe is
compact and P63 gives `|x|<=1+sqrt(7)`, so `phi` is bounded continuous. If
`tilde_Psi_n` is the monic integral primitive coordinate polynomial,

```text
a_n = D_n^(-1) log M(tilde_Psi_n)
    = D_n^(-1) sum_(tilde_Psi_n(alpha)=0) log^+|alpha|.
```

Weak-star convergence yields

```text
a_n -> kappa_J := int phi d(pi_* eta_J).
```

The all-negative fixed sequence has coordinate `-1-sqrt(7)`. Continuity and
full support on reflected cylinders give `kappa_J>0`; P63 gives the upper
bound `kappa_J<=log(1+sqrt(7))`.

For every fixed real `s`, define

```text
Z_n^J(s)=D_n exp(-s n a_n).
```

Since `n^(-1)log D_n -> (1/2)log2`, one obtains

```text
lim_(odd n) n^(-1)log Z_n^J(s)
 = (1/2)log2 - s kappa_J.
```

If

```text
b_n=(nD_n)^(-1) sum_alpha sum_(j=0)^(n-1) phi(H^j z_alpha),
```

then `b_n -> kappa_max=int phi d(pi_*mu_B)` and the orbit-averaged packet
pressure is `(1/2)log2-s kappa_max`.

## 6. Boundary

The theorem concerns a whole-packet Mahler weight. It does not prove the
individual partition `sum_alpha exp(-s n h(alpha))`: reducible primitive
polynomials can assign different Galois-factor heights. It also does not
prove `kappa_J != kappa_max`, a prime trace, determinant continuation, an
operator, or RH.
