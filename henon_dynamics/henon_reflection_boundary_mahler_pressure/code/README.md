# Code

The primary checker independently reconstructs the primitive reflection
polynomials, computes finite packet and orbit diagnostics, enumerates every
primitive palindromic binary word through odd period 21, and rejects 26 claim
mutations. The independent checker uses a separate word-period routine and
the exact period-one/three sentinels.

Run from any directory:

```bash
bash code/run_c64.sh
```

Floating-point slope separation is diagnostic. The all-period pressure
theorem is the symbolic weak-star argument plus the exact Mahler identity.
