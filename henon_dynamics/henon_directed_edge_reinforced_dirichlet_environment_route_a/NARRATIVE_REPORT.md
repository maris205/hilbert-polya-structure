# Narrative report

Linear reinforcement on directed edges is locally a Pólya prediction rule, but
the walker decides which local urn is visited next.  Grouping factors along a
fixed path reveals the full structure: every vertex contributes its own
multivariate rising-factorial ratio.  This is exactly the moment formula of an
independent Dirichlet transition row.

The result converts a history-dependent walk into a static random environment.
The conversion is exact at every finite time and conjugate after every
history.  Because a Dirichlet draw with positive parameters has every arc
probability positive, finite strong connectivity makes the conditional chain
irreducible.  Its ergodic theorem then learns the sampled transition rows and
the random stationary edge flows almost surely.

This is not a repackaged single Pólya urn: the main object is an endogenously
visited family of urns whose limit is a random Markov kernel and whose vertex
occupation law depends nonlinearly on all rows.  It is also distinct from the
undirected ERRW mixing measure and from Wilson's fixed-conductance stacks.
