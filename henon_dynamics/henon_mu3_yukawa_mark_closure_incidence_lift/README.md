# HCS-C75 lifted closure-incidence symmetry

C75 lifts the cyclic-subgroup closure incidence of the frozen C72 named
coordinates into a genuine ambient-
`Q = Z/9 + Z/3 + Z/2` symmetry object.  For a named coordinate `x_i`, write
`F(i) = <x_i>`.  A symmetry is a pair `(alpha, pi)` with `alpha in Aut(Q)` and
`pi in Sym(16)` satisfying

```text
<x_{pi(i)}> = alpha(<x_i>)  for every i.
```

The ambient map is retained in the pair.  C75 therefore does not identify the
group with the generally non-faithful action on the twenty abstract subgroups.
