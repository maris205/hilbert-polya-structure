# C75 theorem package

## Theorem 1: closure fibers

The sixteen C72 coordinates hit nine cyclic subgroups of
`Q = Z/9 + Z/3 + Z/2`.  Their label-fiber sizes are

```text
5, 1, 2, 1, 2, 1, 1, 1, 2.
```

The internal permutation fiber has exact order

```text
5! * 2! * 2! * 2! = 960.
```

The last factor `2!` is essential: `S7,S15` generate the same order-nine
cyclic subgroup even though they are distinct points.

## Theorem 2: weighted ambient stabilizer

Let `w(C)` be the number of labels whose cyclic closure is `C`.  Direct
enumeration of `Aut(Q)` gives

```text
K = {alpha : w(alpha C)=w(C) for every subgroup C},  |K|=12.
```

The group is generated by the commuting matrices

```text
r=(2,0,0,2),  |r|=6;
s=(2,1,2,1),  |s|=2,
```

so the ambient stabilizer candidate is `C6 x C2`.

## Theorem 3: lifted symmetry order

Define

```text
G~ = {(alpha,pi): alpha in K and
      <x_{pi(i)}> = alpha(<x_i>) for all i}.
```

For every `alpha in K`, all independent bijections between source and target
fibers are allowed.  Therefore

\[
|\widetilde G|=|K|\prod_C w(C)! = 12\cdot960=11520.
\]

The producer directly enumerates all 11,520 pairs and separately generates the
same set from six explicit generators.  GAP reports the faithful structure
`C2 x C6 x S5 x D8`, equivalent to `S5 x C2 x D8 x C6`.

## Theorem 4: non-faithful lattice boundary

The action of all 108 automorphisms on the complete 20-subgroup lattice has
image order 18 and kernel order 6.  It is therefore not a substitute for the
lifted pair group: the ambient `alpha` and the label fibers are part of the
object.

The lifted projection to ambient maps has kernel order 960, not 6.  This is
the precise distinction needed to avoid reporting the 18-element lattice image
as the C75 symmetry.
