# C183 narrative report

The paper's large step is not another mixing-time estimate. It closes the complete source operator for every \(S_n\): all partitions, hook dimensions, transposition character ratios, eigenvalues, regular multiplicities, determinant factors, traces, exact identity returns, \(L^2\) distance, spectral extremes, and the exact owner boundary.

The decisive distinction is between two valid but different objects. The Markov contraction on frozen \(S_n\) is not induced by a deterministic map, so its finite determinant is not an unweighted Artin--Mazur determinant on that space. The reciprocal determinant nevertheless has a canonical weighted primitive-cycle product on the directed-edge path lift. That construction changes both phase space and dynamical owner and therefore cannot be used to pass the failed A0/A1 Route-A gates.

The work uses one verified classical citation and explicitly attributes the cutoff. Finite enumeration supports, but never proves, the all-size representation-theoretic theorem. Internal checks are not external peer review.
