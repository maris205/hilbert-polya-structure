# Project contract

This package owns only the BCZ return on 0<a,b<=1, a+b>1. Its native lattice
arithmetic is distinct from the earlier hyperbolic Gauss/Farey interval and
Mayer owners: rational slopes here give parabolic horocycle cycles with a
continuous physical scale, not quadratic-irrational geodesics with logarithmic
algebraic-unit lengths. Full-repository text screening found no existing BCZ,
Boca–Cobeli, or Farey-triangle package. A prior speculative adelic-horocycle
idea is not an implemented owner. This is bounded local dedup, not global newness.

All writes are confined to this package; no commit, push, external-model review,
target arithmetic or Route B invocation belongs to this subtask.
