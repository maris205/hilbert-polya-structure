# Assumptions and conventions

- Real a,b lie in (0,1] with a+b>1; the lower edge is excluded.
- The floor function takes its exact integer value at equality.
- Column branch matrices multiply with the last return on the left.
- Rational slope is written uniquely as delta(q,r), q,r positive coprime.
- Layer N contains 1/(N+1)<delta<=1/N; phi(1)=1.
- The cyclic Farey denominator ledger does not double count 0/1 and 1/1.
- Matrix integer powers may be negative; physical repetitions are positive.
- The physical roof is 1/(ab), not the discrete return counter.
- Standard background is elementary lattice algebra, change of variables,
  and the Basel identity. No weak-mixing theorem is used in a proof here.
