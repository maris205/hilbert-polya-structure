2. Rebuild `Phi(A)` from the 54-point group law for all `65536` supports.
3. Group C80's twenty-coordinate threshold vectors by actual closure and test
   constancy, injectivity, zero-ideal recovery, and the exact fibre spectrum.
4. Test all `20 x 20` subgroup pairs against reversed coordinatewise vector
   order and extract the finite-poset cover relation.
5. Independently enumerate the twenty subgroups and every target-minimal
   support antichain, then reconstruct all `20 x 65536` threshold entries.
6. Cross-check the zeta/Mobius matrices and all `400` meet/join pairs with
   SymPy and direct finite-set operations.
7. Run clean replay, at least fourteen hostile semantic mutations, two
   isolated deterministic LaTeX builds, font/reference/text/visual audits,
   and a complete prefreeze manifest.

Only finite named-support combinatorics are in scope.
