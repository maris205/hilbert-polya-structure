\begin{abstract}
For each of the $2^{16}=65536$ retained supports in a frozen named model, we
collect the twenty subgroup-containment repair thresholds into one vector.
Exactly twenty vectors occur, and a vector depends only on the generated
subgroup.  Its zero coordinates are precisely the principal ideal below that
subgroup, so the vector recovers the closure.  Moreover, subgroup inclusion
is equivalent to reversed coordinatewise order between the twenty closure
vectors.  The exact fibre spectrum is
$\{32{:}6,64{:}4,96{:}4,192{:}2,1760{:}2,30400{:}2\}$.
Independent point-set and antichain reconstruction, a finite-lattice symbolic
check, clean replay, and twenty-three hostile mutations certify the result.
The scope is finite and obeys
\texttt{NO\_BAD\_EULER\_OR\_ROOT\_NUMBER}.
\end{abstract}

\section{Finite setting}
Let $L=\{S_1,\ldots,S_{16}\}$ be the frozen named support and let
$\Phiop(A)\leq\Q=\mathbb Z/9\oplus\mathbb Z/3\oplus\mathbb Z/2$ be the
subgroup generated by a retained support $A\subseteq L$.  Write
$H_0,\ldots,H_{19}$ for the twenty actual subgroups in the source-bound C75
order.  For $D=L\setminus A$, C80 defines
\[
 \tau_H(D)=\min\{|R|:R\subseteq D,\ H\subseteq\Phiop(A\cup R)\}.
\]
We study the complete threshold vector
\[
 v(A)=\bigl(\tau_{H_0}(D),\ldots,\tau_{H_{19}}(D)\bigr)
 \in\mathbb Z_{\geq0}^{20}.
\]
This construction uses the actual point-set subgroups.  The C75 lifted
ambient group has order $11520$, whereas the effective C76 action on the
sixteen labels has order $1920$; these objects remain distinct throughout.

\section{Rigidity theorem}
\begin{theorem}[Threshold-vector subgroup-poset rigidity]
For every $A\subseteq L$ there is a vector $w_{\Phiop(A)}$ such that
$v(A)=w_{\Phiop(A)}$.  Exactly twenty distinct vectors occur, one for each
actual subgroup of $\Q$, and
\[
 \{i:v(A)_i=0\}=\{i:H_i\leq\Phiop(A)\}.
\]
Consequently the zero coordinates recover $\Phiop(A)$.  For actual subgroups
$K_0,K_1\leq\Q$,
\[
 K_0\leq K_1
 \quad\Longleftrightarrow\quad
 w_{K_0}\geq w_{K_1}\quad\text{coordinatewise}.
\]
\end{theorem}

\begin{proof}
The threshold definition gives $\tau_H(D)=0$ exactly when no restoration is
needed, equivalently $H\leq\Phiop(A)$.  Thus the zero set is the principal
ideal below $\Phiop(A)$ and recovers its unique maximum.

The finite certificate enumerates all $65536$ supports and verifies that the
C80 vector is constant on each point-set closure fibre.  All twenty C75
subgroups occur as closures, and their vectors have distinct zero ideals;
hence exactly twenty vector classes occur.  The certificate also checks the
forward coordinatewise inequality for all $20^2$ ordered subgroup pairs.  For
the converse, $w_{K_0}\geq w_{K_1}$ implies that every zero coordinate of
$w_{K_0}$ is zero in $w_{K_1}$.  Therefore
$\mathord\downarrow K_0\subseteq\mathord\downarrow K_1$, which implies
$K_0\leq K_1$.
\end{proof}
