# C134 hostile and integrity audit

The suite contains 47 registered semantic mutations whose payload hash is
repaired before validation, plus one mutation that changes only the payload
hash.  It covers the source locks, including clock, normalization, determinant
convention, precision, and cutoff; exact anchor and inverse; faithfulness;
operator and geometry headlines, example translations, Laurent and Gaussian
coefficients, trace and Fredholm receipts, all-order formulas, all three stored
Newton identities and downstream monomial recovery,
permutation decoding, mod-five alias, faithful separation, parameter inversion,
precision and geometry boundaries, orbit ledger, progress, route tuple, scope,
nonclaims, and closed key schemas.

The registered suite is not claimed to enumerate every possible semantic
corruption.  Its purpose is to show that rejection does not rely only on a
stale checksum and that the main headlines are independently reconstructed.

Failure-mode findings:

- finite quotient alias is demonstrated rather than hidden;
- `D_{-t,u}(z)=D_{t,u^{-1}}(z)` is parameter inversion, not a reciprocal;
- exact injectivity is not promoted to numerical stability;
- integer frozen-family recovery is not arbitrary geometry recovery;
- no target, arithmetic/local, natural-quantization, or Route-B claim enters.

Verdict: PASS within the declared source scope.
