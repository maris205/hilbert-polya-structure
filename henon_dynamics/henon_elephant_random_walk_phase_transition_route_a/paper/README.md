# Manuscript artifacts

`main.tex` is a single deterministic source controlled by `CRevisionRound`.

- `main_round0_original.pdf`: exact finite structure and repaired boundary martingale.
- `main_round1.pdf`: complete phase theorem and endpoint split.
- `main_round2.pdf`: evidence, collision, Route-A, and nonclaim closure.
- `main.pdf`: byte-identical alias of round 2.

The release checker rebuilds every round twice in fresh directories, rejects settled warnings, verifies text certificates, requires embedded subset fonts, and rasterizes every page.
