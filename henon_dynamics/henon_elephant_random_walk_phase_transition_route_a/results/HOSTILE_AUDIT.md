# Hostile audit

The suite recomputes semantic hashes after mutating fixed JSON leaves, so a checksum alone cannot hide a changed theorem. Attacks cover identity, source commit, scope, Route-A tuple, Route-B lock, forbidden flags, model rule, martingale branch, phase labels, probabilities, moments, histories, superdiffusive parameters and constants, endpoint class, and leaf accounting.

Parser attacks include duplicate JSON/YAML keys, nonfinite JSON, wrong root types, YAML anchors/aliases, and scalar-type changes. Non-tuple YAML attacks alter the process family and falsely upgrade finite enumeration into a CLT proof. The checker also refuses `python -O`.
