# Results artifacts

- `c24_certificate.json`: producer output containing the seven-state source
  lock, all 828 primitive-count totals, and the complete 146-cycle
  eventually-positive labeled ledger.
- `c24_independent_check.json`: independent reconstruction and validation.
- `RESULTS.md`: mathematical interpretation and scope.
- `VALIDATION_REPORT.md`: verification passport and audit summary.
- `TEST_REPORT.md`: executed regression/mutation test record.
- `ARTIFACT_HASHES.sha256`: release hashes.

The JSON certificate deliberately records exact integers and rational root
intervals.  Floating-point logarithms are display diagnostics only.
