# Paper

`main.tex` is a self-contained technical note containing the source lock,
exact periodic ledger, fixed-vector character obstruction, discrete
metaplectic atom theorem, and Route-A boundary.

Compile with:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

The manuscript deliberately calls the Weil object a distribution character,
not the ordinary trace of a metaplectic unitary.
