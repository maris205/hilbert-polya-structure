# Paper

The manuscript proves a scoped obstruction for the scalar homogeneous
H\'enon--Tate anomaly route.  Its main novelty is the combined exact chain:
simultaneous equivariant trivialization, prime-loop telescoping, a zero
pre-Poisson essential codimension with an explicit image-index firewall,
and a quantitative non-VMO obstruction to the standard Hardy determinant
line.

Build with:

~~~bash
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
~~~

The compiled PDF and compilation report are release artifacts.  Auxiliary
LaTeX files are excluded from the artifact manifest.
