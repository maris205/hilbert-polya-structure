# Methodology blueprint

## Frozen object

Let \(X=\mathbb A_{\mathbb Q}\) (or an invariant nonzero locus) and

\[
\phi(x)=\psi(2x^3).
\]

For a scaling element \(a\), freeze the scalar cocycle

\[
c(a,x)=\frac{\phi(ax)}{\phi(x)}.
\]

No alternative clock, fitted character, or zero-dependent normalization is
allowed.

## One invariant

The organizing invariant is the equivariant cohomology/index class of
\(c\) after passing from the additive adelic space to the scaling quotient.
It is tested in three successive categories:

1. the transformation groupoid and its equivariant line bundle;
2. the pre-Poisson boundary hyperplane pair;
3. the standard Hardy restricted-unitary polarization.

## Decision logic

### Gate 1: groupoid class

Exhibit an explicit gauge.  If the same gauge trivializes both rational
descent and the full scaling lift, every functorial descendant has trivial
prime-loop holonomy.

### Gate 2: boundary pair

Compare

\[
K_0=\ker(ev_0)\cap\ker\Lambda_0,
\qquad
K_a=\ker(ev_0)\cap\ker\Lambda_{-P_a}.
\]

The relative index is computed before applying the possibly noninjective
Poisson map.  No index is inferred for its image without a kernel theorem.

### Gate 3: determinant-line escape

Test whether multiplication by the cubic chirp lies in the restricted
unitary group for the standard Hardy projection.  An exact shrinking-
interval mean-oscillation witness decides VMO and therefore compactness of
the Hardy commutator.

## Stop/go rule

- GO only if a nonzero, gauge-invariant, determinant-class index survives.
- STOP the scalar functorial/standard-Hardy route if the cocycle is exact,
  the pre-Poisson index is zero, and the natural restricted-unitary gate is
  unavailable.
- Do not reinterpret the inherited Riemann divisor as Hénon-generated
  evidence.
