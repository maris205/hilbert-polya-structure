# C47 code

The finite adversarial scan checks every Laurent polynomial supported on
exponents `[-3,3]` with coefficients in `{-1,0,1}`.  Exactly zero and the
seven monomials with coefficient one satisfy \(R(X^2)=R(X)^2\).  The scan is
a mutation sentinel for the general divisor proof, not a finite proof of the
rational-function theorem.
