# C384: wild additive geometric zeta

For every prime p, the map x+x^p on A1(Fbar_p) has geometric fixed counts p^(n-p^vp(n)), while its fixed-scheme length is p^n. Their zeta functions have radically different analytic behavior: the geometric zeta has a meromorphic natural boundary at |z|=1/p; length counting is rational.

This is one complete source theorem, including all extension degrees, least splitting fields, exact primitive periods, residue degrees, an interior tail bound and the determinant-promotion obstruction HEN-O368. It is a classical-theorem synthesis with explicit Bridy attribution, not a literature-priority claim.
