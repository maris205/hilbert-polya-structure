# Independent exact-code lanes

The producer uses dense modular polynomial Euclid and direct finite-field multiplication. The checker does not import it: sparse modular Euclid and a matrix-rank calculation recover the field counts separately. A recursively typed expected schema refuses bool/integer coercion, unknown fields and coverage drift.

SymPy provides a third symbolic lane. Replay uses two different working directories. Mutations repair the evidence payload digest before the checker is invoked; ten additional attacks test the frozen raw YAML plus strict parser. The release code has an exact whitelist and produces deterministic PDF receipts.

Source baseline and all claim flags are independently locked. None of these implementations is a formal proof assistant.
