# Hostile audit

All 35 attacks are rejected.  The suite repairs every affected JSON payload
hash before semantic checking.  It attacks source/epoch/evaluator locks,
`gamma_phi/2`, the coherence phase, Choi minors, PPT inequality direction,
one-sided finite-time EB claims, the zero-generator kernel, semigroup
composition, threshold enclosures, Route-A flags, collision-boundary text,
unknown keys, exact types, duplicate keys, nonfinite numbers, and stale hashes.

## Proves-too-much tests

1. **Finite determinant is not arithmetic.** Every qubit channel has a finite
   Choi matrix and every four-dimensional generator has a characteristic
   polynomial.  This construction exists for continuously arbitrary rates;
   therefore those objects alone cannot encode distinguished prime norms or a
   target global zero divisor.
2. **A unitary dilation is not the same dynamics.** Stinespring dilation is
   nonunique, enlarges the state space, and generally does not produce an
   autonomous same-clock unitary group realizing this semigroup for all real
   times.
3. **The unitary face does not rescue recurrence.** It has only the tunable
   frequency `omega` plus a continuum of fixed diagonal states, not a certified
   arithmetic orbit repetition law.
4. **The EB limit is not a finite threshold on boundary faces.** One-sided
   amplitude damping and pure dephasing become EB only at infinite time.

The inference firewall remains `NO_BAD_EULER_OR_ROOT_NUMBER`.  No target
arithmetic local data, Euler factors, root numbers, automorphy, target divisor,
functional equation, zero match, Hilbert–Pólya operator, or Route B is claimed.
