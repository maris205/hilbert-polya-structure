# PDF build

Use LuaLaTeX, `SOURCE_DATE_EPOCH=1788048000`, and `FORCE_SOURCE_DATE=1`; compile twice in each fresh directory.
Inject `\CRevisionRound=0,1,2`.  Round 0 contains invariant planes and exact motion; round 1 adds periodicity,
nonclosure, and field atlas; round 2 adds null degeneration, evidence, sources, and Route-A evaluation.
