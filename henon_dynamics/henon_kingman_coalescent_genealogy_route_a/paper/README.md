# C215 manuscript build

`main.tex` is compiled with LuaLaTeX under a fixed `SOURCE_DATE_EPOCH`.
`main_round0_original.pdf`, `main_round1.pdf`, and `main_round2.pdf` are
substantively different revisions; `main.pdf` is byte-identical to round 2 at
release.  The paper explicitly uses the standard projective coupling for the
`n`-to-infinity claim, derives the tree-length CDF from exponential
order-statistic spacings, and never calls a Markov determinant an
Artin--Mazur zeta.
