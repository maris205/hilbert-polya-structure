# Experiment plan

The project is theorem-led.  Finite computations are validation sentinels,
not statistical evidence for the all-orbit limit.

| ID | Check | Type | Pass condition |
|---|---|---|---|
| C1 | reconstruct \(q_n(T)\) and exact trace-field half norms | exact symbolic | all rows nonzero and dependency sentinels agree |
| C2 | recompute multiplier Mahler heights | high precision | producer/independent values agree to \(2\times10^{-12}\) |
| C3 | compare embedding formula with exact norm | high precision | maximum error below \(10^{-50}\) |
| C4 | exercise a unit-circle conjugate branch | adversarial algebraic fixture | exactly two unit-circle roots, no H6 promotion |
| C5 | finite Abel approach | numerical theorem sentinel | final ratio within 0.006 of one |
| C6 | mixed Gamma profile | numerical theorem sentinel | three Laplace rows within 0.002 |
| C7 | reject wrong coefficient | adversarial | physical-only height differs on period one |
| C8 | reject claim promotion | adversarial | continuation/determinant/operator remain OPEN |

No training data, zero data, prime tables or fitted parameters are used.
