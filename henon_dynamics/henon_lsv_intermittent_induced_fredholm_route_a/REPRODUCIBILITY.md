# Reproduce C381

From this package directory:

```bash
python -B code/c381_lsv_producer.py
python -B code/c381_lsv_checker.py
python -B code/c381_lsv_sympy_crosscheck.py
python -B code/c381_lsv_replay.py
python -B code/c381_lsv_mutation.py
python -B -m unittest discover -s tests
python -B code/c381_release_manifest.py --build-pdfs
python -B code/c381_release_manifest.py --write
python -B code/c381_release_manifest.py
```

Requirements are in requirements.txt; LuaLaTeX and Poppler provide the paper lanes. Reproduction uses no GPU, training or target data. The analytic theorem is not generated by extrapolating a successful numerical grid.

The frozen source baseline remains 0596f9d680277288225062a6fdd7ad7ce116e01d even though unrelated remote symbolic-dynamics commits were fast-forwarded before this batch was committed.
