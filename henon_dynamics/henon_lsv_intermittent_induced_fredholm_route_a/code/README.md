# Verification architecture

c381_lsv_producer.py creates the canonical dyadic certificate ledger. c381_lsv_checker.py is a separate implementation importing no producer. c381_lsv_sympy_crosscheck.py adds a symbolic/high-precision lane; replay regenerates in two unrelated working directories; mutation attacks mathematical, clock, serialization and scope invariants. Three smoke tests cover selected boundaries.

The release script must verify exact physical membership, source/evaluator/YAML locks, optimized-mode refusal, every numerical lane, deterministic manuscript bytes and the self-excluding manifest. Actual counts and outcomes are in generated results reports.
