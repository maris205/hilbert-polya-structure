# Failure-mode audit

| Risk | Disposition |
|---|---|
| Finite branch truncation substituted for nuclear theorem | avoided: common complex domain, uniform derivative bound and rank-one sum are explicit |
| Domain imported from a nearby map | avoided: the radical LSV inverse is proved on its own disk; no Farey substitution |
| Endpoint ambiguity | repaired: left branch owns 1/2 and inverse endpoints are excluded before forward coding |
| Two clocks conflated | avoided: u counts returns and zeta original iterations in every primitive factor |
| Neutral orbit hidden in a regular factor | avoided: its multiplier-one trace obstruction is separate from unweighted neutral removal |
| Overclaimed boundary naturalness | avoided: series divergence is not a no-continuation theorem |
| Reference-measure tail called stationary | avoided: Lebesgue normalization is stated; no invariant-density theorem is claimed |
| Uninduced space silently changed | avoided: noncompactness/no-uniform-gap claims refer only to Lebesgue L1 |
| Target or novelty inflation | strict route failure retained; classical lineage and finite evidence role explicit |

These are bounded internal checks, not a guarantee against undiscovered errors. Executable failures and subsequent repairs must be reported as such in the test record.
