# Hostile audit

Thirty-three evidence attacks repair the payload hash before validation.
They cover candidate/baseline/scope/Route-B locks, false-versus-zero types,
the endpoint partition, clock swapping, omitted words, neutral labels and
multipliers, least periods, orientation, root brackets, primitive census,
inverse return and derivative certificates, branch endpoints, return times,
tail measure normalization, divergent mean, invalid and widened tail
intervals, induced-word order, original time, trace denominator, a finite
head promoted to the infinite trace, disk/image radii, derivative constants,
outside-disk defining series, uninduced compactness/gap claims, boolean
numeric substitutions and unknown fields. Result: 33/33 rejected.

Ten serialization attacks cover duplicate/nonfinite JSON, duplicate and
unknown YAML fields, false-to-zero, numeric-to-boolean, implicit date,
anchors/aliases, non-string keys and merges. Result: 10/10 rejected.

The mean-zero power-norm statement was strengthened after independent
review using the same approximate eigenvectors and a telescoping inequality.
This mathematical consequence has no new finite-data assumption. The
all-branch proof, rather than a large cutoff, establishes nuclearity.
