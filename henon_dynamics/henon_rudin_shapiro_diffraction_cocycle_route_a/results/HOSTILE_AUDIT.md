# Hostile audit — HCS-C248

The mutation harness creates 42 independent copies of the pristine evidence.
Twenty-four-plus attacks repair the top-level SHA-256 after changing semantic
content, so a digest-only check cannot pass.  Covered classes include the
substitution matrix/rules/coding, frequency and aperiodicity receipts,
polynomial coefficients/energy/bound, Laurent correlations, route tuple and
Route-B gate, scope flags, citations, ordering, missing rows, and unknown
fields.  The producer-independent checker rejects all 42 copies.

This audit is a software integrity control only.  It does not turn a finite
receipt into a periodic orbit or expand the source-local diffraction result
into a target arithmetic statement.
