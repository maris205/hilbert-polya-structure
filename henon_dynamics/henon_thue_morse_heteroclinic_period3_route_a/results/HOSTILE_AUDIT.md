# C154 hostile audit

The mutation harness changes semantic fields, repairs the payload hash, and
requires rejection by the independent checker.  It covers source/date/scope,
the interface and both alphabets, escape/decomposition claims, dense-full-
orbit versus forward-transitivity wording, wandering and nonwandering sets,
periodic classification, fixed/Möbius/zeta data, Route-A coordinates, scope
flags, and nonclaims.  All 47 repaired-hash cases and the separate stale-hash
case are rejected.
