# C154 narrative report

C149 showed that a free finite disjoint attachment creates a transparent
periodic skeleton but cannot be considered intrinsic to the symbolic source.
C154 moves the interface into the generator itself.  One configuration has a
period-three past and a Thue--Morse future; its full shift-orbit closure
contains both asymptotic components and no others.

The gain is exact.  The period-three orbit is forced as the negative limit
set of the same heteroclinic orbit whose positive limit set is the
Thue--Morse subshift.  It supplies exactly one primitive cycle and the zeta
factor `(1-z^3)^(-1)`.  The unique alphabet crossing also makes the interface
topology completely visible.

The cost is equally sharp.  Every interface point is an isolated wandering
point.  Although the full two-sided orbit is dense, the system fails standard
forward topological transitivity; it is also nonminimal.  Thus the package
records a genuine intrinsic-orbit improvement without promoting a weak
source mechanism to a target match.
