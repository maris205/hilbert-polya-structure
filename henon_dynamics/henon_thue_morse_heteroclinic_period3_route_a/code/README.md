# C154 code

- `c154_heteroclinic_producer.py`: deterministic exact evidence producer.
- `c154_heteroclinic_checker.py`: independent symbolic-window reconstruction.
- `c154_sympy_crosscheck.py`: separate zeta, Möbius, and matrix path.
- `c154_replay.py`: isolated byte-identical production.
- `c154_mutation.py`: repaired-hash semantic and stale-hash rejection.
- `c154_release_manifest.py`: self-excluded 27-payload release ledger.

The checker imports no producer code.
