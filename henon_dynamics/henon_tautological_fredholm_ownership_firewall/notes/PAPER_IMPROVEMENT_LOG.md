# Paper improvement log

1. Replaced the vague phrase "Fredholm ownership" by three separately
   quantified constructions: channel diagonal, universal rank one, and
   literal source-block direct sum.
2. Added local-uniform trace-norm estimates for both `A` and `exp(A)-I`.
3. Added the cyclic-vector argument needed to identify the full finite-block
   characteristic polynomial.
4. Computed singular values from `B*B`, avoiding any normal-operator shortcut.
5. Added a primitive singleton reflection word for every odd period and used
   orthogonal block vectors to prove noncompactness.
6. Recast the finite power coefficient identity as a canonical-basis graded
   ledger and explicitly prohibited its use as an operator trace.
7. Added the rank-one universality lemma and a claim-status table so that an
   analytic determinant cannot be promoted to a genuine transfer theorem.
8. Added dependency locks, independent reconstruction, optimized-mode tests,
   mutation auditing, source auditing, and PDF hygiene checks.
