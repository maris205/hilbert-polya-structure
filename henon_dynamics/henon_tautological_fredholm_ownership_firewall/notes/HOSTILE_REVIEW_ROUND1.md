# Hostile review, round 1

## Objection 1: the diagonal construction already solves ownership

It solves only scalar realization. Its entries are the already derived
logarithmic channels. The rank-one lemma shows that an arbitrary completed
nonvanishing holomorphic scalar admits an even smaller Fredholm realization.
The claim was therefore downgraded to `PROVED_TAUTOLOGICAL`.

## Objection 2: the source blocks should define a Fredholm determinant

Every finite block does. Their undamped Hilbert direct sum does not: the
source edge weights are `1` or `q`, and singleton blocks occur for infinitely
many periods. Unit vectors from distinct blocks have images separated by a
uniform positive norm. Compactness, hence trace class, fails.

## Objection 3: the finite coefficient trace repairs noncompactness

It does not. For a fixed power, only block lengths dividing that power have
nonzero canonical diagonal entries. This is a locally finite graded ledger,
not a basis-independent operator trace. The paper now states the distinction
at every use.

## Required revision

Separate scalar-built, finite source-native, and full source-native operator
claims; state a firewall verdict for each; add exact singular-value and
singleton proofs. All revisions are incorporated.
