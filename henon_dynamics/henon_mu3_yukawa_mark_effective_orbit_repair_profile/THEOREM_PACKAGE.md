# C81 theorem package

Let `E` be the effective label permutation group generated by the five named
C75 permutations.  C76 establishes `|E|=1920`, while the ambient lift has
order `11520` and kernel order `6`.  For a deletion mask `D`, define the C81
profile by the repair pair `(rho,W)`, generated-subgroup order, and the
threshold histogram within each target subgroup-order class.

Every element of `E` preserves this profile: it preserves generated-subgroup
order and carries target subgroups to targets of the same order.  Therefore
the profile descends to the orbit quotient.  Exhaustive orbit enumeration
gives 3024 orbits and 14 distinct profile classes; orbit sizes and weighted
marginals are recorded in the canonical receipt.  The fixed-support identity
is used only as an orbit-count consistency check, not as a claim to a complete
Burnside ring or table of marks.
