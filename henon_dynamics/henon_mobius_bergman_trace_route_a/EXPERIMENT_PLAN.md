# Experiment plan

1. Freeze digits `3,6`, the disk, Bergman normalization, word orientation,
   matrix convention, and positive discriminant root.
2. Prove strict image containment, separation, and derivative contraction by
   rational disk geometry.
3. Prove trace class from an explicit Bergman-basis nuclear decomposition.
4. Derive the fixed point, multiplier, composition trace, all-`n` trace, and
   primitive Fredholm product before enumerating examples.
5. Enumerate all `2^n` words through `n=10` and bind each length by SHA-256.
6. Test `33366` against `33636`: same counts, different cyclic class, matrix,
   multiplier, and trace.
7. Reconstruct the evidence with a checker that does not import the producer.
8. Run a separate SymPy derivation, byte replay, repaired-hash mutations, and
   package closure.
9. Compile the paper at a fixed epoch twice and audit fonts, warnings, and all
   rendered pages.
