# HCS-C325 — Moser--Tardos resampling

This package proves the finite variable-model algorithmic Local Lemma from independent resampling tables.  Under the asymmetric witness criterion it obtains avoidance, almost-sure termination, the per-event bound `x_A/(1-x_A)`, and the summed expectation bound for every legal sequential violated-event rule.

The producer, independent checker, SymPy lane, isolated byte replay, repaired-hash mutation suite, strict Route-A evaluation, three manuscript rounds, and closed release manifest are all package-local.  Route A is rejected and Route B remains locked under `NO_BAD_EULER_OR_ROOT_NUMBER`.
