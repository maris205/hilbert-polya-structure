# Exact evidence plan

The evidence freezes three binary variable-model instances with 112 total assignments and seven bad events.  For every assignment it records the lexicographically chosen violated event and the exact rational refresh kernel.  Independent first-step linear systems recover every per-event and total expected resampling count.

For each event, formal proper-tree generating functions are expanded through size six.  The checker independently reconstructs the dependency graph, all kernels, all rational expectations, all tree coefficients, the asymmetric witness receipts, and the truncated branching bounds.

Strict parsers reject duplicate/nonfinite JSON and duplicate, non-string, anchor, alias, merge, timestamp, missing, unknown, or mistyped YAML.  Repaired-hash mutations attack the model, theorem, state coordinates, tree weights, expectations, provenance, Route A, and scope.  Finite evidence is explicitly not the proof of the all-instance theorem.
