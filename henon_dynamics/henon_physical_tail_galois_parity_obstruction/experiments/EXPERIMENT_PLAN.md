# Experiment and proof plan

## Frozen input

- HCS-P57 commit `752227192ac2c3cc14603e4299e4182ebf0fa260`;
- the exact H6 recurrence \(q_{j+1}=1-6q_j^2-q_{j-1}\);
- the P56 families \(A_m=0^{m-2}21\), \(B_m=0^{m-3}231\);
- the P54 definition of Galois excess.

## Claim-driven checks

1. Derive the negative fixed point, monodromy eigenvalues, and common signed
   square-root contraction constant exactly.
2. Construct the period-eight vertex--vertex and edge--edge closing factors.
3. Construct the period-nine vertex--edge factor as an adversarial control.
4. Eliminate chronological traces, certify modular irreducibility, isolate
   every real trace root, and bind the physical embeddings by rational boxes.
5. Evaluate the three new Mahler heights at high precision for diagnostics.
6. Prove \(\Delta_6<0\) and \(\Delta_7>0\) through integer-product bounds from
   `log(a-1) < acosh(a/2) < log(a)`.
7. Run an independent implementation that does not import the primary module.
8. Mutate parity type, physical root, field degree, inequality direction, and
   claim boundary; every mutation must be rejected.

## Decision rule

- If one physical stable mode controls the full excess, proceed to a strict
  error theorem.
- If the all-conjugate height lives on a different scale, publish that
  interface obstruction and move the next paper to a reflection-ensemble
  compiler.
