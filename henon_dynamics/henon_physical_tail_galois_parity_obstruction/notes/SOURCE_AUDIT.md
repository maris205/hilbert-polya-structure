# Source audit

The new algebra uses no external black-box theorem beyond standard symbolic
calculation: recurrence elimination, resultants, modular factorization, Sturm
root counts, and elementary logarithmic bounds.  The H6 object and Galois
excess definition are dependency-locked to P57 and its predecessors.

Bowen and Parry--Pollicott provide context for hyperbolic symbolic dynamics
and periodic-orbit zeta functions.  Livšic provides the cohomological context
for periodic sums.  None of these sources is cited as proving the new trace
fields or the physical/Galois obstruction.
