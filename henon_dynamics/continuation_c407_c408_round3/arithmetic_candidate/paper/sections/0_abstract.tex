The accumulation set of normalized prime-orbit counting is a Cantor set
of upper box dimension zero for every genuinely distorted hyperbolic
finite-adelically distorted system of positive entropy. Here hyperbolic
means that the multiplicative part of the fixed-point sequence has a unique
dominant root $\Lambda>1$, and the normalized count is
$N\pi_f(N)/\Lambda^N$, where $\pi_f(N)$ counts primitive orbits of length
at most $N$. The result allows any fixed finite set of distortion primes
and the nonzero wild exponential factors in the fixed-point formula.
More precisely, if $d$ primes are active, the accumulation set can be
covered by at most $C(1+\log(1/\eps))^{2d}$ intervals of length $\eps$,
with constants depending on the fixed system. The proof starts from the
known representation of this set as a continuous image of a compact
finite-adelic group. An adaptive valuation partition gives the covering
bound. A separate Fourier argument for positive sums of radial kernels
proves nonconstancy on every admissible cylinder and excludes isolated
image values. Both arguments allow nonnegative real exponent data. The
theorem addresses the multiprime and wild hyperbolic regimes left open in
the cited 2024 public source. Solenoid, additive-group and product examples
illustrate the conclusion using classical fixed-point counts.
