# Paper status

The finite chronology-separation theorem is documented in
`../DERIVATION_PACKAGE.md`, but no standalone paper is promoted. For a fixed
word, the full repetition sequence is the cyclic-resultant sequence of its
packet multiplier polynomial. This turns the proposed fixed-word
strong-divisibility/Zsigmondy route into a classical control rather than a
new paper mechanism.

The project is retained as a scoped negative technical note and exact
arithmetic-chronology certificate. Reopening requires an explicit all-period
relation between distinct chronology words, stated before computation and
separated from matched reciprocal-polynomial and reversible-map controls.
No placeholder theorem stronger than the certificate is authorized.
