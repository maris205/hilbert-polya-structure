# C218 verification code

The producer writes 384 high-precision modal roots over six damping cases.
The independent checker recomputes the quadratic roots, regime labels, Vieta
identities, essential-limit side, and exact gap/optimizer.  SymPy supplies a
separate pencil/Jordan/energy path; replay checks byte identity and mutation
checks repaired and stale hashes, recursive unknown keys, route and scope
tampering.
