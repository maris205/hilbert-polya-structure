# Narrative report

Signed consensus is governed component by component.  Balance permits a gauge
switch to ordinary consensus and contributes one signed constant mode;
unbalance destroys that kernel and drives the whole component to zero.
Disconnected mixtures therefore need neither a connectedness assumption nor a
single global balance label: the exact projector simply sums the balanced
component projectors.

The larger step is combinatorial.  Principal minors do not count rooted trees
alone.  A component with no root may survive when it is a negative unicycle,
and its incidence determinant contributes a factor 4.  Once this is retained,
one formula covers every root set.  Summing over roots promotes it to the
entire characteristic polynomial, with one factor `|V(T)|` for each tree
component.

The bridge-plus-negative-triangle example is a small decisive falsifier: the
rooted cofactor is 7, not its three ordinary spanning trees.  The exhaustive
ledger then tests every graph and root set through four vertices, while the
proof remains Cauchy–Binet and therefore arbitrary-size and positive-weight.

Symmetry supplies a clean self-adjoint semigroup and hence an A4 formal hint.
It does not supply prime powers, the target analytic determinant or a target
operator; Route A is rejected.
