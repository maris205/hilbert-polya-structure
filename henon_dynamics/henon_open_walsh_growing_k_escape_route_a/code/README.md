# C153 exact code

- `c153_walsh_escape_producer.py`: exact rank, alpha, and fixed-period cluster
  evidence in integers and `Q(sqrt(3),i)`.
- `c153_walsh_escape_checker.py`: producer-independent standard-library
  reconstruction, including direct tensor propagation.
- `c153_sympy_crosscheck.py`: literal low-dimensional matrix, rank, trace, and
  control reconstruction.
- `c153_replay.py`: isolated byte-for-byte evidence regeneration.
- `c153_mutation.py`: repaired-hash semantic mutations plus a stale-hash case.
- `c153_release_manifest.py`: final self-excluded 27-payload ledger.

Run all commands from the package root.  No script reads target, arithmetic
local, Euler-factor, root-number, automorphy, or Route-B data.
