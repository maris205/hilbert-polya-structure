# C153 exact experiment plan

## Objective

Turn the all-parameter proof into deterministic, independently reconstructed
implementation sentinels without mistaking finite checks for theorem proofs.

## Plan

1. Freeze the DFT, projector, tensor shift, clock, dimension normalization,
   cutoffs, exact field, and source commit before producing evidence.
2. Generate all 624 rank rows for `k<=24, 0<=n<=2k` from the exact formula,
   retaining quotient/remainder, kernel dimension, and survival fraction.
3. Generate 192 rational-alpha rows for eight slopes and `k<=24`, including
   the `alpha=0` boundary.
4. For fixed periods `1<=n<=20`, enumerate every divisor class, construct its
   infinite gcd subsequence, calculate the exact trace receipt, and merge
   equal values explicitly.
5. Reconstruct direct tensor actions in the independent checker, literal
   low-dimensional matrices in SymPy, and the period-two parity witness.
6. Reject repaired-hash semantic mutations and one stale-hash mutation.
7. Compile a baseline paper, run two genuine internal theorem/scope audits,
   implement each repair, and preserve all PDF snapshots.
8. Run isolated fixed-epoch double builds, log/font/text checks, rendered-page
   inspection, cleanup, and a 27-file self-excluded manifest closure.

## Stop rules

Stop or downgrade if any direct tensor action violates the normal form, any
rank differs, any divisor class lacks an infinite subsequence, equal trace
values are double-counted as distinct clusters, the normalized limit is stated
without fixed period, the unnormalized trace is claimed to converge generally,
the moved-hole control relies only on one-step rank, or a target/arithmetic/
Route-B claim enters the package.
