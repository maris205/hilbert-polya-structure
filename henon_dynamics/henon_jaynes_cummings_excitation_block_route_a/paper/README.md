# Paper build

Compile with LuaLaTeX at `SOURCE_DATE_EPOCH=1787875200`; optional PDF metadata
is suppressed in the source.  The three PDFs correspond to content-distinct
revision rounds 0, 1 and 2, and `main.pdf` must equal `main_round2.pdf`.
Release requires two fresh byte-identical final builds, embedded/subset fonts,
a clean log, extractable text and page-by-page visual review.
