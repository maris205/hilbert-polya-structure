# Results

The three-prime coefficient matrix is

```text
[[1, 0, 5], [1, -4, 7], [1, 0, 11]]
```

with determinant -24 (absolute value 24) and unique rational solution
`(1,0,0)`.  The checker
exhausts 15,625 integral classes in `[-12,12]^3`; exactly one matches.  Six
holdout primes retain first coefficient one for that trivial solution.

The result is an all-class theorem within the finite Tate-plus-CM span, not a
finite-range conjecture.
