# HCS-C340 hostile audit

The mutation lane rejects 55/55 attacks, including more than ten attacks that
repair the canonical evidence payload hash.  Targets include ownership,
evaluator identity, YAML bindings, operator sign, exact fiber domain,
quasi-periodic skew-adjoint boundary cancellation, Floquet source, spectrum, spectral type,
gap count, cubic curve, free face, collision boundary, Route-A tuple, Route B,
scope flags, exact band endpoints, curve coefficients, sign chambers,
periodic/antiperiodic labels, canonical rational strings, row coordinates,
enumeration, references, nested additions, and duplicate/omitted rows.

A stale-hash control and duplicate/nonfinite/nonmapping JSON attacks are
separate.  Strict YAML attacks cover duplicates, non-string keys, anchors,
aliases, merge keys, malformed roots, and repaired-hash changes to evaluator
authority, evidence status, verdict, source, and Route-B permission.
