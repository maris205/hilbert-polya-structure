# Experiment plan

The finite evidence tests conventions and code paths; it is not the proof.

1. Freeze 12 rational profiles spanning `D<2r`, `D=2r`, `D>2r`, `r=0`, and `D=0`, with corner and plateau tags.
2. Enumerate every selected feasible initial state, one- and two-period returns, and verify idempotence.
3. Reconstruct periodic play/stop paths on coarse and plateau-stretched parameterizations.
4. Check order, one-Lipschitz contraction, feasibility, reparameterization invariance, variation split, and dissipation exactly.
5. Run an independent checker, a broader SymPy rational grid, two isolated byte replays, repaired-hash hostile mutations, optimized-Python refusal, three deterministic PDF rounds, and a self-excluding release ledger.
